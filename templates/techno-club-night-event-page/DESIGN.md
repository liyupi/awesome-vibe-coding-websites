# Techno Club Night Event Page — Design System

Apply this design system to an existing project. It describes the look and feel only; for the full site, use prompt.md.

## Colors
- **Acid green** `#C6FF00` — Large hero and lineup block, dark labels. WCAG relative-luminance calculations: #080808 text on #C6FF00: 16.89:1; #FFFFFF text on #8B00FF: 5.93:1; #FFFFFF text on #080808: 20.03:1; #080808 text on #C5D0DB: 12.80:1. Use these pairs for every normal-size label/body/button. Decorative overlaps/gradients carry no text; readable text gets a solid backing.
- **Electric violet** `#8B00FF` — Large hero sculpture field and venue band.
- **Black** `#080808` — Poster base, text on acid, policy ground.
- **White** `#FFFFFF` — Copy on violet/black.
- **Chrome** `#C5D0DB` — Decorative metallic bands only; no low-contrast body copy.

## Typography
- **Display** — Anton (OFL), weights 700. Self-host the font files.
- **Body** — IBM Plex Mono (OFL), weights 400/700. Self-host the font files.

## Spacing & shape
- Spacing: 1240px max, 40px desktop/20px mobile gutters. 8px grid, 96px/56px major spacing. Poster title 144px desktop/68px mobile in 3 deliberate lines, body 16px/1.6 monospace.
- Radius: 0px major blocks, 6px controls, 999px orbit geometry only. 2px hard rules, no translucent gradient text panels.

## Motion
- Warped type is static authored skew/scale and remains real accessible text, no jitter. Large chrome rings slowly rotate only with active user playback and can be paused independently.
- Audio canvas morphs line radius at max ±10% using actual RMS/frequency data; no flashing colors or brightness oscillation. Reduced motion freezes shapes and shows track time plus a stable level value at 2Hz.

## Imagery
Entirely code-drawn original acid poster: intersecting elliptical chrome ribbons, thornless waveform loops, black geometric orbit frames on large acid/violet fields. Hero has a high-craft sound sculpture and live instrument-like UI, not typography alone. No real DJs, copyrighted poster art, identifiable venue photos, logos or existing album art. Artist entries use distinct original abstract signal emblems rather than portrait placeholders; this is an event lineup, not a team profile page.

## Tone
Direct, underground and typographically loud; practical details are calm and specific.
