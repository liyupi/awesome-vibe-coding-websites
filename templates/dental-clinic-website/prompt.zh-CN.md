## 简介
为 [BRAND] 打造的两页网站，[BRAND] 是一家独立诊所，在 [CITY] 这个中型城镇提供 [SPECIALTY] 服务。整体观感平静、干净、值得信赖，兼具临床感与温度：亚麻色与柔和鼠尾草绿的表面、深青色的文字、一抹陶土色点缀、充裕的留白、圆角卡片，以及诊所房间与设备的真实照片（绝不出现患者）。index.html 承载整个就诊决策：急诊横幅、带实时“现在营业”卡片的主视觉区、安心承诺条、新患者优惠（[NEW_PATIENT_OFFER]）、六张含价格区间的治疗卡片、诊所图集、以字母组合卡片呈现并附资质的团队介绍、患者评价、保险与分期付款方案、带日期条、时段选项按钮和成功状态的客户端预约请求表单、带“现在营业”指示的营业时间、手绘地图、关于疼痛与费用的常见问题，以及页脚。treatments.html 按类别列出每一项治疗，附价格区间、时长、保险说明和就诊预期，另有一个隐形矫治器特色板块、一个分期付款计算器和结尾的行动号召。它必须读起来像一家已开业多年的真实诊所：具体的价格、营业时间、虚构的街道地址、有名有姓（虚构）的临床医生和患者，以及直白平实的回答。

- 受众：为自己或家人预约的本地成年人：有幼儿的父母、多年回避看牙且感到紧张的成年人，以及因为没有保险或只有基础保险计划而比较费用的人。大多数人用手机访问，往往来自搜索，想快速知道三件事：是否离我近、要花多少钱、能不能尽快约上。
- 目标：让访客提交预约请求。各处的主要 CTA：'Book a visit'（指向 ./index.html#book）。次要 CTA：致电 [PHONE]（tel: 链接）和 'See treatments & prices'（./treatments.html）。遇到急诊时，横幅和预约侧栏改为推动电话致电，而非表单。
- 语气：温暖、平实、令人安心，像电话那头一位优秀的接待员。句子简短，用真实数字，术语必附通俗解释，不制造恐惧，不用炒作词汇（不用 world-class、state-of-the-art、cutting-edge、best-in-class、revolutionary）。以“你”称呼读者；诊所自称“我们”。

## 技术栈
- 框架：Vite 5 + React 18 + TypeScript

- 库：react（MIT）、react-dom（MIT）、lucide-react（ISC）、tailwindcss（MIT）、postcss（MIT）、autoprefixer（MIT）、vite（MIT）、@vitejs/plugin-react（MIT）、typescript（Apache-2.0）、@fontsource-variable/fraunces（OFL-1.1）、@fontsource-variable/figtree（OFL-1.1）
- 构建：`npm run build` → 静态文件输出到 `dist/`。无后端、无服务端代码、无外部 API。
- 初始化设置：
  - 使用 react-ts 模板通过 npm create vite@latest 脚手架创建项目。项目根目录下有两个真实的 HTML 入口文件：index.html（挂载 src/home.tsx）和 treatments.html（挂载 src/treatments.tsx）。两者共享相同的组件、样式和内容文件。

  - 文件布局：src/content.ts（所有字符串、价格、治疗项目、团队成员、评价、FAQ、营业时间、图片路径和 alt 文本，均带类型）、src/index.css（Tailwind 层、.reveal 样式、keyframes pulse-dot 和 banner-collapse、reduced-motion 覆盖）、src/lib/hours.ts（当前营业状态、今日行、下次开门时间）、src/lib/slots.ts（日期条和时间段生成）、src/lib/reveal.ts（一个共享的 IntersectionObserver）、src/lib/params.ts（从 URL 读取 ?treatment=）。

## 变量
- [BRAND] — 诊所名称（默认："Wrenfield Dental"）。显示在导航文字标识、标题、页脚、预约成功文本和 FAQ 回答中。护理计划称为 '[BRAND] Care Plan'，末尾的 Dental 一词省略（'Wrenfield Care Plan'）。
- [CITY] — 城镇或城市（默认："Calder Springs"）。虚构或真实的城镇名称。用于主视觉眉题、标题、地址区块和页脚。
- [SPECIALTY] — 诊所类型（默认："family & cosmetic dentistry"）。小写短语。决定主视觉眉题、标题以及所有治疗项目、价格、团队资质、FAQ 回答和照片。若为其他类型的诊所，需重写这些内容。
- [NEW_PATIENT_OFFER] — 新患者优惠（默认："$89 first visit: exam, cleaning & X-rays"）。先写价格，再写包含内容。用于优惠区块、主视觉信任行、预约原因列表和 FAQ。
- [PHONE] — 电话号码（默认："(320) 555-0142"）。演示时使用 555-01xx 号码。显示在紧急横幅、导航、预约面板、页脚中，并作为 tel: 链接（href 中仅使用数字，例如 tel:+13205550142）。
- [CREDIT] — 在页脚保留一个小型 "Template by VibeFather" 链接，指向 https://vibefather.ai/t/dental-clinic-website（默认：是；删除此行即可移除）

页面与区块下的文案按默认值编写。如果你的值不同，请为它们重写每个标题、段落、标签和图片——保持相同的长度、语气和结构。布局、颜色、字体和动效保持所述不变。
将所有文案、图片路径和链接放在一个内容文件中（例如 `src/content.ts`），按区块作为键，以便日后无需改动组件即可替换内容。
