# Neo-Brutalist Blog and Portfolio

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
A three-page neo-brutalist personal site for [BRAND], a [ROLE] who makes work about [BEAT]. Home page (hero with giant name, marquee of recent posts, selected illustrations grid with lightbox, latest writing list, about block, big contact link), a blog index with client-side tag and text filtering, and a single post page with a narrow reading column, drop-quote blocks, an inline SVG illustration and previous/next cards. Thick black borders, hard offset shadows with no blur, oversized Archivo Black headlines, warm paper background and one clashing orange accent. Every illustration is drawn in inline SVG.

- Audience: Independent writers, illustrators, zine makers and comics artists who publish essays and drawings under their own name and want a bold, handmade-feeling home on the web.
- Goal: Show the person's drawings and writing at a glance, make posts easy to browse and read, and turn visitors into commission enquiries through the big contact link.
- Tone: Confident, warm and a little odd. Short sentences, first person, specific concrete details (trains, bakeries, drawers, ink). Loud in layout, never shouty in words. No buzzwords.

## Stack
- Framework: Vite 5 + vanilla HTML/CSS/JS
- Styling: Vanilla CSS
- Libraries: lucide (ISC), @fontsource/archivo-black (OFL-1.1), @fontsource/space-mono (OFL-1.1), @fontsource-variable/inter (OFL-1.1), vite (dev dependency) (MIT)
- Build: `npm run build` → static files in `dist/`. No backend, no server code, no external APIs.
- Setup:
  - Scaffold a Vite 5 vanilla JavaScript project (npm create vite@latest site -- --template vanilla), delete the demo files, then npm install lucide @fontsource/archivo-black @fontsource/space-mono @fontsource-variable/inter.
  - package.json scripts: "dev": "vite", "build": "vite build", "preview": "vite preview".
  - vite.config.js: base: './', build.sourcemap: false, build.outDir: 'dist', and build.rollupOptions.input listing three entries: index.html, blog.html and post.html (resolve them with path.resolve(__dirname, ...)).
  - Project root holds index.html, blog.html, post.html, vite.config.js, ASSETS.md and public/favicon.svg. Source lives in src/: content.js, art.js, styles.css, main.js, home.js, blog.js, post.js.
  - src/content.js is the only place copy lives: site (brand, role, beat, location, email), nav labels, hero copy, marquee, the 6 illustrations (id, title, medium, year, art key), the 8 posts (slug, title, date, readingTime, tags, excerpt, art key, body blocks), about copy and facts, contact and footer copy. If the variable values differ from the defaults, rewrite all copy, post titles, excerpts and illustration titles in the same voice to fit the new person and subject.
  - src/art.js exports one function per illustration returning an SVG string (viewBox 0 0 400 300, preserveAspectRatio xMidYMid meet). If the subject changes, you may redraw the SVGs following the same construction rules (6px #111 strokes, flat fills, var(--art-pop) highlights).
  - src/styles.css imports the fonts (import '@fontsource/archivo-black/400.css', '@fontsource/space-mono/400.css', '@fontsource/space-mono/700.css', '@fontsource-variable/inter' from main.js instead of CSS @import), defines all colors, shadows and spacing as CSS custom properties on :root, and contains every @keyframes (marquee, spin, rise, pop) plus the prefers-reduced-motion overrides.
  - Each HTML page has a <header id="nav">, a <main> with empty mount points, and <footer id="footer">; it loads <script type="module" src="/src/main.js"></script> plus its page script (/src/home.js, /src/blog.js or /src/post.js). Vite rewrites the paths on build.
  - src/main.js imports the fonts and styles.css, renders the shared nav and footer from content.js, wires the mobile menu, starts the IntersectionObserver for [data-reveal], and exports a renderIcons() helper that calls createIcons({ icons: { Menu, X, ArrowUpRight, ArrowLeft, ArrowRight, Asterisk, PenTool, Search, Link, Mail, ArrowUp } }) from 'lucide'. Call renderIcons() after every render that inserts <i data-lucide> elements.
  - Post routing: every post link is ./post.html?p=<slug>. post.js reads URLSearchParams, finds the post (falls back to the first post if the slug is missing or unknown), and renders it. Set document.title to '<post title> — [BRAND]'.
  - Each page gets a plain <title>: home '[BRAND] — [ROLE]', blog 'Writing — [BRAND]', post set by script. Favicon is public/favicon.svg linked as ./favicon.svg.

## Variables
- [BRAND] — Person's name (default: "Odile Brask"). Invented full name used as the wordmark, the giant hero headline and the byline.
- [ROLE] — Role (default: "Writer & illustrator"). Short description of what they do, shown in the hero sentence and page title.
- [BEAT] — Subject matter (default: "small towns, night trains and the things people keep in drawers"). What the work is about; completes the hero sentence and shapes post and drawing titles.
- [LOCATION] — Home city (default: "Ghent, Belgium"). Shown in the hero label row, about facts and footer.
- [CONTACT_EMAIL] — Contact email (default: "hello@odilebrask.example"). Used for every mailto link. Use an .example domain for demos.
- [CREDIT] — keep a small "Template by VibeFather" link to https://vibefather.ai/t/neo-brutalist-blog-and-portfolio in the footer (default: yes; delete this line to remove it)

The copy under Pages & Sections is written for the default values. If your values differ, rewrite every headline, paragraph, label and image for them — same length, tone and structure. Layout, colors, type and motion stay as described.
Keep all copy, image paths and links in one content file (for example `src/content.ts`), keyed by section, so the content can be swapped later without touching components.

## Design
### Colors
- Paper `#F4EEE1` — Page background everywhere except the marquee band; also the dot grid base.
- Card `#FFFDF8` — Card, button, input and chip fill; light fills inside SVG art.
- Ink `#111111` — All text, every border, every hard shadow, marquee band background, active chip background.
- Signal Orange `#FF5A1F` — The only accent: name highlight block, stickers, primary buttons, hover fills, odd illustration backgrounds, drop cap, reading progress bar, marquee separators, focus rings.
- Pencil `#5B564D` — Secondary text only: dates, reading times, captions, excerpt metadata.
- Dot `rgba(17,17,17,0.07)` — Body background texture: radial-gradient(var(--dot) 1px, transparent 1.4px) at 24px 24px over Paper.

### Typography
- Display: hero name, section headlines, card and post titles, marquee items, giant contact link, drop cap: Archivo Black (OFL), weights 400
- Body: paragraphs, excerpts, post body, hero sentence: Inter Variable (OFL), weights 400/500/700
- Labels: nav links, buttons, chips, dates, section numbers, captions, counters: Space Mono (OFL), weights 400/700

### Layout & motion
- Spacing: 8px base unit. Container max-width 1280px, side padding 48px at ≥1024px, 32px at 640–1023px, 20px below 640px. Section vertical padding 112px desktop, 72px mobile. Card padding 24px (20px mobile). Grid gaps 32px desktop, 24px mobile. Borders: 3px on cards, buttons, inputs, rules and nav; 2px on chips; 4px on the hero highlight block, lightbox and about card. Shadows: --shadow-sm 4px 4px 0 #111 (buttons, chips on hover), --shadow 6px 6px 0 #111 (cards), --shadow-lg 10px 10px 0 #111 (hovered cards, about card, lightbox). Below 640px every shadow drops one step (cards use 4px). Type scale: section headlines clamp(44px, 7vw, 96px) line-height 0.9 letter-spacing -0.03em uppercase; card titles 24px; list titles clamp(24px, 3vw, 36px); body 18px/1.65 (post body 19px/1.7); labels 13px uppercase letter-spacing 0.06em.
- Radius: 0px on everything (cards, buttons, inputs, art panels, lightbox, nav). The only rounded shapes are chips (999px pill) and the circular hero sticker.
- Motion: Press physics on all buttons and cards: transition transform and box-shadow 140ms cubic-bezier(.2,.8,.2,1). Hover: translate(-2px,-2px) and shadow grows one step. Active (pressed): translate(4px,4px) and box-shadow 0 0 0 #111 so the element sinks into its shadow.
- Motion: Sticker tilt: hoverable cards rotate on hover, odd cards -2deg, even cards 2deg, combined with the hover translate; their chips switch to Signal Orange background and rotate -3deg.
- Motion: Marquee: a duplicated track of items animates translateX(0) → translateX(-50%) over 40s linear infinite; animation-play-state paused while the band is hovered or focused within.
- Motion: Hero intro on load: each name line sits in an overflow:hidden wrapper and rises from translateY(105%) to 0 over 700ms cubic-bezier(.2,.8,.2,1), 90ms stagger; the hero sticker pops from scale(0) rotate(-40deg) to scale(1) rotate(12deg) over 450ms cubic-bezier(.34,1.56,.64,1) starting at 500ms; the sentence and buttons fade up 16px at 650ms.
- Motion: Sticker ring: the circular text on the hero sticker rotates 360deg every 20s linear infinite.
- Motion: Scroll reveal: elements with data-reveal start at opacity 0, translateY(24px) rotate(-1.5deg) and settle to opacity 1, none over 450ms cubic-bezier(.2,.8,.2,1) when 15% visible (IntersectionObserver, unobserve after first reveal). Grid children stagger with transition-delay calc(var(--i) * 70ms).
- Motion: Lightbox and mobile menu open: scale(.96) rotate(-1deg) opacity 0 → scale(1) rotate(0) opacity 1 over 200ms.
- Motion: Post page reading progress bar: transform scaleX(progress) with transform-origin left, updated on scroll inside requestAnimationFrame.
- Motion: prefers-reduced-motion: reduce — marquee animation none and the track becomes a single non-duplicated row with overflow-x auto; sticker ring static; no hero intro (everything visible at once); data-reveal elements visible with no transition; hover keeps color and shadow changes but no rotate or translate; all transition durations 0.01ms.
- Imagery: No photographs and no bitmap files. Every illustration is a flat inline SVG drawn in code: thick 6px #111 strokes with stroke-linejoin round and stroke-linecap round, flat fills only in #111, #FFFDF8 and var(--art-pop) (no gradients, no shading, no faces, no characters). The art sits on a solid panel: odd panels have background #FF5A1F with --art-pop: #FFFDF8; even panels have background #FFFDF8 with --art-pop: #FF5A1F. Decorative elements are CSS or SVG: circular sticker with text on a path, rotated rectangle stamps, the dot grid, Lucide icons inside 3px bordered squares.

## Don'ts
- No backend of any kind: no server code, API routes, databases, auth, analytics or third-party APIs; the only 'contact' is a mailto: link and there are no forms that submit anywhere.

- Three real HTML files (index.html, blog.html, post.html). Every internal link points to a file name (./index.html, ./blog.html, ./post.html?p=slug, ./index.html#work), never to a bare directory or '/'.
- No CDN <script> or <link> tags; never load fonts from fonts.googleapis.com, fonts.gstatic.com, Adobe Fonts or any other CDN — self-host via Fontsource.
- No commercial or custom fonts; only Archivo Black, Space Mono and Inter.

- No photographs, stock images, hotlinked images or placeholder-image services; no Unsplash, Pexels or Pixabay. All art is code-drawn SVG.
- Do not use any real writer's or illustrator's name, likeness, signature or artwork, and no faces, mascots, doodle characters or recognisable sticker designs from existing sites.

- Zero console errors at 1440×900 and 390×844; no horizontal page scroll on mobile (only the marquee and the chip row may scroll inside themselves).
