# Y2K Chrome Fashion Drop Page

> A limited clothing drop page with a liquid-metal 3D wordmark, live countdown and sticker-slapped products.

This template is a single-page launch site for a limited clothing release, and its first screen does most of the work. The label's name fills the hero as a liquid-metal 3D wordmark, rendered live from the outlines of an open-source font. It reflects a studio environment, ripples slowly and tilts toward the cursor. Directly below it, a countdown in chrome-rimmed capsules runs to the next release window. It suits independent fashion labels, merch runs, creator capsules and any small batch of goods that sells out on a set day. Scarcity is part of the structure rather than a banner on top. Die-cut stickers mark edition sizes and low stock over each product, size chips show available, low and sold-out states per piece, and a selection summary follows every choice down the page. The palette is near-black with electric cyan, lilac and hot pink, plus a small dose of acid yellow on stickers. Holographic sweeps appear on borders, buttons and the marquee band, while product cards catch a moving sheen under the pointer and can be dragged sideways. Early-2000s interface details, including pill-shaped windows, pixel stars and thin wireframe globes, tie the sections together without borrowing from any real product of that era. The waitlist runs entirely in the browser. It validates the email, checks that a size is chosen, then swaps the form for a perforated ticket with a queue number and the chosen piece. To adapt it, change the brand, drop name, product line, home base and edition size, and the copy in one content file follows. Swap the four product photos and two lookbook shots for your own. A brand name of up to nine letters gives the wordmark the most presence, and the countdown day and hour are set in one line.

## Variables

Replace these in the prompt with your own values; everything else stays as written.

| Variable | What it is | In the demo |
|---|---|---|
| `[BRAND]` | Brand name | Moonfoil |
| `[DROP_NAME]` | Name of this drop | Afterglow Capsule |
| `[PRODUCT_LINE]` | What the brand makes | small-run heavyweight streetwear |
| `[HOME_BASE]` | City and region | Portland, Oregon |
| `[EDITION_SIZE]` | Pieces per style | 200 |

## How to use it

1. Copy [prompt.md](prompt.md), or run `npx vibefather add y2k-chrome-fashion-drop-page` in your project.
2. Replace the `[VARIABLES]` with your own brand, copy and details.
3. Paste it into Claude Code, Codex, Cursor or another AI coding agent and let it build. [DESIGN.md](DESIGN.md) holds the colors, type and spacing on their own if you only want the look.

## Make it yours

- A creator merch capsule: set BRAND and DROP_NAME to your handle and run name, swap PRODUCT_LINE for your prints or apparel, and rewrite the four product entries around your pieces.
- An indie game studio drop: use the template for a small merch run, change HOME_BASE to your studio city and set EDITION_SIZE to the real print count on each sticker.
- A skate or streetwear label: keep the near-black palette, replace the four product photos with your own garments under cyan and pink light, and adjust size chips to your fit range.
- A vintage reseller's single-day sale: point DROP_NAME at the sale, lower EDITION_SIZE to one-of-one counts, and rewrite the drop rules section to explain shipping and holds.

## FAQ

### How does the waitlist work on the Y2K Chrome Fashion Drop Page, and does it need a backend?
The waitlist on the Y2K Chrome Fashion Drop Page runs entirely in the browser. It validates the email, checks that a size is chosen, then swaps the form for a perforated ticket showing a queue number and the piece you picked. No backend, server code or external API is involved, so no addresses are stored anywhere and nothing is emailed.

### What should I change first when adapting the Y2K Chrome Fashion Drop Page to my own label?
Set the five variables first: BRAND, DROP_NAME, HOME_BASE, EDITION_SIZE and PRODUCT_LINE. The wordmark is generated from the brand name, so keep it to one word of up to nine letters for the most presence. Then rewrite the copy in the single content file to match your line, and swap the four product photos and two lookbook shots.

### How do I set the countdown to my own drop date and time?
The countdown day and hour on the Y2K Chrome Fashion Drop Page are set in one line, and the chrome-rimmed capsules then run live to that release window. Each changed digit slides in with a short animation. If you move the drop, edit that one value and every capsule updates, including the scarcity copy that sits around it.

### Can I change the liquid-metal 3D wordmark to my brand name without adding a font file?
Yes. The Y2K Chrome Fashion Drop Page builds the wordmark live from the outlines of an open-source display font, so typing your brand into BRAND regenerates the geometry at runtime. No extra font file is needed. Two-word names break at the space on phones, so a single word reads better on small screens.

### What do the stickers and size chips on the Y2K Chrome Fashion Drop Page actually show?
Die-cut stickers mark edition sizes and low stock over each product, using the EDITION_SIZE value for the '1 OF ...' labels. Size chips show available, low and sold-out states per piece, and a selection summary follows every choice down the page. Product cards can be dragged sideways and catch a moving holographic sheen under the pointer.
