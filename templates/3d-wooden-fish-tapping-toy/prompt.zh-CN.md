## 简介
构建 [BRAND]，一个可立即游玩的木鱼打击玩具，置于一个昏暗、温暖、富有沉思氛围的房间中。一个精细建模的 [WOOD_FINISH] 木鱼悬浮在一个圆形展示底座上方。点击或轻触乐器、激活敲击按钮，或按空格键，即可触发木槌敲击动画、带阻尼的下沉与回弹、金色涟漪、短促的粒子迸发、一条漂浮的 [CALM_MESSAGE] 消息，以及一声浑厚的 Web Audio 敲击声。包含连击计数器、可选的自动敲击模式、单独控制的合成环境音，以及本地保存的每日总计。

- 受众：在办公桌前或手机上短暂轻松小憩的人群；不作任何医疗或灵性宣称。
- 目标：让第一次敲击可以立即进行，然后通过协调的触觉、视觉和音频反馈来奖励重复输入。
- 基调：安静、触感、人性化且精确。所有界面文案均使用美式英语。将所有内容保留在 src/content.ts 中，并在变量变化时重写表面处理描述和设置文案。

## 技术栈（Stack）
- 框架（Framework）：Vite + TypeScript + Three.js
- 样式（Styling）：原生 CSS（Vanilla CSS）
- 库（Libraries）：three（MIT）、vite（MIT）、typescript（Apache-2.0）、@fontsource/instrument-serif（OFL-1.1）、@fontsource/dm-sans（OFL-1.1）
- 构建（Build）：`npm run build` → `dist/` 中的静态文件。无后端、无服务端代码、无外部 API。
- 设置（Setup）：
  - 安装本项目中的所有依赖。使用 Vite base ./、压缩（minification），并将 build.sourcemap 设为 false。
  - 使用 Three.js WebGLRenderer 渲染场景，所有声音使用原生 Web Audio。程序化创建几何体和所有表面纹理；不使用远程模型、照片、HDRI、音频或 API 调用。
  - 仅导入 Instrument Serif 400 和 DM Sans 400、500、600 的本地拉丁 woff2 子集。将设计令牌（tokens）、响应式规则和减少动态效果（reduced-motion）样式放入 src/style.css。
  - 构建静态 index.html 入口，所有文本和可替换文案放在 src/content.ts 中。将每日计数和偏好设置保存到 localStorage，存储不可用时使用 try/catch 回退。
  - 将渲染器像素比限制在最多 1.75，限制粒子数量，复用几何体和材质，处理窗口尺寸变化（resize），并在文档隐藏时暂停动画和自动点击（automatic tapping）。

- 间距：桌面端构图适配 1440×900，外缩进 40px，顶部标识栏 64px，底部功能区 112px，乐器居中于剩余舞台。使用 8px 间距单位。270px 左侧说明栏与 160px 右侧指标栏分列于约 760px 宽的场景两侧；保持 3D 物体无遮挡。在 390×844 下使用 20px 侧边缩进、54px 顶部栏、紧凑的 34px 两行邀请语、330px 高场景、两列指标行、52px 敲击按钮，以及可换行的两行设置坞。短屏幕上允许常规纵向滚动；绝不裁切控件或出现横向滚动。
- 圆角：控制坞圆角 10px，次级控件 6px，主敲击按钮为 28px 胶囊形，分隔线为发丝级 #3D4438。避免使用悬浮玻璃卡片网格。
- 动效：场景在首次绘制时即就绪；无启动画面、加载遮罩或阻挡游玩的入场序列。
- 动效：空闲漂移为 5 秒内 0.035 单位的垂直正弦运动。敲击动画：木槌在 85ms 内从右上方摆入音槽，主体下沉 0.12 单位并倾斜 0.06 弧度，阻尼弹簧在约 500ms 内将其复位。新的敲击从当前物理状态重新开始。
- 动效：每次敲击发出一个细薄的琥珀色地面涟漪，在 700ms 内从半径 0.4 扩展至 2.3，不超过 18 个暖色小粒子，以及一条屏幕空间 [CALM_MESSAGE] 在 900ms 内向上漂移 30px。池化并限制效果数量。
- 动效：减少动态效果时禁用空闲运动、浮动消息与粒子位移；保留 120ms 的轻微材质高亮与即时计数器更新。自动模式仍以其缓慢节奏推进计数，反馈保持克制。
- 图像：仅使用原创的程序化 Three.js 几何体、Canvas 生成的颗粒与手写 SVG 图标。木鱼必须呈现为一件精心制作的打击乐器，而非普通球体：一个约 2.5×1.7×1.8 单位的扁平圆润椭圆主体，两个柔和隆起的正面瓣，一条狭窄的深色雕刻音槽，一个小巧的扇贝形尾部，两侧环绕细微的铣削棱线，每个前瓣上有一个微小的内嵌眼部细节，以及抛光倒角般的高光。用 canvas 纹理或着色器生成连贯的纵向木纹，并带有细微的粗糙度变化。单独建模一把木槌，配细长手柄与缠绕的奶油色软垫槌头。将乐器悬浮于宽阔石质基座上方，带柔和接触阴影。创建一个建筑壁龛，配有高耸昏暗的竖向鳍片、温暖的侧光、稀疏的尘埃场与轻微的深度雾。保持建筑元素低调，不含宗教符号、人物或复制装饰。对于 [ROOM_SETTING] 调整氛围光与简短说明；对于 Rainlit pavilion 使用更冷的侧窗光，配以抽象的静态雨状竖向痕迹，仍处于同一构图之内。不使用下载图片或生成的位图。

## 页面与区块
### [BRAND] — 静谧一刻（`index.html`）
1. **身份栏** — 左侧：[BRAND] 使用 27px 的 Instrument Serif 字体，配有一个原创的两行小木刻标记。右侧：一个小状态点和 Quiet by design。不要添加指向不存在页面的导航。

2. **可演奏的雕塑与邀请** — 左侧眉题：A SMALL DAILY RITUAL。主邀请语：A little less noise。下方：One tap. One breath.    布局：围绕大型 3D 场景采用非对称开放式构图；文字不得叠放在乐器上。场景是主要视觉锚点，至少占据桌面屏幕的一半。在场景正下方放置一个可见的 HTML 敲击按钮；在触屏宽度下隐藏空格键键帽。在移动端，将邀请语、场景、计数器和按钮纵向堆叠，确保玩具在首屏可见。画布需有可访问标签，且当 WebGL 不可用时，敲击按钮需提供键盘等效交互。若 WebGL 初始化失败，则渲染一个原创的 Canvas 2D 乐器回退方案。
   动效：使用指针射线检测，仅敲击乐器，而非任意空白背景。处理鼠标和触摸的指针事件，避免重复触发。主按钮上的 Space 和 Enter 键可敲击；全局 Space 快捷键仅在焦点不在其他交互控件上时阻止页面滚动。同步动画木槌、木质主体、涟漪、粒子和 [CALM_MESSAGE]。
3. **仪式计数器** — 显示 Today，大号计数从 0 开始，以及较小的 Session 计数。显示 Rhythm，包含连击计数和辅助说明 Keep a gentle rhythm。连击在两次敲击间隔小于 1.6 秒时递增，超出该窗口后重置。每次有效敲击使 session 和 today 各精确增加一。使用隐藏的本地日期键存储 today，并在新本地日期的首次敲击时重置。绝不显示日历日期、时间戳或日历 UI。当连击达到 3 或以上时，一个小状态标签变为 In rhythm。
   布局：桌面端右侧指标栏对齐舞台中上部附近，使用等宽数字、开放式排版和分隔线。移动端将 Today 和 Rhythm 放在场景下方的紧凑行中；Session 作为小型次要行显示。计数不得进入 3D 物体轮廓内。使用礼貌的可访问播报，避免在自动模式下刷屏屏幕阅读器。
   动效：敲击时数字以 140ms 琥珀色闪烁。不要对大数字跳变动画或抖动布局。
4. **声音与节奏停靠栏** — 底部停靠栏包含 Sound（带开关按钮）、Ambience（带独立开关按钮）和 Auto tap（带标签开关）。默认值：Sound 开、Ambience 关、Auto tap 关。Auto tap 每 1.2 秒运行一次，更新相同的计数和效果，并具有清晰的激活状态和 Stop auto 可访问标签。启动 Auto tap 是用户手势，可能解锁音频。激活时显示 Slow rhythm · 50 taps/min。一个细微的页脚写着 Made for a small pause.，并包含可选的 [CREDIT] 链接。
   布局：桌面端停靠栏为 560px 宽的居中条带，带细垂直分隔线和最小 44px 的触控目标。小型辅助文本位于其外。在 390px 屏幕上，它干净地换行为两行，每个控件至少 44px，标签绝不截断。通过视觉和 aria-pressed 或开关语义同时显示按下/选中状态。Tab 焦点使用 2px 象牙色轮廓。
   动效：仅在用户手势后初始化或恢复 AudioContext，且在不支持时绝不抛出异常。通过围绕 180Hz 和 470Hz 的分层衰减正弦/三角振荡器，加上一个非常短的滤波噪声瞬态，合成短促的木敲声；使用柔和的增益包络和低音量合成混响尾音。Ambience 使用安静的低通生成噪声缓冲区和柔和的失谐持续音，在 300ms 内淡入/淡出。不使用音频文件。关闭声音会使敲击静音，但不禁用视觉演奏；环境音保持独立可控。页面隐藏时停止自动敲击并挂起音频；返回后要求用户主动恢复，而非意外重启。
