## FAQ

### What do I get when I open the Roguelike Deckbuilder Card Game template?
The Roguelike Deckbuilder Card Game template opens directly into an active turn-based battle, not a menu. You see Keeper Mira with HP, Block, Energy and Relics facing storm-born enemies with Intent badges and live damage previews, plus five fanned hand cards. Behind that first screen sit 60 original code-illustrated cards with upgraded (+) versions, 20 relics, three acts of branching node maps, shops, rest anchorages, storm events and tide-flipping bosses.

### How do the tide-shifting bosses and status effects work in the Roguelike Deckbuilder Card Game?
The Roguelike Deckbuilder Card Game template gives every card one of four suits: Lamp, Tide, Hull or Storm. Act bosses flip the High and Low Tide rules mid-fight, inverting which suit gets the bonus, so a hand that was strong a turn ago may need rethinking. Damage previews account for Flare (Strength), Fogged (Weak), Soaked (Vulnerable), Burn, Ward and Block, so the number on an enemy is exact before you commit.

### Can I change the game title, hero and world in the Roguelike Deckbuilder Card Game template?
Yes. The Roguelike Deckbuilder Card Game template is driven by four variables: BRAND for the game title, HERO_NAME for the playable lighthouse keeper, WORLD_NAME for the floating island chain and STUDIO_NAME for the studio imprint. Set them to your own names and the prompt asks the AI agent to rewrite every headline, paragraph, label and image reference to match, keeping the same layout, colors, type and motion.

### Where is my run saved in the Roguelike Deckbuilder Card Game template, and is there a daily run?
The Roguelike Deckbuilder Card Game template persists your run in the browser's localStorage, so closing the tab and returning keeps your act, deck, relics and map position. It also includes a seeded Daily Climb, which generates the same map and card rewards for a given seed so two players can compare runs. There is no backend, server code or external API in the build.
