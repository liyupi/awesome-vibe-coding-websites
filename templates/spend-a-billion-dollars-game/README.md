## Variables

Replace these in the prompt with your own values; everything else stays as written.

| Variable | What it is | In the demo |
|---|---|---|
| `[BRAND]` | Game Title | Aunt Margo's Vault |
| `[BENEFACTOR]` | Fictional Benefactor Name | Aunt Margo Vance |
| `[LEDGER_LABEL]` | Receipt Header Label | Inheritance Ledger |

## How to use it

1. Copy [prompt.md](prompt.md), or run `npx vibefather add spend-a-billion-dollars-game` in your project.
2. Replace the `[VARIABLES]` with your own brand, copy and details.
3. Paste it into Claude Code, Codex, Cursor or another AI coding agent and let it build. [DESIGN.md](DESIGN.md) holds the colors, type and spacing on their own if you only want the look.

## Make it yours

- A classroom economics teacher: set [BRAND] to your class name, keep the salary converter presets and use the Feel the Scale tab to open a lesson on orders of magnitude.
- A personal-finance creator: set [BENEFACTOR] to a fictional character your audience knows, then retune the 8 milestones and item notes to match your channel's voice.
- A birthday or party site: set [BRAND] to the guest of honor, rename the [LEDGER_LABEL] to their name and swap the item catalog for in-jokes and gifts.
- A museum or science-center kiosk: set [BRAND] to the exhibit, keep the Feel the Scale tab as the main draw and simplify the Spend grid to a shorter catalog.

## FAQ

### Is there a free spend a billion dollars game I can build with AI?
Yes. The Spend a Billion Dollars Game template on VibeFather is free to build with, and its prompt is free for personal, non-commercial use under CC BY-NC 4.0. You get the full brief, the 60-item catalog structure, the sticky balance counter, the live receipt and the Feel the Scale tab. Commercial or client use needs Pro, which also includes the demo source code.

### What is the Spend a Billion Dollars Game template actually made of?
The Spend a Billion Dollars Game template is a two-page browser game built with Vite, React, TypeScript and Tailwind CSS. The Spend tab holds a sticky $100,000,000,000 balance counter, a 60-item sticker grid from a $4 coffee to a $25B space station, a live itemized receipt, 8 milestones and a salary converter. The Feel the Scale tab compares $1M, $1B and $1T.

### How do I change the brand name and the fictional relative who leaves the fortune?
The Spend a Billion Dollars Game template takes a [BRAND] variable for the game title and a [BENEFACTOR] variable for the fictional relative, defaulting to Aunt Margo's Vault and Aunt Margo Vance. Set both to your own names, then rewrite every headline, item note and label that mentions them so the tone stays consistent. A [LEDGER_LABEL] variable sets the receipt header.

### Can I edit the 60 items, prices and categories in the game?
Yes. The Spend a Billion Dollars Game template keeps all 60 catalog items, category definitions, milestones and copy in one data file, so you can change prices, rename items or swap categories like Everyday, Gadgets & Fun, Wheels & Wings, Real Estate, Culture & Sport and Megaprojects. Each item needs a flat-sticker illustration drawn in code, so new items need artwork too.

### How does the downloadable receipt and the salary converter work?
The Spend a Billion Dollars Game template renders the live receipt as serrated thermal-paper styling, listing every item, quantity, subtotal and grand total. A Download Receipt PNG button draws a high-resolution receipt image with Canvas so players can share it. The How long to earn this converter compares purchases against presets like Median Salary $65k, Surgeon $350k or Pro Athlete $5M, or your own figure.

### How do I build a spend a billion dollars game with AI?
Copy the prompt from this page or run npx vibefather add spend-a-billion-dollars-game, replace [BRAND], [BENEFACTOR] and [LEDGER_LABEL] with your own content, and paste it into Claude Code, Codex, Cursor or another AI coding agent. The live demos were built from exactly that text.
