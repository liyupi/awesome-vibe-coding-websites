# Spreadsheet Web App — Design System

Apply this design system to an existing project. It describes the look and feel only; for the full site, use prompt.md.

## Colors
- **Grid white** `#FFFFFF` — Grid and working surface
- **Ink** `#1F2328` — Text and numerical labels
- **Spreadsheet green** `#1E8E3E` — Selection, header accents and chart bars
- **Butter** `#FFE8A3` — Overview chart background and highlighted totals
- **Forest** `#123F2B` — Rail wordmark and dark contrasting text on green-tinted headers

## Typography
- **Workbook title, ribbon, cells and tabular-numeric totals** — IBM Plex Sans (OFL), weights 400/500/600/700. Self-host the font files.

## Spacing & shape
- Spacing: Rail 192px, desktop content gutters 24px. Header 68px, overview 108px, ribbon and formula bar 38px each. Grid cells 32px tall. Use 4/8/12/16/24px spacing.
- Radius: Use 6px on buttons and 10px on the summary band. Square grid cells and chart bars.

## Motion
- Selection responds immediately. Open menus in 120ms; honor reduced motion.

## Imagery
Code-drawn ledger mark, outline icons, bars and selection chart; the populated sales sheet is the main visual.

## Tone
Practical bookkeeping language. Use short US English labels.
