# Flower Anatomy 3D Explainer

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
Build [BRAND], an original interactive anatomy lesson for [AUDIENCE], centered on a code-generated 3D [SPECIMEN]. The default is an Oriental lily with six tepals, six stamens, one central pistil, a three-lobed stigma, and a superior ovary with three chambers. Learners orbit and zoom the specimen, perform a four-state dissection, inspect linked labels, play a four-stage pollination sequence, and finish a five-question quiz. Use three hash-routed views, #/anatomy, #/pollination, and #/quiz, around one persistent Three.js canvas; index.html opens the anatomy view. This is a polished teaching instrument, not a marketing landing page or a video player.

- Audience: Write every label, explanation, instruction, and quiz question for [AUDIENCE]. The default tone is welcoming to curious beginners without becoming childish. Use correct introductory botany, define technical terms in plain US English, and include a visible note that geometry, structure sizes, pollen counts, and timing are simplified for clarity.
- Goal: Make the flower itself the primary interface and ensure every core action works with mouse, touch, and keyboard. A first-time visitor should understand within five seconds that they can drag the flower, and within one minute should be able to expose the ovary and identify where pollen lands. Keep all variable-derived copy, quiz content, specimen colors, tepal proportions, and model parameters in src/content.ts. When BRAND, SPECIMEN, or AUDIENCE changes, rewrite every dependent headline, explanation, label, question, model material setting, and alt string to suit the new values rather than retaining Oriental lily-specific wording.
- Tone: Precise, calm, curious, and tactile, like a beautifully designed museum specimen station. Use direct verbs and short explanations. Avoid hype, gamified shouting, classroom clipart, childish mascots, fake scientific claims, and generic AI copy.

## Stack
- Framework: Vite 5 + React 18 + TypeScript
- Styling: Vanilla CSS
- Libraries: Vite 5 (MIT), React 18 and React DOM 18 (MIT), TypeScript (Apache-2.0), Three.js with bundled OrbitControls (MIT), lucide-react (ISC), @fontsource/fraunces (OFL), @fontsource/inter (OFL), @fontsource/ibm-plex-mono (OFL)
- Build: `npm run build` → static files in `dist/`. No backend, no server code, no external APIs.
- Setup:
  - Create a Vite React TypeScript project with react@18, react-dom@18, three, lucide-react, and the three listed Fontsource packages; use vite@5, TypeScript, @vitejs/plugin-react, and the matching type packages as development dependencies.
  - Set vite.config.ts to base: './' and build.sourcemap: false. Set the package build script to tsc && vite build so npm run build creates only production files in dist/.
  - Use direct Three.js inside a React component with OrbitControls imported from three/examples/jsm/controls/OrbitControls.js. Do not add react-three-fiber, Drei, Tailwind, GSAP, a physics engine, or a state-management library.
  - Organize the project as src/content.ts for all copy and specimen parameters, src/flowerScene.ts for geometry and animation, src/App.tsx for view and interaction state, src/styles.css for all visual rules, and src/main.tsx for Fontsource imports and mounting.
  - Self-host Fraunces 500, 600, and 700; Inter 400, 500, 600, and 700; and IBM Plex Mono 400 and 500 through Fontsource imports. Bundle every icon, font, script, and generated mesh locally.
  - Implement index.html, #/anatomy, #/pollination, and #/quiz with a small hash router. Keep the WebGL renderer and model mounted while switching views. The brand link returns to ./index.html and chapter links use explicit hash routes.
  - Use React state for the active route, dissection step, selected anatomical part, label visibility, pollination stage and playback, quiz answers, and best score. A derived lowercase hyphenated BRAND key may namespace the best-score localStorage entry.
  - Set the document title to [BRAND] — Flower Anatomy and use a local inline-SVG favicon made from six simple tepal outlines. Do not add other metadata or SEO features.

- [SPECIMEN] — Flower specimen (default: "Oriental lily"). Use a flower whose anatomy fits the six-tepal, six-stamen teaching model; adjust its geometry, colors, and copy.
- [AUDIENCE] — Learner audience (default: "Curious beginners"). Adapt vocabulary, guidance, and quiz wording to this audience.
- [CREDIT] — keep a small "Template by VibeFather" link to https://vibefather.ai/t/flower-anatomy-3d-explainer in the footer (default: yes; delete this line to remove it)

The copy under Pages & Sections is written for the default values. If your values differ, rewrite every headline, paragraph, label and image for them — same length, tone and structure. Layout, colors, type and motion stay as described.
Keep all copy, image paths and links in one content file (for example `src/content.ts`), keyed by section, so the content can be swapped later without touching components.

### Layout & motion
- Spacing: Use a 4px base unit with 8px control gaps, 16px card padding, 24px panel padding, and 32px desktop page gutters. Cap the shared shell at 1600px. Desktop chapter rail, stage, and inspector columns are 220px, minmax(0, 1fr), and 320px with 24px gaps. Keep 44px minimum touch targets and 12px minimum separation between projected labels.
- Radius: Use 2px on small taxonomy chips, 8px on buttons, 14px on the stage and inspector, and fully circular geometry only for status dots and compact icon buttons. Avoid a dashboard made from many floating rounded cards.
- Motion: On first load, ease the specimen from 96% scale and zero opacity to full scale and opacity over 600ms while the header and inspector fade in over 300ms; do not auto-rotate the flower.
- Motion: Use damped orbit controls with damping factor 0.08, limited zoom, and a restrained floor shadow. Dragging never selects text or scrolls the stage on touch; vertical page scrolling remains available outside the canvas.
- Motion: Animate dissection changes over 650ms with cubic-bezier(0.22, 1, 0.36, 1): tepals lift and rotate outward, stamens part, then the camera and clipping plane reveal the ovary. Keep every intermediate state interruptible by Previous, Next, Reset, or label selection.
- Motion: Project HTML labels from 3D anchor positions every frame and draw fine SVG leader lines to them. Update selection with a 160ms highlight and a soft target ring rather than bouncing labels.
- Motion: Crossfade chapter inspector content over 220ms without unmounting the canvas. Pollination is a deterministic 12-second sequence with play, pause, previous, next, replay, and 0.5x or 1x speed; never start it on page load.
- Motion: For prefers-reduced-motion, remove the entrance tween, idle motion, damping, camera tweens, and particle travel. Dissection and chapter changes become immediate, and pollination becomes four user-controlled static storyboard states with the same copy.
- Motion: Pause rendering when the document is hidden or the stage is offscreen. Cap pixel ratio at 1.75 desktop and 1.5 mobile, use one directional and one hemisphere light, avoid real-time shadow maps, and reuse pollen through InstancedMesh.
- Imagery: Create every visual in code: the flower, stem, leaves, pollen, ovary cutaway, leader lines, floor shadow, wordmark, favicon, and WebGL-fallback cross-section. Use no photographs, AI-generated images, downloaded models, HDRIs, image textures, people, or mascots. The default flower uses two alternating whorls of three curved coral tepals, six copper-gold anthers, a green central pistil, and a subtle procedural speckle pattern made from small geometry marks. A specimen change must update tepal silhouette, proportions, material colors, and decorative marks from src/content.ts; a tulip uses smoother cup-shaped unspotted tepals rather than inheriting lily speckles.

### Pollination laboratory (`#/pollination`)
1. **Four-stage pollination sequence** — Change the chapter rail to BOTANY / 02, the headline 'Follow the pollen.', and the introduction 'Watch what happens after a compatible grain reaches a stigma. Play the sequence or inspect one stage at a time.' Keep the same flower and camera controls, but use a side-biased view that can show both anthers and the central pistil. Use exactly four stages: 1 Pollen release — 'Mature anthers split open and expose pollen grains.' Show a small cluster of gold grains at one anther. 2 Pollen transfer — 'A visiting pollinator carries compatible pollen from an anther to the sticky stigma. This transfer is pollination.' Move 24 instanced grains along one curved dotted route from anther to stigma; do not require a bee or mascot. 3 Tube growth — 'After pollination, a grain germinates. Its pollen tube grows down the style toward an ovule.' Fade the outer tepals to a pale ghosted treatment, show the ovary cutaway, and progressively reveal one gold tube through the style. 4 Fertilization — 'A sperm cell joins the egg cell inside an ovule. This is fertilization, not pollination. The ovule can now develop into a seed.' Highlight one ovule and the completed tube. Add the persistent note 'The sequence is simplified. Timing, grain size, and pollen numbers are illustrative.' Controls are Play sequence, Pause, Previous, Next, Replay, and 0.5x / 1x. At reduced motion, Play advances between static stages instead of moving particles.
   Layout: Reuse the anatomy stage and right inspector rather than adding a second canvas. The inspector contains the current stage number, a 32px title, its explanation, and a four-row vertical timeline; the bottom stage toolbar contains playback controls and a 12-second progress track. Stage segments are labeled Release, Transfer, Tube growth, and Fertilization. On mobile, playback controls form two rows, the timeline becomes four equal columns above the inspector, and all labels remain readable at 390px.
   Motion: Map a full 1x playthrough to 12 seconds: release 0–2 seconds, transfer 2–5 seconds, tube growth 5–9 seconds, and fertilization 9–12 seconds. ### Knowledge check (`#/quiz`)
1. **Five-question knowledge check** — Change the chapter rail to BOTANY / 03, the headline 'Check your understanding.', and the introduction 'Five questions. Choose an answer to see why it is right or wrong; your best score stays in this browser.' Reassemble the flower, hide projected labels by default, and leave it orbitable as a visual reference. Ask one question at a time in this fixed default order: 1 'Which part catches compatible pollen?' Options: Stigma (correct), Filament, Tepal, Ovule. Explanation: 'The stigma has a receptive, often sticky surface where compatible pollen lands.' 2 'Which two structures make up a stamen?' Options: Anther and filament (correct), Stigma and style, Ovary and ovule, Petal and sepal. Explanation: 'The filament supports the anther, and the anther produces pollen.' 3 'Where are the ovules located?' Options: Inside the ovary (correct), On the tepals, Inside the anther, Along the stem. Explanation: 'The ovary contains chambers with ovules inside.' 4 'Which event is pollination?' Options: Pollen moves from an anther to a compatible stigma (correct), A pollen tube enters an ovule, A sperm cell joins an egg cell, An ovule becomes a seed. Explanation: 'Pollination is pollen transfer. Later events belong to post-pollination growth or fertilization.' 5 'Which statement correctly separates pollination from fertilization?' Options: Pollination transfers pollen; fertilization joins a sperm cell with an egg cell (correct), Pollination makes seeds; fertilization opens the anther, Pollination grows the style; fertilization colors the tepals, They are two names for exactly the same event. Explanation: 'The grain must first land on a stigma; fertilization happens later inside an ovule.' After each choice, lock that question, mark the selected and correct answers, show its explanation, and enable Next question. The final view says 'Your specimen score' with the dynamic score out of five, a one-sentence review recommendation based on missed parts, Review anatomy, and Try again. Store only the best numeric score locally and provide a five-row answer review.
