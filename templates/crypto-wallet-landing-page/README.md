# Crypto Wallet Landing Page

> A precise self-custody wallet page with interactive device mockups and original network icons.

Crypto Wallet Landing Page is a single-page product site for a fictional self-custody wallet, built around two detailed interface mockups rather than stock imagery. The hero places an interactive phone over a browser-extension window, giving visitors an immediate view of balances, network activity, and a readable approval request. A porcelain canvas, midnight surfaces, lavender accents, fine dividers, and precise type create a technical but approachable visual system. On smaller screens, the overlapping devices reorganize into a compact, legible composition.

The page moves through supported networks, mobile and browser product views, security explanations, a three-step setup sequence, platform download controls, FAQs, and a compact footer. Original geometric network marks and clearly labeled sample balances keep the concept free of real token branding. The interactive details are useful rather than decorative: visitors can switch product surfaces, inspect networks, explore security states, and save a plain-text setup checklist. No wallet connection, account system, transaction, price feed, or remote form is required.

This template suits wallet startups, Web3 product concepts, hackathon demos, and designers who need a polished fintech landing page with two product surfaces. It also works for a broader digital-asset or credential product when the content is rewritten carefully.

Change five variables to adapt the brand, product type, audience, primary call to action, and fictional network list. All copy and sample data live in one content file, while React components handle the interface states. Tailwind CSS and Motion provide the responsive layout and restrained transitions. The finished site is static, self-hosted, keyboard accessible, and reduced-motion aware, with no external asset requests.

## Variables

Replace these in the prompt with your own values; everything else stays as written.

| Variable | What it is | In the demo |
|---|---|---|
| `[BRAND]` | Invented wallet brand | Velmora |
| `[PRODUCT_TYPE]` | Product description | self-custody crypto wallet |
| `[AUDIENCE]` | Primary audience | curious collectors and everyday crypto users |
| `[PRIMARY_CTA]` | Primary action label | Get the wallet |
| `[NETWORK_NAMES]` | Six fictional network names | Nivora, Elarin, Tessera, Kavio, Orren, Mirelle |

## How to use it

1. Copy [prompt.md](prompt.md), or run `npx vibefather add crypto-wallet-landing-page` in your project.
2. Replace the `[VARIABLES]` with your own brand, copy and details.
3. Paste it into Claude Code, Codex, Cursor or another AI coding agent and let it build. [DESIGN.md](DESIGN.md) holds the colors, type and spacing on their own if you only want the look.

## Make it yours

- A hackathon team shipping a wallet prototype: set BRAND to your project name, keep the demo disclosures, and point PRIMARY_CTA at the download panel so judges can try the concept.
- A Web3 credential startup: change PRODUCT_TYPE to digital credential wallet, rewrite the network explorer as issuer networks, and replace balances with sample credential cards.
- A fintech design studio pitching a client: set AUDIENCE to the client's customers, swap NETWORK_NAMES for six fictional partner networks, and reword the security section around the client's controls.
- A developer building a portfolio piece: keep the layered phone and browser hero, set PRIMARY_CTA to View the demo, and rewrite the setup steps to describe your own build process.

## FAQ

### What is included in the Crypto Wallet Landing Page template?
The Crypto Wallet Landing Page template is a single-page site with a header and navigation, a hero built from an interactive phone layered over a browser-extension window, a network explorer, a product surface demo for phone and browser views, a security explorer, a three-step setup sequence, a download panel, an FAQ accordion and a footer. All device screens and network marks are drawn in HTML, CSS and inline SVG rather than images.

### How do I change the wallet brand, product type and audience in this template?
The Crypto Wallet Landing Page template is driven by five variables: BRAND, AUDIENCE, PRIMARY_CTA, PRODUCT_TYPE and NETWORK_NAMES. Set BRAND to your invented wallet name, PRODUCT_TYPE to a short lowercase phrase such as self-custody crypto wallet, AUDIENCE to the group you are speaking to, PRIMARY_CTA to your main button label, and NETWORK_NAMES to exactly six fictional network names. Rewrite the copy in the content file so headlines and labels follow those values.

### Can the Crypto Wallet Landing Page template be used for a non-crypto product?
The Crypto Wallet Landing Page template can support a broader digital-asset or credential product when the content is rewritten carefully. Change PRODUCT_TYPE and AUDIENCE, replace the network list with your own six fictional names, and rework the security and setup sections to describe your product's controls and onboarding. The layered phone and browser mockups, the porcelain and midnight palette and the three-step sequence stay useful for any product with two surfaces.

### Does the Crypto Wallet Landing Page template connect to a real wallet or backend?
No. The Crypto Wallet Landing Page template is a static site with no wallet connection, account system, transaction, price feed or remote form. Every interaction, including switching product surfaces, inspecting networks, exploring security states and saving the plain-text setup checklist, is a local interface demonstration using React state. Sample balances, addresses and network names are fictional, and the page resets on reload.

### Is the Crypto Wallet Landing Page template accessible and does it respect reduced motion?
The Crypto Wallet Landing Page template is keyboard accessible with semantic buttons, visible focus, labeled icon buttons, aria-pressed and aria-selected states, and an Escape-closeable mobile menu and dialog. Under prefers-reduced-motion, pointer response, smooth scrolling and entrance transforms are disabled while every interaction still works. The site is static, self-hosted and makes no external asset requests, with fonts loaded from local packages.

Copy the prompt from this page or run npx vibefather add crypto-wallet-landing-page, replace [BRAND], [PRODUCT_TYPE], [AUDIENCE] and [PRIMARY_CTA] with your own content, and paste it into Claude Code, Codex, Cursor or another AI coding agent. The live demos were built from exactly that text.
