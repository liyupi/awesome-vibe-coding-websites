# Online Learning Platform — Design System

Apply this design system to an existing project. It describes the look and feel only; for the full site, use prompt.md.

## Colors
- **Academy Paper** `#FBFAF5` — Warm reading and dashboard canvas
- **Deep Ink** `#161A33` — Primary text, player stage, and structural accents
- **Sunflower Gold** `#FFC93C` — Streaks, active highlights, and primary action accent
- **Clear Sky** `#5AB2FF` — Progress meters, active chapters, and quiz highlights

## Typography
- **Headings & Course Titles** — Plus Jakarta Sans (OFL), weights 600/700. Self-host the font files.
- **Lesson Prose, Captions & Notes** — Inter (OFL), weights 400/500/600. Self-host the font files.
- **Timers, Progress % & Serial IDs** — JetBrains Mono (OFL), weights 500/600. Self-host the font files.

## Spacing & shape
- Spacing: Crisp top navigation bar + generous 1280px workspace grid with clear card hierarchy and print-specific CSS for the Certificate view.
- Radius: 16px rounded study cards with crisp 1px ink/12 borders.

## Motion
- Real-time animated Canvas visual lessons synced to timeline scrubber, speed (1×–2×), and chapter markers.
- Instant quiz grading feedback and live localStorage note autosave.

## Imagery
Four cohesive flat-geometric editorial illustrations from one unified palette (deep ink #161A33, sunflower #FFC93C, sky #5AB2FF, cream #FBFAF5) for the three seeded courses plus the learner studio banner—zero text inside images.

## Tone
Warm, encouraging editorial academy—structured clarity with tactile study craft.
