A focused online learning workspace opening immediately on a learner's active mid-course dashboard—complete with a 12-day study streak, weekly focus tracker, active course progress bars, and one-click Resume Lesson. Explore a filterable catalog of three complete fictional courses (topic, level, length) with full syllabi, instructor bios, and learner reviews; launch an interactive Lesson Player where animated HTML5 Canvas diagrams stand in for video with chapter jumps, playback speed (1×–2×), toggleable live captions, localStorage per-lesson notes, and instant-feedback quizzes; and print a clean completion certificate.

## Variables

Replace these in the prompt with your own values; everything else stays as written.

| Variable | What it is | In the demo |
|---|---|---|
| `[PLATFORM_NAME]` | Platform Name | Brightleaf Academy |
| `[LEARNER_NAME]` | Active Learner Name | Samira Chen |
| `[STREAK_DAYS]` | Active Streak Days | 12 |

## How to use it

1. Get the full prompt on the [template page](https://vibefather.ai/templates/online-learning-platform?utm_source=github&utm_medium=readme&utm_campaign=awesome-vibe-coding-websites&utm_content=template-howto) (VibeFather Pro), or read the public part in [prompt.md](prompt.md).
2. Replace the `[VARIABLES]` with your own brand, copy and details.
3. Paste it into Claude Code, Codex, Cursor or another AI coding agent and let it build. [DESIGN.md](DESIGN.md) holds the colors, type and spacing on their own if you only want the look.

## Make it yours

- A coding bootcamp: set PLATFORM_NAME to your school, replace the seeded courses with your curriculum tracks, and keep the Canvas diagrams for architecture and data lessons.
- A corporate training team: set LEARNER_NAME to a sample employee, rewrite the dashboard around compliance modules, and use the quiz explanations as knowledge checks.
- An independent course creator: keep the three-course catalog shape but swap in your own topics, instructor bio and reviews, and print certificates with your serial ID format.
- A music or science educator: use the Everyday Sound and Acoustics course as a model for animated Canvas lessons, then rebuild the catalog around your subject.

## FAQ

### Is there a free online learning platform template I can build with AI?
The Online Learning Platform template is a Pro template, so its full prompt and the demo source code come with a Pro membership. Every DESIGN.md on VibeFather is free to read and reuse for personal, non-commercial work under CC BY-NC 4.0, and commercial or client use needs Pro. You can study the public brief, stack and variables before deciding.

### How do I add a course catalog with topic, level and length filters to an online learning platform?
The Online Learning Platform template ships a filterable Course Catalog on its own route with Topic, Level and Length filters and three complete seeded courses: Visual Data Storytelling, Systems Design for Product Builders, and Everyday Sound and Acoustics. To add your own, edit the seeded course data in the content file with real syllabi, instructor bios and reviews, then point the filters at your new topics and levels.

### Can Claude Code or Cursor build the lesson player with animated diagrams, captions and quizzes?
Yes. The Online Learning Platform prompt specifies an interactive Lesson Player with animated HTML5 Canvas diagrams, chapter markers, playback speed from 1x to 2x, toggleable live captions, per-lesson notes saved in localStorage, and instant-feedback quizzes. Paste the prompt into Claude Code, Cursor, Codex, Windsurf or Gemini CLI. The two live demos were built with Gemini 4 Neon in Antigravity and GPT-6.2 Sol in Codex, and you can compare those models on the site.

### How do I change the learner name, platform name and study streak on the dashboard?
Set PLATFORM_NAME, LEARNER_NAME and STREAK_DAYS in the template's variables before you run the prompt. The Online Learning Platform then opens on a mid-course learner dashboard with the streak calendar strip, weekly focus tracker, three enrolled course progress bars and the Resume Lesson card filled in with your values. The learner name also appears on the printable completion certificate, so keep the two in sync.

### How do I turn this online learning platform into an e learning portal for my own school or course business?
Start by replacing the three seeded courses with your own curriculum, then rewrite the dashboard copy around your learner. The Online Learning Platform has five routes: dashboard, catalog, course detail, lesson player and certificate. Swap the illustrated course covers, set the instructor bios and reviews, and link the Mark Complete and quiz results to whatever tracking you use. The certificate prints from the browser, so add your serial ID format and total hours.

### How do I build an online learning platform with AI?
Copy the full prompt (Pro) from this page or run npx vibefather add online-learning-platform, replace [PLATFORM_NAME], [LEARNER_NAME] and [STREAK_DAYS] with your own content, and paste it into Claude Code, Codex, Cursor or another AI coding agent. The live demos were built from exactly that text.

### Which AI model built the Online Learning Platform demo?
The Brightleaf Academy case was built by Gemini 4 Neon in Antigravity; the Northstar Guild case was built by GPT-6.2 Sol in Codex. Each build used the published prompt with nothing added, so you can compare the models side by side.

### What tech stack and pages does the Online Learning Platform template use?
Online Learning Platform is a 5-page site built with React, Tailwind CSS and Typescript, with interactive canvas and micro-interactions. The prompt fixes the stack so every AI tool builds the same kind of project, and the result runs as a static site you can host anywhere.

### Is the Online Learning Platform template free to use?
Online Learning Platform is a Pro template: the brief, stack and variables are public, and the full prompt, the source code of the live demo and a commercial license come with VibeFather Pro. Its DESIGN.md is free for personal projects.

### Does the Online Learning Platform template work on mobile?
Yes. Every Online Learning Platform build was tested on a phone-sized screen as well as desktop before it went live, checking layout, text size and touch targets. Open the live demo on your phone, or switch the preview on this page to mobile view, to check it yourself.
