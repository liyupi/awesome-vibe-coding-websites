# AI 图像生成器落地页

完全按照以下描述构建此网站。将 [VARIABLES] 替换为你自己的值；其余内容保持不变。

## 简介
为 [BRAND]、[PRODUCT] 打造的单页、深色、电影感落地页。首屏是一个看起来正在工作的产品时刻：一个玻璃质感的提示词输入框逐字打出示例提示词，同时旁边的大图通过手写的 WebGL 噪声位移着色器溶解为与之匹配的图片。随后页面用一条数据统计带、带小型 UI 模拟图的三步“工作原理”、功能便当格、可拖拽的前后对比滑块、可筛选且能揭示每张图片背后提示词的瀑布流画廊、基于积分的定价、FAQ，以及覆盖在模糊结果拼贴图上的注册横幅来证明产品实力。

- 受众：[AUDIENCE]，他们希望用一句话得到成品图片，而不想学习复杂工具；以及正在发布生成式产品（图像、视频、虚拟形象或放大类应用）的创始人或独立开发者，他们需要一个可信的落地页。
- 目标：在两秒内展示产品正在工作，让积分定价易于理解，并通过“Start free”按钮和最终 CTA 横幅中的邮箱输入框将访客转化为注册用户。
- 语气：平静、自信、具体。短句、朴实的动词、真实的数字（渲染时间、像素尺寸、积分成本）。不要使用“revolutionary”、“unleash”或“magic”这类炒作词；让图片和实时提示词来完成销售。

- 样式：Tailwind CSS 3.4
- 库：react（MIT）、react-dom（MIT）、motion（motion.dev，从 motion/react 导入）（MIT）、lucide-react（ISC）、tailwindcss（MIT）、postcss（MIT）、autoprefixer（MIT）、vite（MIT）、@vitejs/plugin-react（MIT）、typescript（Apache-2.0）、@fontsource-variable/bricolage-grotesque（OFL-1.1）、@fontsource-variable/dm-sans（OFL-1.1）、@fontsource-variable/jetbrains-mono（OFL-1.1）
- 构建：`npm run build` → 静态文件输出到 `dist/`。无后端、无服务端代码、无外部 API。
- 初始化：
  - 使用 npm create vite@latest 以 react-ts 模板搭建脚手架。单页面：项目根目录的 index.html，入口为 src/main.tsx。package.json 脚本：dev 'vite'，build 'tsc -b && vite build'，preview 'vite preview'。
  - vite.config.ts：base './'，plugins [react()]，build { outDir 'dist'，sourcemap false，assetsInlineLimit 0 }。图片放在 public/images/ 下，并以 './images/<file>' 引用，以便在任何子路径下都能正常工作。不要将 src/ 复制到 dist/。
  - Tailwind 3.4 通过 PostCSS（tailwindcss + postcss + autoprefixer），content ['./index.html', './src/**/*.{ts,tsx}']。在 tailwind.config.ts 中，将每个 Design 颜色以 kebab-case 键添加到 theme.extend.colors（void、panel、raised、lifted、line、line-strong、text、muted、faint、violet、orchid、coral、mint），并设置 fontFamily display ['Bricolage Grotesque Variable', 'system-ui', 'sans-serif']、sans ['DM Sans Variable', 'system-ui', 'sans-serif']、mono ['JetBrains Mono Variable', 'ui-monospace', 'monospace']；maxWidth { container: '1200px' }；borderRadius { tile: '24px', card: '20px', thumb: '16px' }；backgroundImage { accent: 'linear-gradient(100deg, #8E6CFF 0%, #C86BD8 50%, #FF7A59 100%)' }。
  - src/fonts.ts 导入三个 Fontsource 包；src/main.tsx 导入 src/fonts.ts 和 src/index.css。index.css 包含 Tailwind 各层、body 背景 #0B0B10 和颜色 #F2F0EC、.glass 配方、.text-gradient 和 .border-gradient 工具类、caret 'blink' 和 'shimmer' 关键帧，以及一个 @media (prefers-reduced-motion: reduce) 块，用于禁用时长超过 0.01ms 的 CSS 动画和过渡。
  - 文件布局：src/content.ts（所有文案和数据，带类型）、src/lib/brand.ts（brandSlug、emailDomain、companyName、creditSingular）、src/lib/useReducedMotion.ts（matchMedia hook）、src/lib/random.ts（mulberry32）、src/lib/clipboard.ts、src/hero/morphShader.ts（WebGL 设置和 GLSL 字符串）、src/hero/useHeroLoop.ts（状态机）、src/hero/Hero.tsx、src/hero/PromptBox.tsx、src/hero/ImagePanel.tsx、src/art/drawTiles.ts（四个代码绘制的画布）、src/components/（Header.tsx、MobileMenu.tsx、StatsStrip.tsx、HowItWorks.tsx、Bento.tsx、CompareSlider.tsx、Gallery.tsx、GalleryTile.tsx、Pricing.tsx、BillingToggle.tsx、Faq.tsx、CtaBand.tsx、Footer.tsx、SectionHeader.tsx、Button.tsx、Reveal.tsx）、src/App.tsx 按页面顺序组合它们。
  - Morph 着色器（src/hero/morphShader.ts），纯 WebGL1，无库：一个全屏四边形；uniforms uFrom、uTo（sampler2D）、uProgress（0..1）、uZoom（1.00..1.04）、uRes（画布 px）、uFromSize、uToSize（图片自然 px）。为每个纹理计算 cover-fit UV（缩放使图像填满画布宽高比，居中），并围绕中心应用 uZoom。噪声：带 4 倍频 fbm 的 2D value noise。在片段着色器中：n = fbm(uv * 3.0)；t = n * 0.75 + (1.0 - uv.y) * 0.25；m = smoothstep(uProgress - 0.1, uProgress + 0.1, t)（1 = 仍显示 uFrom）；将 from-UV 偏移 (n - 0.5) * 0.10 * uProgress，将 to-UV 偏移 (n - 0.5) * 0.10 * (1.0 - uProgress)；color = mix(texture(uTo), texture(uFrom), m)；在溶解前沿处添加边缘辉光：glow = (1.0 - smoothstep(0.0, 0.05, abs(t - uProgress))) * step(0.001, uProgress) * step(uProgress, 0.999)；color += glow * 0.55 * mix(vec3(0.557, 0.424, 1.0), vec3(1.0, 0.478, 0.349), uv.x)。在所有五张 hero 图片解码后将其作为纹理加载（UNPACK_FLIP_Y_WEBGL true、CLAMP_TO_EDGE、LINEAR）；使用 ResizeObserver 以 devicePixelRatio（上限为 2）设置画布尺寸；仅在过渡或缩放保持运行且 hero 可见时渲染。如果 WebGL 不可用或上下文丢失，则回退到两个堆叠的 <img> 元素，在 700ms 内交叉淡入淡出透明度。
  - Reveal.tsx 使用 Motion whileInView 淡入上移包裹各区块（opacity 0 -> 1，y 24 -> 0，duration 0.6，ease [0.22, 1, 0.36, 1]，viewport once 且 amount 0.2），并在减少动态效果开启时以无动画方式渲染子元素。将应用包裹在 MotionConfig reducedMotion='user' 中。
  - index.html：lang en，<meta name='theme-color' content='#0B0B10'>，<link rel='icon' href='./favicon.svg' type='image/svg+xml'>，<title>[BRAND] — Type a sentence, get the picture</title>。public/favicon.svg 是 logo 标记（带倾斜米白色边框的渐变圆角方块）。
  - 在构建前使用 Assets 下的 curl 命令将六张图片下载到 public/images/，并按 Assets 下所述在项目根目录写入 ASSETS.md。
  - dist/ 包含 index.html、带哈希的 JS/CSS、woff2 文件、favicon.svg 和六张图片；应保持在 5 MB 以下。

## 变量
- [BRAND] — 品牌名称（默认："Driftframe"）。虚构的产品名称。用于字标、页面标题、首屏副标题、画廊标题、FAQ、页脚和电子邮件域名。绝不是真实的 AI 产品、模型系列或公司。
- [PRODUCT] — 产品是什么（默认："an AI image generator that turns one sentence into a print-ready picture"）。一个完成 '[BRAND] is ...' 的小写短语。驱动首屏副标题、步骤文案、功能特性和 FAQ。任何生成式视觉产品都适用：头像、放大、概念艺术、产品图。
- [AUDIENCE] — 面向谁（默认："designers, marketers and indie creators"）。复数名词短语。用于首屏副标题和页脚行；功能特性和 FAQ 示例随之调整。
- [CREDIT_NAME] — 使用单位（复数）（默认："credits"）。用户每次渲染所花费的复数词，例如 credits、sparks、tokens。用于 Generate 按钮、定价标题、额度说明、CTA 和 FAQ；单数形式去掉末尾的 s。
- [CREDIT] — 在页脚保留一个小型 "Template by VibeFather" 链接指向 https://vibefather.ai/t/ai-image-generator-landing-page（默认：是；删除此行以移除它）

Pages & Sections 下的文案是为默认值编写的。如果你的值不同，请为它们重写每个标题、段落、标签和图片——保持相同的长度、语气和结构。布局、颜色、字体和动效保持所述不变。
将所有文案、图片路径和链接放在一个内容文件中（例如 `src/content.ts`），按区块键控，以便之后无需改动组件即可替换内容。
