# Live Shopping Stream Page

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
Build [BRAND], an original live-shopping web experience hosted by the fictional [HOST_NAME] for [AUDIENCE]. The default event is '[SHOW_TITLE]'. Use one wide generated studio photograph and five generated product photographs to simulate a live broadcast through scripted local timing, subtle still-image motion, featured-product overlays, audience chat and gift reactions. Include a claimable countdown coupon, a product shelf drawer and a persistent cart with transparent discount math; no real streaming or commerce service exists.

- Audience: [AUDIENCE]. The page should also be useful to independent retailers, creators and developers evaluating a polished live-commerce interaction prototype that works entirely as static files.
- Goal: Let a visitor watch or manually navigate a five-part show, understand each featured product, join the local conversation, claim the demo offer, browse the shelf and build an accurately calculated sample order. Every visible button must change real client-side state, and the interface must never imply that a real broadcast, audience or transaction is taking place.
- Tone: Warm, composed, convivial and specific. Write like a thoughtful studio host sharing useful details, with gentle audience energy rather than frantic sales pressure, exaggerated claims or platform clichés.

## Stack
- Framework: Vite 6 + React 19 + TypeScript
- Styling: Tailwind CSS 4
- Libraries: motion (MIT), lucide-react (ISC), @fontsource-variable/fraunces (OFL-1.1), @fontsource-variable/manrope (OFL-1.1)
- Build: `npm run build` → static files in `dist/`. No backend, no server code, no external APIs.
- Setup:
  - Set Vite base to './' and build.sourcemap to false; emit only minified static files into dist/ with index.html as the sole HTML entry.
  - Configure Tailwind CSS 4 through @tailwindcss/vite; define the color tokens, font families, stage keyframes, gift lanes and reusable interface utilities in src/index.css.
  - Create src/content.ts as the single source for all variable values and derived copy, five products, five host chapters, seed chat messages, gift events, studio notes, image paths and UI labels; derive the storage namespace by lowercasing BRAND and removing spaces and punctuation.
  - Use one React context with reducers for show playback, active chapter, chat, gifts, claimed coupon, active drawer, expanded product, cart lines, toast and sample-order confirmation; do not add a state-management library.
  - Run the show from one deterministic 60-second local clock with five 12-second chapters. Use a single timer, never Math.random, and keep the active chapter, product overlay and progress segments synchronized. Pause the clock when the document is hidden.
  - Persist cart lines, claimed coupon, user-added chat messages and the coupon deadline in localStorage under one versioned key derived from BRAND; validate parsed data and stored quantities against current stock. Keep the deadline when the show loops or reloads.
  - Use Motion for drawers, dialogs, product overlays and toasts, and CSS keyframes for still-image drift and gift lanes. Use integer minor units for all prices and Intl.NumberFormat with [CURRENCY] for display.
  - Self-host Fraunces Variable and Manrope Variable through the listed Fontsource packages. Bundle Lucide icons locally and create only the original [BRAND] arch-and-lines mark as inline SVG.
  - Implement accessible drawer and dialog behavior with a visible close button, Escape and scrim dismissal, focus trapping, focus restoration and a polite status region for cart and coupon feedback.
  - Start with autonomous show motion paused when prefers-reduced-motion is requested; leave chapter buttons, shelf, cart and all other controls immediately usable.

## Variables
- [BRAND] — Invented live-shopping brand (default: "Moss & Meridian"). Use in the wordmark, document title, storage namespace and footer; rewrite all brand-derived copy when changed.
- [SHOW_TITLE] — Live event title (default: "The Soft Evening Edit"). A short collection or event name; adapt the five chapters and studio notes to this theme.
- [AUDIENCE] — Primary shopper audience (default: "design-conscious renters looking for practical comfort and small home rituals"). Rewrite host explanations, chat and product benefits for this audience without making real performance claims.
- [HOST_NAME] — Fictional host name (default: "Mara Ellison"). Use an invented name only; rewrite host captions and biography while keeping the supplied fictional host image.
- [ACCENT] — Primary action accent as a hex color (default: "#FF7A66"). Apply to primary actions, active chapters, live indicators and gift details while retaining accessible contrast.
- [CURRENCY] — Display currency (default: "USD"). Use Intl.NumberFormat for every price. Changing currency changes formatting only; rewrite price values explicitly rather than implying conversion.
- [CREDIT] — keep a small "Template by VibeFather" link to https://vibefather.ai/t/live-shopping-stream-page in the footer (default: yes; delete this line to remove it)

The copy under Pages & Sections is written for the default values. If your values differ, rewrite every headline, paragraph, label and image for them — same length, tone and structure. Layout, colors, type and motion stay as described.
Keep all copy, image paths and links in one content file (for example `src/content.ts`), keyed by section, so the content can be swapped later without touching components.

## Design
### Colors
- Canvas `#100F0E` — Warm near-black page background, stage scrims and deep surround.
- Surface `#1B1917` — Header, chat, product shelf, cart and secondary panels.
- Raised `#29241F` — Inputs, product cards, chips and elevated overlay surfaces.
- Parchment `#FFF8EE` — Primary text, prices, headings and high-contrast icons.
- Muted `#BCB0A3` — Timestamps, metadata, secondary copy and inactive controls.
- Coral `#FF7A66` — Default value of [ACCENT]; primary buttons, active states and simulated-live indicators.
- Butter `#F2CF7A` — Coupon panel and savings highlights, always with dark text.
- Sage `#A8C5A0` — Claimed, in-stock and successful local-state feedback.
- Hairline `#40372F` — One-pixel dividers, card borders and quiet progress tracks.

### Typography
- Host captions, event title and editorial notes: Fraunces Variable (OFL), weights 500/600/700
- Interface, chat, prices, product data and controls: Manrope Variable (OFL), weights 400/500/600/700/800

### Layout & motion
- Spacing: Use a 4px base unit. Desktop header is 64px with 28px horizontal padding; the main workspace uses a 20px gap and 24px outer gutters. Stage overlays use 20–24px padding, chat rows 12px vertical gaps, and drawer content 20px. Mobile header is 56px, outer gutters 12px, product and coupon controls at least 44px high, and bottom drawers include safe-area padding.
- Radius: Use 20px for the live stage and large drawers, 14px for product and coupon cards, 10px for inputs and small thumbnails, and fully rounded shapes only for compact badges, icon buttons and progress chips. Use 1px Hairline borders and short warm shadows rather than glass effects.
- Motion: Drift the active host still slowly from scale 1.025 translate3d(-0.5%,0,0) to scale 1.075 translate3d(0.75%,-0.75%,0) over 16s, alternating direction. Pause drift with show playback and when the document is hidden.
- Motion: At each 12-second chapter boundary, exit the old featured-product card 8px downward over 160ms and enter the new card 12px upward with 96% to 100% scale over 280ms. Host caption and chapter progress update on the same clock tick.
- Motion: Append one deterministic seed chat message every 2.4 seconds while chat playback is active. New rows use a 180ms opacity and 6px rise; cap the rendered list at 30 rows while retaining user messages.
- Motion: Emit a small gift reaction at seconds 5, 13, 21, 29, 37, 45 and 53 of each show cycle. Move at most three original Lucide-based gift symbols up separate fixed lanes over 1400ms with a slight horizontal drift, then remove them.
- Motion: Open desktop drawers from the right over 320ms and mobile bottom sheets upward over 300ms using cubic-bezier(0.22,1,0.36,1); fade scrims over 180ms and never animate the background page.
- Motion: Pulse the cart badge once at 180ms after an addition. Coupon claiming draws one checkmark, toasts remain for 1800ms, and price changes crossfade without moving surrounding layout.
- Motion: The coupon timer updates numerically once per second without flipping or pulsing. At zero it remains at 00:00 and reads Offer ended; it never resets.
- Motion: Under prefers-reduced-motion, remove host drift, gift travel, staggered entrances, smooth scrolling and count pulses. Start the show paused and use immediate chapter changes with at most a 100ms opacity transition for overlays.
- Imagery: Use exactly six local AI-generated photographs: one wide editorial host scene and five square product still lifes. All share warm tungsten practical light, walnut and cream surfaces, restrained coral accents, soft contact shadows, tactile realistic materials and fine 35mm grain. The host is a fictional adult shown in a spacious wide or medium-wide working scene, never a tight face crop. Apply directional Canvas scrims behind text rather than darkening the whole photograph. Products must remain generic and unbranded with no lettering, packaging marks, logos or watermarks. Do not replace these photographs with real people, recognizable commercial designs or unrelated imagery when variables change.

## Don'ts
- Do not add a backend, server code, API routes, databases, authentication, remote forms, analytics or third-party API calls. All show, chat, audience, coupon, stock and order behavior is local sample state.
- Do not use any existing live-commerce platform name, logo, mascot, slogan, signature illustration, exact color palette, proprietary icon set, custom font, recognizable interface composition or source code.
- Do not use real hosts, celebrity likenesses or recognizable real people. The supplied host is a fictional generated person; do not replace this figure with a real person's photograph or identify the host as a real presenter.
- Do not copy existing usernames, chat transcripts, audience counts, product listings, prices, promotional copy, reviews, product photography or branded packaging; all supplied content and sample values must remain original.
- Do not use recorded streams, real video footage, platform-specific gift artwork, proprietary music, third-party brand marks, anime or game characters, or recognizable commercial product designs.
- Do not imply a real broadcast, real viewers, real purchases or actual scarcity. Retain the visible LIVE DEMO and simulation disclosures, fixed demo-viewer label and sample-offer language.
- Do not add autoplay audio, fake microphone or camera controls, fake streaming settings, real chat submission, payment fields, personal-information collection or a checkout that clears the cart.
- Do not reset the coupon deadline on reload or when the 60-second show loops, restart an ended offer, apply STREAM10 below its threshold, exceed stock or hide shipping and discount calculations.
- Do not hotlink assets or use Unsplash, Pexels, Pixabay, Google Images, placeholder-image services, CC BY-NC or CC BY-SA media. Download the six listed images to their exact local paths and list every third-party file in ASSETS.md.
- Do not load fonts, scripts, icons or styles from a CDN. Use only the fixed stack and permitted licenses, with both fonts self-hosted through Fontsource and no restricted component source.
- Do not emit source maps, copy src/ into dist/, exceed 20 MB or use absolute root asset URLs. The production build must work from a nested static path with relative URLs.
- Do not add more pages, bare-directory links, real routing services or server fallback requirements; keep the complete experience in index.html with local drawers and dialogs.
- Do not hard-code BRAND, SHOW_TITLE, AUDIENCE, HOST_NAME, ACCENT or CURRENCY outside src/content.ts, leave variable tokens visible, or rename a supplied photograph into an unrelated product when values change.
- Do not introduce emoji as icons, recognizable gift badges, generic glassmorphism, neon cyan-and-red treatments, excessive glow, frantic flashes or motion that obscures the host, chat or prices.
- Do not ship inert controls, nonfunctional pause or chapter buttons, broken focus states, tiny touch targets, horizontal overflow or console errors. Verify 1440×900 and 390×844, both drawers, chat, coupon eligibility, cart math and keyboard-only operation.
- Do not ignore prefers-reduced-motion. Autonomous host, chat and gift motion must stop or remain paused while manual chapter, product and cart interactions continue to work.
- Do not add SEO metadata, Open Graph tags, JSON-LD, sitemaps or keyword-stuffed content; a plain [BRAND] document title and original favicon are enough.
- Do not mention VibeFather anywhere in the demo except the optional renderer-provided [CREDIT] footer link.
