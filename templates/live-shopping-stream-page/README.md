# Live Shopping Stream Page

> A cinematic live-shopping simulation with timed products, audience chat, coupons and a working cart.

Live Shopping Stream Page is an original, fully client-side live-commerce experience for independent shops, creators and retail teams. It presents a fictional host in a warm studio scene, then coordinates product spotlights, audience messages, gift reactions and a limited-time coupon around one clear shopping journey. The experience feels like a live event without requiring video hosting, chat infrastructure, accounts or a payment service.

The desktop layout pairs a large photographic stage with a lively but readable conversation rail. A five-chapter run of show changes the featured product and host caption; shoppers can pause the script or jump directly to any chapter. The product shelf provides materials, dimensions, stock and add-to-cart controls, while the cart keeps quantities, savings and the claimed coupon synchronized. Chat contributions, cart contents and the offer deadline persist locally.

Deep walnut surfaces, parchment type and a coral accent give the interface its own identity. Fraunces adds an editorial voice to host captions, while Manrope keeps prices, timers and controls precise. Six coherent generated photographs supply a wide host scene and five unbranded home goods. Subtle crops, lighting and interface motion create the feeling of broadcast without a large video download.

Change the brand, show title, host, audience, accent and currency to adapt the concept for another home, desk or lifestyle edit. Product records, scripted captions, messages and all labels live in one content file. The template is suited to interaction prototypes, campaign concepts and storefront experiments where the relationships between presentation, urgency and commerce matter more than a real checkout. Simulation disclosures remain visible throughout, and reduced-motion users get manual chapter controls without autonomous visual activity.

## Variables

Replace these in the prompt with your own values; everything else stays as written.

| Variable | What it is | In the demo |
|---|---|---|
| `[BRAND]` | Invented live-shopping brand | Moss & Meridian |
| `[SHOW_TITLE]` | Live event title | The Soft Evening Edit |
| `[AUDIENCE]` | Primary shopper audience | design-conscious renters looking for practical comfort and small home rituals |
| `[HOST_NAME]` | Fictional host name | Mara Ellison |
| `[ACCENT]` | Primary action accent as a hex color | #FF7A66 |
| `[CURRENCY]` | Display currency | USD |

- A ceramics studio: set BRAND to your pottery name, swap the five home goods for your glazed pieces, and rewrite HOST_NAME captions around kiln stories and care notes.
- A candle maker's seasonal drop: set SHOW_TITLE to your collection name, keep the five-chapter run of show, and point the coupon at a first-order offer for your mailing list.
- A creator running a live unboxing: set AUDIENCE to your community, change ACCENT to your channel color, and rewrite the seed chat messages in your viewers' voice.
- A furniture retailer testing campaign concepts: keep the product shelf and cart math, set CURRENCY to your market, and replace the studio photographs with your own room scenes.

## FAQ

### Does the Live Shopping Stream Page need a video stream, chat server or payment service to work?
No. The Live Shopping Stream Page is fully client-side: the broadcast is simulated with a generated studio photograph, scripted host captions and a local 60-second clock, chat messages come from a seed list in the content file, and the cart and coupon are local state. It needs no video hosting, chat infrastructure, accounts or payment service, and it ships as static files.

### How do I change the host, show title and products on the Live Shopping Stream Page?
Set HOST_NAME, SHOW_TITLE, BRAND, AUDIENCE, ACCENT and CURRENCY to your values, then rewrite the five host chapters, product records, seed chat messages, gift events and studio notes in the single content file. Product prices are stored as integer minor units and displayed with Intl.NumberFormat, so change the values rather than assuming a currency conversion.

### Is the Live Shopping Stream Page free, and can I use it commercially?
The Live Shopping Stream Page is a free template. Its prompt and DESIGN.md are free for personal, non-commercial use under CC BY-NC 4.0. Commercial or client work needs Pro, which also gives the full prompt and the demo source code. Pro templates publish their brief, stack and variables openly.

### What should I change first in the Live Shopping Stream Page template?
Start with BRAND, ACCENT and CURRENCY so the wordmark, buttons and price formatting match your shop, then set SHOW_TITLE, HOST_NAME and AUDIENCE. After that, rewrite the five chapters and their captions so the run of show follows your products, and adjust the product shelf records, stock levels and coupon so the numbers stay consistent.

### Can I host the Live Shopping Stream Page on static hosting, and does it keep the cart after a reload?
The Live Shopping Stream Page builds to static files in a dist folder, so any static host serves it without server code. Cart lines, the claimed coupon, user chat messages and the coupon deadline persist in localStorage under a key derived from BRAND, and stored quantities are checked against current stock when the page loads.

### How do I build a live shopping stream page with AI?
Copy the prompt from this page or run npx vibefather add live-shopping-stream-page, replace [BRAND], [SHOW_TITLE], [AUDIENCE] and [HOST_NAME] with your own content, and paste it into Claude Code, Codex, Cursor or another AI coding agent. The live demos were built from exactly that text.

### What tech stack and pages does the Live Shopping Stream Page template use?
Live Shopping Stream Page is a single-page site built with Tailwind CSS, Motion and React, with parallax and micro-interactions. The prompt fixes the stack so every AI tool builds the same kind of project, and the result runs as a static site you can host anywhere.

### Can I use the Live Shopping Stream Page template for a client or a business?
The Live Shopping Stream Page prompt and DESIGN.md are free for personal, non-commercial projects under CC BY-NC 4.0. Client work and commercial use need VibeFather Pro, which also includes the source code of the live demo.

### Does the Live Shopping Stream Page template work on mobile?
Yes. Every Live Shopping Stream Page build was tested on a phone-sized screen as well as desktop before it went live, checking layout, text size and touch targets. Open the live demo on your phone, or switch the preview on this page to mobile view, to check it yourself.
