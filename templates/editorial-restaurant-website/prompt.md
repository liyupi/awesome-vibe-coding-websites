# Editorial Restaurant Website

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
Larder: a three-page editorial website (home, menu, visit) for [BRAND], a 32-seat restaurant serving [CONCEPT] in [NEIGHBOURHOOD]. It has oversized serif type on warm paper, an asymmetric 12-column grid, full-bleed parallax strips made of layered code-drawn SVG illustrations, a typographic priced menu for [SEASON], an hours table that highlights today and an invented hand-drawn SVG street map with a pin and a walking route. Booking is by phone ([PHONE]) or email ([EMAIL]) only, with no backend.

- Audience: Diners deciding where to eat this week. That means locals checking the current menu and prices on their phone, and first-time visitors looking for hours, directions and how to book.
- Goal: Make the food and the room feel considered, show this season's menu with prices at a glance, and turn interest into a phone call or an email to book.
- Tone: Calm, warm and literate, like a printed menu card or a food magazine. Short plain sentences in the first-person plural ('we'), with concrete ingredients, places and times. No exclamation marks, superlatives or marketing clichés.

## Stack
- Framework: Vite 5 + vanilla TypeScript
- Styling: Tailwind CSS 3.4
- Libraries: lenis (MIT), lucide (ISC), @fontsource-variable/fraunces (OFL-1.1), @fontsource-variable/instrument-sans (OFL-1.1), tailwindcss (MIT), postcss (MIT), autoprefixer (MIT), typescript (Apache-2.0), vite (MIT)
- Build: `npm run build` → static files in `dist/`. No backend, no server code, no external APIs.
- Setup:
  - Scaffold with npm create vite@5 using the vanilla-ts template. Keep three real HTML files at the project root: index.html, menu.html and visit.html.
  - Install the runtime packages: npm i lenis lucide @fontsource-variable/fraunces @fontsource-variable/instrument-sans. Install the dev packages: npm i -D tailwindcss@3.4 postcss autoprefixer. Then run npx tailwindcss init -p.
  - package.json scripts: dev = 'vite', build = 'tsc && vite build', preview = 'vite preview'.
  - vite.config.ts: base './', build.sourcemap false, build.rollupOptions.input = { index: resolve(__dirname,'index.html'), menu: resolve(__dirname,'menu.html'), visit: resolve(__dirname,'visit.html') }.
  - tailwind.config.js: content ['./*.html','./src/**/*.ts']. theme.extend.colors: paper #F4EEE3, paper-deep #EAE1D1, ink #1E1B17, ink-soft #5B544B, hairline #CFC4B2, terracotta #A8502F, moss #5F6B47, ochre #C8963E, beet #7B3343, cream #FBF8F2. fontFamily: display ['"Fraunces Variable"','Georgia','serif'], sans ['"Instrument Sans Variable"','system-ui','sans-serif']. maxWidth.container '1360px'.
  - At the top of src/main.ts, import '@fontsource-variable/fraunces/full.css', '@fontsource-variable/fraunces/full-italic.css', '@fontsource-variable/instrument-sans', 'lenis/dist/lenis.css' and './styles.css'.
  - src/styles.css holds @tailwind base/components/utilities. It also defines the component classes .label, .display-xl, .display-l, .statement, .dish-row, .leader, .diet-tag, .link-underline and .grain, the [data-reveal] states, @keyframes pulse-ring, and one @media (prefers-reduced-motion: reduce) block that disables every animation and transition.
  - src/content.ts holds every piece of visible copy. That covers the site object (brand, concept, neighbourhood, season, phone, phoneHref with + and digits only, email, address lines), nav, the hours array (day, times, closed flag), the menu courses with dishes (name, price, description, tags), the home/menu/visit section copy, captions, the Market strip price-tag labels and the map labels. Pages render from it with template strings. Nothing visible is hard-coded anywhere else.
  - When the variable values differ from the defaults, rewrite all copy in src/content.ts to fit the new brand, concept, place and season: headlines, dish names, prices, descriptions, hours, address, captions, price tags and map street labels. Keep line counts and string lengths close to the originals so the layout holds.
  - src/art/ contains plate.ts, stillLife.ts, strips.ts (tableStrip, fieldStrip and marketStrip, each returning { back, mid, front } SVG strings) and map.ts. Every function returns inline SVG markup strings, and colors come from one shared palette object.
  - src/main.ts exports initSite(page: 'home' | 'menu' | 'visit'). It renders the header, reservation band and footer into #header, #reserve and #footer, then swaps html.no-js for html.js. It starts Lenis (unless reduced motion is requested), the reveal observer, the parallax loop, the count-ups and the today-highlighting for hours, and finally calls lucide createIcons({ icons: { Phone, Mail, MapPin, Clock, ArrowRight, ArrowUpRight, Menu, X, Footprints, Bus, Accessibility } }).
  - src/pages/home.ts, menu.ts and visit.ts each render their page sections into #main from content.ts and then call initSite(page).
  - Each HTML file contains <html lang='en' class='no-js'>, a <title> ('[BRAND] — [CONCEPT]' for index, 'Menu — [BRAND]', 'Visit — [BRAND]'), <link rel='icon' type='image/svg+xml' href='/favicon.svg'> pointing to public/favicon.svg, and a body with class 'bg-paper text-ink font-sans antialiased' containing <div id='header'></div><main id='main'></main><div id='reserve'></div><div id='footer'></div><div class='grain' aria-hidden='true'></div> and <script type='module' src='/src/pages/<page>.ts'></script>.
  - Write ASSETS.md at the project root listing the fonts and icon set with source URL, author and license, and state that every illustration is drawn in code and no third-party images are used.

## Variables
- [BRAND] — Restaurant name (default: "Wrenfold"). Invented name. Used in the header wordmark, giant footer wordmark, titles and map label.
- [CONCEPT] — What you serve (default: "Seasonal small plates & natural wine"). Short phrase for the hero label, footer line and home title.
- [NEIGHBOURHOOD] — Location (street or yard, district) (default: "Cooper's Yard, Eastmere"). Invented place. Drives the address, directions copy and map street labels.
- [SEASON] — Current season (default: "Autumn"). Shown in menu titles and labels. Dishes and produce should match it.
- [PHONE] — Booking phone (default: "+44 20 7946 0321"). Shown exactly as written. The tel: link uses + and digits only. Use a fictional number.
- [EMAIL] — Booking email (default: "tables@wrenfold.example"). Used for mailto: links. Keep a .example domain for demos.
- [CREDIT] — keep a small "Template by VibeFather" link to https://vibefather.ai/t/editorial-restaurant-website in the footer (default: yes; delete this line to remove it)

The copy under Pages & Sections is written for the default values. If your values differ, rewrite every headline, paragraph, label and image for them — same length, tone and structure. Layout, colors, type and motion stay as described.
Keep all copy, image paths and links in one content file (for example `src/content.ts`), keyed by section, so the content can be swapped later without touching components.

### Layout & motion
- Spacing: 12-column grid inside a container with max-width 1360px, 48px side padding on desktop and 24px on mobile, and 24px column gaps. Sections have 128px vertical padding on desktop and 80px on mobile. Use 24px between a label and its heading and 32px between a heading and its body text. Rules are 1px #CFC4B2 hairlines. Type scale: .display-xl clamp(3.5rem, 10.5vw, 10.5rem) at weight 300, line-height 0.92, tracking -0.035em; .display-l clamp(2.5rem, 6vw, 6rem) at 300, line-height 0.98, tracking -0.03em; .statement clamp(1.75rem, 3.2vw, 3rem) at 300, line-height 1.15, tracking -0.015em. Breakpoints: mobile below 768px, single column; the desktop grid starts at 1024px; tablet (768–1023px) uses the mobile stacking with wider padding.
- Radius: 0px everywhere: buttons, chips, tags, figures, cards and the map frame. Only intrinsically circular things are round: the map pin head, the today dot, the nav dot, the pulse ring and the plate drawings.
- Motion: Smooth scroll: new Lenis({ duration: 1.1, easing: t => Math.min(1, 1.001 - Math.pow(2, -10 * t)) }) driven by one requestAnimationFrame loop that also runs the parallax. Anchor links call lenis.scrollTo(target, { offset: -140 }).
- Motion: Headline entrance on load: every h1 line is wrapped in an overflow-hidden block span. The inner span rises from translateY(105%) to 0 over 1000ms with cubic-bezier(0.22,1,0.36,1), 90ms stagger, starting at 150ms. The label row fades in over 400ms first.
- Motion: Scroll reveals: [data-reveal] elements start at opacity 0 and translateY(24px) (only under html.js) and move to opacity 1 and 0 over 900ms with cubic-bezier(0.22,1,0.36,1). They are triggered once by an IntersectionObserver with threshold 0.15 and rootMargin '0px 0px -8% 0px'. Items in a group stagger 80ms through a --d CSS variable.
- Motion: Parallax strips: each strip holds absolutely positioned layers (top -20%, height 140%) with data-speed (back 0.08, mid 0.18, front 0.32, overlay text 0.45). Per frame, for strips flagged in view by an IntersectionObserver, compute p = clamp((innerHeight - rect.top) / (innerHeight + rect.height), 0, 1) and set each layer to transform: translate3d(0, (0.5 - p) * speed * rect.height px, 0) with will-change: transform.
- Motion: Hero plate: the plate group inside the hero figure rotates from 0deg to 10deg, linked to scroll progress through the hero.
- Motion: Count-up: the home stats count from 0 to their value over 1200ms with easeOutCubic the first time they enter view.
- Motion: Links: nav and text links use a 1px currentColor underline drawn with background-size, growing from 0% to 100% left to right over 400ms on hover. Persistent CTA text links keep the underline and it turns terracotta on hover.
- Motion: Dish rows (hover-capable pointers only): the name shifts 4px right and the dotted leader turns terracotta over 300ms.
- Motion: Reservation links: on hover the text shifts 8px right, the arrow-up-right icon rotates 45deg and the row's top border turns terracotta, all over 300ms.
- Motion: Map: when 30% of the map is in view, the dashed route draws once through an SVG mask whose solid path animates stroke-dashoffset from its length to 0 over 1800ms ease-in-out. The pin then drops from translateY(-24px) with opacity 0 to rest over 500ms with cubic-bezier(0.34,1.56,0.64,1), the label card fades in over 300ms, and a pulse ring under the pin loops (r 10 to 34, opacity 0.5 to 0, 2400ms ease-out, infinite).
- Motion: Mobile nav overlay: clip-path moves from inset(0 0 100% 0) to inset(0) over 600ms with cubic-bezier(0.22,1,0.36,1). Links rise 24px and fade in with a 70ms stagger. Lenis stops while the overlay is open.
- Motion: Footer giant wordmark: letters rise 40% and fade in with a 40ms stagger when the footer enters view.
- Motion: prefers-reduced-motion: reduce: Lenis is never created, parallax transforms are not applied, all [data-reveal] content and headline lines show immediately, count-ups show final values, the hero plate does not rotate, the map route is drawn statically with the pin in place and no pulse, and all CSS transitions and animations are set to 0.01ms.
- Imagery: There are no photographs. All imagery is flat, slightly textured illustration drawn as inline SVG strings in src/art/, using only the palette (cream, paper, paper-deep, ink, ink-soft, hairline, terracotta, moss, ochre, beet). Shapes are simple and geometric with a hand-drawn wobble from one shared SVG filter (feTurbulence type 'fractalNoise' baseFrequency 0.015 numOctaves 2 seed 4, then feDisplacementMap scale 3) applied to shape groups and never to text. A global grain overlay (.grain) is fixed at inset 0 with pointer-events none, z-index 60, opacity 0.07 and mix-blend-mode multiply; its background is a 200px tiled SVG data URI of feTurbulence fractalNoise at baseFrequency 0.8 with 2 octaves. ## Don'ts
- No backend of any kind: no server code, API routes, databases, auth or forms that submit anywhere. Booking happens only through tel: and mailto: links.
- No online booking form, reservation widget or third-party embed or API of any kind.
- No Google Maps, Mapbox, OpenStreetMap tiles, map libraries or real map data. The map is an invented hand-drawn SVG with invented street names and landmarks only.
- No real restaurant's name, logo, wordmark or slogan, and no copied copy, dish names or menu text from any real restaurant. All copy is invented for [BRAND].
- No photos from Unsplash, Pexels, Pixabay or other stock sites, no Google Images and no placeholder-image services. All imagery is code-drawn SVG.
- No people's faces as hero imagery, and no brand logos or brand icons (no Simple Icons).
- No commercial or custom fonts. Fontsource OFL fonts only, self-hosted. Never load anything from fonts.googleapis.com, fonts.gstatic.com, Adobe Fonts or any font CDN.
- No CDN <script> or <link> tags, no hotlinked files and no analytics. Every font, icon and script is bundled locally.
- No source maps in the production build, no src/ copied into dist/, and output must be minified. Keep dist/ under 20 MB.
- Internal links always point to file names (./index.html, ./menu.html, ./visit.html), never to '/' or a bare directory. Asset paths are relative (Vite base './').
- Do not change the stack: no React, Vue or other frameworks, no UI kits, and no Aceternity UI or Tailwind Plus/Tailwind UI source.
- No rounded corners (except the circular elements named in Design), no drop shadows, no gradients on UI elements and no emoji.
- Use only one UI accent color (terracotta). Moss, ochre and beet appear only inside illustrations.
- Under prefers-reduced-motion there must be no smooth scroll, parallax, reveals, headline entrances, count-ups, plate rotation, route drawing or pin pulse. Show all content in its final state.
- Zero console errors at 1440x900 and 390x844, and no horizontal page scroll on mobile (only the course index scrolls sideways).
- No SEO extras: no meta descriptions, Open Graph tags, JSON-LD or sitemaps. Use a plain <title> and the favicon only.
- Use no real phone numbers or domains. Keep the fictional defaults or the user's own values.
- Do not mention VibeFather anywhere in the site except the optional [CREDIT] footer link.
