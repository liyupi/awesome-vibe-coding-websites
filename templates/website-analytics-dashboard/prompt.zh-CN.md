# 网站分析仪表盘

完全按照以下描述构建此网站。将 [VARIABLES] 替换为你自己的值；其余内容保持不变。

## 简介
为 [PUBLICATION] 构建一份隐私友好的流量报告，[PUBLICATION] 是位于 [DOMAIN] 的虚构出版物。[BRAND] 是其分析工作区。

- 受众：独立编辑和受众团队。
- 目标：识别哪些文章、引荐来源、地区和广告系列对读者数量的变化有贡献。
- 语气：平静、分析性、清晰的排版层级，使用实用的编辑语言。

## 技术栈
- 框架：React 19 + Vite
- 样式：原生 CSS（Vanilla CSS）
- 库：无
- 构建：`npm run build` → 静态文件输出到 `dist/`。无后端、无服务端代码、无外部 API。
- 配置：
  - 使用相对 Vite base './'。在本地打包字体和脚本，压缩，并禁用 source map。
  - 将所有可编辑标签、示例内容和产品名称放在一个内容模块中。将模拟服务放在一个适配器文件中。
  - 通过一个可替换的数据适配器创建确定性的 90 天 fixture。从它的事件中推导所有指标、图表数据点和有序漏斗。

## 变量
- [BRAND] — 分析工作区（默认：“Index Lantern”）
- [PUBLICATION] — 出版物（默认：“Fieldwork Dispatch”）
- [DOMAIN] — 出版物域名（默认：“fieldwork.example”）
- [CREDIT] — 在页脚保留一个小型“Template by VibeFather”链接，指向 https://vibefather.ai/t/website-analytics-dashboard（默认：是；删除此行即可移除）

“页面与区块”下的文案是按默认值撰写的。如果你的取值不同，请为它们重写每一个标题、段落、标签和图片——保持相同的长度、语气和结构。布局、颜色、字体和动效保持所述不变。
将所有文案、图片路径和链接放在一个内容文件中（例如 `src/content.ts`），按区块作为键，以便日后无需改动组件即可替换内容。

## 设计
### 颜色
- 纸白（Paper）`#FFFFFF` — 浅色报告画布
- 石板灰（Slate）`#0F172A` — 文本、深色模式表面和导航
- 靛蓝（Indigo）`#4F46E5` — 主序列、活动链接和焦点
- 柔和琥珀（Soft amber）`#F59E0B` — 上一周期虚线曲线、对比图例和带深色标签的标记

### 排版
- 导航和报告标题：Instrument Sans（OFL），字重 400/500/600/700
- 数字和图表标签：IBM Plex Mono（OFL），字重 400/500

### 布局与动效
- 间距：208px 导航、28px 内容边距和 20px 图表内部内边距。将所有图形对齐到一致的基线。在移动端将侧边栏折叠为菜单。
- 圆角：5px 控件、10px 面板和 1px 分隔线。
- 动效：立即绘制趋势，并在 180ms 内插值后续变化。允许键盘/触摸点检查。
- 动效：保持实时计数器更新微妙，并在有请求时抑制动效。
- 图像：原创双序列 SVG 趋势图，带有精细参考线、独特的线型和柔和的靛蓝填充。展示一个真正可识别的矢量世界地图，带有可选区域、工具提示和相邻的带标签国家排名。从实际聚合数据绘制小型趋势线。

## 页面与区块
### 受众概览（`index.html`）
1. **工作区与时间窗口** — 显示 [BRAND]、所选出版物 [PUBLICATION] 及其 [DOMAIN]、Overview、Campaigns、Goals & funnels 和 Share report。默认显示 90 个样本日中的最近 30 天。可选择 7、30、90 天或有效的自定义区间，并与前一个等长窗口对比，当历史数据不完整时给出明确提示。将筛选条件、区间、目标和主题保存在本地。使用相对于周期的轴标签，例如 D1。
   布局：使用带有原创靛蓝色符号的窄导航栏，清晰的激活状态和出版物切换信息。将报告标题、区间选择器、主题切换和分享操作置于紧凑的指标行上方。
2. **流量随时间变化** — 从预置的匿名访问中计算独立访客、页面浏览量、每次访问浏览量和实时访客数。Visitors 和 Pageviews 切换主要度量，对比开关控制琥珀色虚线系列，工具提示显示数据点值。在适配器中模拟实时访问。
   布局：为 Traffic overview 提供宽大清晰的图表、带标签的坐标轴和两部分图例。将实时指示器与对应指标放在一起。
3. **内容与受众报告** — 按所选度量对页面、引荐来源、国家/地区、设备和浏览器进行排名。每个区块和国家/地区地图都从相同的筛选记录中派生。点击任意行或活跃国家/地区会添加筛选标签；添加另一个维度会与当前选择取交集。单个标签和 Clear all 会更新所有计数和图表。使空结果可恢复。
   布局：在图表下方，将 Top pages 放在 Top referrers 旁边，然后是带可点击绘制地图和排名的 Countries、Devices 和 Browsers。显示有意义的标题和带精确计数的克制仪表条；保持触摸目标。
4. **隐私** — 使用确定性合成会话，包含匿名访问键、有序事件、相对日槽、国家/地区、引荐来源、设备、浏览器和广告系列。包含重复会话，使访客数和页面浏览量不同。无跟踪器、同意对话框或客户端标识符。
   布局：小型隐私说明应放在来源信息旁边。

### 广告系列（`#/campaigns`）
1. **广告系列报告** — 按 UTM campaign、source 和 medium 对流量分组，并显示访问、页面浏览量和目标转化。点击一行可筛选所有报告。在导航过程中保持活跃区间和标签。
   布局：提供可操作表格，最强的来源排在最前，并允许窄屏逐行查看。

### 目标与漏斗（`#/goals`）
1. **目标编辑器** — 预置两个可用目标，包括 newsletter signup。添加、重命名和删除带事件或路径条件的目标，并计算当前选择的完成数。
   布局：将命名目标列表和简洁表单与实时结果配对。
2. **漏斗构建器** — 预置一个三步阅读漏斗。允许用户添加、移除、重新排序和选择事件步骤，命名并保存漏斗。统计在同一会话中按顺序到达每个步骤的会话数，并显示流失和转化。在叠加筛选条件下重新计算。
   布局：在共享基线上使用缩放的水平条和真实计数。将编辑控件放在每个步骤旁边。

### 公开报告（`#/share`）
1. **分享视图** — 复制一个可用链接，编码区间、所有筛选条件以及在任何其他设备上重现该视图所需的任何自定义目标/漏斗定义。以只读模式打开，无编辑控件或对个人本地设置的访问权限。无参数的直接访问显示预置报告。
   布局：保留报告标题、趋势和细分表格，带有紧凑的出版物标题和 Read-only 标签。

## 不要做
- 不要展示虚构的固定 KPI 总计、无功能的导航、标注为空的空地图或虚假的分享链接。保持示例完全在本地运行。
- 默认构建仅使用变量默认值。不要使用真实产品、平台、品牌或徽标。全程使用英文文案。不要装饰性日期或时间戳。
- 不要后端、认证、外部 API、CDN 或远程字体。使用相对本地资源 URL 和哈希路由或 HTML 文件，从子目录提供直接链接。保持构建后的站点在 20 MB 以下，不包含 source map 或源码树。
- 在 ASSETS.md 中记录所有字体、第三方文件和代码绘制的资源。遵循减少动态效果、键盘焦点和 AA 级对比度。在 390px 宽度下，所有控件必须保持可访问且页面不溢出。避免空的首帧、禁用的模拟控件以及仅改变标签的交互。
