# Website Analytics Dashboard — Design System

Apply this design system to an existing project. It describes the look and feel only; for the full site, use prompt.md.

## Colors
- **Paper** `#FFFFFF` — Light report canvas
- **Slate** `#0F172A` — Text, dark mode surfaces and navigation
- **Indigo** `#4F46E5` — Primary series, active links and focus
- **Soft amber** `#F59E0B` — Previous period dashed curve, comparison key and markers with dark labels

## Typography
- **Navigation and report titles** — Instrument Sans (OFL), weights 400/500/600/700. Self-host the font files.
- **Numbers and chart labels** — IBM Plex Mono (OFL), weights 400/500. Self-host the font files.

## Spacing & shape
- Spacing: 208px navigation, 28px content gutter and 20px internal chart padding. Align all figures on consistent baselines. Collapse the rail into a menu on mobile.
- Radius: 5px controls, 10px panels and 1px separators.

## Motion
- Draw the trend immediately and interpolate subsequent changes in under 180ms. Allow keyboard/touch point inspection.
- Keep real-time counter updates subtle and suppress motion when requested.

## Imagery
Original two-series SVG trend with fine guides, distinct line patterns and a soft indigo fill. Show a genuinely recognizable vector world map with selectable regions, tooltip and adjacent labeled country ranking. Draw small trend lines from actual aggregates.

## Tone
Calm, analytical, crisp typographic hierarchy with practical editorial language.
