# Ceramics Shop Product Page

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
A calm, minimal single-product ecommerce page for [BRAND], a small invented pottery studio in [STUDIO_PLACE] that sells one item: [PRODUCT_NAME], a [PRODUCT_KIND] made up of [SET_PIECES], priced at $[PRICE]. The page centers on a two-column product hero: a large gallery of five code-drawn SVG views with zoom on the left, and a sticky buy panel with round glaze swatches on the right. Choosing a swatch smoothly recolors every SVG render of the product on the page. The buying flow runs entirely in the browser: a quantity stepper, a slide-in cart drawer with line items, an add-on, a free-shipping progress bar, and a mock checkout that only shows a toast. Below the hero, in order: a story strip, what's in the set, a care accordion, shipping and returns, reviews with rating bars, an FAQ and a footer. There are no photos. All product art is inline SVG with an SVG-filter stoneware speckle and a paper-grain overlay. All copy below is written for the default variable values. If the variables differ, rewrite every headline, paragraph, item name, review, FAQ and care entry so it fits the new brand and product, while keeping the same length, tone and structure. Keep all copy and product data in one file: src/content.ts.

- Audience: Ceramicists, makers, small DTC and craft brands that sell one hero product in several finishes, and developers who want a polished static single-product store to adapt.
- Goal: Let the visitor pick a glaze, see the product change color instantly, check the details (pieces, care, shipping, reviews) and add the set to a cart. Everything must feel like a real shop while running as static files.
- Tone: Quiet, warm and plain-spoken, like a potter describing their work at a market stall. Short sentences, concrete numbers (ml, cm, °C, days), no hype words, no exclamation marks.

## Stack
- Framework: Vite 5 + React 18 + TypeScript
- Styling: Tailwind CSS 3.4
- Libraries: react (MIT), react-dom (MIT), motion (MIT), lucide-react (ISC), @fontsource-variable/fraunces (OFL-1.1), @fontsource-variable/inter (OFL-1.1), tailwindcss (MIT), postcss (MIT), autoprefixer (MIT), typescript (Apache-2.0), vite (MIT)
- Build: `npm run build` → static files in `dist/`. No backend, no server code, no external APIs.
- Setup:
  - Scaffold with: npm create vite@latest kiln -- --template react-ts
  - Install: npm i motion lucide-react @fontsource-variable/fraunces @fontsource-variable/inter
  - Install dev deps: npm i -D tailwindcss@3.4 postcss autoprefixer, then npx tailwindcss init -p
  - In vite.config.ts set base: './' and build: { sourcemap: false, outDir: 'dist' }
  - In main.tsx import '@fontsource-variable/fraunces' and '@fontsource-variable/inter' before index.css
  - In tailwind.config.js set content to ./index.html and ./src/**/*.{ts,tsx}. Extend colors with bone #F4EFE6, paper #FBF8F3, sand #E3D8C6, ink #2B2420, muted #6E625A, clay #B4532F, clayDark #9A4426, foot #C8A27C. Extend fontFamily with display ['Fraunces Variable', 'Georgia', 'serif'] and sans ['Inter Variable', 'system-ui', 'sans-serif']. Extend boxShadow with soft: '0 1px 2px rgba(43,36,32,0.04), 0 12px 32px -12px rgba(43,36,32,0.18)' and lift: '0 2px 4px rgba(43,36,32,0.05), 0 20px 40px -14px rgba(43,36,32,0.24)'
  - src/content.ts holds every string, the GLAZES array, the views array, pieces, care, shipping, reviews, FAQ, the add-on item, FREE_SHIPPING_THRESHOLD = 150 and FLAT_SHIPPING = 9
  - src/index.css holds the Tailwind directives, @property registrations for --glaze-hi, --glaze-base and --glaze-lo (syntax '<color>', inherits: true), the steam keyframes, and a prefers-reduced-motion block that disables steam and all transitions
  - Glaze state lives in a GlazeContext (src/state/GlazeContext.tsx). The selected glaze's hi/base/lo hex values are set as CSS custom properties on <body>, and body has transition: --glaze-hi 600ms, --glaze-base 600ms, --glaze-lo 600ms ease
  - Cart state lives in a CartContext (src/state/CartContext.tsx) using useReducer. Persist to localStorage key 'kiln-cart-v1' and rehydrate on load. Line items are keyed by productId + glazeId
  - SVG product pieces are React components in src/render/ (Dripper.tsx, Server.tsx, Cup.tsx, SetScene.tsx, GlazeMacro.tsx, ScaleDrawing.tsx, Crate.tsx, Defs.tsx). They read color from var(--glaze-*), or from an explicit glaze prop when drawn in the cart
  - Render <Defs /> once at the top of <body> as a hidden 0×0 SVG that holds the shared gradients and filters (glazeGrad, footGrad, speckle, grain, softShadow), referenced by id
  - index.html <title> is '[BRAND] — [PRODUCT_NAME]'. The favicon is public/favicon.svg: a 32×32 terracotta #B4532F circle with an inner bone #F4EFE6 ring stroke of 2px at radius 9
  - Add ASSETS.md at the project root listing the Fontsource fonts and Lucide icons with source URL, author and license, and stating that all product art is original inline SVG

## Variables
- [BRAND] — Studio / brand name (default: "Ollan Ceramics"). Invented maker or shop name; used in header wordmark, title, footer and copy.
- [PRODUCT_NAME] — Product name (default: "The Ridgeline Pour-Over Set"). The single product the page sells.
- [PRODUCT_KIND] — Product kind (default: "handmade stoneware pour-over coffee set"). Short description used in the eyebrow, intro and story copy.
- [SET_PIECES] — Pieces in the set (default: "dripper, 600 ml server, two 180 ml cups"). Comma-separated list; drives the 'What's in the set' cards and which SVG pieces are drawn.
- [PRICE] — Price (USD, number only) (default: "148"). Keep below the $150 free-shipping threshold so the progress bar has something to show.
- [STUDIO_PLACE] — Studio location (default: "Fernlow Valley"). Invented place name used in the announcement bar, story strip and footer.
- [CREDIT] — keep a small "Template by VibeFather" link to https://vibefather.ai/t/ceramics-shop-product-page in the footer (default: yes; delete this line to remove it)

The copy under Pages & Sections is written for the default values. If your values differ, rewrite every headline, paragraph, label and image for them — same length, tone and structure. Layout, colors, type and motion stay as described.
Keep all copy, image paths and links in one content file (for example `src/content.ts`), keyed by section, so the content can be swapped later without touching components.

### Layout & motion
- Spacing: 8px base grid. Container max-width 1240px, centered, horizontal padding 24px on mobile and 40px from 1024px up. Section vertical padding 112px on desktop and 72px on mobile. Card padding 28px (20px on mobile). Grid gap 24px, hero column gap 64px. Type scale: H1 product name Fraunces 500 48px/1.05 desktop, 36px mobile, letter-spacing -0.02em, font-variation-settings 'opsz' 96, 'SOFT' 50. Section H2 Fraunces 400 40px/1.1 desktop, 30px mobile. Card titles Fraunces 500 22px. Body Inter 400 16px/1.65. Small labels Inter 500 12px uppercase with 0.12em tracking, in Muted.
- Radius: Gallery stage 28px; cards, accordion panels and drawer line thumbnails 20px; thumbnails 14px; buttons, steppers, swatches, badges and toast fully rounded (9999px). The drawer has no radius on its outer edge.
- Motion: Library: Motion (motion/react). Global easing [0.22, 1, 0.36, 1].
- Motion: Scroll reveal: every section's heading block and cards fade up from y 24px, opacity 0 to 1, over 700ms, whileInView with once: true and amount 0.2. Cards in a grid stagger by 80ms.
- Motion: Glaze change: the --glaze-hi/base/lo custom properties transition over 600ms ease, so every render shifts color smoothly at the same time. The glaze name label beside 'Glaze —' crossfades over 200ms.
- Motion: Gallery view change: AnimatePresence crossfade, opacity plus scale 0.98→1, 300ms.
- Motion: Steam: three wavy SVG paths above the dripper and server (in the set and dripper views). Each rises translateY 0→-28px while opacity goes 0→0.55→0 over 6s, looping, with delays of 0s, 2s and 4s. Stroke #FFFFFF, width 6, linecap round, blurred by feGaussianBlur stdDeviation 2.
- Motion: Hover lifts: cards translateY -4px and swap shadow-soft for shadow-lift over 200ms. Swatches scale to 1.08. Thumbnails raise their border to Ink at 40% opacity.
- Motion: Add to cart: the button label swaps to a Check icon plus 'Added' for 1.4s (crossfade 150ms), then the drawer opens.
- Motion: Cart drawer: the panel slides x 100%→0 over 380ms. The overlay fades to rgba(43,36,32,0.4) with backdrop-blur 2px over 250ms. New line items animate height and opacity in, and removed items collapse out (layout animation 250ms).
- Motion: Free-shipping bar width animates 500ms whenever the subtotal changes.
- Motion: Rating bars animate width from 0 to their value over 900ms when scrolled into view, staggered by 60ms.
- Motion: Accordion: content height auto-animates 280ms, and the Plus icon rotates 45° to read as a close mark.
- Motion: Toast: slides up 16px and fades in over 250ms at bottom center, stays 3s, then fades out.
- Motion: prefers-reduced-motion: reduce (check with useReducedMotion and the CSS media query): no translate or scale animations, steam paths hidden, glaze and gallery changes are instant, the drawer appears with an opacity-only fade of 150ms, and rating bars render at full width.
- Imagery: No bitmaps at all. Every product image is an original inline SVG (viewBox 0 0 800 800) built the same way. Each piece is a simple silhouette path filled with url(#glazeGrad), a horizontal linearGradient going var(--glaze-hi) at 0%, var(--glaze-base) at 45% and var(--glaze-lo) at 100%. The glaze stops about 82% down each piece at a hand-drawn wavy 'dip line', and below it a band of unglazed foot shows in #C8A27C with a #A88560 shadow side. A 'speckle' filter overlays tiny dark iron flecks: feTurbulence fractalNoise baseFrequency 0.85, numOctaves 2, then feColorMatrix to a sparse alpha threshold, colored #3A2A20, at 35% opacity, clipped to the glazed area. A white rim highlight runs along each lip (1.5px stroke, 50% opacity), with a narrow vertical highlight streak (white, 18% opacity, blurred). Each piece sits on a soft ground shadow ellipse (Ink at 18%, blurred 14px). The forms are generic and original. The dripper is a smooth, slightly convex cone with a rolled rim, a flat round base flange and a small half-round loop handle on the right, with no ribs or signature details. The server is a round-bellied carafe with a short pulled spout and a narrowing neck. The cups are low, unhandled tumblers with a slight taper. The gallery stage background is a radial gradient from #FBF8F3 at the center to #EFE7DA at the edges. A fixed full-screen paper-grain overlay (feTurbulence baseFrequency 0.9, numOctaves 2, mix-blend-mode multiply, opacity 0.05, pointer-events none) covers the whole page. Review avatars are initials in circles tinted with their glaze color. There are no faces, people, product photos or logos of any kind.
