# Language School Website

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
Build a polished single-page website for [BRAND], an invented neighborhood language school offering [COURSE_LANGUAGES] to [AUDIENCE] in [LOCATION], with in-person and live-online options. Combine course discovery, an accurate ten-question placement quiz, recurring schedules, transparent prices, teacher profiles, and an enrollment request in one cohesive experience. Use the exact default copy below, but rewrite every course, question bank, teacher bio, schedule, testimonial, address, and contact detail when variable values change.

- Audience: Prospective language learners who want to understand the right level, weekly time commitment, teaching approach, and cost before enrolling, plus the educators or small school team adapting the site.
- Goal: Help a visitor move from initial interest to a suitable course and a completed client-side enrollment request without hiding the schedule or price.
- Tone: Warm, articulate, encouraging, and practical. Use concise educational language, concrete class details, and no guarantees about fluency, accreditation, or outcomes.

## Stack
- Framework: Vite 5 + React 18 + TypeScript
- Styling: Tailwind CSS 3.4
- Libraries: react (MIT), react-dom (MIT), vite (MIT), tailwindcss (MIT), motion (MIT), lucide-react (ISC)
- Build: `npm run build` → static files in `dist/`. No backend, no server code, no external APIs.
- Setup:
  - Create a Vite React TypeScript app with base './' in vite.config, sourcemaps disabled, and npm run build producing static files in dist/.
  - Configure the Tailwind theme with the specified colors and font families; keep global keyframes, focus styles, reduced-motion overrides, and selection colors in src/index.css.
  - Self-host Fraunces through @fontsource-variable/fraunces and DM Sans through @fontsource-variable/dm-sans; import only the required axes and weights.
  - Keep all visible copy, course records, schedule rows, prices, teacher bios, quiz banks, FAQs, and contact details in src/content.ts. Derive content from [BRAND], [COURSE_LANGUAGES], [AUDIENCE], [LOCATION], and [BASE_PRICE], and rewrite all dependent copy when values change.
  - Use Motion for React for reveals, filter layout changes, quiz transitions, and the mobile menu; use Lucide icons rather than manually imitating any existing icon set.
  - Use accessible React components with semantic buttons, fieldsets, radio groups, labels, focus management, and aria-live for quiz results and form confirmation. Store only the latest quiz result and enrollment draft in localStorage.

## Variables
- [BRAND] — School name (default: "Cedar & Verb"). An invented language school name; never a real school or VibeFather.
- [COURSE_LANGUAGES] — Languages taught (default: "Spanish, French, and Italian"). Three languages; provide courses and a ten-question quiz bank for each.
- [AUDIENCE] — Learner audience (default: "adults learning for travel, work, and connection"). A concise phrase describing who the classes serve.
- [LOCATION] — School location (default: "Portland, Oregon"). City and state or region used in the hero, visit details, and time-zone copy.
- [BASE_PRICE] — Group course price (default: "$240"). Price in USD for one eight-week group course; update dependent pricing copy when changed.
- [CREDIT] — keep a small "Template by VibeFather" link to https://vibefather.ai/t/language-school-website in the footer (default: yes; delete this line to remove it)

The copy under Pages & Sections is written for the default values. If your values differ, rewrite every headline, paragraph, label and image for them — same length, tone and structure. Layout, colors, type and motion stay as described.
Keep all copy, image paths and links in one content file (for example `src/content.ts`), keyed by section, so the content can be swapped later without touching components.

## Design
### Colors
- Paper `#F7F3EA` — Main page background and quiet section fills
- Ink `#19352F` — Headlines, body text, borders, and dark footer
- Persimmon `#E76F51` — Primary buttons, active quiz states, and small editorial accents
- Cobalt `#3157D5` — Secondary links, level chips, and focus rings
- Sage `#B7C9A8` — Course-card washes, progress tracks, and decorative shapes
- Chalk `#FFFCF7` — Cards, form surfaces, and text on Ink or Persimmon

### Typography
- Display and section headlines: Fraunces (OFL), weights 500/600/700
- Body, navigation, forms, and tables: DM Sans (OFL), weights 400/500/600/700

### Layout & motion
- Spacing: Use an 8px base grid, a 1280px maximum content width, 32px desktop gutters and 20px mobile gutters. Sections have 112px vertical padding on desktop and 72px on mobile. Use a 12-column desktop grid, 24px card gaps, and generous 40–56px internal padding for major interactive panels.
- Radius: Use 24px card radii, 32px image-frame radii, 12px input radii, and fully rounded buttons and filter chips. Major surfaces have a 1px Ink border at 18% opacity; avoid heavy drop shadows.
- Motion: On hero load, rise the two headline lines 32px with a 650ms ease-out and stagger them by 90ms; settle the photograph from scale 1.04 to 1 over 900ms.
- Motion: Reveal section headings and card groups once with opacity 0 to 1 and y 24 to 0 over 550ms, staggered by 70ms; never hide content while waiting for JavaScript.
- Motion: Crossfade and slide quiz questions by 20px over 240ms, animate the progress bar width over 300ms, and announce the final level through aria-live.
- Motion: Animate filtered course layouts with Motion layout transitions, lift course cards 4px on hover, and scale teacher portraits only to 1.025.
- Motion: Use reduced-motion hooks and a prefers-reduced-motion CSS override to remove transforms, smooth scrolling, and nonessential transitions while preserving every final state.
- Imagery: Use the six supplied warm editorial documentary photographs as one coherent shoot: creamy walls, forest-green furnishings, restrained persimmon accents, soft window light, natural 35mm texture, and diverse fictional adults. The hero is a spacious classroom scene rather than a face close-up. Teacher portraits are consistent half-length working portraits of fictional people who do not resemble any real individual. Do not add readable text, logos, famous landmarks, or recognizable real people to any image.

## Don'ts
- Do not add a backend, API routes, a database, authentication, analytics, external form submission, maps embeds, or third-party API calls. Quiz scoring, filtering, local persistence, and enrollment confirmation must run entirely in the browser.
- Do not hotlink images or load scripts, fonts, icons, or styles from a CDN. Download the six supplied images, self-host both fonts, and keep every runtime asset local with relative paths.
- Do not emit source maps, copy src/ into dist/, exceed 20 MB in dist/, or require more than npm run build. The single-page site must open from index.html and use hash anchors rather than bare-directory links.
- Do not scatter copy through components. Keep all editable text and records in src/content.ts, derive brand-dependent values from variables, and rewrite all default-only content when variables change.
- Do not use real school names, logos, slogans, branded visual systems, existing-school copy, custom commercial fonts, or page code from another website.
- Do not use real teacher identities, celebrity or public-figure likenesses, recognizable real people, or initials-only teacher cards. All teacher profiles and portraits are fictional placeholders and must vary naturally.
- Do not use Unsplash, Pexels, Pixabay, Google Images, CC BY-NC, CC BY-SA, placeholder-image services, or any asset with unclear redistribution rights. Do not add text, logos, famous landmarks, or branded products to the generated imagery.
- Do not claim accreditation, guaranteed fluency, verified student outcomes, real review counts, or fabricated performance statistics. Keep the placement result explicitly advisory rather than a certificate.
- Do not leave decorative or dead controls. Language and level filters, course details, both schedule tabs, all ten quiz steps and scoring, result-to-course filtering, retake, mobile navigation, accordions, enrollment preselection, validation, success, edit, and reset must all work.
- Do not use lorem ipsum, generic stock slogans, fake urgency, countdowns, unrelated brands, or VibeFather's own name, pricing, licensing, metrics, or membership content in the site UI.
- Do not compromise accessibility or responsiveness: no horizontal overflow at 390px, no table-only mobile layout, no missing labels or alt text, no focus traps, no hover-only information, and no console errors at 390×844 or 1440×900.
- Do not ignore prefers-reduced-motion, smooth-scroll users into motion they cannot disable, hide core content behind animation, or use unnecessary 3D, parallax, autoplay carousels, or looping decoration.
