# Sticker Shop Website

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
Build [BRAND], a fictional sticker shop launching [COLLECTION] for [AUDIENCE]. Cherry/lemon color blocks and original abstract rainbow die-cut shapes are the visual identity.

- Audience: [AUDIENCE] who want small, expressive objects without licensed characters.
- Goal: Filter products, inspect original art, build a six-sticker pack and manage a correctly priced local-only shopping bag.
- Tone: Playful, specific and useful about size, materials and price; no fake sales urgency or real checkout claims.

## Stack
- Framework: Vite + React + TypeScript
- Styling: Vanilla CSS
- Libraries: vite (MIT), react (MIT), react-dom (MIT), typescript (Apache-2.0), @fontsource/baloo-2 (OFL-1.1), @fontsource/nunito-sans (OFL-1.1)
- Build: `npm run build` → static files in `dist/`. No backend, no server code, no external APIs.
- Setup:
  - Set Vite base to ./ and build.sourcemap to false. Use a single src/content.ts for all editable content and fully rewrite its data for variable changes.
  - Implement responsive components and CSS tokens in src/styles.css. Bundle fonts through the listed Fontsource packages; import only the weights actually used.
  - Provide semantic native controls and keyboard/touch alternatives; implement focus-managed dialogs and local-only validated form feedback.

## Design
### Colors
- Cherry red `#FF2D55` — Large hero half, catalog dividers and original artwork. WCAG relative-luminance calculations: #141126 text on #FF2D55: 5.06:1; #141126 text on #FFF35C: 16.02:1; #141126 text on #FFFFFF: 18.45:1; #FFFFFF text on #254DFF: 5.86:1; #141126 text on #19C37D: 8.04:1. Use these pairs for every normal-size label/body/button. Decorative overlaps/gradients carry no text; readable text gets a solid backing.
- Lemon `#FFF35C` — Large hero half and pack-building desk.
- Ink `#141126` — Body and controls on cherry/lemon/white.
- White `#FFFFFF` — Die-cut border and product reading panels.
- Cobalt `#254DFF` — Secondary solid panels and selected pack actions.
- Leaf green `#19C37D` — Decorative sticker art and selected-count chips.

### Typography
- Display: Baloo 2 (OFL), weights 700
- Body: Nunito Sans (OFL), weights 400/700

### Layout & motion
- Spacing: 1200px max, 40px desktop/20px mobile gutters, 8px unit, 88px/52px sections. 4col catalog/2 mobile, pack desk 55/45 with 3×2 visible slots. H1 92px/54px.
- Radius: 20px product photos/panels, 12px controls, 999px category tags. Stickers have contour-following 6–10px white die-cut borders and soft shadows, not square image frames.
- Motion: Sticker hover/focus tilt maximum 3deg and a small corner curl for 160ms; tap Preview peel button toggles the same effect without adding a product. Drag can be an optional enhancement, never required to fill slots.
- Motion: Cart drawer 200ms slide, reduced motion instant; no floating sticker loop, cursor replacement or motion that hides prices.
- Imagery: Four unified photorealistic tabletop product images with hard-soft daylight, cherry red/lemon colored surfaces, unbranded notebooks and mailers, original abstract rainbow die-cut stickers with clean white edges. No existing characters, faces, logos, slogans or lettered sticker designs. Product thumbnails are original inline SVG artworks with the exact recurring original motifs, not random emoji. Use photography for physical storefront credibility and SVG for precise selectable items. Any visible hand belongs to a fictional person, no face.

## Don'ts
- Build a static-only demo: no backend, API routes, databases, authentication, payments, third-party APIs, analytics, telemetry, or forms that send network requests. Confirmations must explicitly say local demo; never claim an order, booking, generated service result, or email was sent.
- Use Vite base ./, relative local assets, hash routes or real .html filenames; no bare-directory links. Direct-open every route and ensure any detail route without an ID renders its first item. Build minified dist/ with npm run build, no source maps or source files, total dist under 20 MB.
- Keep all editable copy, fictional sample data, prices, interaction labels, alt text and A/B content in a single src/content.ts module. Keep 3–6 variables. When variables change, rewrite all related content consistently; never leave the default brand or subject in the second case.
- All visible language and alt text use US English. Do not render calendar dates, years, dated copyright lines, fake freshness or popularity metrics. Operational weekdays and times, track durations, relative timers, issue identifiers and dimensions are permitted.
- Use only original code/art/copy, permissive MIT/ISC/BSD/Apache/CC0 dependencies and locally bundled OFL fonts. No copied site code, existing logos, famous characters, commercial fonts, restricted components or recognizable real-person likeness. List every font, dependency and generated artwork in ASSETS.md with source and license.
- Everything is local at runtime: no hotlinked pictures, font CDNs, remote scripts, remote music or placeholder-image services. Download exactly the specified template-hosted images before build; record full source URL, target path, alt text and generated credit in ASSETS.md.
- At 1440×900 and 390×844 keep zero console errors and no horizontal overflow. Touch targets at least 44px, visible keyboard focus and labeled inputs, Escape/outside close and focus restore for dialogs, drawer focus trap, scroll lock and aria-live for result changes. Hover effects need equivalent focus/tap paths.
- Respect prefers-reduced-motion: remove looping transforms, scroll scrub and parallax, show final static states, never autoplay audio/video, no flashing, strobe or rapid full-screen luminance changes. Do not hide essential content pending animation.
- Preserve the assigned palette with at least two strong hero colors occupying large areas. No neutral cream/charcoal fallback, no gradients behind normal text, no low-contrast small labels. Use the calculated AA text/background pairs in Design.
- Never use recognizable existing characters, mascots, game/anime art, real logos, slogans, copyrighted sticker designs, copied product photos or emoji substitutes. Generated realistic product photos and original SVG art share the same abstract motifs; no faces or identifiable people.
- The six-slot builder must actually track selections/removals/limits and immutable cart snapshots; no inert slots, fake Add buttons or drag-only controls. Cart cents, quantity, pack contents and shipping must calculate correctly. No Checkout, payment, order confirmation, real stock promise, email form or network request.
- Sample reviews must be clearly fictional and unverified next to the review wall. No invented real customers, aggregate ratings, verified purchase labels, durability certification, origin or eco claim.
- For Layer Picnic rewrite all product names, pack names, prices, collection text, review names/quotes and audience use cases around craft-club journaling. Keep eight original geometric motifs and four consistent no-logo photos as generic physical product placeholders, same local formulas and six-slot architecture; update fixed custom-pack price and all labels consistently if changed. No default shop/collection/audience remains.
