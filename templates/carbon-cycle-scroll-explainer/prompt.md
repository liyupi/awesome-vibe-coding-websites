# Carbon Cycle Scroll Explainer

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
A single-page illustrated scroll story by [BRAND], a small independent science explainer studio, about [TOPIC]. One large code-drawn SVG cross-section (sky, land with forest and mountains, open ocean, rock strata with fossil seams) is moving from the first frame: glowing particles stream between the four reservoirs ([RESERVOIRS]) along curved paths, with speed and density showing the size of each flow ([FLOWS]). The scene stays pinned while text steps scroll past and the camera pans and zooms from reservoir to reservoir. The fourth, human-driven flow starts as a thin thread and thickens through the industrial era. A yearly ledger follows, then a scenario lab: a slider with three stops ([SCENARIOS]) that smoothly redraws a curve of [OUTCOME], updates a big readout and shifts the sky tint. Every figure is tagged Illustrative and a closing sources note explains the rounding.

- Audience: High-school and early-university classes, curious adult readers, and the teachers, museum educators, nonprofits and newsrooms who would link to or project this page.
- Goal: Make one system story understandable in about four minutes of scrolling, let the reader feel the imbalance before it is stated, and end with an interaction (the scenario slider) that makes the choice between futures tangible. Secondary goal: easy reuse in class (print button, discussion prompts).
- Tone: Plain, warm and exact. Short sentences, concrete round numbers, no alarmism and no jokes about the subject. Poster-bold visuals, calm text. Write all copy for the default values below and keep it in src/content.ts; if the variables change, rewrite every headline, step, ledger row, FAQ answer and sources line to fit the new topic with the same length and rhythm.

## Stack
- Framework: Vite 5 + vanilla TypeScript
- Styling: Vanilla CSS
- Libraries: vite 5 (MIT), typescript 5 (Apache-2.0), gsap 3.12 (core + ScrollTrigger) (GSAP Standard License (free, commercial use allowed)), lucide 0.4x (vanilla package) (ISC), @fontsource-variable/bricolage-grotesque (OFL-1.1), @fontsource/atkinson-hyperlegible (OFL-1.1), @fontsource/jetbrains-mono (OFL-1.1)
- Build: `npm run build` → static files in `dist/`. No backend, no server code, no external APIs.
- Setup:
  - Scaffold with the Vite vanilla-ts template; package.json scripts: dev = vite, build = tsc && vite build, preview = vite preview.
  - vite.config.ts: base './', build.outDir 'dist', build.sourcemap false, build.assetsInlineLimit 0. Single entry index.html.
  - File layout: src/main.ts (boot, fonts, icons), src/content.ts (every string and number on the page, typed), src/scene.ts (builds the inline SVG scene and exposes named groups), src/flows.ts (particle clock), src/story.ts (ScrollTrigger steps and camera), src/scenario.ts (slider, curve paths, readout, tint), src/styles.css (tokens, layout, keyframes, reduced-motion and print rules).
  - In main.ts import '@fontsource-variable/bricolage-grotesque', '@fontsource/atkinson-hyperlegible/400.css', '@fontsource/atkinson-hyperlegible/700.css', '@fontsource/jetbrains-mono/500.css'.
  - Register GSAP once: import { gsap } from 'gsap'; import { ScrollTrigger } from 'gsap/ScrollTrigger'; gsap.registerPlugin(ScrollTrigger).
  - Icons: import only the needed icons from 'lucide' and call createIcons({ icons: { Wind, Waves, Trees, Layers, Flame, Thermometer, Info, ArrowDown, Printer, Plus, Minus } }) after the DOM is built; elements use data-lucide attributes.
  - Build the scene SVG in TypeScript (scene.ts) from content.ts data and inject it into #scene; do not ship it as an external image. viewBox origin 0 0 1600 1000, preserveAspectRatio 'xMidYMid slice'.
  - Define all colors as CSS custom properties on :root in styles.css and reference the same values from the SVG via fill='var(--name)' where possible.
  - <title> is '[BRAND] · [TOPIC], explained'. Favicon: public/favicon.svg, a 32x32 indigo (#160F3D) rounded square with two curved arrows forming a ring, one acid lime (#C6FF3D), one molten orange (#FF6A1A).
  - Gate all motion on window.matchMedia('(prefers-reduced-motion: reduce)'); the reduced path is described in Design > motion.

## Variables
- [BRAND] — Studio or publication name (default: "Lowtide Lab"). Who publishes the explainer. Used in the header wordmark, title and footer.
- [TOPIC] — System the story explains (default: "The carbon cycle"). Any system that moves one quantity between four stores.
- [RESERVOIRS] — Four reservoirs, in story order (default: "Atmosphere, Land, Ocean, Fossil reserves"). Comma-separated, exactly four. Mapped onto sky, land, ocean and rock strata in the scene.
- [FLOWS] — Four flows, in story order (default: "Photosynthesis, Respiration and decay, Ocean exchange, Fossil fuel burning"). Comma-separated, exactly four. The last one is the human-driven flow that thickens in the industrial-era step.
- [SCENARIOS] — Three slider stops, best to worst (default: "Rapid cuts, Current path, High emissions"). Plain invented labels; never official scenario codes.
- [OUTCOME] — What the scenario curve shows (default: "Warming by 2100, in °C"). Y-axis label and readout unit of the scenario curve.
- [CREDIT] — keep a small "Template by VibeFather" link to https://vibefather.ai/t/carbon-cycle-scroll-explainer in the footer (default: yes; delete this line to remove it)

The copy under Pages & Sections is written for the default values. If your values differ, rewrite every headline, paragraph, label and image for them — same length, tone and structure. Layout, colors, type and motion stay as described.
Keep all copy, image paths and links in one content file (for example `src/content.ts`), keyed by section, so the content can be swapped later without touching components.

### Layout & motion
- Spacing: 8px base grid. Content max-width 1200px with 6vw side padding on desktop and 16px gutters on mobile. Sections are separated by 160px (desktop) / 96px (mobile). Hero headline 112px desktop / 52px mobile (clamp(52px, 8vw, 112px)); section headings clamp(36px, 5vw, 64px); step titles 40px desktop / 28px mobile.
- Radius: Cards and step panels 20px; buttons and chips fully rounded (999px); slider track 999px; ledger bars 6px. The scene itself is full-bleed with no radius.
- Motion: Load: the scene fades in from Night Indigo over 600ms, then the hero headline lines rise 24px and fade in with a 90ms stagger (power3.out, 700ms). Particles start immediately; there is no static first frame.
- Motion: Particle clock: one requestAnimationFrame loop in flows.ts drives every flow. Each flow is an SVG path sampled once into 240 points (Float32Array, via getPointAtLength at init). Each particle i of a flow sits at u = (time * speed + i / count) mod 1 and is drawn as a circle of radius 2.5 to 4px with a soft glow (an feGaussianBlur stdDeviation 2 filter on the flow group). count = clamp(round(value / 3), 3, 44); speed = 0.05 + value / 1500 cycles per second. Every guide path is also stroked at 25% opacity, 1.5px, dash 2 6.
- Motion: The loop pauses when the story section is fully offscreen (IntersectionObserver) and when document.hidden is true.
- Motion: Camera: a GSAP timeline scrubbed across the story track (scrub 0.6) tweens a proxy {x, y, w, h} through one keyframe per step and writes it to the scene's viewBox in onUpdate. Keyframes are listed in the story section.
- Motion: Step activation: each step panel has a ScrollTrigger (start 'top 60%', end 'bottom 40%'); the active panel is opacity 1, inactive panels 0.3; the active reservoir in the scene gets a 3px Acid Lime outline glow that fades in over 400ms, and its row in the reservoir gauge highlights.
- Motion: Industrial era: a second scrubbed tween drives a value industry 0 to 1 across step 5; the fossil-burning flow's stroke width goes 1px to 7px, its particle count 3 to 40, its speed x3, and the year counter interpolates 1850 to 2025 (rounded to whole years).
- Motion: Counters: the atmosphere stock in step 6 counts 600 to 900 with the scroll (scrubbed, whole numbers, tabular-nums).
- Motion: Ledger bars grow from 0 to their width over 900ms (power2.out) with a 120ms stagger when the ledger enters the viewport (once).
- Motion: Scenario curve: dragging the slider interpolates the projection path between the two neighbouring scenario point arrays every input event; on release the thumb snaps to the nearest stop and the path tweens to that scenario over 500ms (power2.inOut) using the same interpolation. The readout number tweens with it; the sky tint variable --heat (0, 0.45, 1 for the three stops) tweens alongside.
- Motion: Buttons: hover lifts 2px and brightens 8%; press scales 0.97. FAQ items expand with a 280ms height transition and the plus icon rotates 45 degrees.
- Motion: prefers-reduced-motion: no camera tweens and no scrub. Each step snaps the viewBox to its keyframe instantly when it becomes active (stepped static scenes). Particles are not animated: each flow is drawn as a static dashed stroke with arrowheads, width scaled by value. Counters show their end values. Slider updates the curve instantly without tweening. Load fade-ins are removed.
- Imagery: No photographs and no bitmap images. Everything is drawn in code as flat, layered vector shapes with a visible grain: one SVG feTurbulence (baseFrequency 0.9, numOctaves 2) noise rect over the whole scene at 9% opacity with mix-blend-mode overlay, plus a CSS grain overlay on section backgrounds using the same SVG filter as a data URL. Shapes are poster-like: bold silhouettes, no outlines, at most three tones per object, no gradients except the sky and the ocean depth. Icons are Lucide at 20px, stroke 1.75, in Mist or the flow color. No mascots, no characters, no people, no recognizable landmarks or real facilities; the factory is a generic block with two chimneys.

## Don'ts
- No backend: no server code, API routes, databases, auth, analytics, third-party APIs, and no forms that submit anywhere (the corrections address is plain text).
- No CDN script or link tags; every font, icon and script is bundled locally. Never load fonts from fonts.googleapis.com, fonts.gstatic.com or any other font CDN; use the Fontsource packages listed.
- Production build must be minified, with no source maps and no src/ files copied into dist/; vite base must be './' so all asset paths are relative.
- Internal links are in-page anchors (#story, #ledger, #scenarios, #sources) or point to ./index.html; never link to a bare directory.
- Keep dist/ under 20 MB; no bitmap images at all.
- Must work at 1440x900 and 390x844 with zero console errors and no horizontal scroll; the slider must be fully usable by touch and keyboard.
- Respect prefers-reduced-motion with the stepped static fallback described in Design.
