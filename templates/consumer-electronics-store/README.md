- A camera and lens retailer: keep the Optic series framing, set STORE_NAME to your shop, and swap the spec filters for sensor size and lens mount.
- A refurbished phone seller: use the Phones category, set battery endurance as the lead filter, and rewrite the protection plan copy for your warranty terms.
- A smart home installer: rename the Smart Home category to your service bundles and link the support email to your installation help desk.
- An audio equipment shop: lean on the Acoustic series, keep the compare table for driver sizes, and change the deals page to seasonal bundle offers.

## FAQ

### How do I add a product comparison feature to an electronics store built with AI?
The Consumer Electronics Store template includes a compare route where shoppers pin up to three products and see a side-by-side table with highlighted best-in-class specs. To use it, add '+ Compare' pins on the category catalog, then adjust which spec rows appear in the comparison table. The comparison IDs persist in localStorage, so the selection survives page reloads.

### Can I sell products with this template or is it only a catalog?
The Consumer Electronics Store template is a storefront with a cart drawer, variant pricing, optional protection plans and a three-step mock checkout that creates a trackable order code. It does not connect to a payment processor or backend, so real sales need a separate checkout integration. It works as a product catalog and demo storefront for retailers and e-commerce teams.

### How do I change the store name, tagline and support email in the Consumer Electronics Store template?
Set STORE_NAME, TAGLINE and SUPPORT_EMAIL in the content file the prompt asks you to keep. The defaults are VoltGrid Hardware, 'Engineered Essentials. Zero Brand Markup.' and support@voltgrid.example. When your values differ, rewrite every headline, paragraph, label and image reference for them while keeping the same layout, colors, type and motion.

### What should I change first to make the Consumer Electronics Store template fit my retail business?
Start with the three variables: STORE_NAME, TAGLINE and SUPPORT_EMAIL. Then replace the invented product series, studio photos and spec tables with your own catalog data. Adjust the category mega menu to your actual departments, and update the seeded tracking order IDs and deals page so the storefront reflects your real ranges and promotions.

### How does the mock checkout and order tracking work in this electronics store template?
The Consumer Electronics Store template walks shoppers through Shipping, Delivery Speed and Review in a three-step checkout that is clearly labelled as a demo with no real payment. Placing an order creates a trackable code, and the tracking page is pre-seeded with two sample order IDs plus any new mock orders, each showing a four-stage fulfillment stepper. Placed orders persist in localStorage.

### How do I build a consumer electronics store with AI?
Copy the full prompt (Pro) from this page or run npx vibefather add consumer-electronics-store, replace [STORE_NAME], [TAGLINE] and [SUPPORT_EMAIL] with your own content, and paste it into Claude Code, Codex, Cursor or another AI coding agent. The live demos were built from exactly that text.
