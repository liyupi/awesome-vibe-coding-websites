# Private Tutor Website

> A personal tutoring site with subject guidance, sample progress, clear packages, and intro-call scheduling.

Private Tutor Website is a warm, credible one-person tutoring site for independent teachers who want their first impression to feel as thoughtful as their lessons. It gives families and adult learners one clear path through subjects and levels, the teaching process, sample progress, prices, availability, and a free introductory-call request. The experience is personal without relying on inflated claims: the tutor is visible, practical details are specific, and every sample outcome is labeled as illustrative.

The design combines an editorial serif with a crisp sans serif, chalk-white surfaces, midnight ink, periwinkle, and a restrained apricot accent. A spacious working portrait anchors the hero, while a consistent set of fictional tutoring photographs brings the teaching approach to life. Subject tabs and level rows make expertise easy to scan. Four process steps explain what happens before, during, and after a session. Package cards feed the visitor's selection into a rolling availability calendar, where choosing a day and time carries directly into the booking form.

The defaults introduce Mara Ellison Tutoring, an invented mathematics and physics practice for high school students in Cambridge, Massachusetts. Six variables change the brand, tutor, subjects, audience, location, and hourly rate; dependent lesson descriptions, packages, contact details, and calls to action are rewritten with them. The alternate case turns the same layout into a writing and study-skills practice. Filtering, calendar navigation, field validation, local draft persistence, and the confirmation state all run in the browser. No appointment is presented as real, making the finished site suitable for static hosting while providing a complete front-end foundation for a tutor's own booking workflow.

## Make it yours

- A solo SAT or ACT coach: set subjects to test prep, audience to juniors and seniors, and rewrite the sample progress rows around practice-test score bands rather than grades.
- A university writing center freelancer: keep the editorial layout, set subjects to essay craft and study skills, and swap the packages for single-session and term-length editing support.
- A music teacher offering lessons online: set subjects to piano and theory, adjust the hourly rate for 45-minute sessions, and rewrite the process steps around practice routines between lessons.
- An adult language tutor: set audience to working professionals, move location details to online-only copy, and reframe the intro-call form around a short level assessment.

## FAQ

### What sections does the Private Tutor Website template include for a one-person tutoring practice?
The Private Tutor Website template is a single-page site with a sticky header and mobile menu, a personal photographic hero, subject tabs with level-specific lesson content, four process steps, labeled sample student progress, package cards priced from the hourly rate, an interactive availability calendar, a free intro-call request form, and a dark footer. All sections live on one page.

### How do the package prices and the four-session total work in this tutoring template?
The Private Tutor Website template parses the amount and currency from the hourly rate variable and calculates the four-session total as exactly four times that amount. Default is $68 per 60-minute session, so the four-session package reads $272. Change the rate once and every dependent price and package description is rewritten from that single value.

### Can I change the subjects and audience from math and physics to something else?
Yes. The Private Tutor Website template exposes subjects and audience as variables, and changing them rewrites the subject tabs, the level rows, lesson descriptions, the tutor bio, sample outcomes, FAQs and calls to action. The alternate demo turns the same layout into a writing and study-skills practice, so you can see how far the copy shifts when the subject changes.

### Is the availability calendar on the Private Tutor Website template connected to a real booking system?
No. The Private Tutor Website template generates a rolling sample calendar in the browser and stores only the latest booking draft locally. Choosing a day and time carries into the intro-call form and ends in a confirmation state, but no appointment is presented as real. The finished site is a complete front end that a tutor can later connect to their own booking workflow.

### What should I change first when adapting the Private Tutor Website template to my own practice?
Set the brand, tutor name, subjects, audience, location and hourly rate first, since dependent copy, packages, contact details and the tutor time zone are rewritten from them. Then replace the four fictional photographs with your own teaching scenes and review the sample progress labels so every outcome stays clearly marked as illustrative.
