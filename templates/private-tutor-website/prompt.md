# Private Tutor Website

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
Build a polished single-page website for [BRAND], the invented one-person tutoring practice of [TUTOR_NAME], offering [SUBJECTS] to [AUDIENCE] in [LOCATION] and online. Combine subject and level guidance, a transparent teaching process, clearly labeled sample student progress, packages derived from [HOURLY_RATE], an interactive availability calendar, and a free intro-call request in one cohesive experience. Use the exact default copy below, but rewrite every subject, level, tutor bio, outcome, package description, availability detail, FAQ, and contact detail when variable values change.

- Audience: Students and families comparing a one-person tutor's subject fit, teaching style, likely commitment, cost, and availability before making an inquiry, plus independent tutors adapting the site to their own practice.
- Goal: Help a visitor move from initial interest to a suitable subject and a completed client-side free intro-call request with a selected sample date and time, while keeping all outcomes and availability explicitly illustrative.
- Tone: Warm, calm, intelligent, and practical. Write like a thoughtful tutor who explains the next step clearly. Use specific educational details, avoid pressure, and never promise grades, admissions, or guaranteed improvement.

## Stack
- Framework: Vite 5 + React 18 + TypeScript
- Styling: Tailwind CSS 3.4
- Libraries: react (MIT), react-dom (MIT), vite (MIT), tailwindcss (MIT), motion (MIT), lucide-react (ISC)
- Build: `npm run build` → static files in `dist/`. No backend, no server code, no external APIs.
- Setup:
  - Create a Vite React TypeScript app with base './' in vite.config, sourcemaps disabled, and npm run build producing static files in dist/.
  - Configure the Tailwind theme with the specified colors and font families; keep global keyframes, focus styles, reduced-motion overrides, and selection colors in src/index.css.
  - Self-host Lora through @fontsource-variable/lora and Manrope through @fontsource-variable/manrope; import only the required axes and weights.
  - Keep all visible copy, subject and level records, sample outcomes, prices, tutor details, FAQs, and contact information in src/content.ts. Derive content from [BRAND], [TUTOR_NAME], [SUBJECTS], [AUDIENCE], [LOCATION], and [HOURLY_RATE], and rewrite all dependent copy when values change.
  - Parse the numeric amount and currency symbol from [HOURLY_RATE], calculate the four-session total as exactly four times that amount, and format all dependent prices from one pricing helper rather than duplicating hard-coded totals.
  - Use Motion for React for reveals, subject-tab changes, mobile navigation, and form states; use Lucide icons rather than manually imitating any existing icon set.
  - Use accessible React components with semantic buttons, fieldsets, radio groups, labels, focus management, and aria-live for selected slots, validation summaries, and form confirmation. Store only the latest booking draft in localStorage.
  - Use America/New_York for the default tutor time zone and choose an appropriate IANA time zone in src/content.ts when [LOCATION] changes. Generate the rolling sample calendar locally without external APIs.

## Variables
- [BRAND] — Tutoring practice name (default: "Mara Ellison Tutoring"). An invented one-person practice name; never a real tutoring business or VibeFather.
- [TUTOR_NAME] — Tutor name (default: "Mara Ellison"). An invented tutor identity whose name is used consistently in the hero, biography, and contact copy.
- [SUBJECTS] — Subjects taught (default: "mathematics and physics"). Two or three related subjects; provide subject tabs and level-specific lesson content for each.
- [AUDIENCE] — Learner audience (default: "high school students preparing for exams"). A concise phrase describing who the tutor serves; adapt levels, examples, and parent guidance accordingly.
- [LOCATION] — Tutor location (default: "Cambridge, Massachusetts"). City and state or region used for in-person details and the tutor's local time-zone copy.
- [HOURLY_RATE] — Single-session price (default: "$68"). Price in USD for one private 60-minute session; calculate the four-session total from this value.
- [CREDIT] — keep a small "Template by VibeFather" link to https://vibefather.ai/t/private-tutor-website in the footer (default: yes; delete this line to remove it)

The copy under Pages & Sections is written for the default values. If your values differ, rewrite every headline, paragraph, label and image for them — same length, tone and structure. Layout, colors, type and motion stay as described.
Keep all copy, image paths and links in one content file (for example `src/content.ts`), keyed by section, so the content can be swapped later without touching components.

## Design
### Colors
- Chalk `#F7F4EC` — Main page background and quiet editorial sections
- Midnight `#172A3A` — Headlines, body text, borders, primary buttons, and dark footer
- Periwinkle `#5B6BB2` — Subject tabs, selected calendar states, links, and focus rings
- Apricot `#D89A3D` — Small notebook-inspired accents and highlight rules with Midnight text
- Mist `#DDE7E0` — Secondary panels, availability washes, and progress tracks
- Paper `#FFFDF8` — Cards, forms, image captions, and text on Midnight or Periwinkle

### Typography
- Display, tutor quotations, and section headlines: Lora (OFL), weights 500/600/700
- Body, navigation, prices, calendar, and forms: Manrope (OFL), weights 400/500/600/700

### Layout & motion
- Spacing: Use an 8px base grid, a 1240px maximum content width, 32px desktop gutters and 20px mobile gutters. Sections have 104px vertical padding on desktop and 68px on mobile. Use a 12-column desktop grid, 24px card gaps, and 32–48px internal padding for major interactive panels. Keep paragraphs near 62 characters per line.
- Radius: Use 20px card radii, 28px image-frame radii, 10px input radii, and fully rounded buttons and tabs. Major surfaces have a 1px Midnight border at 16% opacity and a restrained 0 12px 36px Midnight shadow at 6% opacity only on the booking panel.
- Motion: On hero load, rise the eyebrow and two headline lines 26px with a 600ms ease-out and stagger them by 80ms; settle the photograph from scale 1.035 to 1 over 850ms.
- Motion: Reveal section headings and card groups once with opacity 0 to 1 and y 22 to 0 over 500ms, staggered by 65ms; content remains visible if JavaScript or IntersectionObserver is unavailable.
- Motion: Crossfade and slide subject-level panels by 16px over 220ms, move the active tab underline with a layout transition, and preserve keyboard focus on the selected tab.
- Motion: Animate selected calendar slots with a 180ms background and border transition; expand the booking summary with opacity and height over 220ms without shifting the calendar unexpectedly.
- Motion: Use reduced-motion hooks and a prefers-reduced-motion CSS override to remove transforms, smooth scrolling, and nonessential transitions while preserving every final state.
- Imagery: Use the four supplied warm editorial documentary photographs as one coherent shoot featuring the same fictional tutor: chalk-white plaster, light oak, midnight-blue shelving, restrained periwinkle clothing, small apricot accents, soft late-afternoon window light, natural skin texture, and subtle 35mm grain. The hero is a spacious working scene rather than a tight face close-up. The tutor and any student are fictional people who do not resemble any real individual. Use no readable text, logos, famous landmarks, branded products, or real student imagery.

## Don'ts
- Do not add a backend, API routes, a database, authentication, analytics, external form submission, maps embeds, or third-party API calls. Calendar generation, local persistence, pricing calculations, validation, clipboard fallback, and confirmation must run entirely in the browser.
- Do not hotlink images or load scripts, fonts, icons, or styles from a CDN. Download the four supplied images, self-host both fonts, and keep every runtime asset local with relative paths.
- Do not emit source maps, copy src/ into dist/, exceed 20 MB in dist/, or require more than npm run build. The single-page site must open from index.html and use hash anchors rather than bare-directory links.
- Do not scatter copy through components. Keep all editable text and records in src/content.ts, derive brand-dependent values and package totals from variables, and rewrite all default-only content when variables change.
- Do not use real tutoring business names, logos, slogans, branded visual systems, existing-site copy, custom commercial fonts, or page code from another website.
- Do not use real tutor or student identities, celebrity or public-figure likenesses, recognizable real people, real testimonials, or initials-only tutor presentation. The tutor profile and all photographed people are fictional placeholders.
- Do not use Unsplash, Pexels, Pixabay, Google Images, CC BY-NC, CC BY-SA, placeholder-image services, or any asset with unclear redistribution rights. Do not add readable text, logos, famous landmarks, or branded products to generated imagery.
- Do not claim accreditation, verified student outcomes, guaranteed grades, admissions results, real review counts, or fabricated performance statistics. Keep every progress card and the availability calendar explicitly labeled as illustrative sample content.
- Do not imply that a real appointment has been booked or that personal information was transmitted. The confirmation must say that the request was saved only in this browser and nothing was sent.
- Do not leave decorative or dead controls. Subject tabs, level-to-form preselection, package-to-form synchronization, calendar navigation, disabled dates, time selection, Change time, mobile navigation, accordions, validation, local draft restore, copy, edit, and reset must all work.
- Do not use lorem ipsum, generic stock slogans, fake urgency, countdowns, unrelated brands, or VibeFather's own name, pricing, licensing, metrics, or membership content in the site UI.
- Do not compromise accessibility or responsiveness: no horizontal overflow at 390px, no hover-only information, no missing labels or alt text, no focus traps, no color-only calendar states, and no console errors at 390×844 or 1440×900.
- Do not ignore prefers-reduced-motion, hide core content behind animation, or add unnecessary 3D, parallax, autoplay carousels, looping decoration, or smooth scrolling that cannot be disabled.
