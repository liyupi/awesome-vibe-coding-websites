# Lo-fi Room Ambience Mixer

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
Build [BRAND], an original single-page ambience mixer set in [ROOM_NAME], [ROOM_SETTING]. The first screen is a rich hand-drawn SVG room with five independently controlled ambient channels: rain, café murmur, fireplace, vinyl crackle, and birds. Each slider changes both a bundled local audio loop and a corresponding part of the room. Include a focus timer whose default duration is [FOCUS_MINUTES] minutes, three presets, and named mixes saved in localStorage. The default invitation is '[ROOM_TAGLINE]'. Sound is opt-in; everything else works immediately without an account.

- Audience: Creators, students, developers, designers, and anyone building a quiet focus space, an interactive portfolio piece, or a polished browser toy for people who enjoy customizable ambient sound.
- Goal: Let visitors understand the experience within five seconds, shape a visible and audible atmosphere without instructions, start a focused work interval, and return to favorite mixes on the same device. Keep the room dominant and make every visible control perform a real local action.
- Tone: Warm, unhurried, concise, and lightly poetic without becoming whimsical or vague. Use practical control labels and small moments of hospitality. Make no medical, sleep, productivity, or mental-health claims.

  - Create scripts/generate-audio.mjs with no dependencies. Use a fixed seeded PRNG, 22050Hz mono 16-bit PCM, and 12-second loops. Generate public/audio/rain.wav from layered filtered noise and droplet ticks; cafe.wav from band-limited unintelligible murmur-like noise with soft cup and spoon ticks, never speech or music; fireplace.wav from low filtered noise and seeded crackle envelopes; vinyl.wav from restrained pink noise, dust pops, and subtle mechanical hiss; birds.wav from seven original sine-glissando chirp motifs over faint leaf noise. Apply short seam crossfades, normalize peaks below 0.82, write canonical WAV headers, and make repeated runs byte-identical. Commit the five generated files; together they should be about 2.6 MB.
  - Implement src/lib/audio.ts with one lazily created AudioContext. Only after an explicit Listen press, fetch and decode the five exact local WAV paths, create one looping AudioBufferSourceNode and GainNode per channel, connect them through a master GainNode capped at 0.7, and start playback. Sliders call setTargetAtTime for click-free gain changes. Mute preserves the prior nonzero value; Pause sounds suspends the context without losing levels. Handle loading and decode failures visibly and never autoplay.
  - Implement src/lib/storage.ts with safe JSON parsing, schema checks, try/catch around localStorage, and keys derived from a lowercase hyphenated BRAND slug. Persist current channel levels, mute states, and up to eight named custom mixes. Do not persist or display calendar dates. Timer state may reset on reload.
  - Drive RoomScene.tsx from React state and CSS custom properties for the five channel levels. Update SVG attributes and classes only when controls change; use CSS transforms and opacity for continuous motion rather than rerendering the SVG every animation frame. Honor prefers-reduced-motion with static rain, flame, steam, record, birds, and instant interface state changes.
  - Use performance.now() and an absolute end time for the focus timer, updating the visible remaining time four times per second. Pause stores remaining milliseconds, reset restores the selected duration, and switching duration while stopped updates the ring. Completion announces 'Session complete. Take a breath.' in an aria-live region and may play a short synthesized chime only when the visitor already enabled sound.

## Variables
- [BRAND] — Ambience space name (default: "Nooklight"). An invented short name used in the wordmark, document title, storage prefix, and footer.
- [ROOM_NAME] — Room name (default: "The Amber Study"). A specific invented name for this illustrated space.
- [ROOM_SETTING] — Room setting (default: "an upstairs reading room on a rainy evening"). A short lowercase phrase describing the room and moment.
- [ROOM_TAGLINE] — Hero invitation (default: "Make a little weather for your thoughts."). One gentle sentence of roughly 35–55 characters; rewrite it when the room changes.
- [FOCUS_MINUTES] — Default focus length (default: "25"). A positive whole number of minutes from 1 to 120; use it for the initial timer and middle duration preset.
- [CREDIT] — keep a small "Template by VibeFather" link to https://vibefather.ai/t/lo-fi-room-ambience-mixer in the footer (default: yes; delete this line to remove it)

The copy under Pages & Sections is written for the default values. If your values differ, rewrite every headline, paragraph, label and image for them — same length, tone and structure. Layout, colors, type and motion stay as described.
Keep all copy, image paths and links in one content file (for example `src/content.ts`), keyed by section, so the content can be swapped later without touching components.
