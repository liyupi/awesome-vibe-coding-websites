# WebGL Gradient SaaS Landing Page

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
A single-page marketing site for [BRAND], [PRODUCT] for [AUDIENCE]. Light and premium: an off-white canvas, a full-bleed hand-written WebGL mesh gradient hero that flows slowly and bends toward the cursor, glassy product panels drawn in code floating at different depths beside the headline, then an invented-customer logo marquee, a metrics band, a tabbed feature walkthrough, a platform bento, a testimonial carousel, three-tier pricing, an FAQ, a closing call to action on a second gradient and a dense footer.

- Audience: [AUDIENCE] evaluating a new tool: controllers, finance leads and CFOs at 50 to 1,000 person companies who compare vendors on trust, clarity and price. Secondary: founders and marketers who want to launch their own B2B product with this look.
- Goal: Get the visitor to start a free trial or book a demo. The hero states the promise, the floating panels show the product working, the metrics and testimonials prove it, and pricing plus FAQ remove the last doubts. Every call to action is an in-page anchor; nothing submits.
- Tone: Calm, confident, specific. Short declarative sentences, concrete numbers, no hype words, no exclamation marks, no emoji. Reads like software made by people who have run a month-end close themselves.

## Variables
- [BRAND] — Product or company name (default: "Fernway"). Shown in the header wordmark, hero subline, code sample, pricing, footer and <title>. One or two words.
- [BRAND_SLUG] — Lowercase slug for code and email (default: "fernway"). Used for the SDK package name (@[BRAND_SLUG]/sdk), the API key env var ([BRAND_SLUG] upper-cased with underscores + _API_KEY), the client variable and hello@[BRAND_SLUG].com.
- [PRODUCT] — What the product is (default: "month-end close automation"). Lower-case noun phrase used inside sentences. Drives the headline, all four feature tabs and every panel's data.
- [AUDIENCE] — Who it is for (default: "finance teams at growing companies"). Lower-case plural phrase. Drives the subline, testimonial roles, pricing seat names and metrics wording.
- [CREDIT] — keep a small "Template by VibeFather" link to https://vibefather.ai/t/webgl-gradient-saas-landing-page in the footer (default: yes; delete this line to remove it)

The copy under Pages & Sections is written for the default values. If your values differ, rewrite every headline, paragraph, label and image for them — same length, tone and structure. Layout, colors, type and motion stay as described.
Keep all copy, image paths and links in one content file (for example `src/content.ts`), keyed by section, so the content can be swapped later without touching components.

Uniforms: uTime (seconds), uRes (vec2 px), uMouse (vec2, 0..1 in uv space, y up), uStrength (float 0..1), uSeed (float), uBase #FFF1E4, uC0 #FF9E7A, uC1 #B39DFF, uC2 #8FD3FF, uC3 #FFE08A, uC4 #9EECD0 (convert hex to vec3 0..1 in mesh.ts from one exported palette array so colors change in one place). Vertex shader: pass uv as vUv, gl_Position = vec4(position, 0.0, 1.0). Fragment shader (write it this way, after the pasted snoise): float aspect = uRes.x / uRes.y; vec2 p = vec2(vUv.x * aspect, vUv.y); vec2 m = vec2(uMouse.x * aspect, uMouse.y); vec2 d = p - m; float fall = exp(-dot(d, d) * 3.2) * uStrength; p -= d * fall * 0.24; float t = uTime * 0.035 + uSeed; vec2 q = vec2(snoise(vec3(p * 0.9, t)), snoise(vec3(p * 0.9 + 4.7, t + 1.3))); vec2 w = p + q * 0.55; float n0 = snoise(vec3(w * 1.10, t * 1.2)); float n1 = snoise(vec3(w * 1.40 + 9.1, t * 0.9)); float n2 = snoise(vec3(w * 0.80 - 3.3, t * 1.1)); float n3 = snoise(vec3(w * 1.70 + 2.2, t * 0.7)); float n4 = snoise(vec3(w * 1.25 - 7.4, t * 0.8)); vec3 col = uBase; col = mix(col, uC0, smoothstep(-0.35, 0.65, n0)); col = mix(col, uC1, smoothstep(-0.10, 0.80, n1) * 0.90); col = mix(col, uC2, smoothstep(0.00, 0.85, n2) * 0.85); col = mix(col, uC3, smoothstep(0.15, 0.95, n3) * 0.70); col = mix(col, uC4, smoothstep(0.25, 1.00, n4) * 0.55); col += vec3(fall * 0.07); col = mix(col, vec3(1.0), 0.16 * (1.0 - smoothstep(0.0, 0.55, vUv.x))); float g = fract(sin(dot(gl_FragCoord.xy + fract(uTime) * 61.0, vec2(12.9898, 78.233))) * 43758.5453); col += (g - 0.5) * 0.018; gl_FragColor = vec4(col, 1.0); The swell (fall) is the 'bends toward the cursor' effect: the color field is pulled toward the pointer and brightened slightly around it. Pointer: listen to pointermove on window; target = pointer position relative to the gradient's parent rect, x = (clientX - left) / width, y = 1 - (clientY - top) / height. Each frame: mouse += (target - mouse) * 0.045; strength eases toward 1 while the pointer is inside the parent and toward 0 when it leaves (same 0.045 factor). Start with mouse at (0.7, 0.6) and strength 0. Touch or no fine pointer (matchMedia('(pointer: fine)') false): no listeners; the mouse target drifts on a slow Lissajous path, x = 0.5 + 0.28 * sin(time * 0.21), y = 0.55 + 0.2 * sin(time * 0.17), strength 0.6. ## Don'ts
- No backend of any kind: no server code, API routes, databases, auth, analytics or third-party API calls. No forms or email inputs; every call to action is an in-page anchor and the only outbound links are the mailto link and the optional [CREDIT] link.
- Do not load fonts from fonts.googleapis.com, fonts.gstatic.com, Adobe Fonts or any CDN. Fontsource packages only.
- No CDN <script> or <link> tags. ogl, motion and lucide-react are installed from npm and bundled.
- Production build: build.sourcemap false, no src/ copied into dist/, Vite base './' so every asset path is relative. Internal links point to in-page anchors or ./index.html, never to a bare directory.
- Do not change the stack (Vite 5 + React 18 + TypeScript, Tailwind CSS 3.4, OGL, Motion, Lucide) unless the user asks. No three.js, no other WebGL or shader library, no UI kit. The gradient is one hand-written fragment shader as specified; only the simplex noise function is pasted from webgl-noise (MIT).
- No real payments or SaaS company's logo, wordmark, product names or brand name anywhere, including the well-known fintech homepage this gradient style is associated with. Never call the site a clone or name a real company as its source.
- Do not reuse that company's gradient palette (no hot magenta, electric purple, saturated orange set), shader code, skewed straight-diagonal hero edge or its hero geometry, and no globe or signature illustration assets. Use only the pastel hues and the soft curved bottom edge specified here.
- No marketing copy, slogans or taglines from any real SaaS site. Write all copy fresh from this prompt.
- Every logo in the customer strip is an invented, code-drawn wordmark. No real customer logos, no Simple Icons, no brand icons. No real bank, card network, ERP or payroll brand names in panels, integration tiles or FAQ answers.
- No commercial or proprietary fonts (for example Söhne, Camphor or any custom brand typeface). Use only Instrument Sans, Inter and JetBrains Mono.
- No screenshots of real product dashboards. All UI panels are built in code with the invented data given here.
- No code from Aceternity UI, Tailwind Plus / Tailwind UI or purchased Framer or ThemeForest templates for the gradient, glass panels or floating-card effects; write every effect from scratch. Every dependency must be MIT, ISC, BSD, Apache-2.0, 0BSD, CC0, Unlicense or OFL-1.1 (fonts).
