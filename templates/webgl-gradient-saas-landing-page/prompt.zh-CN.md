# WebGL 渐变 SaaS 落地页

请完全按照以下描述构建此网站。将 [VARIABLES] 替换为你自己的值；其余内容保持不变。

## 简介
为 [BRAND] 打造的单页营销网站，[PRODUCT] 面向 [AUDIENCE]。轻盈而高级：米白画布，一个全出血的手写风 WebGL 网格渐变首屏，缓慢流动并随光标弯曲，代码绘制的玻璃质感产品面板以不同深度悬浮在标题旁，随后是虚构客户 logo 跑马灯、指标带、标签页式功能导览、平台 bento 布局、客户评价轮播、三档定价、FAQ、位于第二层渐变上的收尾行动号召，以及一个信息密集的页脚。

- 受众：正在评估新工具的 [AUDIENCE]：50 至 1,000 人公司的控制人、财务负责人和 CFO，他们从信任、清晰度和价格三方面比较供应商。次要受众：希望以这种视觉风格推出自有 B2B 产品的创始人和营销人员。
- 目标：让访客开始免费试用或预约演示。首屏陈述承诺，悬浮面板展示产品实际运行，指标和客户评价加以证明，定价加 FAQ 消除最后的疑虑。每个行动号召都是页内锚点；不提交任何内容。
- 语气：平静、自信、具体。简短的陈述句，具体的数字，不用炒作词汇，不用感叹号，不用 emoji。读起来像是由亲自跑过月末结账的人打造的软件。

## 技术栈
- 框架：Vite 5 + React 18 + TypeScript
- 样式：Tailwind CSS 3.4
- 库：react 18（MIT）、react-dom 18（MIT）、ogl（用于网格渐变的 WebGL 渲染器）（Unlicense）、motion（motion.dev，从 'motion/react' 导入）（MIT）、lucide-react（ISC）、@fontsource-variable/instrument-sans（OFL-1.1）、@fontsource-variable/inter（OFL-1.1）、@fontsource-variable/jetbrains-mono（OFL-1.1）、tailwindcss 3.4 + postcss + autoprefixer（MIT）、vite 5 + @vitejs/plugin-react（MIT）、typescript（Apache-2.0）、webgl-noise 3D simplex noise 代码片段，作者 Ian McEwan 和 Stefan Gustavson（粘贴的 GLSL，不是包）（MIT）
- 构建：`npm run build` → 静态文件输出到 `dist/`。无后端、无服务端代码、无外部 API。
- 设置：
  - 使用 react-ts 模板通过 npm create vite@latest 搭建脚手架。单页面：项目根目录的 index.html，入口为 src/main.tsx。使用 vite ^5、react ^18.3、react-dom ^18.3、tailwindcss ^3.4、ogl ^1.0，以及 motion 和 lucide-react 的当前版本。
  - vite.config.ts：base './'，plugins [react()]，build { outDir 'dist'，sourcemap false，emptyOutDir true }。不要将 src/ 复制到 dist/。package.json scripts：dev = vite，build = tsc -b && vite build，preview = vite preview。
