A living brand book for a fictional company, built so that a team could publish its own brand with it. A sidebar lists every section and a search jumps straight to a rule, such as clear space, contrast or easing. The logo page draws the mark in code and shows the lockups, clear space, minimum sizes and six misuse examples. The colour system gives every swatch a copy button and calculates contrast ratings live from the hex values. The type scale is a set of live specimens whose sample text can be edited, iconography shows the grid and stroke rules with do and don't pairs, and the imagery page demonstrates illustration and photography principles with duotone scenes drawn in code. Motion principles come with durations and easing curves that can be played, voice and tone pairs every don't with a do and includes a tone slider, and component previews show buttons, inputs, badges and alerts with their code. Templates are drawn to scale, and the downloads page produces real files in the browser: the logo as SVG and PNG, colour tokens as JSON and the type scale as CSS variables. Deep blue and electric yellow in light and dark modes. Swap the name, tagline and version in the content file and replace the mark with your own path; layout, palette and motion stay as described.

## Make it yours

- A design studio publishing its own identity: set BRAND to the studio name, rewrite the voice pairs for your tone and replace the mark path with your logo so the downloads page exports your files.
- A software company with a growing design system: keep the colour and component pages, swap the swatches for your product palette and point the component previews at your button, input and alert styles.
- A marketing team at a clinic or agency: set TAGLINE to your service line, rewrite the imagery principles for your photography and use the tone slider to show writers how formal or casual copy should read.
- A freelance brand designer delivering to a client: set VERSION to the handover label, fill the templates page with the client's stationery sizes and hand over the JSON tokens and CSS variables from the downloads page.

## FAQ

### What does the Brand Guidelines Website template include besides the logo page?
The Brand Guidelines Website template spreads a brand book across 11 pages: an overview, logo, colour, type, icons, imagery, motion, voice, components, templates and downloads. Each page holds a working tool rather than a static image. Colour swatches copy their hex values and calculate contrast ratings live, type specimens accept your own sample text, easing curves play, and component previews show buttons, inputs, badges and alerts with their code.

### How do I put my own logo and brand name into the brand guidelines site?
Set BRAND, TAGLINE and VERSION in the content file, then replace the mark with your own SVG path. The Brand Guidelines Website template draws the logo in code, so the lockups, clear space, minimum sizes and six misuse examples all update from that one path. The wordmark uses the display face, and every download file name picks up your brand through its slug.

### Can the brand guidelines site export real logo and colour files for my team?
Yes. The downloads page of the Brand Guidelines Website template produces files in the browser: the logo as SVG and PNG, colour tokens as JSON and the type scale as CSS variables. Nothing is sent to a server. Designers can hand engineers a token file, and marketers can grab a PNG without opening a design tool or asking for a rebuild.

### How does search work in the Brand Guidelines Website template?
The Brand Guidelines Website template builds a search index from the content file, covering every section and subsection with its title, keywords and route. Typing a rule such as clear space, contrast or easing jumps straight to that subsection and flashes it. A sidebar lists every section, so readers can also browse. Both the index and the sidebar read from the same content, so adding a rule keeps them in sync.

### Can I use the Brand Guidelines Website template for a client's brand book?
Commercial and client work needs Pro, and the Brand Guidelines Website template is a Pro template. Pro members see the full prompt and get the source code of the demos. Free prompts and every DESIGN.md are licensed for personal, non-commercial use only. Once you have Pro access, you can publish a client's brand book with their name, tagline and mark.
