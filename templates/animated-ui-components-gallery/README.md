## FAQ

### How do I add one of these animated components to my own landing page?
Open any card in the Animated UI Components Gallery, tune Speed, Intensity and Accent Color in the Workbench, then copy the clean React and Tailwind CSS snippet from the code tab. The snippet is production-ready and drops into a Vite, Next.js or any React project. If you would rather have an AI agent rebuild it, use the one-click Copy as Prompt button instead.

### Can I change the accent color and animation speed of the gallery itself?
Yes. The Animated UI Components Gallery ships with an electric violet accent (#7C5CFF) set through DEFAULT_ACCENT, and visitors can pick swatches or a custom color from the sticky header. The featured Workbench exposes Speed from 0.5× to 2.5× and Intensity from 20% to 100%, and every one of the 30 live previews responds to those settings immediately.

### What is the ⌘K command palette in this gallery and how does it work?
The Animated UI Components Gallery includes a keyboard-accessible command palette that opens with ⌘K. It lets you jump straight to any of the 30 components without scrolling the grid, and it sits alongside the search bar and 6 category filters. It is built for the way developers actually browse a component library: type a name, hit enter, land on the live demo.

### Can I use the Animated UI Components Gallery for client work or a commercial product?
Commercial and client use of the Animated UI Components Gallery needs Pro. The template is a Pro template: the brief, stack and variables are public, the full prompt and the demo source code come with Pro membership. Free prompts and every DESIGN.md on VibeFather are licensed for personal, non-commercial use only.

### How do I install the Animated UI Components Gallery and what do I edit first?
Run npx vibefather add animated-ui-components-gallery to pull it into your project, then set BRAND, TAGLINE and DEFAULT_ACCENT to your own values. The default brand is KineticKit with the tagline about 30 animated React and Tailwind components. After that, rewrite the hero copy and category labels, and keep the copy in one content file so it stays easy to swap.

### How do I build an animated UI components gallery with AI?
Copy the full prompt (Pro) from this page or run npx vibefather add animated-ui-components-gallery, replace [BRAND], [TAGLINE] and [DEFAULT_ACCENT] with your own content, and paste it into Claude Code, Codex, Cursor or another AI coding agent. The live demos were built from exactly that text.

### Which AI model built the Animated UI Components Gallery demo?
The KineticKit (Electric Violet #7C5CFF) case was built by Gemini 4 Neon in Antigravity; the MotionForge (Cyber Cyan #00D4FF) case was built by GPT-6.2 Sol in Codex. Each build used the published prompt with nothing added, so you can compare the models side by side.

### What tech stack and pages does the Animated UI Components Gallery template use?
Animated UI Components Gallery is a single-page site built with React and Tailwind CSS, with text animation, cursor effects and micro-interactions. The prompt fixes the stack so every AI tool builds the same kind of project, and the result runs as a static site you can host anywhere.

### Is the Animated UI Components Gallery template free to use?
Animated UI Components Gallery is a Pro template: the brief, stack and variables are public, and the full prompt, the source code of the live demo and a commercial license come with VibeFather Pro. Its DESIGN.md is free for personal projects.

### Does the Animated UI Components Gallery template work on mobile?
Yes. Every Animated UI Components Gallery build was tested on a phone-sized screen as well as desktop before it went live, checking layout, text size and touch targets. Open the live demo on your phone, or switch the preview on this page to mobile view, to check it yourself.
