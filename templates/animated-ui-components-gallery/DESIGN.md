# Animated UI Components Gallery — Design System

Apply this design system to an existing project. It describes the look and feel only; for the full site, use prompt.md.

## Colors
- **Obsidian Canvas** `#0A0A0B` — Primary near-black studio backdrop
- **Carbon Surface** `#131317` — Component card wells, workbench stage, and ⌘K modal
- **Neutral Hairline** `#27272F` — Crisp 1px dark studio borders and dividers
- **Studio Chalk** `#FAFAFB` — High-contrast headings and Light preview surface
- **Electric Violet** `#7C5CFF` — Default visitor-changeable accent color across all 30 live demos

## Typography
- **Brand Wordmark & Component Titles** — Space Grotesk (OFL), weights 500/600/700. Self-host the font files.
- **Descriptions, Filters & Controls** — Inter (OFL), weights 400/500/600. Self-host the font files.
- **Code Snippets, Props Readouts & ⌘K Shortcuts** — JetBrains Mono (OFL), weights 400/500/600. Self-host the font files.

## Spacing & shape
- Spacing: Compact sticky top command bar with live accent picker and ⌘K button, immediately followed by the interactive Featured Component Workbench above the fold and the 30-item live bento gallery grid below.
- Radius: 14px studio component wells with crisp 1px neutral borders; full-pill category tabs and accent swatches.

## Motion
- Every single one of the 30 components runs its own real interactive CSS/React animation responding to pointer hover, click, drag, and live Speed/Intensity/Accent controls.
- Live CSS custom properties propagate accent color and speed changes instantly with zero jank.
- Respect prefers-reduced-motion by pausing continuous ambient loops while preserving interactive state transitions.

## Imagery
100% live code-rendered interactive React, CSS, and SVG component demos—zero stock photos or external assets.

## Tone
Razor-sharp developer studio—restrained near-black chrome letting every glowing interactive component steal the spotlight.
