# Swiss Design Agency Portfolio

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
A two-page portfolio site for [BRAND], a small design studio in [CITY] working in [DISCIPLINE]. It is built strictly in the Swiss International Typographic Style: a visible 12-column grid, oversized grotesk headlines set flush-left and ragged-right, a red/black/white palette, hairline rules and numbered everything. The home page (index.html) introduces the studio and lists six numbered case studies as ruled rows. The case-study page (case-study.html?p=01 … ?p=06) renders any project from the content file. Clicking a project row morphs its number and title into the case-study hero through cross-document View Transitions, with a red full-screen wipe as the fallback. All imagery is geometric SVG drawn in code.

- Audience: Prospective clients of [BRAND] (cultural institutions, transit authorities, publishers, festivals) who want proof of rigour, plus designers browsing the studio's work.
- Goal: Make the studio's discipline visible at first glance and get visitors to open a case study, then write to [CONTACT_EMAIL].
- Tone: Precise, calm, confident and factual. Short declarative sentences, numbers over adjectives, no exclamation marks, no marketing superlatives.

- [CONTACT_EMAIL] — Contact email (default: "studio@ostrand.example"). Shown as a mailto link in the contact section and footer. Use a .example domain for demos.
- [CREDIT] — keep a small "Template by VibeFather" link to https://vibefather.ai/t/swiss-design-agency-portfolio in the footer (default: yes; delete this line to remove it)

The copy under Pages & Sections is written for the default values. If your values differ, rewrite every headline, paragraph, label and image for them — same length, tone and structure. Layout, colors, type and motion stay as described.
Keep all copy, image paths and links in one content file (for example `src/content.ts`), keyed by section, so the content can be swapped later without touching components.

## Design
### Colors
- Paper `#FFFFFF` — Page background, text on red and black blocks
- Ink `#111111` — All text, hairline rules (1px), black blocks, contact/footer background
- Signal Red `#E62314` — Row hover fill, case-study numerals, principles band, art accents, wipe panel, focus ring on dark
- Grid Tint `rgba(230,35,20,0.08)` — Grid overlay column fill only (with 1px rgba(230,35,20,0.35) column edges)

### Typography
- Display: hero, section headlines, project titles, numerals, wordmark: Inter Tight Variable (OFL), weights 500/700/800
- Text: body copy, nav, lists: Inter Variable (OFL), weights 400/500
- Captions: section labels like (02), meta labels, figure captions, small footer lines: IBM Plex Mono (OFL), weights 400/500

### Layout & motion
- Spacing: 8px base unit. Section padding-block 160px desktop / 96px mobile. Header 56px tall desktop, 48px mobile. Project rows 112px tall desktop (padding-block 32px), auto with 20px padding on mobile. Type scale: hero clamp(4rem, 14.5vw, 15rem) weight 800, line-height 0.84, letter-spacing -0.045em. Section headline clamp(2.5rem, 6vw, 6rem) weight 700, line-height 0.9, letter-spacing -0.035em. Row title clamp(1.5rem, 3vw, 2.75rem) weight 700, letter-spacing -0.02em. Case numeral clamp(7.5rem, 24vw, 22.5rem) weight 800, line-height 0.8, letter-spacing -0.05em. Body Inter 17px/1.45 desktop, 16px mobile, max 60ch. .caption = IBM Plex Mono 500, 12px, line-height 1.3, uppercase, letter-spacing 0.04em. All text flush-left, ragged-right; numerals use font-variant-numeric: tabular-nums.
- Radius: 0 everywhere. No rounded corners on anything, including buttons, focus rings and art.
- Motion: Headline line reveal: headlines are stored as arrays of lines and rendered as <span class="line" style="display:block;overflow:hidden"><span class="line-inner" style="display:block">…</span></span>. Under html.js, .line-inner starts at translateY(105%). When the headline enters the viewport (Motion inView, amount 0.4, once), animate each inner to translateY(0) over 700ms, ease [0.22, 1, 0.36, 1], stagger 70ms. The hero plays on load after 100ms.
- Motion: Rule draw: elements with data-reveal="rule" (1px ink hairlines) start at transform scaleX(0) with transform-origin left and animate to scaleX(1) over 600ms, ease [0.65, 0, 0.35, 1], when in view. Project-row top rules stagger 60ms down the list.
- Motion: Fade-up: captions and paragraphs with data-reveal="fade" go from opacity 0, translateY(16px) to opacity 1, 0 over 500ms, ease-out, when in view.
- Motion: Figure clip: art blocks with data-reveal="clip" go from clip-path inset(0 0 100% 0) to inset(0 0 0 0) over 900ms, ease [0.76, 0, 0.24, 1], when 25% visible.
- Motion: Row hover (pointer devices): background ink→signal transition 150ms linear, all text turns paper, the arrow SVG rotates from 0deg to -45deg over 200ms, and the number translates 8px right. :focus-visible gets the same state plus a 2px ink outline inset by -2px.
- Motion: Cross-document page transition (home ↔ case, case → next case): @view-transition { navigation: auto; }. The clicked link's [data-vt=num] and [data-vt=title] elements receive view-transition-name proj-num and proj-title. The case hero numeral and title carry the same names, so they morph. ::view-transition gets background #E62314 so a red field shows between pages. ::view-transition-old(root) fades out over 250ms ease. ::view-transition-new(root) animates clip-path inset(100% 0 0 0)→inset(0) over 600ms cubic-bezier(0.65,0,0.35,1) with a 150ms delay. ::view-transition-group(proj-num) and (proj-title) animate over 600ms cubic-bezier(0.65,0,0.35,1). Their old/new images use height:100%; width:auto; object-position:left top, and old fades out in the first 40% while new fades in from 30% to 100%.
- Motion: Fallback wipe (when 'onpageswap' in window is false): a fixed #wipe div (inset 0, background #E62314, z-index 100, pointer-events none, clip-path inset(100% 0 0 0)). On an internal link click with data-transition, preventDefault, set sessionStorage 'gridline:wipe' = '1', animate the panel with Motion to clip-path inset(0 0 0 0) over 420ms, ease [0.76, 0, 0.24, 1], then set location.href. On page load, if the flag is set, start the panel at inset(0) and animate it to inset(0 0 100% 0) over 480ms with the same ease, then remove the flag.
- Motion: Grid overlay toggle: the overlay fades opacity 0↔1 over 200ms.
- Motion: prefers-reduced-motion: reduce: skip every reveal (elements render in their final state), set @view-transition { navigation: none; } inside the media query, never run the wipe, and remove the hover rotation and translation (the colour change stays). No smooth-scroll library and no scroll hijacking; anchors use native CSS scroll-behavior: smooth, disabled under reduced motion.
- Imagery: No photographs and no people. Every image is a flat geometric SVG composition from src/art.ts, built only from paper, ink and signal red: bars, circles, rings, arcs, dot grids and giant letterforms on a 12×8 module of 100 units inside a 1200×800 viewBox. No strokes thinner than 8 units, no gradients, no shadows, no textures. Arrows are inline SVG lines (stroke 2px, square caps, currentColor). Variant a: paper background, ink elements, one red element. Variant b: red background, paper and ink elements. Variant c: ink background, paper elements, one red element.

## Don'ts
- No backend of any kind: no server code, API routes, databases, auth, analytics or third-party APIs. The contact is a plain mailto link and there are no forms.
- Do not load fonts from fonts.googleapis.com, fonts.gstatic.com, Adobe Fonts or any CDN. Self-host via Fontsource only.
- No CDN <script> or <link> tags. Every script, font and asset is bundled locally.
- No source maps in the production build (build.sourcemap false), and do not copy src/ into dist/.
- Use base './' and relative asset paths. Every internal link points to a file name (./index.html, ./index.html#work, ./case-study.html?p=02), never to a bare directory or /.
- Keep dist/ under 20 MB, with zero console errors at 1440×900 and 390×844.
- Respect prefers-reduced-motion: no reveals, no view transitions, no wipe, no hover transforms.
- Do not change the stack (Vite + vanilla TypeScript + Tailwind CSS 3.4 + Motion) unless the user asks. Do not add React, Lenis, GSAP or any smooth-scroll or scroll-hijacking library.
- Use no colours other than #FFFFFF, #111111 and #E62314 (plus the 8% red grid-overlay tint). No greys, no opacity-faded text, no gradients, no shadows, no blur, no rounded corners.
- Do not centre body text or headlines. Everything is flush-left and ragged-right, and every element is placed on the 12-column (mobile 4-column) grid via col-start/col-span.
- Do not use any real agency's name, logo, wordmark or slogan, and no real client names or real case-study copy. All brands, clients, projects, quotes and numbers are invented.
- No commercial grotesks (Helvetica, Helvetica Neue, Neue Haas Grotesk, Akzidenz-Grotesk, Univers) anywhere, including as named CSS fallbacks. Use Inter Tight, Inter and IBM Plex Mono only, with Arial/sans-serif as generic fallbacks.
- Do not reproduce real Swiss posters or Josef Müller-Brockmann artwork or compositions. Use only the geometric compositions specified in Assets.
- No stock photography, no bitmaps of people or faces, no placeholder-image services, no hotlinked files.
- No third-party icon sets or brand logos. Only the code-drawn arrows, numerals and squares described here.
- Do not copy code or exact layouts from any existing agency site, or source from Aceternity UI, Tailwind Plus/Tailwind UI or purchased templates.
- No SEO extras: no meta descriptions, Open Graph tags, JSON-LD or sitemaps. Only a plain <title> and the SVG favicon.
- Do not mention VibeFather anywhere in the site except the optional credit link from the Credit section.
- Do not scatter copy across files. All text lives in src/content.ts, and the copy there must be rewritten when the variable values differ from the defaults.
