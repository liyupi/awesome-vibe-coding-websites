# Design System Guidelines Deck — Design System

Apply this design system to an existing project. It describes the look and feel only; for the full site, use prompt.md.

## Colors
- **Swiss White** `#FFFFFF` — Primary pure gallery slide canvas
- **Carbon Ink** `#141414` — Primary display typography, Swiss grid rules, and specimen anchors
- **Signal Vermilion** `#E63946` — Architectural accent, active rulers, curve highlights, and primary markers
- **Cool Gray** `#E5E7EB` — Hairline grid borders and neutral token panels
- **Graphite Muted** `#52525B` — Token annotations and caption text

## Typography
- **Architectural display headings** — Space Grotesk (OFL), weights 500/600/700. Self-host the font files.
- **Specimen body copy and UI labels** — Inter (OFL), weights 400/500/600/700. Self-host the font files.
- **CSS tokens, hex values, px rulers, and bezier coordinates** — JetBrains Mono (OFL), weights 400/500/600. Self-host the font files.

## Spacing & shape
- Spacing: Crisp 16:9 Swiss typographic grid with generous 54px cover headline paired with a carbon architectural token specimen block.
- Radius: 16px for slide stage, 8px for sharp Swiss token specimens, 999px for state pills.

## Motion
- Live interactive SVG cubic-bezier motion preview ball on the Motion slide.
- Tactile swatch copy badge and component state switcher transitions.
- Respects prefers-reduced-motion; all content visible immediately.

## Imagery
100% live code-drawn Swiss UI specimens: clickable color token matrix, interactive typography scale, spacing & radius rulers, live UI controls, and SVG bezier curves.

## Tone
Architectural, Swiss rationalism, razor-sharp precision.
