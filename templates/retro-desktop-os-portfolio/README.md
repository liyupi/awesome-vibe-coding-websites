# Retro Desktop OS Portfolio <sup>PRO</sup>

> A fictional 90s-style desktop OS portfolio with draggable windows, a start menu and looping motion previews.

Pixelshell is a portfolio template built as a fictional desktop operating system from the late nineties. It is made for motion designers who want visitors to play with the site before they read it. A short typed boot log gives way to a teal-gray desktop with a column of pixel icons, a taskbar with a live clock, and cream windows with chunky warm-gray bevels. You drag windows by their title bars. Clicking a window brings it to the front and dims the others. Windows minimize to the taskbar and maximize on a double-click. The start menu has About, Work, Showreel, Contact, a wallpaper switcher and a shut-down item that ends on a goodbye screen.

The Work window is a file browser with six projects. Each one opens in its own window with a looping preview drawn in CSS, SVG or canvas: sine-wave title cards, orbiting shapes, bouncing type, easing curves side by side, a rotating grid and equalizer bars. None of them is a video file, so the build stays small and you can restyle every loop in code. A showreel window plays all six in turn, and you can empty the Scraps bin after a small confirmation dialog.

The template suits motion designers, animators, illustrators and creative developers who want a personal site people remember that still reads quickly. The palette is muted teal and cream with one tangerine accent. Titles use Pixelify Sans, tiny labels use Silkscreen and body text uses IBM Plex Mono. It uses no real operating system's logos, palettes or icons.

To adapt it, change the brand, name, discipline, city and email, then rewrite the project list in the single content file. To swap a preview, replace one small component. On phones the desktop turns into a stacked list of accordion windows above a fixed taskbar. Visitors who prefer reduced motion skip the boot and see still frames.

## Make it yours

- A freelance animator: set BRAND to your studio name, DISCIPLINE to animator, and replace the six Work projects with your reel pieces so each opens its own looping preview window.
- A creative developer: keep the desktop metaphor, point CONTACT_EMAIL at your inbox, and rewrite the About window to describe the tools and effects you build with.
- An illustrator: swap the motion loops for drawn previews, set CITY and OWNER_NAME, and reword the start menu labels to match a sketchbook-style body of work.
- A small design studio: set BRAND to the studio, list team work in the Work browser, and use the Showreel window to play the whole portfolio in sequence.

## FAQ

### What can visitors actually do on the Retro Desktop OS Portfolio?
Visitors watch a short typed boot log, then land on a teal-gray desktop with pixel icons and a taskbar clock. They can drag windows by their title bars, click to bring one to the front, minimize windows to the taskbar, double-click to maximize, and open a start menu with About, Work, Showreel, Contact, a wallpaper switcher and a shut-down item that ends on a goodbye screen.

### How do the project previews work if they aren't videos?
The Retro Desktop OS Portfolio draws all six project previews as loops in CSS, SVG or canvas: sine-wave title cards, orbiting shapes, bouncing type, easing curves side by side, a rotating grid and equalizer bars. No video files ship with the build, so the page stays light, and you can restyle any loop by editing the small component that draws it.

### How do I change the name, role, city and email in the Retro Desktop OS Portfolio?
Set the five variables in the Retro Desktop OS Portfolio: BRAND becomes your studio or shell name, OWNER_NAME your name, DISCIPLINE your role, CITY your city and CONTACT_EMAIL your address. Then rewrite the copy in the single content file so the About text, project list, boot log lines and dialog text match the new person and discipline, keeping the same lengths and structure.

### Can I use the Retro Desktop OS Portfolio for a client project?
The Retro Desktop OS Portfolio is a Pro template, so commercial and client use is covered by Pro membership. ### What should I change first after adding the Retro Desktop OS Portfolio?
Start with the five variables, then rewrite the content file: the six projects in the Work file browser, the boot log lines, the Scraps bin notes and the confirmation dialog text. After that, swap any preview loop you want to replace and adjust the palette in the Tailwind theme if the muted teal, cream and tangerine accent don't suit your work.
