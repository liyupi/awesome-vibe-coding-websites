# University Admissions Website

> A confident admissions site with a program finder, cost estimator, and visit-day sign-up.

University Admissions Website is a confident one-page recruiting site for a fictional university, built around two working tools: a program finder and a cost-and-aid estimator. The finder filters eleven invented programs by level, area, and format with a live results count and a shortlist you can toggle; the estimator turns two sliders — family contribution and living arrangement — into a clearly labeled sample net price with a stacked cost bar. A campus-life photo strip, an apply-review-decide timeline with round deadline labels, and a visit-day sign-up saved in the browser complete the page.

Visually it trades crests for confidence: a strong typographic wordmark set in Fraunces, deep collegiate blue over warm stone and parchment, brass accents, near-square editorial corners, and one photographic set of golden-hour campus scenes — quads, arches, a riverwalk, studios — with people only distant and seen from behind. The hero anchors on a full-bleed quad photograph under a navy scrim.

The template suits admissions offices, small colleges, conservatories, and training institutes — anywhere a program catalog, a transparent cost story, and visit scheduling drive applications. It adapts to any catalog-driven institution by swapping the program records and filter vocabularies in one content file.

Variables cover the university, location, audience, and signature strength. The estimator math, program list, timeline copy, and visit slots are specified exactly, so two builds from the same prompt land on the same site: a static Vite + React + Tailwind build with Motion transitions, self-hosted fonts, generated photography, and localStorage for the shortlist and visit request. No real institutions, no calendar dates, no aid promises — invented samples, clearly labeled.

| `[LOCATION]` | Location | Millhaven, Vermont |

| `[SIGNATURE_STRENGTH]` | Signature strength | freshwater science and sustainability studies |

1. Copy [prompt.md](prompt.md), or run `npx vibefather add university-admissions-website` in your project.
2. Replace the `[VARIABLES]` with your own brand, copy and details.
3. Paste it into Claude Code, Codex, Cursor or another AI coding agent and let it build. [DESIGN.md](DESIGN.md) holds the colors, type and spacing on their own if you only want the look.

## Make it yours

- A small liberal arts college: set BRAND and LOCATION to your campus, rewrite the eleven program records for your majors and keep the cost estimator with your published figures.
- A music conservatory: point SIGNATURE_STRENGTH at performance and composition, replace the program levels with instrument and degree tracks, and swap the campus photo strip for rehearsal and recital hall scenes.
- A training institute for adult learners: set AUDIENCE to career changers, filter programs by part-time and online formats, and relabel the timeline rounds for rolling admission.
- A graduate school: narrow the program finder to master's and doctoral areas, adjust the estimator sliders for assistantships and housing, and keep the visit-day sign-up for open house requests.

## FAQ

### What does the University Admissions Website template include besides the hero?
The University Admissions Website template is a one-page admissions site with a program finder that filters eleven invented programs by level, area and format with a live results count and a toggleable shortlist, a cost-and-aid estimator that turns family contribution and living arrangement sliders into a labeled sample net price with a stacked cost bar, a campus-life photo strip, an apply-review-decide timeline with round deadline labels, and a visit-day sign-up saved in the browser.

### How do I change the programs and filters in the program finder?
All eleven program records and the filter vocabularies live in one content file, so you swap the program names, levels, areas, formats and one-liners there and the finder rebuilds around them. The same file holds the estimator constants, timeline copy, visit-day slots and brand strings, so a college, conservatory or training institute can replace the invented catalog without touching the layout.

### Is the cost estimator on this admissions site real financial aid information?
No. The cost-and-aid estimator on the University Admissions Website template uses clearly invented sample figures and a specified formula to show a labeled sample net price, not a real aid offer. The template states no real institutions and no aid promises, so an admissions office adapting it should replace the figures with its own published numbers and keep the sample label visible.

### What should I change first to make this admissions template my own college?
Start with the four variables: set BRAND to your institution name, LOCATION to your town and state, AUDIENCE to the applicants you serve, and SIGNATURE_STRENGTH to what you are known for. The crest-free wordmark, storage keys and slugs derive from BRAND, so changing it first avoids leftover default-brand text in the header, footer and saved visit requests.

### Where is the visit-day sign-up stored, and does it need a backend?
The visit-day sign-up on the University Admissions Website template is saved in the visitor's browser with localStorage, namespaced to the brand slug, and the shortlist is stored the same way. The build is static Vite with React and Tailwind CSS, with no backend and no external APIs, so a real admissions office would connect the saved request to its own form or scheduling system.

### How do I build an university admissions website with AI?
Copy the prompt from this page or run npx vibefather add university-admissions-website, replace [BRAND], [LOCATION], [AUDIENCE] and [SIGNATURE_STRENGTH] with your own content, and paste it into Claude Code, Codex, Cursor or another AI coding agent. The live demos were built from exactly that text.
