# First-Person Ski Run Game — Design System

Apply this design system to an existing project. It describes the look and feel only; for the full site, use prompt.md.

## Colors
- **Fresh Powder** `#F7FBFF` — Sunlit snow terrain, highlights, and clean HUD cards
- **Glacier Blue** `#7EC8E3` — Alpine sky, icy accents, ghost trail, and speed gauges
- **Alpine Pine** `#1F4D3A` — Instanced evergreen tree runs and deep forest accents
- **Summit Slate** `#0F2233` — Frosted translucent HUD chrome and high-contrast typography
- **Blue Piste** `#2563EB` — Beginner Glacier Cruiser piste markers and gates
- **Red Piste** `#E11D48` — Intermediate Timber Ridge piste markers and gondola cabins
- **Black Diamond** `#18181B` — Expert Ice Chute markers and steep chute warnings

## Typography
- **Mountain Title, Speed Readout & Trick Callouts** — Barlow Condensed (OFL), weights 600/700/800. Self-host the font files.
- **Controls, Trail Map & Run Summary** — Inter (OFL), weights 400/500/600. Self-host the font files.
- **Stopwatch, Vertical Meters & Gate Splits** — JetBrains Mono (OFL), weights 500/600/700. Self-host the font files.

## Spacing & shape
- Spacing: Full-bleed 100dvh Three.js alpine viewport with compact frosted-glass top telemetry bar, unobtrusive summit launch pill on frame one, and responsive bottom control strip (plus mobile left/right/tuck/jump touch pads).
- Radius: 14px frosted summit HUD cards; full-pill Blue/Red/Black piste selector badges.

## Motion
- Dynamic first-person camera roll leaning into carved edges, subtle pitch drop when tucking, and exhilarating airborne arc off freeride kickers.
- Overhead gondola cabins continuously glide along tensioned steel cables above the piste while snow sparkles shimmer in morning light.
- Carving edge turns kick up curved plumes of procedural snow spray particles.
- Respect prefers-reduced-motion by softening camera roll and particle density while preserving full skiability.

## Imagery
100% procedural Three.js 3D alpine terrain, snow-capped horizon peaks, instanced pine trees, red gondola cabins, wooden valley chalets, glowing cyan ghost skier, and a crisp code-drawn SVG trail map.

## Tone
Crisp, sunlit alpine athleticism—fresh mountain air, clean glacier-blue telemetry, and unmistakable Blue/Red/Black piste markings.
