# 3D 照片画廊

完全按照以下描述构建此网站。将 [VARIABLES] 替换为你自己的值；其余内容保持不变。

## 简介
为 [BRAND] 打造的一场沉浸式在线展览：二十四张真实的公共领域照片以装裱平面的形式，悬挂在 WebGL 中一条无尽的黑暗走廊两侧。访客可滚动、拖拽或滑动来前进和后退；走廊首尾相接，因此行走永无止境。作品被分为四个具名展厅（[ROOMS]），每个展厅都由一个悬浮于黑暗中的巨大斜体展厅标题来宣告。点击一张照片，相机会飞升至该照片处，并打开一个带信箱式黑边的详情视图，其中包含完整的图注、来源与授权信息；从那里，一个 2D 灯箱可展示完整图像并支持缩放。一层纤细的 HUD 框住屏幕：品牌、当前展厅、滚动作品计数器、进度轨道，以及 Index 与 About 面板。单页，无后端，每张图像都下载到项目中并注明来源。

- 受众：小型摄影档案馆或博物馆的访客，他们希望慢慢浏览一个收藏系列；此外还有摄影师、策展人和档案馆，他们正在寻找一种令人难忘的方式来展示一组 15–40 张图像。
- 目标：让浏览一个收藏系列感觉像走过一间安静的画廊，同时每张图像都保持恰当的图注与来源信息：标题、创作者、日期、工艺、收藏与授权，一键可达。
- 语调：安静、精确且具策展气质。简短的事实性图注，不使用感叹号，不使用营销语言。标签读起来像博物馆墙上的说明文字。

## 技术栈
- 框架：Vite 5 + TypeScript + three.js
- 样式：原生 CSS，自定义属性
- 库：three（MIT）、@types/three（开发依赖）（MIT）、vite（MIT）、typescript（Apache-2.0）、@fontsource/cormorant-garamond（OFL-1.1）、@fontsource-variable/hanken-grotesk（OFL-1.1）、@fontsource/ibm-plex-mono（OFL-1.1）
- 构建：`npm run build` → 静态文件输出到 `dist/`。无后端、无服务端代码、无外部 API。
- 初始化：
  - 使用 npm create vite@latest 以 vanilla-ts 模板搭建脚手架。不使用 UI 框架。单页面：index.html 加 src/main.ts。
  - vite.config.ts：base './'，build { outDir: 'dist', sourcemap: false, assetsInlineLimit: 0 }。不要将 src/ 复制到 dist/。
  - 文件布局：src/content.ts（品牌字符串、房间、24 件作品及其全部说明字段、About 文案）、src/scene/（Renderer.ts、CameraRig.ts、Corridor.ts、WorkPlane.ts、RoomTitle.ts、Dust.ts、shaders.ts）、src/ui/（Loader.ts、Hud.ts、Panel.ts、Detail.ts、Lightbox.ts、Cursor.ts、Fallback.ts）、src/styles.css。
  - 字体：在 src/main.ts 中导入 '@fontsource/cormorant-garamond/400-italic.css'、'@fontsource/cormorant-garamond/500-italic.css'、'@fontsource/cormorant-garamond/500.css'、'@fontsource-variable/hanken-grotesk' 以及 '@fontsource/ibm-plex-mono/400.css'、'@fontsource/ibm-plex-mono/500.css'。在绘制任何 canvas 文本之前，先 await document.fonts.load 加载 'italic 400 64px "Cormorant Garamond"' 和 '400 32px "IBM Plex Mono"'。
  - 24 张照片存放在 public/photos/ 下，文件名与 Assets 中的完全一致，并以相对路径引用（'./photos/01-effect-of-the-sun.jpg'）。构建前在项目根目录写入 ASSETS.md。
  - 所有颜色以 CSS 自定义属性形式定义在 src/styles.css 的 :root 上；相同的十六进制色值从 src/content.ts 或一个小的 src/theme.ts 导入到 three.js 代码中。
  - dist/ 包含 index.html、带哈希的 JS/CSS、woff2 字体、favicon.svg 和 24 张 JPEG（总计约 12 MB）。保持在 20 MB 以下。

## 变量
- [BRAND] — 档案馆、博物馆或工作室名称（默认："Halvard Archive"）。以斜体字标形式显示在左上角、加载器、<title> 和关于面板中。
- [EXHIBITION] — 展览或收藏标题（默认："First Light"）。一到三个词。在加载器中以大号字体显示，并显示在字标下方。
- [COLLECTION_NOTE] — 收藏的一句话描述（默认："Early photographs of water, stone, leaf and sky, 1841–1900"）
- [ROOMS] — 四个展厅名称，按参观顺序排列（默认："Tide, Stone, Leaf, Sky"）。恰好四个单词。作品 01–06 挂在第一个展厅，07–12 在第二个，13–18 在第三个，19–24 在第四个。
- [VISIT_LINE] — 实用信息行：地址、开放时间或票价（默认："Reading room: 9 Cinder Wharf, Port Aldery · Thu–Sun 11:00–17:00 · Free entry"）
- [CREDIT] — 在页脚保留一个小型 "Template by VibeFather" 链接，指向 https://vibefather.ai/t/3d-photo-gallery（默认：是；删除此行即可移除）

页面与区块下的文案是按默认值撰写的。如果你的取值不同，请为它们重写每一个标题、段落、标签和图片——保持相同的长度、语气和结构。布局、颜色、字体和动效保持所述不变。
将所有文案、图片路径和链接放在一个内容文件中（例如 `src/content.ts`），按区块作为键，以便之后无需改动组件即可替换内容。

- Albumen（蛋清）`#c99a5b` — 唯一强调色：进度填充、光标点、活动索引数字、焦点环、按钮中的小圆点。绝不用于大面积填充或正文文本。
- Letterbox（黑边）`#000000` — 详情视图的黑边条与灯箱背景（96% 不透明度）

### 字体排印
- Display（字标、房间标题、作品标题）：Cormorant Garamond（OFL），字重 400/500
- Text（说明文字、面板、按钮）：Hanken Grotesk（OFL），字重 400/500
- Mono 微型标签（计数器、房间标签、提示、致谢）：IBM Plex Mono（OFL），字重 400/500

### 布局与动效
- 间距：HUD 位于固定的内嵌边框上：宽度 ≥ 900px 时距每边 28px，以下为 18px。面板使用 40px 内边距（移动端 24px）。等宽标签为 11px 大写，字距 0.16em。详情文本列从左侧 6vw 开始，最大宽度 520px。文本块中的垂直节奏为 8px 的倍数（8、16、24、40）。
- 圆角：所有地方均为 0（边框、面板、图像、灯箱）。仅胶囊按钮使用 999px，光标环为圆形。
- 动效：缓动：入场 cubic-bezier(.2,.8,.2,1)；面板与黑边 cubic-bezier(.7,0,.2,1)；相机飞行 easeInOutCubic。阻尼辅助函数 damp(a, b, λ, dt) = a + (b − a)·(1 − e^(−λ·dt)) 驱动每一个连续值。
- 动效：惯性行走：滚轮、拖拽和滑动写入滚动目标；相机以阻尼 λ 5 追随它，并在释放后保持动量（速度按 e^(−3.5·dt) 衰减）。
- 动效：速度弯曲：相机移动时，照片平面沿其宽度略微弯曲（uBend = clamp(speed × 0.02, −0.35, 0.35)），停止时变平。
- 动效：指针视差：相机在 x 方向最多偏移 0.25 单位、y 方向 0.15 单位，并朝指针方向最多旋转 0.04 rad，阻尼 λ 3。
- 动效：相机在 1.2 s 内飞向一张照片，并伴随 FOV 冲击（中点时 +8°），其他作品在 0.6 s 内变暗至 12% 亮度。
- 动效：滚动数字：每个数字是一条被遮罩的垂直 0–9 条带，在 0.6 s 内滑到新值；房间名称在 0.5 s 内通过遮罩向上滑出并滑入。
- 动效：加载器快门：加载器分成上下两半，在 0.9 s 内滑出屏幕，随后 HUD 元素上升 12px 并以 80ms 的错峰淡入，作品由近及远依次显现。
- 动效：胶片颗粒叠加层每秒步进 8 个偏移；尘埃缓慢漂移。prefers-reduced-motion：无惯性（λ 14，无动量）、无弯曲、无 FOV 冲击、无自动行走、静态颗粒与尘埃、相机跳转替换为 0.35 s 交叉淡入、滚动数字即时切换。
- 图像：仅使用真实的十九世纪照片：24 张来自 The Cleveland Museum of Art Open Access 的 CC0 图像，保留其原有的暖调蛋清、盐纸、蓝晒和彩色照片色调。无调色、无滤镜、无裁剪：每个平面使用图像的自然宽高比。其他一切（边框、标签、房间标题、尘埃、颗粒、暗角、光标、favicon）均以代码绘制。无肖像，无标志。

2. **加载器** — 左上角：'[BRAND]'，Cormorant Garamond italic 500，28px，Bone。居中：'[EXHIBITION]'，Cormorant Garamond italic 400，clamp(72px, 13vw, 210px)，line-height 0.9，Bone，居中。其下，mono 11px Ash：'HANGING PLATES  014 / 024'，其中第一个数字统计实际加载的纹理数（零填充至三位）。左下角 mono 11px Ash：'[COLLECTION_NOTE]'。右下角 mono 11px Ash：'Drag, scroll or swipe'。
   布局：固定全屏，背景 Void，z-index 高于一切。一条 1px Hairline 线在 50% 高度处横跨全宽，位于标题后方；一条 Albumen 1px 线在其上从左向右随加载进度增长（宽度 = loaded / 24）。
   动效：展览标题逐字母进入：每个字母在 overflow-hidden 行内从 110% 升至 0，40ms 错开，0.8s。当全部 24 个纹理加载完毕且进度线到达 100% 时，保持 300ms，然后加载器分裂：上半部分平移至 −100%，下半部分平移至 +100%（两个堆叠的 div，各含一半内容，无需 clip-path），0.9s cubic-bezier(.7,0,.2,1)。过渡结束后从 DOM 中移除加载器。减少动效：无字母动画，纯 0.4s 淡出。
3. **3D 走廊（场景）** — three.js WebGLRenderer（antialias true，alpha false），像素比桌面端 min(devicePixelRatio, 2)，视口宽度小于 900px 时 min(devicePixelRatio, 1.75)，outputColorSpace SRGBColorSpace，无色调映射，清除色 #0b0a09。PerspectiveCamera FOV 45（aspect < 0.8 时为 55），near 0.1，far 80，起始于 (0, 0, 0) 朝 −z 方向看。走廊布局常量：作品间距 3.2 单位，房间长度 25.2，循环长度 L = 100.8。房间 r（0–3）偏移 O = r × 25.2；其房间标题位于 z = −(O + 3)；其作品 k（0–5）位于 z = −(O + 7 + k × 3.2)。作品 k 的每房间偏移：x = [−1.6, 1.45, −1.35, 1.7, −1.5, 1.4][k]，y = [0.12, −0.18, 0.22, −0.08, 0.05, −0.2][k]，rotation.y = −sign(x) × 0.12（每件作品略微转向走廊中心）。当 aspect < 0.8 时，x 乘以 0.42，平面尺寸乘以 0.8。
   布局：无限循环：每件作品、房间标题和尘埃粒子保持一个基础 z；每帧其渲染 z = camZ + rel，其中 rel = ((baseZ − camZ − 4) mod L + L) mod L − L + 4，因此物体保持在相机前方 L − 4 单位与后方 4 单位之间。每件作品是一个 THREE.Group，包含：一个边框平面（Frame 颜色，MeshBasicMaterial，尺寸 w + 0.08 × h + 0.08，z −0.01）；照片平面（PlaneGeometry w × h，24×1 分段，移动端 16×1，自定义 ShaderMaterial）；以及一个博物馆标签平面，位于边框底边下方 0.18 单位，与其左对齐：一个 1024×128 canvas 纹理，mono 34px Ash '07'，然后 48px 后，Cormorant italic 52px Bone 短标题，绘制在透明背景上，平面宽度 1.4 单位。照片尺寸：h = 1.7，w = 1.7 × imageAspect；若 w > 2.3 则 w = 2.3，h = 2.3 / imageAspect。照片着色器 uniforms：uTex、uReveal（0–1）、uDim（1 = 正常）、uHover（0–1）、uBend、uFogColor #0b0a09、uFogNear 6、uFogFar 34。顶点：position.z += sin(uv.x × π) × uBend × w × 0.25；传递视图深度。片元：color = texture × uDim × (1 + uHover × 0.08)；按 smoothstep(uFogNear, uFogFar, depth) 向 uFogColor 混合；alpha = uReveal。纹理：TextureLoader，colorSpace SRGBColorSpace，各向异性 min(8, renderer max)，开启 mipmaps。仅对照片平面进行射线检测。
   动效：相机装置：滚动目标 s（正值 = 前进），位置 p，速度 v。滚轮：s += deltaY × 0.01（deltaMode 1 → × 16，deltaMode 2 → × innerHeight）。舞台上的指针拖拽：s += (clientY − lastY) × 0.018（触摸为 0.03），平移 x 目标 −= (clientX − lastX) × 0.003，限制在 ±1.1（aspect < 0.8 时为 ±0.5）；释放时，v = 最后 100ms 的平均拖拽速度，平移目标以 λ 1.5 缓回 0。每帧：s += v·dt，v *= e^(−3.5·dt)，p = damp(p, s, 5, dt)；相机 z = −p，相机 x = pan + pointerX × 0.25，相机 y = pointerY × 0.15，rotation.y = −pointerX × 0.04，rotation.x = pointerY × 0.03。按键：ArrowDown / PageDown / S = s + 3.2；ArrowUp / PageUp / W = s − 3.2；Enter 打开当前作品；I 切换 Index；Esc 关闭最顶层覆盖层。自动行走：6 秒无输入且无覆盖层打开后，s += 0.25·dt 直到下一次输入。悬停：当指针位于照片平面上时，其 uHover 缓动至 1，其组缩放至 1.035（damp λ 8）。加载器之后的入场：作品由近及远显现，uReveal 0→1，y 偏移 −0.3→0，0.8s，90ms 错开。仅当指针自 pointerdown 以来移动小于 6px 时，pointerup 才计为点击。

## 禁止事项
- 不得使用任何形式的后端：不得有服务器代码、API 路由、数据库、认证、分析、会提交的表单，也不得在运行时调用博物馆 API。唯一的外链是 'Source record ↗' 链接、mailto 链接和 [CREDIT] 链接。
- 绝不要热链图片。全部 24 张照片都要按给定的确切 URL 和文件名下载到 public/photos/ 中，并在 ASSETS.md 中列出其来源、作者和许可。
- 不要换用来自 Unsplash、Pexels、Pixabay、Google Images 或任何非 CC0 来源的照片。如果要替换某张照片，请使用另一张 CC0 / 公有领域开放获取图片，并更新 content.ts 和 ASSETS.md。
- 不要对照片进行裁剪、重新着色、染色、去饱和或滤镜处理；每张照片都要以其原始宽高比展示。不要用肖像或可识别的面孔作为精选作品，不要使用标志。
- 不要从 fonts.googleapis.com、fonts.gstatic.com、Adobe Fonts 或任何 CDN 加载字体。只能通过 Fontsource 自托管。不要使用 CDN 的 <script> 或 <link> 标签，也不要用指向 CDN 的 import maps：three.js 从 npm 安装并打包。
- 生产构建中不要有 source maps（build.sourcemap: false），dist/ 中不要有 src/。只使用相对资源路径（Vite base './'）。每个内部链接都指向 ./index.html 或页面内元素，绝不能指向裸目录。
- 除非用户要求，否则不要更改技术栈（Vite + TypeScript + three.js + 纯 CSS + Fontsource）。不要用 React，不要用 Tailwind，不要用 UI 套件，不要用后处理库。
- 不得有任何声音或音频，也不得有自动播放的媒体。
- 不要使用名称 'Nocturne'、短语 'An endless archive'、'Twenty works, four rooms'、'Lighting the rooms'、'Headphones optional' 或 'Opening the doors'，也不要使用任何虚构的项目标题、客户，或其他画廊演示中程序化绘制的作品。此处所有标题都是这 24 张照片的真实标题。

- Albumen（#c99a5b）是唯一的强调色，且只用于小细节。除暗角（vignette）和详情视图可读性渐变外，不要使用渐变，不要霓虹，不要玻璃拟态（glassmorphism），不要圆角卡片，不要 emoji。
