# 3D Photo Gallery

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
An immersive online exhibition for [BRAND]: twenty-four real public-domain photographs hang as framed planes along an endless dark corridor in WebGL. Visitors scroll, drag or swipe to walk forward and back; the corridor wraps around so the walk never ends. The works are grouped into four named rooms ([ROOMS]), each announced by a huge italic room title floating in the dark. Clicking a photograph flies the camera up to it and opens a letterboxed detail view with full caption, credit and license; from there a 2D lightbox shows the full image with zoom. A thin HUD frames the screen: brand, current room, rolling work counter, progress track, Index and About panels. One page, no backend, every image downloaded into the project and credited.

- Audience: Visitors of a small photography archive or museum who want to browse a collection slowly, plus photographers, curators and archives looking for a memorable way to show a set of 15–40 images.
- Goal: Make browsing a collection feel like walking through a quiet gallery, while every image stays properly captioned and credited: title, maker, date, process, collection and license one click away.
- Tone: Quiet, exact and curatorial. Short factual captions, no exclamation marks, no marketing language. Labels read like museum wall text.

## Stack
- Framework: Vite 5 + TypeScript + three.js
- Styling: Plain CSS, custom properties
- Libraries: three (MIT), @types/three (dev) (MIT), vite (MIT), typescript (Apache-2.0), @fontsource/cormorant-garamond (OFL-1.1), @fontsource-variable/hanken-grotesk (OFL-1.1), @fontsource/ibm-plex-mono (OFL-1.1)
- Build: `npm run build` → static files in `dist/`. No backend, no server code, no external APIs.
- Setup:
  - Scaffold with npm create vite@latest using the vanilla-ts template. No UI framework. One page: index.html plus src/main.ts.
  - vite.config.ts: base './', build { outDir: 'dist', sourcemap: false, assetsInlineLimit: 0 }. Do not copy src/ into dist/.
  - File layout: src/content.ts (brand strings, rooms, the 24 works with every caption field, About copy), src/scene/ (Renderer.ts, CameraRig.ts, Corridor.ts, WorkPlane.ts, RoomTitle.ts, Dust.ts, shaders.ts), src/ui/ (Loader.ts, Hud.ts, Panel.ts, Detail.ts, Lightbox.ts, Cursor.ts, Fallback.ts), src/styles.css.
  - Fonts: import '@fontsource/cormorant-garamond/400-italic.css', '@fontsource/cormorant-garamond/500-italic.css', '@fontsource/cormorant-garamond/500.css', '@fontsource-variable/hanken-grotesk' and '@fontsource/ibm-plex-mono/400.css', '@fontsource/ibm-plex-mono/500.css' in src/main.ts. Before drawing any canvas text, await document.fonts.load for 'italic 400 64px "Cormorant Garamond"' and '400 32px "IBM Plex Mono"'.
  - The 24 photographs live in public/photos/ under the exact file names in Assets and are referenced with relative paths ('./photos/01-effect-of-the-sun.jpg'). Write ASSETS.md at the project root before building.
  - All colors as CSS custom properties on :root in src/styles.css; the same hex values are imported into the three.js code from src/content.ts or a small src/theme.ts.
  - dist/ holds index.html, hashed JS/CSS, the woff2 fonts, favicon.svg and the 24 JPEGs (about 12 MB total). Keep it under 20 MB.

## Variables
- [BRAND] — Archive, museum or studio name (default: "Halvard Archive"). Shown as the italic wordmark top-left, in the loader, the <title> and the About panel.
- [EXHIBITION] — Exhibition or collection title (default: "First Light"). One to three words. Shown large in the loader and under the wordmark.
- [COLLECTION_NOTE] — One-line description of the collection (default: "Early photographs of water, stone, leaf and sky, 1841–1900")
- [ROOMS] — Four room names, in walking order (default: "Tide, Stone, Leaf, Sky"). Exactly four single words. Works 01–06 hang in the first room, 07–12 in the second, 13–18 in the third, 19–24 in the fourth.
- [VISIT_LINE] — Practical line: address, hours or price (default: "Reading room: 9 Cinder Wharf, Port Aldery · Thu–Sun 11:00–17:00 · Free entry")
- [CREDIT] — keep a small "Template by VibeFather" link to https://vibefather.ai/t/3d-photo-gallery in the footer (default: yes; delete this line to remove it)

The copy under Pages & Sections is written for the default values. If your values differ, rewrite every headline, paragraph, label and image for them — same length, tone and structure. Layout, colors, type and motion stay as described.
Keep all copy, image paths and links in one content file (for example `src/content.ts`), keyed by section, so the content can be swapped later without touching components.

## Design
### Colors
- Void `#0b0a09` — Page and scene background, fog color, loader background
- Soot `#15130f` — Index and About panels, mobile detail sheet, fallback page
- Frame `#2a241d` — Thin frame plane behind every photograph
- Bone `#ece4d6` — Primary text, room titles, cursor ring, dust particles
- Ash `#8f877a` — Secondary text, mono labels, dates, inactive controls
- Hairline `rgba(236,228,214,0.14)` — 1px dividers, progress track, panel borders
- Albumen `#c99a5b` — The only accent: progress fill, cursor dot, active index number, focus rings, the small dot in buttons. Never for large fills or body text.
- Letterbox `#000000` — Detail-view letterbox bars and the lightbox backdrop (at 96% opacity)

### Typography
- Display (wordmark, room titles, work titles): Cormorant Garamond (OFL), weights 400/500
- Text (captions, panels, buttons): Hanken Grotesk (OFL), weights 400/500
- Mono micro-labels (counters, room labels, hints, credits): IBM Plex Mono (OFL), weights 400/500

### Layout & motion
- Spacing: HUD sits on a fixed inset frame: 28px from each edge at ≥ 900px wide, 18px below. Panels use 40px padding (24px mobile). Mono labels are 11px uppercase with 0.16em letter-spacing. Detail text column starts at 6vw from the left, max-width 520px. Vertical rhythm in text blocks is 8px multiples (8, 16, 24, 40).
- Radius: 0 everywhere (frames, panels, images, lightbox). Only pill buttons use 999px, and the cursor ring is a circle.
- Motion: Easing: entrances cubic-bezier(.2,.8,.2,1); panels and letterbox cubic-bezier(.7,0,.2,1); camera flights easeInOutCubic. Damping helper damp(a, b, λ, dt) = a + (b − a)·(1 − e^(−λ·dt)) drives every continuous value.
- Motion: Inertial walk: wheel, drag and swipe write to a scroll target; the camera chases it with damp λ 5 and keeps momentum after release (velocity decays by e^(−3.5·dt)).
- Motion: Velocity bend: photograph planes curve slightly along their width while the camera moves (uBend = clamp(speed × 0.02, −0.35, 0.35)) and flatten when it stops.
- Motion: Pointer parallax: camera offsets up to 0.25 units in x and 0.15 in y and rotates up to 0.04 rad toward the pointer, damped λ 3.
- Motion: Camera flight to a photograph in 1.2 s with a FOV kick (+8° at the midpoint), other works dimming to 12% brightness in 0.6 s.
- Motion: Rolling digits: each digit is a masked vertical 0–9 strip that slides to the new value in 0.6 s; room names slide up out and in through a mask in 0.5 s.
- Motion: Loader shutter: the loader splits into a top and bottom half that slide off-screen in 0.9 s, then HUD items rise 12px and fade in with an 80ms stagger and the works reveal nearest-first.
- Motion: Film grain overlay steps through 8 offsets per second; dust drifts slowly. prefers-reduced-motion: no inertia (λ 14, no momentum), no bend, no FOV kick, no auto-walk, static grain and dust, camera jumps replaced by 0.35 s crossfades, rolling digits switch instantly.
- Imagery: Real nineteenth-century photographs only: 24 CC0 images from The Cleveland Museum of Art Open Access, kept in their original warm albumen, salted-paper, cyanotype and photochrom tones. No color grading, no filters, no crops: each plane uses the image's natural aspect ratio. Everything else (frames, labels, room titles, dust, grain, vignette, cursor, favicon) is drawn in code. No portraits and no logos.

3. **3D corridor (scene)** — three.js WebGLRenderer (antialias true, alpha false), pixel ratio min(devicePixelRatio, 2) desktop and min(devicePixelRatio, 1.75) when the viewport is under 900px wide, outputColorSpace SRGBColorSpace, no tone mapping, clear color #0b0a09. PerspectiveCamera FOV 45 (55 when aspect < 0.8), near 0.1, far 80, starting at (0, 0, 0) looking down −z. Corridor layout constants: work spacing 3.2 units, room length 25.2, loop length L = 100.8. Room r (0–3) has offset O = r × 25.2; its room title sits at z = −(O + 3); its work k (0–5) sits at z = −(O + 7 + k × 3.2). Per-room offsets for work k: x = [−1.6, 1.45, −1.35, 1.7, −1.5, 1.4][k], y = [0.12, −0.18, 0.22, −0.08, 0.05, −0.2][k], rotation.y = −sign(x) × 0.12 (each work turns slightly toward the corridor center). When aspect < 0.8 multiply x by 0.42 and plane size by 0.8.
   Layout: Infinite wrap: every work, room title and dust particle keeps a base z; each frame its rendered z = camZ + rel, where rel = ((baseZ − camZ − 4) mod L + L) mod L − L + 4, so objects stay between L − 4 units ahead and 4 units behind the camera. Each work is a THREE.Group with: a frame plane (Frame color, MeshBasicMaterial, size w + 0.08 by h + 0.08, z −0.01); the photo plane (PlaneGeometry w × h with 24×1 segments, 16×1 on mobile, custom ShaderMaterial); and a museum label plane 0.18 units below the frame's bottom edge, left-aligned with it: a 1024×128 canvas texture with mono 34px Ash '07' then, after 48px, Cormorant italic 52px Bone short title, drawn on transparency, plane width 1.4 units. Photo size: h = 1.7, w = 1.7 × imageAspect; if w > 2.3 then w = 2.3 and h = 2.3 / imageAspect. Photo shader uniforms: uTex, uReveal (0–1), uDim (1 = normal), uHover (0–1), uBend, uFogColor #0b0a09, uFogNear 6, uFogFar 34. Vertex: position.z += sin(uv.x × π) × uBend × w × 0.25; pass view depth. Fragment: color = texture × uDim × (1 + uHover × 0.08); mix toward uFogColor by smoothstep(uFogNear, uFogFar, depth); alpha = uReveal. Textures: TextureLoader, colorSpace SRGBColorSpace, anisotropy min(8, renderer max), mipmaps on. Raycast only against photo planes.
   Motion: Camera rig: scroll target s (positive = forward), position p, velocity v. Wheel: s += deltaY × 0.01 (deltaMode 1 → × 16, deltaMode 2 → × innerHeight). Pointer drag on the stage: s += (clientY − lastY) × 0.018 (0.03 for touch), pan x target −= (clientX − lastX) × 0.003, clamped to ±1.1 (±0.5 when aspect < 0.8); on release, v = average drag speed over the last 100ms, and pan target eases back to 0 with λ 1.5. Each frame: s += v·dt, v *= e^(−3.5·dt), p = damp(p, s, 5, dt); camera z = −p, camera x = pan + pointerX × 0.25, camera y = pointerY × 0.15, rotation.y = −pointerX × 0.04, rotation.x = pointerY × 0.03. Keys: ArrowDown / PageDown / S = s + 3.2; ArrowUp / PageUp / W = s − 3.2; Enter opens the current work; I toggles Index; Esc closes the top-most overlay. Auto-walk: after 6s with no input and no overlay open, s += 0.25·dt until the next input. Hover: when the pointer is over a photo plane, its uHover eases to 1 and its group scales to 1.035 (damp λ 8). Entrance after the loader: works reveal nearest-first, uReveal 0→1 and y offset −0.3→0 over 0.8s with 90ms stagger. A pointerup counts as a click only if the pointer moved less than 6px since pointerdown.

## Don'ts
- No backend of any kind: no server code, API routes, databases, auth, analytics, forms that submit, or calls to the museum API at runtime. The only outbound links are the 'Source record ↗' links, the mailto link and the [CREDIT] link.
- Never hotlink images. All 24 photographs are downloaded into public/photos/ with the exact URLs and file names given, and listed in ASSETS.md with source, author and license.
- Do not swap in photos from Unsplash, Pexels, Pixabay, Google Images or any non-CC0 source. If you replace a photo, use another CC0 / public-domain open-access image and update content.ts and ASSETS.md.
- Do not crop, recolor, tint, desaturate or filter the photographs; show each at its natural aspect ratio. No portraits or recognizable faces as featured works, no logos.
- Do not load fonts from fonts.googleapis.com, fonts.gstatic.com, Adobe Fonts or any CDN. Self-host via Fontsource only. No CDN <script> or <link> tags and no import maps pointing to CDNs: three.js is installed from npm and bundled.
- No source maps in the production build (build.sourcemap: false) and no src/ in dist/. Relative asset paths only (Vite base './'). Every internal link points to ./index.html or an in-page element, never a bare directory.
- Do not change the stack (Vite + TypeScript + three.js + plain CSS + Fontsource) unless the user asks. No React, no Tailwind, no UI kits, no postprocessing libraries.
- No sound or audio of any kind, and no autoplaying media.
- Do not use the name 'Nocturne', the phrases 'An endless archive', 'Twenty works, four rooms', 'Lighting the rooms', 'Headphones optional' or 'Opening the doors', or any invented project titles, clients or procedurally painted artworks from other gallery demos. All titles here are the real titles of the 24 photographs.
- Do not use Instrument Serif, Inter Tight or JetBrains Mono. Use only Cormorant Garamond, Hanken Grotesk and IBM Plex Mono.
- Albumen (#c99a5b) is the only accent and only for small details. No gradients other than the vignette and the detail-view legibility gradient, no neon, no glassmorphism, no rounded cards, no emoji.
- No dependencies outside MIT, ISC, BSD, Apache-2.0, 0BSD, CC0 or Unlicense (OFL for fonts). No Aceternity UI, Tailwind Plus / Tailwind UI or purchased template code; write every effect from scratch.
- Respect prefers-reduced-motion exactly as described (no inertia, bend, FOV kick, auto-walk, animated grain or dust; crossfades instead of flights).
- Must work at 1440×900 and 390×844 with zero console errors, no page scrollbars on the gallery view, and every control reachable by keyboard with a visible 1px Albumen focus ring. Dispose nothing that is still in use; the render loop pauses while the tab is hidden.
- Keep dist/ under 20 MB. No extra bitmaps beyond the 24 photographs and the favicon.
- No mention of the template source inside the site except the optional [CREDIT] link. No lorem ipsum, no invented facts about the photographs beyond the captions given here.
