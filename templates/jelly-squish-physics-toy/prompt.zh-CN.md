## 简介
为 [BRAND] 构建一个完整的原创单页果冻挤压游乐场。主角是一个实时、可物理变形的带凹槽果冻甜点，而不是图片或刚性模型。它可以用鼠标或触摸来戳、抓、拉伸、压扁，并掉落到盘子上。包含三种口味、可调节的硬度和合成的挤压声。

- 受众：正在短暂轻松休息的人以及创意编程爱好者，使用手机或桌面设备。
- 目标：让物体在第一屏就立即吸引人且功能可用，然后让用户无需离开页面即可改变其手感和外观。
- 语气：温暖、略带幽默、有触感且简洁。绝不描述健康益处或做出健康声明。

## 技术栈
- 框架：Vite + TypeScript + Three.js
- 样式：原生 CSS（Vanilla CSS）
- 库：three（MIT）、@fontsource/dm-sans（OFL-1.1）、@fontsource/fraunces（OFL-1.1）
- 构建：`npm run build` → `dist/` 中的静态文件。无后端、无服务端代码、无外部 API。
- 设置：
  - 使用 npm 搭配 Vite 和 TypeScript；在本地安装每个库并锁定依赖。将 Vite base 设为 ./，build sourcemap 设为 false，build minify 设为 true。
  - 将所有面向访客的文案、风味名称和颜色保留在 src/content.ts 中。BRAND、HEADLINE、INTRO、FLAVORS 和 ACCENT 变量必须控制所有版本专属内容；更改时自然地重写相关标签。
  - 通过 Fontsource 导入本地拉丁字体文件。一个标明 [BRAND] 的普通文档标题和一个代码绘制的 favicon 就足够了。
  - 使用 Three.js WebGLRenderer 作为舞台，使用原生指针事件处理输入，使用 Web Audio 处理所有声音。无需物理库、外部模型或外部媒体。
  - 编写 ASSETS.md，列出原始代码艺术作品、Three.js MIT 以及两个字体包及其源 URL 和许可证。最后以 npm run build 完成，仅生成静态分发文件。

- 间距：桌面端：40px 外侧留白，居中内容最大宽度 1360px，24px 页头内边距。主视觉介绍位于左上方，大舞台占据中右部；控制托盘居中位于物体下方。使用 8px 间距网格、16px 紧凑间隙和 24px 托盘间隙。移动端：20px 留白，页头 58px，标题 40px，介绍 14px，场景高度 300–340px；将完整的首次交互控件放置在 390×844 视口内或非常接近的位置。不要在物体之前创建高大的空白间隙。
- 圆角：控制托盘 24px，按钮和口味标签 999px，小说明标签 8px。使用细的 #d8cabe 边框和柔和的暖色阴影，而不是大量卡片。
- 动效：形变本身是主要动画；避免持续漂浮或相机旋转。果冻明显地静置在盘子上。
- 动效：建模一个封闭的、非西瓜的凹槽穹顶，约 16–20 个纬度环和 40–48 个纵向节点。使用位置/速度或 Verlet 质量-弹簧求解器，包含结构和对角邻居约束、阻尼静止形状恢复力和稳定的固定时间步长子步。求解后更新实际的 BufferGeometry 位置和法线；高光必须跟随形变后的表面。
- 动效：使用有界步长、速度钳制和足够的求解器迭代，以保持快速拖拽的稳定性。柔和的体积或径向恢复保留可识别的甜点轮廓。下环可以沿盘子滑动/压缩，而不是穿透盘子。附近的环应跟随被抓取的节点，影响平滑递减。
- 动效：指针按下时对网格进行射线检测，并在面向相机的拖拽平面中抓取局部顶点簇。移动时将簇以弹簧力拖向指针，允许明显的局部凹陷或拉伸；释放时移除抓取并产生阻尼振荡。快速点击或轻触施加短暂的内向冲量。钳制极端拉伸以保持形状可恢复。
- 动效：放下时从盘子上方约一个果冻高度处释放果冻；重力、碰撞、压缩和阻尼回弹在稳定前明显改变网格。按钮必须可重复工作。刚度范围映射到求解器恢复和阻尼，使其两端感觉明显不同，且不会发生数值爆炸。
- 动效：减少动效偏好会禁用装饰性过渡，并降低下落高度、冲量幅度和回弹持续时间，同时保留有意的直接操控。隐藏时暂停模拟；桌面端设备像素比上限为 1.75，移动端为 1.5。仅在舞台上使用 touch-action none，而不是整个页面。
- 图像：在 Three.js 中程序化创建所有视觉效果。果冻是一个原创的圆润凹槽布丁穹顶，宽约 2.6 单位、高约 1.8 单位，具有柔和的扇贝边缘和一个小顶部凹痕。使用半透明的 MeshPhysicalMaterial 或等效的物理着色材质：粗糙度约 0.13，清漆层 1，透射约 0.45，厚度约 0.8，颜色来自激活口味。几个微妙的气泡可以跟随附近的形变节点，但没有籽或果皮。使用代码构建的象牙色盘子，带有两个柔和同心边缘、温暖的地面、接触阴影、左上方大而柔和的主光和柔和的轮廓光。使用 Three.js RoomEnvironment 或代码绘制的 CanvasTexture 在本地构建任何反射环境。在 CSS 中包含克制的精细摄影棚颗粒。不使用外部照片、生成图像、西瓜块、可识别标志或复制构图。

   动效：立即渲染稳定的合成视图，透视相机约在 (4,3.2,5.5) 处对准果冻中心。抓取期间不使用轨道控制。调整大小以适应容器而不溢出。一个键盘可访问的 Squish 按钮可以作为小叠加层，并且必须触发与点击相同的物理冲量。

   布局：桌面端：一个水平 780px 最大托盘，风味组在左，硬度居中，实心强调色 Drop it 在右。移动端：一个紧凑托盘，第一行有三个风味芯片，第二行有滑块加 Drop it；每个触摸目标至少 44px，无水平滚动。保持托盘在正常文档流中，使其绝不覆盖盘子或手势区域。
   动效：使用 140ms 控件颜色过渡；风味材质在 220ms 内交叉淡化，除非减少动效。范围输入支持原生箭头键和清晰的焦点轮廓。在聚焦的 Drop it 上按空格必须触发一次下落，不得双重触发。
4. **声音与页脚** — Web Audio 仅从显式指针/键盘交互初始化或恢复。声音保持关闭，直到访客将其打开。在点击/释放/下落时合成短促的滤波噪声挤压声加上低正弦音高弯曲；强度跟随冲量速度，具有有界增益和主限幅器或温和的增益包络。无采样文件、自动播放或背景音轨。页脚写着 Made for a moment of play. 如果公共 CREDIT 变量启用，则包含其可选的模板信用链接。
   布局：托盘下方一个安静的细页脚，12px 次要文本。无日期、暗示受欢迎程度的计数器、新闻通讯表单或冗长解释。当浏览器音频不可用时，音频控件必须保持可理解。
   动效：关闭或暂停不需要的音频节点；对快速冲量进行防抖，以避免咔嗒声和过大增益。所有键盘控件都是真实 DOM 元素。为风味更改和下落提供礼貌的实时状态，而不逐帧宣布动画。
