# Template Library Landing Page

> Near-black template-library landing with an auto-scrolling wall of browser demos and one acid-lime accent.

Lumen Index is a single-page landing template for a library or marketplace of website templates, prompts or developer resources. The hero opens on a headline about vibe-coding templates. Below it is a wall of browser-frame cards in four rows that scroll sideways in alternating directions. Each card is a small invented website drawn in CSS and SVG: a ceramics shop, a fintech dashboard, a Swiss-style portfolio, a docs site, a pixel game. There are no screenshots or bitmaps, and the whole build stays small and sharp at any size.

Below the hero, a three-step explainer (Pick, Copy, Ship) uses mono step labels and hairline dividers. Next comes a trending grid with type filters and copy-prompt buttons, then a browse-by-type list with large mono counts that shows preview thumbnails when you hover a row. After that are a tabbed code panel with CLI, MCP and Skill snippets, an early-access block with a spots meter and a mailto button, an FAQ accordion, and a dense footer.

The colours are a near-black neutral base, hairline borders and one acid-lime accent. The lime appears only on calls to action, step numerals and the blinking caret in the code panel. A faint, low-saturation glow in green, teal and amber sits behind the hero and nowhere else. There are no glass cards, no blue-purple gradients and no emoji.

The template suits developer tools, prompt libraries, UI kit stores, component catalogs and any product that has a lot of visual examples to show. To adapt it, set the brand, the CLI slug, the contact email and the two spot numbers. Swap the twelve mini-site recipes for your own product categories, and rewrite the FAQ. It builds with Vite, React and Tailwind into a static folder you can host anywhere.

## Variables

Replace these in the prompt with your own values; everything else stays as written.

| Variable | What it is | In the demo |
|---|---|---|
| `[BRAND]` | Brand name | Lumen Index |
| `[BRAND_SLUG]` | CLI / package slug | lumen-index |
| `[CONTACT_EMAIL]` | Contact email | hello@example.com |
| `[SPOTS_TOTAL]` | Pro early-access spots (total) | 500 |
| `[SPOTS_CLAIMED]` | Pro early-access spots (claimed) | 312 |

## How to use it

1. Copy [prompt.md](prompt.md), or run `npx vibefather add template-library-landing-page` in your project.
2. Replace the `[VARIABLES]` with your own brand, copy and details.
3. Paste it into Claude Code, Codex, Cursor or another AI coding agent and let it build. [DESIGN.md](DESIGN.md) holds the colors, type and spacing on their own if you only want the look.

## Make it yours

- A solo developer selling a prompt pack: set BRAND to your store name, swap the twelve mini-site recipes for your prompt categories and point CONTACT_EMAIL at your support inbox.
- A design studio launching a component catalog: keep the browse-by-type list, replace the trending grid with your component sets and rewrite the Pick/Copy/Ship steps for your download flow.
- An indie maker running a Pro waitlist: set SPOTS_TOTAL and SPOTS_CLAIMED to your real numbers and rewrite the early-access block around your own launch offer.
- A developer tool team showing integrations: keep the code panel and rewrite the CLI, MCP and Skill tabs with your own commands and BRAND_SLUG.

## FAQ

### What sections does the Template Library Landing Page template include?
The Template Library Landing Page is a single page with hash anchors for each block: a hero with a wall of auto-scrolling browser-frame cards, a Pick/Copy/Ship explainer, a trending grid with type filters and copy-prompt buttons, a browse-by-type list with counts and hover thumbnails, a code panel with CLI, MCP and Skill tabs, a Pro early-access block with a spots meter, an FAQ accordion and a dense footer. Every visual is drawn in CSS and SVG, so there are no screenshots to replace.

### How do I change the mini-websites in the scrolling wall?
The scrolling wall in the Template Library Landing Page is built from twelve mini-site recipes drawn in CSS and SVG, such as a ceramics shop, a fintech dashboard and a docs site. Swap those recipes for your own product categories and keep the browser-frame card shape and the alternating row directions. Each row holds its card list twice so the marquee loops without a gap, and hovering a row pauses it.

### Which variables do I set before publishing the Template Library Landing Page?
Set five variables in the Template Library Landing Page: BRAND for the wordmark, title and footer, BRAND_SLUG for the CLI and package snippets, CONTACT_EMAIL for the Pro mailto button and footer link, and SPOTS_TOTAL and SPOTS_CLAIMED for the early-access meter fill. The default spot numbers are invented placeholders, so replace them with your own figures or reword the block.

### Can the Template Library Landing Page promote a prompt library or UI kit store instead of templates?
Yes. The Template Library Landing Page suits any product with many visual examples, including prompt libraries, UI kit stores and component catalogs. Change the hero headline, the trending grid entries and the browse-by-type rows to your own categories, then rewrite the Pick/Copy/Ship explainer and the FAQ so they describe how people get and use your files. The code panel tabs can show your own install commands.
