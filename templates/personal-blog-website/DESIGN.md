# Personal Blog Website — Design System

Apply this design system to an existing project. It describes the look and feel only; for the full site, use prompt.md.

## Colors
- **Warm Paper** `#FBF8F1` — Default reading canvas background
- **Paper Card** `#F3EDE0` — Subtle alternating callouts, pull-quote wells, and figure mats
- **Editorial Ink** `#1B1B1B` — Primary display serif and body reading text
- **Muted Graphite** `#5A564E` — Captions, reading time, footnotes, and secondary metadata
- **Tomato Accent** `#E5533D` — Reading progress bar, active nav rule, drop-cap accents, tag pills, and links
- **Sepia Paper** `#F3E8D2` — Sepia reading theme canvas with #2E2418 ink and #C9442E accent
- **Night Ink** `#171717` — Dark reading theme canvas with #EFECE6 text and #FF6F59 accent

## Typography
- **Editorial Display & Essay Body** — Newsreader (OFL), weights 400/500/600/700. Self-host the font files.
- **Navigation, Tags & Controls** — Inter (OFL), weights 400/500/600. Self-host the font files.
- **Code Blocks & Issue Numbers** — JetBrains Mono (OFL), weights 400/500. Self-host the font files.

## Spacing & shape
- Spacing: Literary magazine rhythm: 64px top bar with integrated reading-theme/font-size controls, 1080px shell width, 68ch optimal essay reading measure, generous 48px–64px vertical cadence.
- Radius: 4px for subtle paper tags and buttons; 8px for code frames, figures, and newsletter boxes.

## Motion
- Continuous scroll-linked 3px Tomato reading progress bar pinned at top of viewport on essay pages.
- Smooth 140ms hover underlines and theme-switch transitions.
- Respect prefers-reduced-motion across all transitions.

## Imagery
Bespoke linocut-style editorial SVG illustrations drawn in code (matching Warm Paper, Editorial Ink, and Tomato Accent) depicting a coastal night train, hand-stitched notebook press, brass pocket compass, and minimalist terminal bench—each rendered with print registration marks and editorial captions so every page feels authored and visually rich.

## Tone
Thoughtful, observant, grounded, first-person essays about craft, small tools, and slow travel—never corporate or clickbaity.
