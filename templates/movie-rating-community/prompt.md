# Movie Rating Community

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
Build [BRAND], an original static movie-rating community for [AUDIENCE]. The default invitation is [TAGLINE], the featured film is [FEATURED_FILM], the signed-in sample member is [PROFILE_NAME], and the editorial ranked list is [RANKED_LIST_NAME]. Provide a discovery home, movie detail routes, a combined short-take and long-essay review feed, a filterable 100-film ranked canon, want-to-watch and watched libraries, and a personal taste dashboard. All films and people are fictional; the interface must feel like a useful product, not a landing page with disconnected mockups.

- Audience: Write concise, welcoming US English for [AUDIENCE]. Assume visitors understand film titles and star ratings but do not need a tutorial, account, or backend. Favor specific observations about mood, craft, pacing, and rewatching over generic praise or marketing language.
- Goal: Let a visitor discover a film, inspect its aggregate five-star distribution, read both kinds of reviews, rate it, place it on a list, vote a review helpful, and immediately see the personal library and taste profile update. Keep every route interactive at 1440×900 and 390×844 with zero console errors and no external service.
- Tone: Literate, warm, opinionated, and unhurried: an independent film journal translated into a precise community app. Use exact film details and memorable review copy, not hype, awards language, engagement bait, streaming claims, or calls to sign up.

## Stack
- Framework: Vite 5 + React 18 + TypeScript
- Styling: Vanilla CSS + hand-built SVG
- Libraries: React 18 and React DOM (MIT), Vite 5 (MIT), TypeScript 5.6 (Apache-2.0), lucide-react (ISC), @fontsource/instrument-serif (OFL-1.1), @fontsource/dm-sans (OFL-1.1), @fontsource/ibm-plex-mono (OFL-1.1)
- Build: `npm run build` → static files in `dist/`. No backend, no server code, no external APIs.
- Setup:
  - Create package.json with scripts dev = vite, build = tsc --noEmit && vite build, and preview = vite preview. Use React 18.3, Vite 5.4, TypeScript 5.6, lucide-react 0.468.0, and the three listed Fontsource packages; install and bundle every dependency locally.
  - Configure vite.config.ts with base './', build.outDir 'dist', build.sourcemap false, build.target 'es2020', and minification enabled. Use one index.html entry and hash-based navigation; do not copy src/ into dist/.
  - Organize src/content.ts for every variable, visible string, film record, review, seed list, and chart label; src/data/catalog.ts for deterministic derived metadata; src/state/community.tsx for shared state; src/components/ for the shell, film cards, rating input, charts, review cards, filters, and dialogs; src/pages/ for the six route views; src/App.tsx for routing; and src/styles.css for tokens and responsive rules.
  - Use a small hash router supporting '#/', '#/film', '#/film/<slug>', '#/reviews', '#/rankings', '#/library', and '#/profile'. All hrefs use './index.html#/…' form. Opening '#/film' without a slug displays the film selected by FEATURED_FILM, falling back to the first catalog record if it does not match. Unknown film slugs also show that first film with a plain notice rather than an empty page.
  - Derive BRAND_SLUG locally from BRAND with lowercase ASCII, spaces to hyphens, and unsafe characters removed; use it only for internal keys or ids, never as an external package or URL. Set lang en, the plain document title to the current view plus [BRAND], and create an original local frame-mark favicon.svg.
  - Keep one canonical catalog of exactly 100 film objects and one review collection. Derived counts, charts, library views, search results, profile metrics, and related films must read from shared state rather than duplicated hard-coded numbers.   - Wrap localStorage access in try/catch because a sandboxed demo can reject storage. Use versioned key '[BRAND_SLUG]-community-v1' for personal ratings, list state, helpful votes, written reviews, and drafts. If storage fails, retain the same state in memory for the session without throwing or showing a technical error. Seed the sample profile only when no saved state exists.
  - Self-host Instrument Serif 400, DM Sans 400/500/600/700, and IBM Plex Mono 400/500 through Fontsource Latin subsets. Use no chart, router, animation, form, or state-management dependency. Build charts as labeled SVG/HTML composites with textual values available outside the graphics.
  - Write ASSETS.md at the project root listing all six generated images with their source URLs, target paths, and required generated-image credit, plus Lucide ISC and each Fontsource package with author, package URL, and OFL-1.1 license. Download the six images into public/posters/ during the build task and use relative paths; never hotlink them at runtime.
  - Use a single React community provider for ratings, watched and want-to-watch states, helpful votes, local reviews, filters, search, and mobile navigation. Mutually exclude watched and want-to-watch; setting a star rating also marks the film watched. Offer explicit buttons for removing a rating or moving a film between lists. Keep personal changes when navigating and after reload when storage is available.

## Variables
- [BRAND] — Community name (default: "Fableframe"). An invented one- or two-word name for the wordmark, document title, profile welcome, and storage-key prefix; never a real film or community brand.
- [TAGLINE] — Home invitation (default: "Rate the films. Find your people. Know your taste."). A concise original invitation of at most 64 characters; use it as the home H1 and adapt supporting copy naturally when it changes.
- [AUDIENCE] — Community audience (default: "curious film lovers"). A short lowercase audience phrase used in the home eyebrow and supporting copy.
- [FEATURED_FILM] — Featured film title (default: "The Cartographer's Dream"). One of the six art-directed catalog titles: The Cartographer's Dream, The Night Orchard, Static Between Stars, A Room for August, Salt on the Projectionist's Hands, or The Clockwork Heron.
- [PROFILE_NAME] — Sample member name (default: "Mara Ellison"). An invented member name used for the profile greeting, initials, local reviews, and library labels; never a real person.
- [RANKED_LIST_NAME] — Ranked canon name (default: "The Hundred"). A short original name for the 100-film ranked list, used in navigation and the rankings heading.
- [CREDIT] — keep a small "Template by VibeFather" link to https://vibefather.ai/t/movie-rating-community in the footer (default: yes; delete this line to remove it)

The copy under Pages & Sections is written for the default values. If your values differ, rewrite every headline, paragraph, label and image for them — same length, tone and structure. Layout, colors, type and motion stay as described.
Keep all copy, image paths and links in one content file (for example `src/content.ts`), keyed by section, so the content can be swapped later without touching components.
