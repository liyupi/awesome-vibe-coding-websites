# Cozy Isometric Farm Game

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
Build [BRAND], an original, self-contained isometric farming game set in [SETTING]. The playable farm is [FARM_NAME]. Use the three crop names in [CROPS] and call the soft currency [CURRENCY]. The first screen is the game itself, not a landing page: a code-drawn 6×6 SVG plot, four working tools, a seed shop, a player-controlled day cycle, and automatic local progress. Keep every string, crop definition, default value, notification, and label in src/content.ts. Rewrite all default-specific names, visual details, and copy when the variables change while preserving the mechanics and composition.

- Audience: Casual players who want a calm two-minute farming session, and creators or developers who want an original browser game they can reskin without setting up a backend.
- Goal: Make the complete till → plant → water → end day → harvest → buy seeds loop immediately playable with mouse, touch, or keyboard, then persist every meaningful state change locally so returning players can continue.
- Tone: Warm, patient, lightly whimsical, and tactile. Use concise friendly instructions and satisfying visual feedback, never competitive pressure, real-money language, or childish mascot copy.

## Stack
- Framework: Vite 5 + React 18 + TypeScript 5
- Styling: Vanilla CSS + inline SVG
- Libraries: react (MIT), react-dom (MIT), vite (MIT), @vitejs/plugin-react (MIT), typescript (Apache-2.0), lucide-react (ISC), @fontsource/fraunces (OFL), @fontsource/nunito-sans (OFL)
- Build: `npm run build` → static files in `dist/`. No backend, no server code, no external APIs.
- Setup:
  - Create a Vite React TypeScript project with package.json scripts dev=vite and build=tsc && vite build; use @vitejs/plugin-react and no other runtime framework.
  - Set base: './' and build.sourcemap: false in vite.config.ts. Production output must be minified static files in dist/ and stay below 20 MB.
  - Use src/content.ts for all variables, default game configuration, crop names and colors, interface copy, help text, notifications, and dialog text. Derive a lowercase BRAND_SLUG from BRAND for the localStorage key; never duplicate default-specific copy inside components.
  - Separate the typed game reducer and persistence helpers from rendering: src/game/engine.ts owns legal actions and transactions, src/game/storage.ts validates saved data, and React components only dispatch actions and render state.
  - Import Fraunces weights 600 and 700 and Nunito Sans weights 400, 600, 700, and 800 from their Fontsource packages in src/main.tsx. Use no external font URLs.
  - Render the field and all scenery as inline SVG with reusable React components and CSS classes. Use Lucide only for interface icons; do not install an icon font, canvas engine, physics package, or 3D library.
  - Define reusable CSS custom properties, keyframes, focus states, and responsive breakpoints in src/styles.css. Include explicit 1440×900 and 390×844 layouts and prefers-reduced-motion overrides.

- [CROPS] — Three crop names (default: "Carrot, Turnip, Strawberry"). Exactly three comma-separated invented or generic crop names in shop order; give each an original code-drawn appearance.

The copy under Pages & Sections is written for the default values. If your values differ, rewrite every headline, paragraph, label and image for them — same length, tone and structure. Layout, colors, type and motion stay as described.

## Design
### Colors
- Parchment `#F6EFD8` — Page background and quiet outer negative space
- Cream `#FFF9EA` — Panels, dialogs, and primary text on dark green
- Forest Ink `#304032` — Primary text, outlines, and dark icon strokes
- Pine `#2F5D50` — Header accents, primary buttons, and selected tools
- Moss `#6E9B61` — Grass tiles, healthy foliage, and success states
- New Leaf `#A8C686` — Grass highlights and young crop leaves
- Earth `#9A6248` — Untilled soil edges, fences, and wooden panels
- Furrow `#6F4336` — Dry tilled soil and deep contact shadows
- Brook `#78B7C2` — Water tool, droplets, river, and watered-soil glints
- Sunbeam `#F3C969` — Sun, currency, ripe-crop sparkles, and harvest bursts
- Apricot `#D9825B` — Warm accents, dusk wash, and selected secondary details
- Blue Hour `#27344B` — Night overlay and darkened scenery during the day transition

### Typography
- Display: brand, farm name, day heading, and dialog titles; 700 weight, tight -0.02em tracking: Fraunces (OFL), weights 600/700
- Interface: buttons, resources, crop names, prices, instructions, and notifications; 400–800 weights: Nunito Sans (OFL), weights 400/600/700/800

### Layout & motion
- Spacing: Use a 4px base unit. Page gutters are 24px desktop and 12px mobile; panel padding is 18px desktop and 14px mobile; grid gaps are 16px; control gaps are 8px. Keep all touch targets at least 44×44px and the main tool buttons at least 52px tall.
- Radius: Large panels 24px, resource pills 999px, buttons and seed cards 14px, dialogs 28px, and SVG scenery joins rounded. Use 2px Forest Ink outlines at 18–28% opacity rather than heavy black strokes; shadows are soft olive-brown, never neon.
- Motion: Hovering or keyboard-focusing a legal tile raises its crop and highlight by 3px over 120ms; the focused diamond receives a 3px Cream and Pine double outline. Illegal actions use one restrained 180ms horizontal nudge and a text reason.
- Motion: Planting scales the seed mound from 0.7 to 1 with a 220ms ease-out. Watering drops three SVG droplets for 450ms and darkens the soil immediately. Harvesting lifts the crop 16px, fades it over 300ms, and releases six small leaf-and-coin shapes for 600ms.
- Motion: Buying a seed pulses the relevant inventory count for 240ms and briefly displays a '-4 sun coins' style delta using the actual price and CURRENCY value. Currency and inventory totals update without animated counting delays.
- Motion: End day runs a single 1400ms sequence: 0–550ms Apricot dusk wash, 550–900ms Blue Hour night wash with three small stars, then 900–1400ms return to morning. Advance the reducer once at the night midpoint and announce the new day after the transition.
- Motion: Two small clouds drift no more than 24px over 18 seconds and ready crops gently bob by 2px on a staggered 2.8-second loop. Disable clouds, bobbing, particles, nudges, and the long day transition under prefers-reduced-motion; retain immediate state and color changes.
- Imagery: Create every visual from original inline SVG and CSS: rounded diamond soil tiles, simple geometric crops at four growth stages, two generic round-canopy trees, a short fence, rounded hills, two clouds, a narrow river ribbon, tiny stones, and grass marks. Use a fixed 2:1 isometric projection, layered SVG shading, sparse hand-drawn-looking dashes, and no downloaded sprites, raster textures, people, animals, mascots, logos, or recognizable game assets. Adapt crop colors and distant decorative scenery to CROPS and SETTING while retaining the palette roles, composition, and exact field geometry.

## Don'ts
- Do not add a backend, serverless functions, API routes, database, authentication, analytics, remote forms, third-party APIs, multiplayer, real payments, or network-dependent game state. All gameplay and saving must work from static files offline after loading.
- Do not change the prescribed Vite/React/TypeScript stack, add a game engine, use Unity/Unreal/Godot, or introduce Three.js for this 2D SVG isometric game. Build with npm run build to dist/ using base './', minification, no source maps, no src/ copied to dist/, and total output below 20 MB.
- Do not hotlink or download stock photos, sprites, textures, audio, placeholder services, scripts, stylesheets, or fonts. Everything must be local; use original inline SVG/CSS art, bundled Lucide icons, and Fontsource packages only.
- Do not load fonts from Google Fonts, Adobe Fonts, or any CDN, and do not use commercial fonts or license-restricted libraries, including Aceternity UI source, Tailwind Plus source, purchased templates, packages without licenses, or CC BY-NC/CC BY-SA assets.
- Do not use existing farming-game or other brand names, logos, mascots, character designs, signature scenery, recognizable sprites, crop illustrations, icons, exact interface layouts, dialogue, slogans, or copied copy. Do not depict real people, branded products, or anime/game characters.
- Do not make the first screen a marketing hero, landing page, title-only splash, or instructions wall. The complete playable 6×6 field and its controls must be immediately visible and interactive on desktop and mobile.
- Do not enlarge the field, add levels, random events, combat, energy timers, loot boxes, real-time countdown pressure, automatic day advancement, or a backend economy. Preserve the specified 6×6 grid, four tools, three crops, prices, player-controlled day cycle, and deterministic growth rules.
- Do not create additional routes or bare-directory links. Keep the experience in index.html with dialogs and a mobile bottom sheet; any internal link must point to ./index.html or an in-page anchor, and the optional credit may be external.
- Do not rely on hover, right-click, drag, or pointer-only SVG targets. Every action must work with mouse, single tap, and keyboard; maintain visible focus, 44px minimum targets, accessible tile names, focus-managed dialogs, and aria-live feedback.
- Do not allow negative coins or inventory, double-charge repeated taps, grow unwatered crops, advance a day more than once per transition, or lose progress on reload. Validate localStorage and confine reset to this game's own versioned key.
- Do not hard-code BRAND, FARM_NAME, SETTING, CURRENCY, CROPS, or their default-specific sentences outside src/content.ts. Rewrite interface and decorative details when variables change, and never mention VibeFather in the site except the optional [CREDIT] link.
- Do not add SEO metadata, Open Graph tags, JSON-LD, sitemap code, keyword-stuffed headings, or dates from the real calendar. A plain [BRAND] document title, original favicon, and in-game day counter are sufficient.
- Do not ignore prefers-reduced-motion, crop the SVG field on mobile, cause horizontal overflow, obscure controls with sticky UI, or ship console errors. Verify the real game at 1440×900 and 390×844 with touch emulation and a production build.
