# Coworking Space Website

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
A single-page site for [SPACE], a [DESKS]-desk coworking space in [CITY] — [VIBE]. It must show the space honestly: an interactive floor map with per-zone availability (sample state), three membership plans, amenities, community events with client-side RSVP, a noise-honesty strip, and a tour booking form that carries the map selection through. One page: index.html with sections (#map, #plans, #amenities, #events, #tour). Everything runs in the browser; nothing is submitted anywhere.

- Audience: Freelancers and small teams scouting a desk: remote workers escaping home, two-person startups, moonlighting side-project builders. They want to feel the space's sound level, see real pricing, and book a tour without an email maze.
- Goal: Book the tour. Within ten seconds a visitor sees the space, the from-price and the map; within two minutes they've hovered the map, picked a plan and chosen a tour day.
- Tone: Warm and matter-of-fact, like the community manager's welcome email. Real numbers (desks, hours, prices), honest noise talk, one joke about the printer.

- Setup:
  - Scaffold with npm create vite@latest using the react-ts template. One HTML page at the project root: index.html (entry src/main.tsx).
  - vite.config.ts: base './', plugins [react()], build { outDir 'dist', sourcemap false, assetsInlineLimit 0 }. Do not copy src/ into dist/.
  - Tailwind 3.4 through PostCSS, content ['./index.html', './src/**/*.{ts,tsx}']. In tailwind.config.ts add every color under Design to theme.extend.colors with kebab-case keys (offwhite, linen, card, walnut, bark, coral, coral-deep, sage, rule) and fontFamily display ['Sora Variable', 'system-ui', 'sans-serif'], sans ['Albert Sans Variable', 'system-ui', 'sans-serif']. Set borderRadius DEFAULT to 12px and add maxWidth { container: '1200px' }.
  - In src/fonts.ts import '@fontsource-variable/sora' and '@fontsource-variable/albert-sans'; import src/fonts.ts and src/index.css from the entry file.
  - File layout: src/content.ts (every string, plan, amenity, event, zone, availability seed, price and image path, typed), src/lib/brand.ts (spaceSlug = [SPACE] lowercased with every run of non-alphanumeric characters replaced by '-', emailDomain = spaceSlug without hyphens + '.com'), src/lib/storage.ts (safe localStorage get/set wrapped in try/catch, keys prefixed with spaceSlug + ':'), src/lib/floorplan.ts (zone list with geometry ids, seeded availability counts stable across reloads, takenZones(zoneId) deterministic list).
  - State: src/store/tour.ts is a tiny external store (useSyncExternalStore) holding { zoneId, name, email, day, rsvps: string[] } persisted to localStorage key spaceSlug + ':tour'. Selecting a zone on the map writes zoneId; the tour form and RSVPs read from it.

  - Write ASSETS.md at the project root as described under Assets.

## Variables
- [SPACE] — Space name (default: "The Print Works"). Invented coworking name. Used in the wordmark, title, footer, email (hello@ + spaceSlug without hyphens + .com) and localStorage keys. Never a real space or brand.
- [CITY] — City (default: "Philadelphia, Pennsylvania"). Where the space is. Used in the hero, events' neighborhood lines and the footer. Real cities fine; the street invented.
- [DESKS] — Desk count (default: "40"). Total desks as digits. Drives the hero strip, the map's zone capacities and the plans' availability lines. Keep it 15–80.
- [VIBE] — Vibe phrase (default: "warm, plant-heavy and quietly busy"). One lowercase phrase describing the atmosphere. Drives the hero line, the noise strip's honesty and the tour form's reassurance.
- [CREDIT] — keep a small "Template by VibeFather" link to https://vibefather.ai/t/coworking-space-website in the footer (default: yes; delete this line to remove it)

The copy under Pages & Sections is written for the default values. If your values differ, rewrite every headline, paragraph, label and image for them — same length, tone and structure. Layout, colors, type and motion stay as described.
Keep all copy, image paths and links in one content file (for example `src/content.ts`), keyed by section, so the content can be swapped later without touching components.

### Layout & motion
- Spacing: 8px base unit. Container max-width 1200px, centered, side padding 48px desktop, 32px tablet, 20px under 640px. 12-column grid, column gap 24px. Section vertical padding 96px desktop, 72px under 1024px, 56px under 640px. Type scale: H1 clamp(42px, 6.2vw, 78px) Sora 700, line-height 1.04; H2 clamp(28px, 3.8vw, 46px) Sora 700; H3 21px Sora 600; lead Albert Sans 400 17.5px / 1.65 Walnut at 90%; body 15.5px / 1.7 (max-width 64ch); eyebrow Albert Sans 700 12px uppercase letter-spacing 0.16em Bark; caption 13px Bark. Buttons: height 50px, Albert Sans 700 14px. Primary: Walnut fill, Card text. Secondary: 1px Walnut border, Walnut text. Inputs: height 50px, 1px Rule border, Card fill, focus Walnut border. Focus ring everywhere: 2px Walnut outline with 3px offset.
- Radius: 12px on cards, buttons, inputs, chips and photos. 999px only for pills, availability dots and RSVP ticks.
- Motion: Easing: --ease-out cubic-bezier(0.22, 0.61, 0.36, 1) for reveals and zone transitions; --ease-io cubic-bezier(0.65, 0, 0.35, 1) for map selection and the tour swap. Calm — this is a workspace pitch.
- Motion: Reveal: blocks wrapped in <Reveal> start at opacity 0, translateY(12px) and settle over 650ms --ease-out when 15% visible (Motion whileInView, viewport once). Siblings stagger 70ms.
- Motion: Hero: the lounge photo scales 1.04→1.0 over 2400ms; the headline rises; the from-price ticks up once.
- Motion: Floor map: zones idle at Rule strokes with Bark labels; hover fills Linen, lifts 1px and shows the availability tooltip (Sage dot '6 of 8 free' tabular); taken desks within a zone dim as small squares; clicking selects — the zone fills Coral at 12% with a Coral stroke and the legend updates; selection swaps with a 200ms --ease-io crossfade. The plan draws in on first view (stroke-dashoffset, 1000ms).
- Motion: Plans: the featured card lifts 6px permanently; hover ticks the price 2px; the 'included' checks stagger 40ms.
- Motion: Events: RSVP toggles the button to 'Going ✓' (Sage tick drawing, 300ms) and increments the count with a tabular tick; second click cancels politely ('Maybe not' on hover).
- Motion: Tour form: day chips fill Walnut on select; invalid submit shakes 4px with inline labels; sending swaps to Confirmed (300ms --ease-io) — a drawn floor-plan fragment stamp 'TOUR BOOKED' rotating in -5deg→-2deg, the selected zone echoed ('Asking about: the mezzanine, 3 dedicated desks free').
- Motion: Links: .link-draw grows a 1px currentColor underline over 280ms on hover and focus-visible.
- Motion: prefers-reduced-motion: reduce — the plan renders drawn, no lifts, ticks, staggers or stamps; zone selection is an instant color change. Use CSS @media in index.css plus Motion's useReducedMotion in components.
- Imagery: Warm workplace photography, all six made for this template in one consistent style: big windows, pale wood and plants, walnut tones with coral accents — desks, lounges, booths and kitchen corners, never a person (no faces, no hands, no laptops-with-screensavers-of-people). No readable text or signage. Every photo uses object-fit cover with the object-position given under Assets, 12px corners, no shadow; photos on Offwhite get a 1px Rule outline. Captions in Albert Sans 13px Bark. Drawn in code: the floor plan (linework zones, desks as small squares, doors as arcs), tooltips, availability dots, the stamp, chips and the favicon. Icons: lucide-react only, stroke width 1.75.

## Don'ts
- No backend, no form submission, no fetch to any API: the map selection, RSVPs and tour save in the browser only (localStorage); availability is labeled sample state; the form says nothing is sent.
- All links on this single page are anchors (./index.html#map, #plans, #amenities, #events, #tour).
- Self-host everything: fonts through Fontsource, icons as npm packages or inline SVG, images downloaded into public/images/. No CDN <script> or <link> tags, no Google Fonts, no analytics.
- Production build: minified, no source maps, no src/ copied into dist/, single command npm run build, output in dist/ under 10 MB.
- No real coworking brands, members or hosts; no photos with people, faces or hands; no readable signage; all prices, counts and events invented.
- No dates or years anywhere: events are weekday-named, the tour picker shows weekday chips without full dates; the site never shows today's date.
- Never mention VibeFather or any other brand inside the site except the optional credit footer link; all copy is invented US English.
- Respect prefers-reduced-motion: the plan renders drawn, no lifts/ticks/stamps/staggers; zone selection is a color change; hovers stay.
- The site must work at 1440x900 desktop and 390x844 mobile with zero console errors; zones, chips, RSVPs and the form work with keyboard only and visible focus rings; the map is focusable per-zone (arrow keys move between zones).
- Keep copy concrete: no lorem, no 'synergy'; every price, count and amenity lives in src/content.ts.
