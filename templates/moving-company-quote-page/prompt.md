# Moving Company Quote Page

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
Build an original single-page lead-generation website for [BRAND], an invented moving company serving [SERVICE_AREA]. The page helps [AUDIENCE] create a transparent instant estimate from home size, editable room inventory, and driving distance, then save a booking request with that estimate attached. Use the default English copy specified below, and rewrite all copy, examples, reviews, and contact details when the variable values change.

- Audience: People comparing local movers who want a useful planning range before speaking to a coordinator, plus moving-company owners who need a credible, high-intent quote and booking page.
- Goal: Make the quote calculator the primary interaction, explain how the numbers are produced, build trust with concrete service details and invented reviews, and convert the completed estimate into a client-side booking request.
- Tone: Calm, capable, warm, and precise. Sound like an experienced move coordinator rather than a sales page. Use plain US English, specific inclusions, realistic sample details, and no pressure tactics.

## Stack
- Framework: Vite 6 + React 19 + TypeScript
- Styling: Tailwind CSS 4
- Libraries: react (MIT), react-dom (MIT), tailwindcss (MIT), @tailwindcss/vite (MIT), motion (MIT), lucide-react (ISC), @fontsource-variable/fraunces (OFL-1.1), @fontsource-variable/dm-sans (OFL-1.1)
- Build: `npm run build` → static files in `dist/`. No backend, no server code, no external APIs.
- Setup:
  - Configure vite.config.ts with base './', build.sourcemap false, and the React and Tailwind Vite plugins; the production entry is index.html and all asset URLs must be relative.
  - Use Tailwind CSS 4 with a small src/index.css theme for the exact colors, font families, keyframes, focus rings, and reduced-motion overrides; keep layout components in src/components.
  - Put every variable default, headline, button label, review, FAQ, contact detail, inventory item, move-size preset, and pricing constant in src/content.ts. Rewrite default-specific content when variables change; never leave the old brand, location, audience, rate, or phone number behind.
  - Implement the pure calculation functions in src/lib/estimate.ts and shared React state in src/App.tsx. Persist the current inventory, distance, and booking draft in localStorage, with safe defaults if storage is unavailable.
  - Import the self-hosted Fraunces Variable and DM Sans Variable packages in src/main.tsx. Use Motion for React through motion/react and Lucide React for all interface icons.
  - Create an original favicon from three simple offset rectangular outlines in spruce and apricot; do not imitate an existing moving-company mark.

## Variables
- [BRAND] — Moving company name (default: "Juniper Lane Movers"). An invented local moving-company name used throughout the site.
- [SERVICE_AREA] — Service area (default: "Portland and the Willamette Valley"). The city or region the company serves.
- [AUDIENCE] — Primary customers (default: "Apartment renters, growing families, and small offices"). A short phrase describing the people and organizations the mover serves.
- [BASE_RATE] — Two-mover hourly rate in USD (default: "145"). Numeric only. The calculator adds 45 per additional mover per hour.
- [PHONE] — Booking phone number (default: "(503) 555-0148"). A display and telephone-link number; use fictional sample contact details.
- [CREDIT] — keep a small "Template by VibeFather" link to https://vibefather.ai/t/moving-company-quote-page in the footer (default: yes; delete this line to remove it)

The copy under Pages & Sections is written for the default values. If your values differ, rewrite every headline, paragraph, label and image for them — same length, tone and structure. Layout, colors, type and motion stay as described.

- Do not leave console errors, nonfunctional buttons, inaccessible disclosures, low-contrast helper text, or horizontal overflow. Verify 1440×900 and 390×844, keyboard operation, visible focus, and 48px mobile form targets.
