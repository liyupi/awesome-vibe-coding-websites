# Food Delivery Mobile App — Design System

Apply this design system to an existing project. It describes the look and feel only; for the full site, use prompt.md.

## Colors
- **Warm White** `#FFFDF9` — Primary appetizing light canvas
- **Espresso Ink** `#1C1917` — Headlines, prices, and high-contrast cards
- **Saffron Orange** `#EA580C` — Primary order CTAs, active cuisine chips, courier pin, and promo highlights
- **Basil Green** `#16A34A` — Live ETA badges, verified ratings, promo applied state, and active delivery step
- **Warm Sand** `#F4EFE6` — Subtle input fills, chip backgrounds, and map blocks
- **Stone Muted** `#78716C` — Distance metadata, item descriptions, and secondary captions

## Typography
- **Appetizing editorial display headings** — Fraunces (OFL), weights 600/700. Self-host the font files.
- **Menus, cards, and controls** — Plus Jakarta Sans (OFL), weights 400/500/600/700. Self-host the font files.
- **Prices, ETAs, promo codes, and order IDs** — IBM Plex Mono (OFL), weights 400/500/600. Self-host the font files.

## Spacing & shape
- Spacing: Mobile (<768px) uses 16px horizontal padding with 84px bottom clearance above the fixed bottom tab bar and floating cart banner. Desktop (>=1024px) displays a clean top bar + 2-column kitchen grid alongside a 360px sticky right cart & live-order rail.
- Radius: 16px for dish cards and customization bottom sheets, 12px for menu rows and map cards, 999px for cuisine chips and ETA pills.

## Motion
- Smooth slide-up animation for the dish customization bottom sheet and mobile cart drawer.
- Live animated courier marker gliding along the stylized SVG neighborhood route in Orders view.
- Respects prefers-reduced-motion; all content visible immediately.

## Imagery
Six cohesive warm-daylight studio photographs of freshly plated neighborhood dishes shot on handmade stoneware and warm wood, with zero brand logos, zero text, and zero packaging labels.

## Tone
Warm, appetizing, neighborhood-friendly, fast, and clear.
