> Moody two-page cocktail bar site with a spirit-grouped drinks menu, events, private hire enquiry and table booking.

A two-page website for a craft cocktail bar: a home page opening on the room in amber candlelight with the bar's promise and a book-a-table CTA, the drinks menu grouped by spirit (gin, whiskey, agave, zero-proof) with honest one-liners and prices, a bartender-at-work photograph anchoring the menu, the room in three photographs (leather booths, the back bar, the terrace), four recurring event nights (weekday-named, never dated) and a trust strip; and a visit page with hours and an open-now indicator, private hire enquiry (capacity, occasion — client-side), and a table booking flow (party size, day chips, seating-area preference) confirming client-side. The default content follows an invented basement bar, but the structure suits any dark drinking or listening bar — wine, mezcal, jazz: change the name, city and spirit list and every menu line still reads true. The look is amber noir: near-black surfaces, candle amber light, one brass hairline, Oswald tall condensed headlines over Karla, glassware photography and small-caps menu typography with unhurried fades. Photography shows the room, glassware, blank-labeled bottles and one AI-generated fictional bartender at work — no customer faces. To adapt it, swap the variables and rewrite the copy in one content file.

## Variables

Replace these in the prompt with your own values; everything else stays as written.

| Variable | What it is | In the demo |
|---|---|---|
| `[BAR]` | Bar name | The Amber Room |
| `[CITY]` | City | New Orleans, Louisiana |
| `[NEIGHBORHOOD]` | Neighborhood | the Warehouse District |
| `[SPIRITS]` | House spirits | gin, rye and agave |

## How to use it

1. Copy [prompt.md](prompt.md), or run `npx vibefather add cocktail-bar-website` in your project.
2. Replace the `[VARIABLES]` with your own brand, copy and details.
3. Paste it into Claude Code, Codex, Cursor or another AI coding agent and let it build. [DESIGN.md](DESIGN.md) holds the colors, type and spacing on their own if you only want the look.

## Make it yours

- A mezcal and listening bar: set SPIRITS to mezcal, tequila and rum, rewrite the menu one-liners around agave, and swap the event nights for record-listening sessions.
- A neighbourhood wine bar: set SPIRITS to the wine styles you pour, replace the cocktail rows with bottles and by-the-glass prices, and keep the room strip and booking flow.
- A private event venue: keep the visit page's private hire enquiry, raise the capacity field to your room size, and lead the home page with the three room photographs.
- A members-style jazz bar: use NEIGHBORHOOD for the district, rename the four event nights after your weekly sets, and point the book CTA at your table booking flow.

## FAQ

### What does the Cocktail Bar Website template include on each of its two pages?
The Cocktail Bar Website template has two pages. The home page opens on an amber-candle hero with the bar's promise and a book-a-table button, then a drinks menu grouped by spirit with prices, a bartender-at-work photo, the room in three photographs, four recurring event nights and a trust strip. The visit page holds hours with an open-now indicator, a private hire enquiry and a table booking flow.

### How do I change the bar name, city and spirits in the Cocktail Bar Website template?
The Cocktail Bar Website template is driven by four variables: BAR, CITY, SPIRITS and NEIGHBORHOOD. Set them in the prompt before you build, or edit the single content file afterward. BAR feeds the wordmark, page titles, footer, contact email and saved booking state; SPIRITS drives the three spirit groups on the menu plus the zero-proof group, so keep exactly three.

### Do the table booking and private hire forms actually send anything?
No. Both forms in the Cocktail Bar Website template are client-side only. The table booking flow takes party size, day chips and a seating-area preference; the private hire enquiry takes capacity and occasion. Both write to the same saved request and show a confirmation card, and nothing is submitted to a server. To take real bookings you connect them to your own booking system or inbox.

### Can the Cocktail Bar Website template work for a wine bar or a mezcal bar instead of a cocktail bar?
Yes. The Cocktail Bar Website template suits any dark drinking or listening bar. One live demo already renders it as a mezcal listening bar. Change BAR, CITY, NEIGHBORHOOD and SPIRITS, then rewrite the drink one-liners, the room captions and the four event nights in the content file. The structure holds as long as you keep three spirits and a zero-proof group.

### What should I change first in the Cocktail Bar Website template before publishing?
Start with the four variables, then the contact details. Set BAR, CITY, NEIGHBORHOOD and SPIRITS so the wordmark, titles, hero line and menu groups match your venue, and check that the email address built from the bar name is one you actually read. Next rewrite the drinks with real prices and honest one-liners, then the hours table, which drives the open-now indicator.

### How do I build a cocktail bar website with AI?
Copy the prompt from this page or run npx vibefather add cocktail-bar-website, replace [BAR], [CITY], [NEIGHBORHOOD] and [SPIRITS] with your own content, and paste it into Claude Code, Codex, Cursor or another AI coding agent. The live demos were built from exactly that text.
