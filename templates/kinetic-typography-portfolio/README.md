# Kinetic Typography Portfolio <sup>PRO</sup>

> A motion designer portfolio where giant variable type splits, stretches and re-forms as you scroll.

This is a four-page portfolio for a motion designer, type animator or title designer, built so the lettering itself is the main artwork. The designer's name fills the first screen in a wide variable font, with a studio photograph showing through the letters of the first line. As you scroll, the letters break apart, squeeze and widen along the width axis, then lock back together. The project index is a stack of very large titles. Hovering a title moves it through weight and width, and a small preview still clips in beside the cursor. Clicking a project starts a full-screen transition: one giant word sweeps across an orange-red panel and gets heavier as it moves, and then the case study appears. The palette is near-black and warm off-white with one hot accent. Display type uses the open-license Anybody variable font, with Inter for body text and JetBrains Mono for labels, all self-hosted. The project stills are drawn in code with canvas and SVG, so they stay sharp and keep the build small, and they still look like frames from a real reel. A few photographs of a fictional designer at work keep the pages human. The template suits freelance motion designers, art directors, lettering artists and small type-led studios who want their portfolio to show how they handle motion before anyone opens a case study. It also works for anyone presenting a body of creative work in a type-driven way. To adapt it, change the name, discipline, city, specialties and booking note, then rewrite the project list in the single content file. Each case page builds its header, credits grid, stills and next-project link from that list. Under reduced-motion settings, all animation stops and the type sits at its resting weights.

## Make it yours

- A freelance title designer: set BRAND to your name and SPECIALTIES to film and series title sequences, then rewrite the project list around opening credits and end cards.
- A small type-led studio: use a two-word studio name as BRAND, set DISCIPLINE to brand motion systems, and swap the case studies for identity and campaign work.
- A lettering artist: keep the giant variable type but point SPECIALTIES at custom lettering and signage, and replace the motion stills with letterform studies.
- An art director building a personal brand: set CITY and AVAILABILITY to your booking window, and rewrite the about page credits, clients and awards around your own career.

## FAQ

### How do I change the designer name and details in the Kinetic Typography Portfolio?
The Kinetic Typography Portfolio template pulls every page from one content file. Set BRAND to your name, DISCIPLINE to what you do, CITY to your base, SPECIALTIES to the work you want commissioned and AVAILABILITY to your booking note. The prompt asks you to rewrite the headlines, project list and clients so they fit the new person, because the default copy is written for a motion designer.

### What does the scrolling type animation actually do on the Kinetic Typography Portfolio?
The Kinetic Typography Portfolio template sets the designer's name as giant variable type on the first screen, with a studio photograph showing through the letters. As you scroll, the letters split apart, stretch and squeeze along the width axis, then lock back together. The motion runs on GSAP and Lenis smooth scrolling, and all of it stops under reduced-motion settings, where the type sits at resting weights.

### How do I add my own projects and case studies to the Kinetic Typography Portfolio?
Add each project to the projects list in the template's single content file, with its slug, title, client, year, category, role, duration, team, tools, summary, brief, approach, outcome and quote. The project index, the hover previews, each case page header, credits grid and stills, and the next-project link all build from that list. The case page opens with ?slug= and defaults to the first project.

### Can I use the Kinetic Typography Portfolio for client work?
The Kinetic Typography Portfolio template is a Pro template, so commercial and client use is covered by Pro membership. Free templates' prompts and every DESIGN.md are licensed for personal, non-commercial use only.

### What should I edit first after generating the Kinetic Typography Portfolio?
Start with BRAND, since the name is the hero artwork, the wordmark and the email address, and two short words of about 8 to 14 letters read best as giant type. Then set DISCIPLINE, CITY, SPECIALTIES and AVAILABILITY, and rewrite the project list so the titles, clients and stills match your own reel rather than the fictional motion designer's.
