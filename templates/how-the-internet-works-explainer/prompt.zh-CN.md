# 互联网工作原理讲解站

完全按照以下描述构建此网站。将 [VARIABLES] 替换为你自己的值；其余内容保持不变。

## 简介
由 Northbeam Primers 发布的一个单页滚动叙事式讲解页面，追踪一次从笔记本电脑到源服务器再返回的、针对 https://kettleandcrumb.example/recipes/rye-sourdough 的 HTTPS 请求。七个全高场景（请求、DNS 查询、抽象点状地图上的路由器跳转、TCP 握手、TLS 与锁、服务器以数据包形式的回复、渲染），每个场景将三个简短的阅读节拍与一个粘性代码绘制的 SVG 图表以及恰好一个动手控件配对。一个头部轨道追踪数据包所处的阶段和一个运行中的往返计时器；一个快速重放和一份 14 词术语表为故事收尾。当变量变化时，所有文案和示例数据都会被重写以适配它们；将所有内容保留在 src/content.ts 中。

- 受众：每天使用网络但从未见过底层发生什么的好奇读者；也可供教师和开发者倡导者用作课程页面。
- 目标：让一次往返变得具体可感：读者最终应能按顺序了解七个阶段，理解为什么距离和握手会增加时间，以及锁究竟保护了什么，并且应在此过程中玩过每一个控件。
- 语气：冷静、精确且友好，像一位优秀的科学编辑：短句， sparingly 使用日常类比，精确数字用等宽字体，不炒作，不开以读者为代价的玩笑。

## 技术栈
- 框架：Vite 5 + 原生 TypeScript
- 样式：Tailwind CSS 3.4
- 库：vite 5（MIT）、typescript 5（Apache-2.0）、tailwindcss 3.4、postcss、autoprefixer（MIT）、gsap 3（核心 + ScrollTrigger）（GSAP Standard License（免费，允许商业使用））、lucide（原生包）（ISC）、@fontsource-variable/space-grotesk（OFL-1.1）、@fontsource-variable/source-serif-4（OFL-1.1）、@fontsource/ibm-plex-mono（OFL-1.1）
- 构建：`npm run build` → 静态文件输出到 `dist/`。无后端、无服务端代码、无外部 API。
- 设置：
  - 使用 Vite vanilla-ts 模板搭建脚手架。单一入口 index.html，包含 <title>[TOPIC] · [BRAND]</title> 和 <link rel="icon" href="./favicon.svg" type="image/svg+xml">；index.html 仅包含 <div id="app"></div> 和 script 标签，main.ts 从 content.ts 构建 DOM。
  - vite.config.ts：base './'，build.outDir 'dist'，build.sourcemap false，默认 esbuild 压缩。package.json 脚本：dev = vite，build = tsc --noEmit && vite build，preview = vite preview。
  - tailwind.config.ts：content ['./index.html', './src/**/*.ts']；theme.extend.colors 包含设计部分的所有令牌（ink、panel、raised、grid、hairline、fog、haze、paper、paper-ink、paper-muted、paper-rule、signal、amber、loss）；fontFamily display ['Space Grotesk Variable', 'system-ui', 'sans-serif']，serif ['Source Serif 4 Variable', 'Georgia', 'serif']，mono ['IBM Plex Mono', 'ui-monospace', 'monospace']。
  - src/main.ts 导入 '@fontsource-variable/space-grotesk'、'@fontsource-variable/source-serif-4'、'@fontsource/ibm-plex-mono/400.css'、'@fontsource/ibm-plex-mono/500.css'、'@fontsource/ibm-plex-mono/600.css' 和 './styles.css'，然后调用一次 gsap.registerPlugin(ScrollTrigger)。
  - src/styles.css：@tailwind base/components/utilities，颜色的 CSS 变量，.dot-grid 背景（径向渐变点 1px #1F2E4D 每 22px），闪烁光标关键帧，.packet-trail 虚线关键帧，以及一个 @media (prefers-reduced-motion: reduce) 块，移除粘性定位和所有动画。
  - src/content.ts 保存每个字符串和每个数字：hero 文案、轨道阶段标签、七个场景（kicker、headline、三个节拍、标注文本、控件标签）、DNS 服务器和每步毫秒数、三个路由预设及其节点名称、坐标和每链路毫秒数、握手数字、TLS 证书字段、响应头、瀑布图标签、回顾标签、术语表和页脚。场景模块仅从中读取。当变量值变化时，重写文案并重新生成此文件中的示例数据以适配它们，保持相同的形状和数量。
  - src/state.ts：一个小型存储（get、set、subscribe），持有 activeStage（0-7）、distance（'city' | 'country' | 'ocean'，默认 'country'）、lossPercent（0 | 5 | 10 | 15 | 20，默认 0）、warmReload（布尔值）、dnsCache（已查找域名的 Set，初始为空）和 handshakeStep（0-3）。导出 timeline(state)，返回 Pages 部分描述的累积里程碑；头部计时器、场景标签、瀑布图和回顾都从中读取。
  - src/scenes/：每个场景一个模块（request.ts、dns.ts、route.ts、tcp.ts、tls.ts、response.ts、render.ts、recap.ts），每个导出 mount(sceneEl, store)，构建其 SVG、连接其一个控件并注册其 ScrollTriggers。src/lib/svg.ts 有辅助函数（el(tag, attrs)、pathFromPoints、pointAt(path, t) 使用 getPointAtLength）；src/lib/motion.ts 从 matchMedia('(prefers-reduced-motion: reduce)') 导出 prefersReducedMotion。
  - 图标：从 'lucide' 导入单个图标并用 createElement(IconNode) 渲染，以便仅打包使用的图标；大小 18，描边宽度 1.75，颜色 currentColor。
  - public/favicon.svg：BRAND 标记（见头部）在 #0A1222 圆角方块上。
  - 在项目根目录编写 ASSETS.md，列出三个 Fontsource 包和 lucide（源 npm URL、作者、许可证），并声明本项目中的每个图表和插图均以代码绘制。

## 变量
- [BRAND] — 发布者或系列名称（默认：“Northbeam Primers”）。该解释页面的虚构发布者，显示在页眉字标、主视觉引导语、<title> 和页脚中。
- [TOPIC] — 解释页面标题（默认：“How one web page reaches your laptop”）。页面所回答的问题；用作主视觉标题和 <title> 中的标题。
- [SITE_DOMAIN] — 正在加载的示例站点（默认：“kettleandcrumb.example”）。读者“访问”的虚构站点。必须以保留名称结尾（.example 或 .test，或 example.com 的子域名），以确保它永远不会指向真实站点。用于地址栏、DNS 记录、证书、标头和模拟页面。
- [PAGE_PATH] — 在该站点上请求的页面（默认：“/recipes/rye-sourdough”）。地址栏和 GET 行中的路径。场景 7 中笔记本电脑上绘制的模拟页面显示与此路径匹配的内容。
- [AUDIENCE] — 页面的目标读者（默认：“curious readers who use the web every day but have never seen what happens underneath”）。决定词汇、类比以及每个节拍使用多少术语。
- [CREDIT] — 在页脚保留一个小型“Template by VibeFather”链接，指向 https://vibefather.ai/t/how-the-internet-works-explainer（默认：是；删除此行以移除它）

“页面与区块”下的文案是为默认值编写的。如果你的值不同，请为它们重写每个标题、段落、标签和图像——保持相同的长度、语气和结构。布局、颜色、字体和动效保持所述不变。
将所有文案、图像路径和链接放在一个内容文件中（例如 `src/content.ts`），按区块作为键，以便之后可以在不触及组件的情况下替换内容。

### 布局与动效
- 间距：8px 基础单位。内容容器最大宽度 1280px，两侧内边距 32px（移动端 16px）。场景在桌面端有 120px 垂直内边距，移动端 72px，节拍在桌面端间隔 60vh，移动端 40svh。卡片内部使用 20-30px 内边距；图表内部标签与边缘之间至少保持 24px。
- 圆角：图表面板 20px，主视觉卡片和回顾面板 24px，阅读卡片 16px（移动端 14px），标注和输入框 10px，术语表卡片 14px，按钮、标签和计时器胶囊 999px，数据包方块 3px，数据包瓦片 4px。
- 动效：场景结构使用 CSS position: sticky 实现图表（而非 GSAP pin），GSAP ScrollTrigger 仅用于检测哪个节拍处于活动状态。每个节拍卡片一个 ScrollTrigger：start 'top 65%'，end 'bottom 65%'，onToggle 时当 isActive 设置该场景的节拍索引（0-2）。节拍变化运行一个 GSAP 时间线（0.7s，ease 'power3.inOut'），从当前图表状态过渡到该节拍的目标状态，overwrite 'auto'，因此向上滚动时能干净地反向播放。
- 动效：节拍卡片：非活动卡片处于不透明度 0.45；活动卡片变为不透明度 1，并在 0.4s 'power2.out' 内从 y 12px 平移到 0。
- 动效：数据包：一个 12x12px 信号色圆角方块（rx 3），顶部三分之一处有一条 3px ink 条纹（即"头部"），通过 GSAP 补间在代理 {t: 0 → 1} 上沿 SVG 路径移动，在 update 时调用 path.getPointAtLength(t * length)；节点之间 ease 'none'，在每个路由器处暂停 0.12s，此时节点环脉冲（scale 1 → 1.6，opacity 0.8 → 0，持续 0.5s）。
- 动效：虚线轨迹：每条活动链接是一条 1.5px 信号色路径，stroke-dasharray '3 6'，使用第二条遮罩路径在数据包后方显现，其 stroke-dashoffset 与数据包同步从路径长度补间到 0；一旦显现，虚线漂移（stroke-dashoffset 以每秒 -18 线性无限动画）。
- 动效：页头往返计时器通过 GSAP 补间在 0.6s 'power2.out' 内向上或向下计数到新的里程碑，四舍五入到整毫秒；活动轨道数据包点在 0.5s 'power3.inOut' 内在阶段站点之间滑动。
- 动效：主视觉：引导语、标题、副标题和按钮在加载时依次淡入上移 16px（stagger 0.08s，每个 0.6s）；主视觉笔记本电脑中的 URL 以每字符 32ms 的速度打字输入，2px 信号色光标闪烁（steps(1) 1s）；主视觉数据包每 3.2s 沿其路径无限循环。
- 动效：锁定：TLS 锁在 SVG 中绘制；其锁梁从 y -6px（打开，绕右腿旋转 -18deg）在 0.5s 'back.out(2)' 内平移到闭合，徽章闪烁琥珀色一次。
- 动效：微交互：按钮和标签在悬停时上浮 1px，过渡 150ms；focus-visible 获得 2px 信号色轮廓，偏移 2px；分段控件在活动选项下方滑动一个凸起滑块，持续 0.25s。
- 动效：prefers-reduced-motion：无打字、无循环数据包、无漂移虚线、无补间、无粘性图表。每个场景在介绍文本之后以最终节拍状态将图表渲染为普通块，节拍作为普通卡片跟随，每个控件仍然以即时（0s）更新工作。
- 图像：无照片，无栅格图像。所有视觉元素均为代码绘制的内联 SVG：一台中性、通用的笔记本电脑（圆角上盖、带一个地址栏的普通窗口框架、无标志、无交通灯按钮、无可识别的操作系统或浏览器界面）、一个通用服务器机架（堆叠单元带 LED 点）、路由器节点（6px 圆带 1.5px 环）、一张由数学生成的抽象点状陆地地图（网格上的点保持在几个重叠椭圆内，边缘带正弦摆动，绝不描摹真实地理）、序列图、数据包瓦片以及笔记本电脑屏幕上的简单模拟网页。描边为 1.5px，圆角，调色板限于上述令牌。数据包始终是抽象圆角方块，绝不是字符。Lucide 图标仅出现在 UI 控件中。
