# Biotech Startup Website

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
A single-page marketing site for [BRAND], an invented science company whose [PLATFORM] platform works on [FOCUS]. The page opens with a hero anchored by a large code-drawn molecule rotating on canvas over a faint dot grid, with two drifting cell shapes behind it. It then explains the platform in three moves (problem, three-step approach, mechanism with a drawn diagram), presents the pipeline as a stage table (Discovery, Preclinical, Phase I, Phase II) with invented [PROGRAM_PREFIX] codes and pill status chips, a metrics band with count-up numbers, an invented publications list with generic journal descriptors, a team row of monogram tiles and a careers strip with three roles. Static site, no backend, no forms; both CTAs are mailto links. Every visual is drawn in code.

- Audience: Prospective pharma and ag-tech partners evaluating the platform, early-stage investors, job candidates in science and engineering, and journalists looking for a credible deep-tech story. Secondarily, founders of any science or materials startup who want a credible, quiet, lab-clean presence.
- Goal: Convince a technical reader in one scroll that [BRAND] runs a real, disciplined platform: they should grasp the three-step approach, remember the stage pipeline, trust the numbers as examples, and end on the careers or partner CTA.
- Tone: Precise, calm, confident. Short declarative sentences, concrete sample numbers, no hype, no exclamation marks, no marketing superlatives. Headlines read like figure captions from a well-set paper; mono labels carry the data.

## Stack
- Framework: Vite 5 + React 18 + TypeScript
- Styling: Tailwind CSS 3.4
- Libraries: react (MIT), react-dom (MIT), tailwindcss (MIT), motion (MIT), lucide-react (ISC), vite (MIT), typescript (Apache-2.0), @fontsource/sora (OFL-1.1), @fontsource/inter (OFL-1.1), @fontsource/ibm-plex-mono (OFL-1.1)
- Build: `npm run build` → static files in `dist/`. No backend, no server code, no external APIs.
- Setup:
  - Scaffold with npm create vite@latest using the react-ts template, then install tailwindcss 3.4, motion, lucide-react and the three Fontsource packages.
  - vite.config.ts: base './', build { outDir: 'dist', sourcemap: false, assetsInlineLimit: 0 }. Do not copy src/ into dist/.
  - tailwind.config.js: content covers index.html and src/**/*.{ts,tsx}; theme.extend.colors maps exact tokens: paper #fcfefd, ink #12262e, slate #5d6f7c, mist #e9f2f1, hairline #d8e5e3, teal #0e7c86, tealdeep #0a5a62, cellsoft #90a4ad; theme.extend.fontFamily: display ['Sora','sans-serif'], text ['Inter','sans-serif'], mono ['IBM Plex Mono','monospace'].
  - Fonts imported in src/main.ts: @fontsource/sora/600.css, @fontsource/sora/700.css, @fontsource/inter/400.css, @fontsource/inter/500.css, @fontsource/inter/600.css, @fontsource/ibm-plex-mono/400.css, @fontsource/ibm-plex-mono/500.css.
  - File layout: src/content.ts holds every string (hero, platform blocks, programs, metrics, publications, team, roles, footer); src/molecule-data.ts exports ATOMS and BONDS; src/components/ holds Header, Hero, CellField, Molecule, Platform, Pipeline, Metrics, Publications, Team, Careers, Footer; src/App.tsx composes them; src/index.css carries the dot-grid utility, keyframes and reduced-motion overrides.
  - Molecule canvas: DPR-aware (Math.min(devicePixelRatio, 2)); the animation loop runs only while the hero is intersecting the viewport and the tab is visible; under prefers-reduced-motion render exactly one frame at t = 0 and stop.
  - Scroll reveals use motion/react whileInView with once: true, viewport { margin: '-15% 0px' }; count-up numbers run once over 1.1 s with ease-out.
  - All copy lives in src/content.ts. When any variable value differs from the defaults, rewrite the copy there to fit the new brand, platform, focus, headquarters and program prefix, keeping the same lengths, structure and tone. Never leave default copy under new values.
  - public/favicon.svg is hand-written as described in the Document section. <title>[BRAND]</title>, lang 'en'. Write ASSETS.md at the project root listing the three Fontsource packages (OFL-1.1), lucide-react (ISC) and the hand-written favicon (original).

## Variables
- [BRAND] — Company name (default: "Vantra Biosciences"). Wordmark, <title>, footer and mailto links built from it (partners@<brand-slug>.example).
- [PLATFORM] — Platform name (default: "Loopfold"). One coined word for the internal platform; appears in the hero sub, approach steps and one publication title.
- [FOCUS] — What the platform works on (default: "protein circuits"). Lower-case phrase used inside sentences, e.g. 'nitrogen-fixing soil consortia'.
- [HQ_LINE] — Headquarters line (default: "14 Meridian Lane, Cambridge, MA"). Address in the footer; its city segment is the location shown on team and role cards.
- [PROGRAM_PREFIX] — Program code prefix (default: "VN-"). Pipeline program codes are built from it: VN-241, VN-307, VN-318, VN-332, VN-345.
- [CREDIT] — keep a small "Template by VibeFather" link to https://vibefather.ai/t/biotech-startup-website in the footer (default: yes; delete this line to remove it)

The copy under Pages & Sections is written for the default values. If your values differ, rewrite every headline, paragraph, label and image for them — same length, tone and structure. Layout, colors, type and motion stay as described.
Keep all copy, image paths and links in one content file (for example `src/content.ts`), keyed by section, so the content can be swapped later without touching components.

## Design
### Colors
- Paper `#fcfefd` — Page ground everywhere; slightly cool white
- Ink `#12262e` — Primary text, Phase II filled chip, molecule carbon atoms
- Slate `#5d6f7c` — Secondary text, Discovery outlined chips, inactive table dots
- Mist `#e9f2f1` — Panel tint behind approach steps, careers strip and team tiles
- Hairline `#d8e5e3` — 1px rules, table grid, dot-grid dots, card borders
- Teal `#0e7c86` — The single accent: links, buttons, Phase I filled chip, Preclinical outlined chip, nitrogen atoms, focus rings
- Teal deep `#0a5a62` — Button hover state, oxygen atoms in the molecule, strong underlines
- Cell soft `#90a4ad` — Molecule hydrogen atoms, inactive stage dots, muted mono labels

### Typography
- Display (wordmark, headlines, program names, stat numbers): Sora (OFL), weights 600/700
- Text (body copy, buttons, chips, captions): Inter (OFL), weights 400/500/600
- Mono (eyebrows, program codes, technical depth lines, table headers, small print): IBM Plex Mono (OFL), weights 400/500

### Layout & motion
- Spacing: 8px vertical rhythm throughout. Sections py-28 (desktop) / py-16 (mobile); container max-w-[1160px] with px-6 (px-5 mobile). Hero min-h-[92vh] with items centered. Eyebrow to headline 16px, headline to body 20px, body max-width 560px. Table cells py-5 px-4; program column 260px, stage columns equal. Mono eyebrows 12px, uppercase, letter-spacing 0.16em.
- Radius: Pills 999px for status chips and the header CTA; 12px on the molecule card and mechanism panel; 6px on buttons and inputs; 0 on the pipeline table, hairline rules and stat blocks. No other rounded shapes except the code-drawn cells.
- Motion: Molecule canvas: rotate the fixed 18-atom model around Y at 0.16 rad/s under a constant X tilt of -18 degrees; orthographic projection, center (280,280), scale 80; depth factor 1 - 0.18*zN on atom radius, bond alpha 0.92 - 0.38*mean(zN); draw far to near each frame; loop paused off-screen or when the tab is hidden.
- Motion: Cell blobs drift on 26 s and 34 s keyframe loops (translate up to 20px, rotate up to 4 degrees, alternate, ease-in-out); they stop under prefers-reduced-motion.
- Motion: Section entrances: eyebrow, headline and body rise 20px and fade over 0.6 s with 90 ms stagger, once, cubic-bezier(.2,.8,.2,1).
- Motion: Pipeline: each stage column's header underline draws scaleX 0 to 1 over 0.5 s when the column enters; its chips pop from scale 0.85 and fade in, 80 ms stagger; past columns stay lit when scrolling back up.
- Motion: Metrics count up once from 0 over 1.1 s ease-out; under reduced motion the final numbers render immediately.
- Motion: Hover micro-interactions: buttons darken to Teal deep and shift the Lucide arrow 3px; publication titles draw a 2px Teal underline scaleX 0 to 1; team monogram rings brighten from 40% to 100% Teal.
- Motion: prefers-reduced-motion: molecule renders one static frame at t = 0 (tilt only), cells rest, entrances become plain opacity fades, counters render final values, chips render in their final state.
- Imagery: Everything is drawn in code and nothing is a bitmap: the hero molecule (canvas, exact atom and bond data below), the two drifting cell blobs (SVG), the mechanism circuit diagram (SVG), the pipeline chips and dots, the dot-grid background (CSS radial-gradient), and the favicon (hand-written SVG). No photographs, no people, no logos, no downloaded files beyond fonts and the icon package. Palette strictly the eight tokens above.

## Don'ts
- No backend of any kind: no server code, API routes, databases, auth, analytics, or forms that submit. Both CTAs are mailto links built from the BRAND slug; nothing posts anywhere.
- No real biotech or pharmaceutical companies, drugs, trials, gene names or journal names anywhere; programs, papers, stages, numbers and journals are invented examples. Journal descriptors stay generic ('Journal of Directed Protein Design', 'Assay Engineering Reports', 'Computational Biology Collective', 'Notes in Structural Biochemistry').
- No medical, therapeutic or efficacy claims: copy stays at platform-science level. Never write 'treats', 'cures', 'patients receive' or outcome claims about any program; keep the 'RESEARCH-STAGE EXAMPLES - NOT APPROVED PRODUCTS' footnote on the pipeline.
- Everything code-drawn: no photographs, no bitmaps, no people, no external image downloads, no placeholder-image services. The only files in public/ are favicon.svg.
- No calendar dates, years or timestamps anywhere on the page, including publications and the pipeline (rule: the front end never shows dates).
- Do not load fonts from fonts.googleapis.com, fonts.gstatic.com or any CDN; Fontsource only. No CDN <script> or <link> tags; every dependency is npm-bundled.
- Production build: minified, build.sourcemap false, no src/ in dist/, relative asset paths (Vite base './'). Internal links are in-page anchors on ./index.html.
- Do not change the stack (Vite 5 + React 18 + TypeScript + Tailwind CSS 3.4 + motion + lucide-react) unless the user asks. No three.js, no WebGL, no UI kits, no Aceternity UI or Tailwind Plus source.
- Use only Sora, Inter and IBM Plex Mono, and only the eight hex tokens in Design. Teal is the single accent; no gradients except the hero's radial dot fade, no shadows beyond the molecule card's single soft shadow.
- The molecule must be deterministic: exactly the ATOMS/BONDS data given, fixed rotation speed, no random values, so two builds produce the same visual. Do not add randomized drift or particles.
- Respect prefers-reduced-motion exactly as specified (static molecule frame, no cell drift, opacity-only reveals, instant counters). Pause the canvas loop when the hero is off-screen or the tab is hidden.
- Must work at 1440x900 and 390x844 with zero console errors, no horizontal scroll, keyboard-reachable links with a visible 2px Teal focus ring.
- Keep dist/ under 20 MB (it should be well under 1 MB); no video, no audio.
- Keep all copy in src/content.ts and rewrite it whenever variable values differ from the defaults; never ship default copy under a changed brand, platform, focus, HQ or program prefix. No lorem ipsum, no filler.
- No mention of VibeFather or any template source inside the site except the optional [CREDIT] footer link.
