## FAQ

### Can I use the Fluid Simulation Agency Website template for a client project?
Client and commercial work with the Fluid Simulation Agency Website template needs a Pro membership. Free prompts and every DESIGN.md are licensed for personal, non-commercial use only. The Pro version shows the brief, stack and variables publicly, gives Pro members the full prompt, and includes the source code of the live demos.

### What do I change first in the Fluid Simulation Agency Website template?
Start with the four variables: set BRAND to your studio wordmark, CITY to your location pair, STUDIO_TAGLINE to your one-line positioning, and CONTACT_EMAIL to your inquiry address. The giant wordmark is cut out of the fluid hero, so keep BRAND short and uppercase. Then rewrite the Selected Work project data and studio copy in the content file.

### How does the interactive WebGL fluid hero work on the Fluid Simulation Agency Website?
The Fluid Simulation Agency Website runs a real-time fluid simulation across the full viewport. Cursor movement and touch gestures stir glowing dyes under the cutout wordmark, clicks trigger radial splashes, and scrolling shifts the dye palette per section. A floating Fluid Settings chip offers palette selection, a dye intensity slider, a bloom toggle and a low-power mode.

### What happens if a visitor's device cannot run WebGL or prefers reduced motion?
The Fluid Simulation Agency Website falls back to a slow-moving CSS and Canvas radial gradient whenever WebGL is unavailable, low-power mode is on, or the visitor prefers reduced motion. The simulation also pauses when the hero scrolls off screen, so the page stays usable and keeps the editorial layout and case cards intact.

### How do I add my own case studies to the Selected Work section?
The Fluid Simulation Agency Website keeps all studio copy and project data in one content file keyed by section. Replace the four project entries there with your own titles, descriptions and links, and the code-drawn animated previews and detail drawer follow automatically. Keep the same entry structure so the scroll palette shift and case cards keep working.
