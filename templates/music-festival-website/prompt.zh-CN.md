# 音乐节网站

完全按照以下描述构建此网站。将 [VARIABLES] 替换为你自己的值；其余内容保持不变。

## 简介
为 [BRAND] 打造的三页网站（index.html、map.html、tickets.html）。[BRAND] 是一个虚构的为期三天的夏季音乐节，举办时间为 [EVENT_DATES]，地点在 [LOCATION]。它看起来像一张活起来的饱和度极高的音乐节海报：炽热的日落渐变和一抹电光强调色叠在深紫墨色之上，超大号窄体字，以及真实的户外摄影。首页主视觉区带有一个 Canvas 2D 可视化器，在访客按下播放前运行一段精心设计的待机动画，按下后则跟随本项目脚本生成的原创循环音频的真实频率数据。网站还包含一面海报墙式的阵容展示，带日期筛选和悬停预览；一张手绘风格的内联 SVG 场地地图；以及一个票档对比，带价格计算器，不含结账流程。每一个演出者、舞台、摊商和地点都是虚构的。

- 受众：正在决定是否要去音乐节、该买哪种通行证的人，用手机的频率和用笔记本电脑一样高；他们想毫不费力地找到阵容、日程、场地如何运作以及价格。
- 目标：让访客在一屏之内就想亲临现场，然后引导他们选到正确的票档。购票行动号召在每一页的每一个滚动位置都可见。
- 语调：响亮、温暖、具体，还带点幽默，就像由运营这场活动的人亲手写的一张海报。短句和真实的后勤信息。绝不企业腔。

## 技术栈
- 框架：Vite 5 多页面 + 原生 TypeScript
- 样式：Tailwind CSS 3.4
- 库：vite@5（MIT）、typescript@5（Apache-2.0）、tailwindcss@3.4（MIT）、postcss（MIT）、autoprefixer（MIT）、gsap@3（核心、ScrollTrigger、Flip）（GSAP Standard License，免费含商业使用）、lucide（ISC）、@fontsource/anton（OFL-1.1）、@fontsource-variable/instrument-sans（OFL-1.1）、@fontsource/dm-mono（OFL-1.1）
- 构建：`npm run build` → 静态文件输出到 `dist/`。无后端、无服务端代码、无外部 API。
- 配置：
  - package.json 脚本："gen:audio": "node scripts/make-loop.mjs"；"dev": "npm run gen:audio && vite"；"build": "npm run gen:audio && tsc --noEmit && vite build"。
  - vite.config.ts：base 为 './'，build.sourcemap 为 false，build.rollupOptions.input 列出项目根目录下的 index.html、map.html 和 tickets.html，因此三者都是 dist/ 中的真实文件。
  - tailwind.config.ts：content 覆盖 ./*.html 和 ./src/**/*.ts。在 colors 中扩展 Design 里的 ink、raised、line、flare、tangerine、sun、volt、paper、haze 和 lake。在 fontFamily 中扩展 display（Anton）、sans（Instrument Sans Variable）和 mono（DM Mono）。
  - src/styles.css：先导入 @fontsource/anton/400.css、@fontsource-variable/instrument-sans、@fontsource/dm-mono/400.css 和 @fontsource/dm-mono/500.css，再导入 Tailwind 各层。在此定义 --sunset 渐变、marquee 关键帧和 font-synthesis: none。在 html 和 body 上设置 overflow-x: clip。
  - 文件布局：src/content.ts（所有文案、幕、区域、档位、图片路径和链接）；src/shell.ts（页头、跑马灯、页脚、移动端栏、页面擦除、滚动显现）；src/pages/home.ts、src/pages/map.ts、src/pages/tickets.ts；src/audio/engine.ts（AudioContext、循环、主增益、闪避）；src/audio/visualizer.ts（首屏 canvas）；src/audio/previews.ts（幕片段）；scripts/make-loop.mjs。TypeScript 严格模式已开启。
  - scripts/make-loop.mjs 仅使用 Node 内置模块，写出 public/audio/loop.wav：44,100 Hz、16 位 PCM、单声道、124 BPM、8 小节 4/4（长度 = round(32 * 60 / 124 * 44100) 个采样，约 1.4 MB）。混入一个环形缓冲区，使每个尾音都越过末尾回绕，循环无缝。
  - 循环声部。每小节根音：A2、F2、C3、G2、A2、F2、D2、E2。底鼓在每一拍：正弦波在 90 ms 内从 130 扫到 48 Hz，指数衰减 240 ms，增益 0.95。拍手在第 2 和第 4 拍：带种子的白噪声，以两个一阶滤波器的差值做带限，衰减 120 ms，增益 0.35。踩镲在反拍八分音符：高通滤波的带种子噪声，衰减 35 ms，增益 0.16。贝斯在小节根音上的八分音符：锯齿波经 420 Hz 一阶低通，增益 0.42。铺底：三个锯齿波分别失谐 -7、0 和 +7 音分，位于该小节的小三或大三和弦上，经 1,200 Hz 低通，总增益 0.12，起音 300 ms。拨弦在十六分音符网格上：带种子 mulberry32(7017)，每步 62% 概率，从 A 小调五声音阶中选取 220 到 880 Hz 之间的音，三角波，指数衰减 180 ms，增益 0.22。
  - 循环混音：将每个非底鼓声部乘以侧链 0.55 + 0.45 * (1 - exp(-secondsSinceKick / 0.12))，总和通过 tanh(1.2x)，然后将峰值归一化到 0.89。
  - src/audio/engine.ts：仅在用户手势内创建 AudioContext。获取 import.meta.env.BASE_URL + 'audio/loop.wav'，decodeAudioData，并用 loop = true 的 AudioBufferSourceNode 播放。图：source -> loopGain -> analyser -> masterGain -> destination。AnalyserNode：fftSize 2048，smoothingTimeConstant 0.78。暂停会停止源并存储偏移量；恢复会在该偏移量处新建源。静音仅设置 masterGain，因此视觉效果继续运动。如果获取或解码失败，显示内联提示 'Audio could not load. The visuals keep running.'，并且不向控制台记录任何错误。
  - src/audio/previews.ts：每一幕从 mulberry32(actIndex + 1) 获得一个 16 步片段。音符来自小调五声音阶偏移 [0,3,5,7,10,12]，根音在 110 到 220 Hz 之间；波形类型按幕索引循环 sawtooth、square、triangle；步长为 125 到 190 ms，由带种子生成器选择。每个音符经过 1,800 Hz、Q 6 的低通，带短增益包络，然后进入预览分析器（fftSize 512）再到 masterGain。片段播放期间，在 150 ms 内将 loopGain 闪避到 0.18，之后恢复。指针离开时以 120 ms 淡出停止。
  - 代码中引用图片用 import.meta.env.BASE_URL + 'images/<file>'，HTML 中用 ./images/<file>。添加 public/favicon.svg：ink 背景上日落渐变的半轮太阳。将每个页面的标题设置为包含 [BRAND] 的普通 <title>。
  - 在项目根目录写 ASSETS.md，列出每张图片的路径、来源 URL、作者和许可证，每个字体和图标包及其许可证，以及 public/audio/loop.wav 为 'original, generated by scripts/make-loop.mjs in this project'。

## 变量
- [BRAND] — 音乐节名称（默认："Sunspill"）。虚构名称，一到两个词。它会以全宽填满主视觉标题，因此标题由脚本调整字号以适配。
- [EVENT_DATES] — 音乐节日期（默认："July 16–18, 2027"）。连续三天。日期标签和日程标签（Fri Jul 16、Sat Jul 17、Sun Jul 18）由此推导。
- [LOCATION] — 场地和城镇（默认："Cinder Meadows, Port Alder, WA"）。虚构地点。地图标签（如湖名）随其变化。
- [LINEUP_GENRES] — 演出阵容的音乐类型（默认："indie, disco and warm electronics"）。据此改写虚构的演出艺人名称和类型标签。绝不使用真实艺人。
- [GA_PRICE] — 3 日通票价格（默认："$189"）。决定货币符号和其他价格：单日票约为 42%，露营周末票约为 142%，黄金时刻 VIP 约为 238%，各自四舍五入到以 9 结尾的最近数字。
- [CREDIT] — 在页脚保留一个小型 "Template by VibeFather" 链接，指向 https://vibefather.ai/t/music-festival-website（默认：是；删除此行即可移除）

页面与区块（Pages & Sections）下的文案是按默认值撰写的。如果你的取值不同，请为它们改写每个标题、段落、标签和图片——保持相同的长度、语气和结构。布局、颜色、字体和动效保持所述不变。
