# 锦鲤池网页小玩具（Koi Pond Web Toy）

完全按照以下描述构建此网站。将 [VARIABLES] 替换为你自己的值；其余内容保持不变。

## 简介
[BRAND] 是一个网页小玩具：一个占满整个视口的庭园池塘，从正上方俯视，完全用代码绘制。锦鲤摆动着身体、拖着飘逸的鱼鳍，在明亮的水光波纹上游动，穿行于睡莲叶、踏脚石和木桥边缘之间。访客可以在四个季节之间切换，开关夜晚与雨天，轻点水面激起涟漪，按住不放给鱼喂食，拖动水面画出水流，开启生成式配乐，还可以启动一个 [FOCUS_MINUTES] 分钟的专注模式，隐藏界面，让页面充当桌面背景。整个场景就是整个网站：没有营销区块，没有滚动，没有第二个页面。

- 受众：工作时喜欢开着一个安静标签页的人，以及喜欢并乐于分享小型代码绘制网页玩具的开发者和设计师。
- 目标：在最初两秒内就作为一张静态截图显得完整而美丽，每一次触碰都给出可信的物理反馈，并且足够宜人，能在笔记本电脑或手机上整个专注时段一直开着。
- 基调：安静、从容、精确，像一幅恰好活了起来的水墨画。文案简短、低调、具体。不用感叹号，不用健康生活口号。

## 技术栈
- 框架：Vite 5 + TypeScript，无 UI 框架
- 样式：原生 CSS
- 库：vite（MIT）、typescript（Apache-2.0）、lucide-static（ISC）、@fontsource/shippori-mincho-b1（OFL-1.1）、@fontsource-variable/instrument-sans（OFL-1.1）
- 构建：`npm run build` → 静态文件输出到 `dist/`。无后端、无服务端代码、无外部 API。
- 配置：
  - vite.config.ts：将 base 设为 './'，build.sourcemap 设为 false。src/ 中的任何内容都不会被复制到 dist/。
  - index.html：标题为 '[BRAND] · Koi Pond'，包含指向 ./favicon.svg 的链接，以及一个内联样式块，将 html 和 body 的背景设为 #0E3B43、margin 为 0、overflow 为 hidden，使页面从首次绘制起即为墨青色。public/favicon.svg 为手写：一条朱红色 #F2542D 的锦鲤弯曲成 C 形，置于墨青色 #0E3B43 的圆形之上。
  - 文件布局：src/content.ts 存放所有字符串和变量值；src/main.ts 启动舞台；src/quality.ts 选择并调整质量档位；src/scene/water.ts（WebGL 着色器加 2D 回退）、koi.ts、flora.ts（睡莲叶、荷花、石头、桥）、particles.ts、ripples.ts、seasons.ts、night.ts；src/input.ts 处理手势；src/audio.ts 处理所有声音；src/ui.ts 和 src/styles.css 负责标题、停靠栏和专注模式。
  - 字体：在 src/main.ts 中导入 '@fontsource/shippori-mincho-b1/latin-500.css'、'@fontsource/shippori-mincho-b1/latin-700.css' 和 '@fontsource-variable/instrument-sans'。仅导入展示字体的拉丁子集，以保持构建体积小巧。字体栈：展示字体为 'Shippori Mincho B1'、'Iowan Old Style'、'Palatino Linotype'、Georgia、serif；文本字体为 'Instrument Sans Variable'、system-ui、sans-serif。
  - 图标：使用 Vite 的 ?raw 后缀从 lucide-static 导入 SVG 文件（例如 'lucide-static/icons/leaf.svg?raw'）并内联，使其继承 currentColor。将 stroke-width 设为 1.75。
  - 所有颜色均为 :root 上的 CSS 自定义属性，使用设计部分中的精确十六进制值，相同的值也从 src/scene/palette.ts 导出，供 canvas 和着色器使用。不要近似或重新调色四个核心颜色。
  - 场景中的所有内容（鱼群名单、睡莲叶位置、粒子路径）使用一个带种子的伪随机生成器（mulberry32，种子 7）。场景代码中绝不调用 Math.random，因此每次加载都会打开相同的构图。
  - 加载时读取三个可选查询参数：season（spring、summer、autumn、winter）、night（1 或 0）和 rain（1 或 0）。它们覆盖 [START_SEASON] 和 [START_NIGHT]，并使任何状态都可链接。
  - 暴露一个小的只读对象 window.__pond，包含 firstFrameMs（从导航开始到第一个完整绘制帧的时间）、tier（high、mid 或 low）和 fps（滚动平均值），用于检查性能。

## 变量
- [BRAND] — 池塘的名称（默认："Emberfin"）。作为大标题、小字标和页面标题显示。虚构名称，一到两个词。
- [TAGLINE] — 标题下方的一行文字（默认："A small pond for long thoughts."）。最多约 40 个字符，句首大写，以句号结尾。
- [START_SEASON] — 池塘开启的季节（默认："autumn"）。spring、summer、autumn 或 winter。
- [START_NIGHT] — 以夜间模式开启（默认："off"）。on 或 off。
- [KOI_COUNT] — 桌面屏幕上锦鲤的数量（默认："9"）。4 到 16 之间的整数。手机和较慢的设备会自动显示更少的数量。
- [FOCUS_MINUTES] — 专注时段的时长，以分钟为单位（默认："25"）。1 到 90 之间的整数。用于计时器、停靠栏标签和会话完成卡片。
- [CREDIT] — 在页脚保留一个小的 "Template by VibeFather" 链接，指向 https://vibefather.ai/t/koi-pond-web-toy（默认：是；删除此行即可移除）

页面与区块（Pages & Sections）下的文案是按默认值撰写的。如果你的取值不同，请为它们重写每一个标题、段落、标签和图片——保持相同的长度、语气和结构。布局、颜色、字体和动效保持所述不变。
将所有文案、图片路径和链接放在一个内容文件中（例如 `src/content.ts`），按区块作为键，以便日后无需改动组件即可替换内容。

### 布局与动效
- 间距：没有页面网格：场景填满视口。界面元素遵循 8px 刻度，在宽布局中距边缘内缩 56px，在高布局中内缩 20px，并且每边都加上 env(safe-area-inset-*)。Dock 高度 56px，内边距 6px，间隙 4px。每个控件至少 44px 高；在手机上 Dock 单元格宽度可缩至 36px，但高度保持 48px。场景尺寸使用一个单位 u = sqrt(viewportWidth × viewportHeight) / 1140，因此在 1440×900 下 u 为 1px，在 390×844 下为 0.5px。
- 圆角：Dock、按钮和工具提示为完整胶囊形（999px）。卡片为 20px。专注进度线为平头端点。唯一的界面阴影是 Dock 和卡片下方的 0 12px 40px rgba(4, 22, 27, 0.35)；水面上的文字改用 text-shadow 0 1px 18px rgba(8, 42, 49, 0.55)，而不是面板。
- 动效：每个动作都有物理成因（水、风、某条鱼做出的决定）或标记状态变化。没有只为显得忙碌而循环的东西，也没有两个相邻元素共享同一相位：每个周期和延迟都由种子生成器从某个范围内抽取。
- 动效：仅两种界面缓动。柔和出场：cubic-bezier(0.22, 1, 0.36, 1)，用于元素到达。进出：cubic-bezier(0.65, 0, 0.35, 1)，用于状态间的交叉淡入淡出。界面时长：悬停和显现为 240ms，季节缩略图为 360ms，标题和专注淡入淡出为 600 到 900ms。
- 动效：锦鲤以滑行与摆尾的节奏游动：1.6 到 3.2s 的摆尾，然后 0.8 到 1.6s 的滑行，身体波幅为 35%，同时速度衰减五分之一。速度变化遵循时间常数为 0.8s 的临界阻尼弹簧，巡航时转向上限为每秒 70 度，因此转向是弧线，绝不旋转。
- 动效：涟漪以 ease-out 三次方半径扩张，并以指数透明度曲线在 2.6s 内淡出：诞生时快而亮，结束时慢而淡。
- 动效：季节变化为 2.4s 的进出交叉淡入淡出，各部分错开；夜晚为 1.8s 进出；雨在 2.5s 内渐入，在 4s 内渐出。中断过渡时从当前混合状态继续，绝不跳变。
- 动效：模拟基于真实经过时间运行，帧增量钳制在 1/30s，标签页隐藏时暂停，并遵循最后一节中的减少动效规则。
- 图像：一切都在代码中绘制为扁平、绘画感的形状：纯色填充加一个较亮和一个较暗的色调，柔和的偏移阴影，无描边，无照片纹理，无精灵图。深度来自分层（池底和焦散、鱼及其阴影、水面植物和结构、顶层的涟漪和光）。首屏的视觉锚点是场景本身：墨青底上的朱红与金色，配一个大号奶油色标题。

## 页面与区块
### [BRAND] · 锦鲤池 (`index.html`)
1. **舞台与首帧** — 一个固定舞台，100vw × 100dvh，无滚动，无其他区块。它承载三个堆叠的 canvas 和一个 DOM 界面层。首屏必须已经是完成画面：在导航开始后 2 秒内（在普通笔记本连接下检查 window.__pond.firstFrameMs），画面显示带焦散的墨青色水面、所有锦鲤游动中、睡莲叶、踏脚石、桥边缘、当季已漂浮的落叶或花瓣、大号 [BRAND] 标题和码头。绝不允许出现黑屏或白屏、加载旋转器、进度条、启动画面或“点击开始”状态，首屏上没有任何内容等待点击、声音或字体。
   布局：从底部的堆叠顺序：canvas#water（WebGL：池底、焦散、涟漪折射）、canvas#life（2D：锦鲤阴影、锦鲤、食物）、canvas#surface（2D：睡莲叶、荷花、石头、桥、冰、涟漪环、粒子、夜间色调、灯光），然后是界面层。所有 canvas 使用 touch-action: none 和 user-select: none。位置是视口宽度 W 和高度 H 的分数。宽布局（W 至少 900px 且 W 至少 H）：桥覆盖右上角，其边缘从 (0.56W, 0) 延伸到 (W, 0.38H)；踏脚石在左下角呈弧形排列于 (-0.01, 0.62)、(0.05, 0.75)、(0.12, 0.86)、(0.21, 0.95)、(0.29, 1.04)；睡莲叶簇位于 (0.68, 0.62) 有 5 片叶、(0.24, 0.47) 有 4 片叶和 (0.47, 0.22) 有 2 片叶；标题在左上角；码头在底部中央；锦鲤群松散地环绕 (0.50, 0.54)。高布局（其他所有情况，包括手机）：桥边缘从 (0.58W, 0) 到 (W, 0.15H)；4 块石头位于 (-0.03, 0.63)、(0.09, 0.71)、(0.05, 0.81)、(0.14, 0.86)；睡莲叶簇位于 (0.70, 0.56) 有 4 片叶、(0.26, 0.38) 有 3 片叶和 (0.42, 0.74) 有 1 片叶；标题在左上角，max-width 50vw 使其永不触及桥；码头横跨底部。在调整大小或旋转时（防抖 150ms），锚点重新布局，静态部分重绘到其缓存中，鱼保持位置，被限制在视野内。
   运动：启动是同步的：创建 canvas，从种子生成器构建场景，然后在首次绘制前运行 300 个模拟步骤（5 秒池时间），使首帧显示鱼沿自然弧线分布、14 片落叶或花瓣已漂浮、8 片在空中。在第一个动画帧中绘制 2D 层，即使着色器仍在编译；canvas#water 有一个 CSS 背景，从中心的 #0E3B43 到角落的 #082A31 的径向渐变，因此即使没有 WebGL 画面也是完整的。总 JavaScript 保持在 150 KB gzipped 以下。
2. **水面、池底与焦散** — 在全屏三角形上使用单个原始 WebGL 片段着色器，从头编写（无着色器库）。它以墨青色 #0E3B43 绘制池底，带有正负 6% 亮度的柔和值噪声斑驳，以及向角落深水色 #082A31 的暗角，然后添加光焦散：由奶油色 #F5EFE0 的细亮脉络组成的网，细胞约 90u 到 140u 宽，白天以 12% 强度添加。脉络由两层动画细胞图案构建（到最近细胞边缘的距离，用 6 次幂锐化），第二层为 1.7 倍缩放；两层脉络交叉处光线更亮。季节色调：春季纯奶油色，夏季亮 25%，秋季向金色 #E0B04A 混合 40%，冬季强度 60% 且略冷。
   布局：填充视口后方的一切。Uniforms：时间、分辨率、季节混合、夜间量、雨量以及最多 24 个涟漪的数组（x、y、半径、强度）。每个涟漪在其半径周围 18u 宽的带内沿环法线将池底和焦散查找位移最多 6u，因此焦散在环经过时明显弯曲。WebGL 不可用或上下文丢失时的回退：在启动时在离屏 2D canvas 上生成三个可平铺的焦散纹理（描边细胞边缘，通过以三个略微不同的比例绘制来柔化），并以 'lighter' 混合模式、10% alpha 绘制其中两个，向相反方向漂移。
   运动：细胞点在细胞内环绕，使网以约 7 秒的周期呼吸；两层以每秒 5u 和 8u 向相反方向漂移。运动缓慢连续，从不闪烁。雨中焦散在 1.5 秒内淡至 35%，因为太阳消失了；夜间降至 5%，读作微弱月光。
3. **锦鲤** — [KOI_COUNT] 条程序化锦鲤（默认 9 条）绘制在 canvas#life 上，按深度排序。按顺序的名单，长度以 u 计：1) 长老，240，奶油色身体带三个朱红色鞍斑；2) 200，纯朱红色带奶油色边缘的鳍；3) 190，金色带奶油色头部；4) 180，奶油色带头顶一个圆形朱红斑；5) 175，朱红色带背部墨色斑点；6) 170，奶油色带金色和朱红色斑块；7) 160，纯金色带微弱深色鳞网；8) 150，全奶油色且略半透明；9) 150，朱红色头部渐变为奶油色尾部。较小的数量取前 N 条；较大的数量从第 2 条开始重复名单，长度在 150 到 200 之间。每条鱼建立在 12 个点的脊柱上（低档为 9 个）。身体是沿脊柱左右偏移的闭合平滑路径，宽度轮廓为：圆润的鼻子，在长度的 30% 处最宽（横跨长度的 0.21），向尾根渐细至 0.035。斑块是 2 到 4 个存储在身体坐标中并裁剪到身体的柔和斑点，因此随身体弯曲。两个墨色眼点位于鼻子后方 8%，一条细墨色背脊从 30% 到 60%，一条 12% alpha 的奶油色高光沿背部延伸。24% 处的胸鳍是半透明扇形（奶油色 55% alpha 带五条细肋）。尾巴是两叶扇形，长 0.26 倍体长，体色 70% 渐隐至尖端透明。每条鱼下方深水色 28% alpha 的柔和阴影偏移 (10u, 14u)，以 1.0 和 1.12 比例绘制身体形状两次，而非使用 canvas 模糊。较深的鱼小 8%、更偏青色 18%，阴影更近。
   布局：鱼生活在整个视口中，可能游到桥、石头和睡莲叶下方，这些绘制在它们上方。转向结合分离（半径 0.9 体长）、少量对齐（权重 0.3）和凝聚（权重 0.15），加上每条鱼周期 6 到 11 秒的缓慢航向游走，以及从任何视口边缘 140u 处开始的柔和折返。鱼群松散地环绕其家园点，但每条鱼保持自己的路线。
   运动：头部引领，每个脊柱点以固定距离跟随前一个，在转弯中产生自然的跟随动作。在此基础上，一个行波正弦波从头到尾运行，每个体长一个波长，其侧向振幅从头部 0 上升到尾部 0.11 倍体长。尾拍频率跟随速度：巡航时 0.9 Hz（每秒 38 到 55u，取决于大小，大鱼较慢），爆发时高达 2.4 Hz（每秒 190u）。每条鱼按运动规则交替踢水和滑行。胸鳍以与尾巴反相的 25 到 70 度划动，在鱼刹车或急转弯时张开到 85 度。尾巴以自己的弹簧拖曳（刚度 40，阻尼 8），并将最后两个脊柱段的弯曲放大 1.6 倍，因此像丝绸一样在身体后方扫动。每条鱼的深度缓慢漂移。冬季巡航速度降至 60%。
4. **睡莲叶、踏脚石与桥边缘** — 睡莲叶：宽布局 11 片，高布局 8 片，半径 34u 到 66u，每片是睡莲绿 #2E6F5E 的圆盘，带随机旋转的 28 度 V 形缺口，九条睡莲浅绿 #4C9A7A 的细脉纹 25% alpha，略深的边缘和水面上偏移 (8u, 11u) 的 30% 柔和阴影。踏脚石：扁平不规则圆润形状，半径 46u 到 70u，石头色 #6F8480 带较亮斑点，深水色的深色水线边缘，其中两块有小苔藓斑；外侧的被视口边缘裁切。桥边缘：仅可见木甲板的一角。44u 宽的木板，桥木色 #7A4A2E，垂直于边缘，带 2u 墨色间隙和交替亮度，每块两到三条纹理线。沿边缘延伸一条 10u 的朱红色 #F2542D 漆栏杆，带细奶油色高光，栏杆上在长度的 30% 和 72% 处有两根圆立柱，每根带金色 #E0B04A 柱帽，旁边有一个圆形纸灯笼（白天奶油色，未点亮）。桥和石头在水面上投下偏移 (14u, 18u) 的柔和阴影。它们上面没有纹章、印章、文字或刻字，桥是通用甲板，不是可辨认的真实桥梁。
   布局：位置如舞台部分所述。石头和桥是静态的：每次调整大小和每个季节渲染一次到离屏 canvas，每帧 blit。睡莲叶实时绘制，因为它们会移动。
   运动：每片叶在微小的闭合路径上漂移（正负 3u，两个不同周期在 5 到 9 秒之间）并摇摆正负 2 度。当涟漪环经过叶子时，它被向外推 4u 并膨胀到 1.03 比例，然后在 500ms 内弹回。绘制的水流 60u 内的叶子沿其滑动最多 6u 并返回。石头和桥从不移动。
5. **标题与字标** — 加载时池塘像海报一样呈现：显示字体中的标题 '[BRAND]'，其下的标语 '[TAGLINE]'，再下面一行三个手势提示：'Tap for ripples'、'Hold to feed'、'Drag a current'。在访客首次与水互动后，大标题让位给小的 '[BRAND]' 字标。当构建器提供署名行时（见署名部分），将其显示为左下角 11px 奶油色链接、60% 不透明度；它与码头一起隐藏。
   布局：左上角，宽布局内边距 56px，高布局 20px。标题：显示字体，字重 500，大小 clamp(44px, 8.4vw, 128px)，行高 0.95，字距 -0.01em，奶油色，允许换行至两行。标语：文本字体 17px、78% 奶油色，标题下方 16px。提示：13px 大写标签，间隔 20px，每个带 14px 图标（水滴、手、波浪），标语下方 20px；手机上垂直堆叠。文本直接位于水面上，带柔和 text-shadow，无面板。小字标为显示字体，字重 700，22px，在同一角落。
   运动：在水面上首次点击、按住或拖动时，标题块在 600ms 内淡出并上滑 12px（in-out），字标在 300ms 延迟后 400ms 内淡入。提示行保持在字标下方 24px；每个提示在首次使用其手势时变暗至 35% 并将图标换成金色对勾，全部三个完成后 2 秒或首次互动后 20 秒该行淡出。在任何互动之前，这里没有任何东西移动。
6. **控制码头** — 一个浮动码头，依次为：四向季节开关（春季带 flower-2 图标、夏季带太阳、秋季带叶子、冬季带雪花）、细线分隔符、三个切换（夜间带月亮、雨带云雨、声音关闭时带 volume-x 开启时带 volume-2）和聚焦按钮（计时器图标和标签 'Focus [FOCUS_MINUTES]:00'）。冬季时雨切换的标签和工具提示读作 'Snow'。键盘：1 到 4 选择季节，N 夜间，R 雨，M 声音，F 聚焦，Escape 离开聚焦模式。每个控件都是真实按钮，带 aria-label 和 aria-pressed，以及 2px 金色 focus-visible 环偏移 2px。
   布局：底部中央，安全区域上方 24px。背景 rgba(8, 42, 49, 0.62) 带 backdrop-filter blur(14px) saturate(1.2)，1px 奶油色边框 14% alpha，高度 56px，全胶囊形。宽布局：季节按钮显示图标和标签，切换是 44px 图标按钮，悬停 400ms 后或键盘聚焦时上方出现工具提示，聚焦按钮是金色 #E0B04A 胶囊带墨青色文本。活动季节位于奶油色滑块上，带墨青色图标和文本。开启的切换以金色显示其图标，下方有 4px 金色圆点。高布局：码头横跨宽度，12px 边距，作为八个等宽单元格，仅图标（聚焦单元格显示计时器图标和分钟数），每个至少 36px 宽、48px 高。
   运动：季节滑块以柔和缓出在 360ms 内滑到所选按钮。按钮悬停时在 240ms 内变亮，按下缩至 0.96 比例。码头和字标保持完全可见，直到访客首次互动；之后在 6 秒无指针移动、触摸或按键后淡至 0 不透明度并下移 8px（指针在码头上或控件有焦点时绝不），任何指针移动、触摸或按键时在 240ms 内返回。声音切换在其前 8 秒每 2.4 秒携带一个缓慢金色环脉冲作为邀请；任何控件被使用后永久停止。
7. **手势：点击、按住、拖动** — 水面上的三个手势，通过 Pointer Events 对鼠标、笔和触摸相同，最多同时三个指针。点击（250ms 内释放，移动小于 12px）：涟漪。按住（350ms 未移动 12px）：在按住期间散布食物，如果随后移动则跟随手指。拖动（在按住阈值前移动 12px）：绘制水流。canvas 上抑制长按上下文菜单、文本选择和标注，水面上鼠标光标是 20px 奶油色环，绘制为内联 SVG data URI。
   布局：点击：三个同心环在点击后 0、140 和 300ms 开始。每个从 6u 增长到 240u 半径，描边从 2.2u 到 0.6u，奶油色。最多 24 个环存活（中档 16，低档 12）；最旧的被丢弃。按住：在按压建立时，指针周围一个细金色环在 350ms 内顺时针填充，使手势可发现。然后颗粒以每秒 9 个落在指针 46u 内：3.5u 琥珀色 #C98F3A 点带奶油色斑点，每个落地时带一个小环，0.7 秒内达到 26u。最多 60 个颗粒存活（低档 36）；未吃的颗粒随水流漂移并在 14 秒后淡出。拖动：路径每 24u 采样并保留 9 秒。显示为三条 35% alpha 的细奶油色条纹沿路径，虚线以每秒 120u 沿拖动方向行进，在最后 3 秒淡出。最多同时存在三个水流。
   运动：涟漪半径在 2.6 秒内缓出（三次）；不透明度在环的生命周期内遵循 0.55 × e^(-2.2t)，最后五分之一线性淡至零。相同的环发送到水着色器，使焦散弯曲。点击 140u 内的锦鲤以爆发速度直接逃离 0.6 秒，并在 1.8 秒内恢复巡航；140u 到 380u 之间的锦鲤在 500ms 后转向该点，漂过它然后恢复。食物：每条锦鲤都注意到颗粒，但每条在自己的 150 到 900ms 延迟后反应，使鱼群呈波浪状转向，而非同时。它们以 1.6 倍巡航接近，在 90u 内减速，并围绕喂食点作为松散旋转玫瑰形环绕。当嘴到颗粒 10u 内时，颗粒消失并带一个小奶油色环，鱼甩头。食物消失后它们逗留 2 到 3 秒，然后一条条向外剥离。水流：路径 180u 内的锦鲤对齐其方向（权重 0.8）并以 1.3 倍巡航像溪流一样乘流，在其末端离开；漂浮的花瓣、落叶和颗粒以每秒 60u 被携带。
8. **季节** — 四个可切换季节，以 [START_SEASON] 开启。每个有名称和一行显示在季节卡片上：春季，'Petals on the water'；夏季，'Lotus and dragonflies'；秋季，'Ginkgo gold'；冬季，'Thin ice, slow fish'。春季：睡莲叶较小（0.8 半径）且更新鲜（睡莲浅绿），60% 存在；空中最多 46 片花瓣，漂浮 60 片，每片是奶油色圆润泪滴带腮红 #F6B8A8 基部。夏季：所有睡莲叶全尺寸；叶上三朵荷花，每朵两圈尖花瓣，奶油色带腮红尖端围绕金色种子头；两只蜻蜓（低档一只）带细金色身体、两对半透明奶油色翅膀和偏移 (22u, 30u) 的阴影，因为它们飞得高。秋季：80% 的睡莲叶，一些带琥珀色边缘；最多 38 片银杏叶，扇形带中心缺口和短茎，金色 #E0B04A 和琥珀色。冬季：30% 的睡莲叶带奶油色霜边；五到七块大多边形冰板，冰色 #CFE6E4 16% alpha，带 35% 的奶油色裂纹线和它们之间的深色开阔水域；石头上的雪帽；140 片雪花（中档 98，低档 60）为 1.5u 到 4u 的奶油色点。
   布局：下落物绘制在 canvas#surface 上、睡莲叶上方，水面上有微弱阴影，随下降而收拢；一旦落地，它们平躺在涟漪环下方的水面上。季节卡片水平居中出现在高度的 38% 处：名称在显示字体中 clamp(40px, 6vw, 92px)，其下的行在文本字体中 15px、78% 奶油色。首次加载时不显示，仅在季节变化时显示。
   运动：切换耗时 2.4 秒，in-out 缓动。在前 1.2 秒，退出的季节停止生成，其粒子下沉并淡出；在整个 2.4 秒内，焦散色调、睡莲叶大小（每片叶在弹簧上，错开 40ms）和鱼速混合到新值；从 1.2 秒到 2.4 秒，进入季节的生成率从零升至满。季节卡片上升 12px 并在 500ms 内淡入（柔和缓出），保持 1600ms，在 700ms 内淡出。花瓣下落时翻滚（旋转加宽度翻转），落地带一个小环，然后以每秒 8u 的微风向左下漂移。银杏叶以正负 28 度、0.5 Hz 的钟摆摆动下落，落地带环，漂浮时缓慢转动。夏季到来时荷花在 1.8 秒内逐瓣开放并摇摆 2 度。蜻蜓以细微抖动悬停 1.2 到 2.6 秒，在 0.35 秒内以硬缓出飞 180u 到 320u，偶尔在叶或花上休息 3 到 5 秒。冰板以每秒 2u 漂移；冰下的锦鲤看起来暗四分之一。点击冰不产生环：它在 180ms 内绘制五到七条 30u 到 70u 长的细奶油色星形裂纹，在 6 秒内愈合，下方有一个 40% 强度的低沉环；点击开阔水域照常起涟漪。雪花斜向漂移，较大的更快，接近水面时缩小，然后在水上消失或在冰上沉积。
9. **夜间模式** — 一个独立切换，可在任何季节之上工作；池塘以它 [START_NIGHT] 开启。水变为夜水色 #061C24，整个场景上绘制 46% 的 #0A2230 色调，灯光以 'lighter' 混合模式添加在其上：两个桥灯笼发光（金色核心、朱红色边缘、70u 柔和光晕），每个在桥边缘下方的水面上投下倒影，池塘上方出现萤火虫：高档 26 只，中档 18 只，低档 12 只，夏季满数，春季和秋季一半。冬季没有萤火虫；取而代之的是灯笼 220u 内的雪花捕捉其光并变金。
   布局：色调是 canvas#surface 上所有表面对象之后、灯光之前的一次全屏填充。每个灯笼倒影是从桥边缘延伸 160u 的金色条纹，由七个水平切片（中档和低档五个）构建，随距离变窄和淡出。每只萤火虫是 2u 金色 #E0B04A 点带 10u 光晕，其正下方水面上有更微弱的辉光点。
   运动：白天到夜间及返回耗时 1.8 秒，in-out 缓动；灯笼在色调开始后 400ms 亮起，使黑暗先到。倒影切片以 0.4 到 0.9 Hz 独立侧滑正负 6u，涟漪环穿过它们时使该摆动在 1 秒内增至三倍。萤火虫以每秒 12u 到 20u 在缓慢弯曲路径上漫游，以 2.8 到 4.5 秒的自身周期正弦缓动脉冲，每个周期约三分之一时间黑暗。
10. **雨** — 一个切换，在水面播撒雨滴并改变光线和声音。雨滴落在随机点：高档每秒 14 个，中档 10，低档 7。冬季同一切换将降雪加厚到 2.5 倍雪花，而非产生雨滴。
   布局：每滴是一个环，在 0.9 秒内从 4u 增长到 46u，前两帧中心有小奶油色点。雨滴环计入单独的 40 上限，不发送到着色器。下雨时整个场景暗 8%。
   运动：雨在 2.5 秒内渐入、4 秒内渐出，in-out 缓动：雨滴率、变暗和焦散淡出都遵循同一渐变。雨滴落在 30u 内时漂浮的落叶和花瓣轻微抖动。锦鲤忽略雨。
11. **生成式音轨** — 所有声音用 Web Audio API 合成；没有音频文件。加载时声音关闭，仅在访客打开声音切换时开始（该切换也在该点击内创建音频上下文）。该切换是静音控件，始终显示其状态。层：两个柔和振荡器在 D3 和 A3 的持续音，通过 900 Hz 低通带 0.07 Hz 颤音；钟声般音符的旋律（正弦加高八度的较安静三角波，20ms 起音，3.2s 指数衰减），由五声音阶上最多两步的随机游走选取，每 1.4 到 4.2 秒一个音符，四分之一概率在 380ms 后第二个音符，馈入反馈延迟（0.42s，反馈 0.35，30% 湿）；生成噪声通过带通的水床，以 0.11 Hz 扫过 400 到 900 Hz。按季节缩放：春季和夏季 D 大调五声音阶（D E F# A B），秋季 D 小调五声音阶（D F G A C），冬季同一小调音阶高八度，间隔 3 到 7 秒，音色更玻璃质。夜间旋律降八度，冬季之外添加合成蟋蟀（每 1.5 到 3 秒短促 4.2 kHz 啁啾三连音，非常安静）。雨添加高通噪声床和每秒约三个小音调滴答。触摸声音：点击播放柔和 'bloop'（正弦在 160ms 内从 520 滑到 260 Hz），声像到点击的水平位置；颗粒轻响（限速每秒 12 次）；冰上裂纹是短促明亮咔嗒；季节变化播放新音阶的上升两音音程。
   布局：信号路径：每层进入主增益（0.5）、温和压缩器，然后输出。除声音切换外无视觉面板。
   运动：主音量在 1.5 秒内淡入、0.8 秒内淡出。雨和夜间层遵循与其视觉相同的渐变（2.5 秒入，4 秒出；1.8 秒）。音符在音频时钟上略微提前调度，使帧下降时定时保持均匀。标签页在后台时声音继续播放，使池塘可伴随其他工作。
12. **聚焦模式** — 聚焦按钮将池塘变成桌面背景，带 [FOCUS_MINUTES] 分钟计时器。码头、字标、提示和光标环淡出，只留下场景、一条细线进度线和小号剩余时间数字。水仍然响应点击、按住和拖动。移动指针或触摸屏幕会在右上角显示一个小胶囊，带 'Pause'（或 'Resume'）和 'Exit focus'；Space 也暂停，Escape 退出。归零时播放柔和钟声，一个缓慢金色环从池塘中心扩散，出现卡片：标题 'Session complete'，行 '[FOCUS_MINUTES] minutes by the water. The koi kept watch.'，按钮 'Another round' 和 'Back to the pond'。钟声是计时器的目的，因此即使环境音轨关闭也播放（开始聚焦模式是解锁音频的手势）。
   布局：进度线：沿最底部边缘 2px 高，全宽，轨道奶油色 10%，填充金色 55%，从左到右增长。数字：显示字体，28px，奶油色 28% 不透明度，左下角标准内边距，格式 MM:SS，每个字符在 0.62em 的固定宽度槽中，使数字永不抖动。胶囊匹配码头风格，40px 高。卡片居中，最宽 360px，20px 半径，码头背景，标题在显示字体中 36px，主按钮金色。
   运动：进入：界面在 800ms 内淡出（in-out），进度线和数字在同一时间淡入。胶囊在 240ms 内出现，无输入 3 秒后隐藏。计时器从挂钟时间戳计算，而非帧，因此标签页隐藏时保持正确；在 Screen Wake Lock API 存在处，会话期间保持屏幕唤醒锁并在退出时释放，否则静默失败。钟声是三次敲击，间隔 1.6 秒，每次是 A4、A5 和 E6 分音的钟声，6 秒衰减。金色环以涟漪缓动在 4 秒内增长到远角，卡片在第一次敲击后一秒在 600ms 内上浮 12px（柔和缓出）。
13. **自适应质量与手机** — 池塘必须在手机上保持流畅，目标 60 帧每秒，绝不降至 30 以下。启动时选择档位：主指针为粗或较短视口边小于 600px 时为低档；否则设备报告 4 个或更少逻辑核心或 4 GB 或更少内存时为中档；否则高档。高档：2D canvas 为 min(devicePixelRatio, 2)，水为 min(devicePixelRatio, 1.5)，所有 [KOI_COUNT] 锦鲤，完整粒子数。中档：2D 为 min(devicePixelRatio, 1.5)，水为 CSS 像素的 0.75 倍 min(devicePixelRatio, 1.5)，80% 的锦鲤，70% 的粒子。低档：2D 为 min(devicePixelRatio, 2)，水为 CSS 像素的 1.0 倍（像素比 1），60% 的锦鲤（至少 4 条）带 9 点脊柱，45% 的粒子，一层焦散而非两层。
   布局：无可见质量控制。其他部分引用的档位特定计数（环、萤火虫、雨滴、颗粒、雪、灯笼切片）都来自 src/quality.ts 中的一个表。
   运动：调速器监视最近 90 帧的平均帧时间。超过 22ms 持续 2 秒时在运行时降一档：多余的锦鲤游出屏幕且不返回，粒子停止生成直到低于新上限，因此没有突变。低于 12ms 持续 10 秒时可能升回，绝不超过启动时选择的档位。热循环每帧不分配：涟漪、颗粒和粒子来自固定池。标签页隐藏时循环停止，恢复时无时间跳跃。
14. **减少动态** — 当 prefers-reduced-motion 设为 reduce 时（启动时和变化时检查），池塘仍是完成、生动的画面但平静得多：锦鲤以 35% 速度游动，尾巴振幅减半，从不爆发；焦散以四分之一速度漂移；花瓣、落叶和雪以 60% 数量停留在水面，无下落物；一只蜻蜓停在叶上；萤火虫原地不动，带缓慢 6 秒辉光；灯笼倒影静止。点击产生一个持续 1.2 秒的环，睡莲叶不浮动。雨以每秒 3 滴落下。喂食和水流仍然工作，以降低的鱼速。
   布局：相同构图和控件。
   运动：季节、夜间和聚焦变化变为 400ms 不透明度交叉淡入淡出，无移动；界面过渡仅 150ms 不透明度；声音切换上的邀请脉冲和季节滑块的滑动被移除。
