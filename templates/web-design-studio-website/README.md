A site for a small studio that designs and builds websites, written to sell fixed prices instead of vibes. The first screen is a stack of browser windows drawn in code, each showing one of the studio's launches; as the visitor scrolls, the hero stays put and the windows fan out like cards so four pieces of work are on show without a single screenshot. Case studies follow with before and after sliders between a dated layout and the redesign, each with measured results marked as sample numbers. Three fixed-price packages, Launch, Grow and Custom, list exactly what is included, and a project calculator turns pages, a CMS, a shop, extra languages and the timeline into a price range and a number of weeks. A process timeline, a small shop for the studio's own starter sites, an FAQ and a discovery-call booking form close the page. The palette is paper white, near-black, electric blue and small lime highlights, with a characterful grotesk for headlines, a clean sans for body text and a mono for prices and labels. Everything on the page is drawn in code, so there are no screenshots or photographs to license. Change the studio name, city and launch price in the content file and swap the case studies for your own; layout, palette and motion stay as described.

## Variables

Replace these in the prompt with your own values; everything else stays as written.

| Variable | What it is | In the demo |
|---|---|---|
| `[BRAND]` | Studio name | Keel Studio |
| `[CITY]` | Studio city | Seattle |
| `[LAUNCH_PRICE]` | Price of the Launch package (covers up to five pages) | $3,200 |

## Make it yours

- A freelance web designer: set BRAND to your name, CITY to your base, drop the packages to two and point the discovery-call form at your own calendar.
- A branding and web studio: keep the before and after sliders, swap the browser-window projects for identity launches and rewrite the process timeline around brand strategy.
- A small development shop selling starter sites: change the shop section to list your own starter templates and set LAUNCH_PRICE to the entry build price.
- A solo consultant who builds sites on retainer: replace the fixed packages with monthly plans and adjust the calculator inputs to match your scope.

## FAQ

### What sections does the Web Design Studio Website template include?
The Web Design Studio Website template is a single page with a fanning browser-window hero, before and after case study sliders, three fixed-price packages called Launch, Grow and Custom, a project calculator, a process timeline, a small shop for starter sites, an FAQ and a discovery-call booking form. All copy lives in one content file, so you can rewrite each section without touching the layout.

### How does the project calculator on the Web Design Studio Website template work?
The project calculator on the Web Design Studio Website template takes pages, a CMS, a shop, extra languages and the timeline and returns a price range and a number of weeks. It is a pure function with the Launch price as its starting figure, and the visitor's inputs are saved in the browser under a key built from your studio name, so a returning visitor keeps their estimate.

### Can I use the Web Design Studio Website template for client work?
The Web Design Studio Website template is a Pro template. Commercial and client use needs Pro, and Pro members get the full prompt and the source code of the demos. The free DESIGN.md and the prompts of free templates cover personal, non-commercial use only. You can rebuild the page for a client studio under Pro and change the studio name, city and Launch price.

### What do I need to change first in the Web Design Studio Website template?
Change the three variables first: BRAND sets the studio name, CITY sets the location and LAUNCH_PRICE sets the starting figure in the packages and the calculator. Then replace the sample projects in the hero and the before and after case studies with your own launches. The measured results in the case studies are marked as sample numbers, so swap them for your own figures or remove them.

### Which AI coding agents can build the Web Design Studio Website template?

Web Design Studio Website is a single-page site built with Motion, React and Tailwind CSS, with scroll animation, drag & physics and micro-interactions. The prompt fixes the stack so every AI tool builds the same kind of project, and the result runs as a static site you can host anywhere.

### Is the Web Design Studio Website template free to use?
Web Design Studio Website is a Pro template: the brief, stack and variables are public, and the full prompt, the source code of the live demo and a commercial license come with VibeFather Pro. Its DESIGN.md is free for personal projects.

### Does the Web Design Studio Website template work on mobile?
Yes. Every Web Design Studio Website build was tested on a phone-sized screen as well as desktop before it went live, checking layout, text size and touch targets. Open the live demo on your phone, or switch the preview on this page to mobile view, to check it yourself.
