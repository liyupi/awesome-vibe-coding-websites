# Compound Interest Interactive Explainer

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
A single-page interactive explainer published by [BRAND] that teaches compound interest to [AUDIENCE]. The hero is a working calculator: sliders for monthly deposit, annual rate and years drive a large hand-drawn SVG stacked area chart (deposits vs. interest) and an animated final-balance counter. Below it, scrollytelling chapters with a sticky chart explain compounding step by step, a 'start at [START_AGES]' scene compares two savers, an inflation toggle reframes every figure in today's money, and a formula corner shows the math with live values. Every figure is a labeled hypothetical; the page never gives advice.

- Audience: [AUDIENCE]: curious beginners who have heard 'start early' but never seen why, plus teachers and writers who want to link to a clear, playable explanation.
- Goal: The reader drags a slider within five seconds of landing, understands that interest on interest makes the curve bend upward, and leaves able to explain in one sentence why starting ten years earlier matters more than depositing a bit more. No sign-up, no lead capture.
- Tone: Calm, warm and precise, like a well-edited magazine explainer. Short sentences, concrete numbers, second person used only to describe what the chart shows ('your deposits', 'your balance'), never to tell the reader what to do. No hype, no urgency, no 'guaranteed', no 'you should'.

## Stack
- Framework: Vite 5 + React 18 + TypeScript
- Styling: Tailwind CSS 3.4
- Libraries: react, react-dom 18 (MIT), vite 5, @vitejs/plugin-react (MIT), typescript 5 (Apache-2.0), tailwindcss 3.4, postcss, autoprefixer (MIT), motion (motion.dev, import from motion/react) (MIT), d3-shape (area, line, curveMonotoneX) (ISC), d3-scale (scaleLinear) (ISC), lucide-react (ISC), @fontsource-variable/fraunces (OFL-1.1 font, MIT package), @fontsource-variable/public-sans (OFL-1.1 font, MIT package), @fontsource/ibm-plex-mono (OFL-1.1 font, MIT package)
- Build: `npm run build` → static files in `dist/`. No backend, no server code, no external APIs.
- Setup:
  - Scaffold with Vite's react-ts template; the single page is index.html at the project root mounting src/main.tsx.
  - vite.config.ts: base './', build.sourcemap false, build.outDir 'dist'. Do not copy src/ into dist/.
  - package.json scripts: dev = vite, build = tsc -b && vite build, preview = vite preview.
  - Import fonts once in src/main.tsx: '@fontsource-variable/fraunces', '@fontsource-variable/public-sans', '@fontsource/ibm-plex-mono/400.css', '@fontsource/ibm-plex-mono/500.css'.
  - tailwind.config.ts: extend colors with paper, paper2, card, ink, muted, rule, slate, green, greenDeep, coral, coralTint, amber using the hex values in Design; fontFamily display = ['Fraunces Variable', 'Georgia', 'serif'], sans = ['Public Sans Variable', 'system-ui', 'sans-serif'], mono = ['IBM Plex Mono', 'ui-monospace', 'monospace']; maxWidth page = '1240px'.
  - src/index.css: Tailwind layers, body bg paper and text ink, font-feature-settings 'tnum' 1 on every element with class .num, custom range-input styling (track 4px rule color, filled part green via a CSS variable --fill set inline, 22px round thumb in card color with a 2px ink border and a soft shadow, thumb scales to 1.1 on active, visible 2px green focus ring).
  - All copy, variable values, slider ranges, the hypothetical defaults and FAQ text live in one file: src/content.ts. When the variable values differ from the defaults, rewrite the copy in that file to fit them; components only read from it.
  - src/lib/finance.ts holds pure functions: simulate({ monthly, ratePct, years, perYear }) returns one row per year { year, deposits, interest, balance } using month-by-month simulation with deposits at the end of each month and periodic monthly rate i = (1 + r/n)^(n/12) - 1 where n is compounding periods per year (1, 4, 12 or 365); toReal(value, inflationPct, year) = value / (1 + inflationPct/100)^year; crossoverYear(rows) = first year where interest > deposits, or null.
  - src/lib/format.ts: one LOCALE constant 'en-US' and the CURRENCY from content.ts feed a single Intl.NumberFormat for currency (maximumFractionDigits 0), a compact formatter for axis labels ($100K style, notation 'compact'), and a percent formatter with one decimal. Every number on the page goes through these.
  - src/state.tsx: a React context holding monthly, ratePct, years, perYear (default 12), inflationOn (default false), inflationPct (default 2.5). Every chart and sentence on the page reads from this one store, so moving a hero slider updates every section.
  - src/hooks/useTweenedNumber.ts: wraps motion's animate() to tween a displayed number to its new target over 0.6s with ease [0.22, 1, 0.36, 1]; returns the target immediately when useReducedMotion() is true.
  - src/hooks/useActiveStep.ts: IntersectionObserver with rootMargin '-45% 0px -45% 0px' that returns the index of the scrollytelling step currently in the middle of the viewport.
  - Charts are hand-written SVG components in src/charts/ using d3-scale for scales and d3-shape area/line with curveMonotoneX for paths. Each chart is responsive via a ResizeObserver on its wrapper, with a viewBox that matches the measured width.
  - Put the downloaded illustrations in public/images/ and reference them with relative paths (./images/...). Add ASSETS.md at the project root listing every image and font with path, source URL, author and license.
  - Favicon: public/favicon.svg, a 32px rounded square in green #2F8F5B with a white upward-bending curve stroke. Page <title>: '[BRAND] · How compound interest works'.

## Variables
- [BRAND] — Publisher name (default: "Tallypine"). The newsletter, school or blog publishing the explainer. Shown in the header, footer and page title.
- [AUDIENCE] — Who it is written for (default: "people in their twenties opening their first savings account"). Shapes the intro copy, examples and FAQ wording.
- [CURRENCY] — Currency (ISO 4217 code) (default: "USD"). Passed to Intl.NumberFormat with the en-US locale; every figure on the page uses it.
- [MONTHLY_DEPOSIT] — Default monthly deposit (default: "200"). Whole number in the chosen currency. Starting value of the deposit slider and the deposit used in the comparison scene.
- [START_AGES] — Two starting ages to compare (default: "25 and 35"). Earlier age first, ten years apart works best. Both savers stop at 65.
- [CREDIT] — keep a small "Template by VibeFather" link to https://vibefather.ai/t/compound-interest-interactive-explainer in the footer (default: yes; delete this line to remove it)

The copy under Pages & Sections is written for the default values. If your values differ, rewrite every headline, paragraph, label and image for them — same length, tone and structure. Layout, colors, type and motion stay as described.
Keep all copy, image paths and links in one content file (for example `src/content.ts`), keyed by section, so the content can be swapped later without touching components.

### Layout & motion
- Spacing: 8px base unit. Page container max-width 1240px with 24px side padding (16px under 640px). Sections are separated by 128px vertical padding on desktop, 80px on mobile. Text columns cap at 62ch. Cards use 28px inner padding (20px on mobile). 12-column grid with 32px gutters on desktop.
- Radius: Cards and chart wells 18px; sliders' tracks fully rounded; buttons and segmented controls 999px pill; tooltips 10px; illustrations 14px with a 1px rule-colored border.
- Motion: Chart redraws: when any input changes, area and line paths morph to the new shape over 0.5s with ease [0.22, 1, 0.36, 1] (animate the path 'd' via motion's motion.path with the new d value, both paths always built from the same number of points so they interpolate cleanly); during an active slider drag, update instantly without tweening to keep it responsive.
- Motion: Numbers never jump: every currency figure uses useTweenedNumber (0.6s).
- Motion: Scroll reveals: section headings and paragraphs fade up 16px over 0.6s when 25% visible, once only, staggered 0.08s between siblings.
- Motion: Scrollytelling: the sticky chart crossfades layers and highlights over 0.45s when the active step changes; inactive step paragraphs drop to 35% opacity.
- Motion: Comparison scene: a 'Play the decades' button animates an age scrubber from the earlier start age to 65 over 6s (linear), drawing both lines progressively via pathLength; the gap bracket at 65 grows in after the lines finish (0.6s spring, stiffness 160, damping 20).
- Motion: Micro-interactions: slider thumb scales to 1.1 while dragged; segmented controls slide a pill highlight between options with a motion layoutId; the inflation toggle swaps the mode badge text with a 0.25s vertical slide.
- Motion: prefers-reduced-motion: disable path morphing, tweening, reveals and the play animation (show the finished state with the scrubber at 65), keep only instant state changes and color transitions.
- Imagery: The first screen's visual anchor is the polished live chart card itself, not a photo. Supporting imagery is a set of four gouache-and-colored-pencil editorial illustrations on warm cream paper in the page's palette (slate blue, leaf green, soft coral, ink), generated for this template, one per chapter, shown at 4:3 inside 14px-rounded frames with a caption below in muted 14px text. Icons are Lucide at 18px with 1.75 stroke width. Everything else (charts, basket, brackets, markers) is drawn in SVG. No stock photos, no people's faces, no coins with real currency markings.

## Don'ts
- No backend of any kind: no server code, API routes, databases, auth, analytics or third-party APIs. No forms that submit anywhere, no email capture, no sign-up, no 'talk to an advisor' or lead flow.
- No CDN script or link tags. Fonts are self-hosted through Fontsource only; never load fonts.googleapis.com, fonts.gstatic.com, Adobe Fonts or chart scripts from a CDN. No commercial fonts.
- No chart library (no Recharts, Chart.js, ECharts, Nivo, Highcharts). Charts are hand-written SVG with d3-shape and d3-scale only.
- No code or visuals copied from existing calculator sites or from restricted UI libraries (Aceternity UI, Tailwind Plus / Tailwind UI); recreate every effect from scratch.
- No real bank, brokerage, fund, fintech or app names, logos, products, index funds or tickers anywhere, including sample data and FAQ.
- No claims about real historical market returns or real-world rates presented as fact. All rates are labeled hypothetical, and the disclaimer appears both under the header and in the footer.
- No advice language: never 'you should invest', 'guaranteed', 'best investment', 'risk-free' or similar.
