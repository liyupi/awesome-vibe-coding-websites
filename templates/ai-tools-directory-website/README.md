AI Tools Directory Website is a complete discovery interface for an independent directory publisher. The default site, Sprigstack, presents 64 fictional tools across writing, design, coding, audio, video, research, automation and productivity. Visitors can search by purpose, narrow the catalog by pricing and platform, save a shortlist and compare up to three tools without leaving the site.

The visual direction combines near-black surfaces with electric lime and lilac. Large colored editorial cards give the opening screen an immediate identity, while original geometric marks and detailed product workspaces make the catalog feel populated. Compact typography, aligned card actions and restrained motion keep the experience useful when browsing a large set of entries. On smaller screens, filters move into a sheet and comparison tables scroll within their own frame.

Every tool has a detail page with features, pricing, strengths, limitations and related suggestions. Its local product preview offers a small working interaction suited to the category, from organizing writing notes to stepping through an automation. Curated collections turn the catalog into practical starting points. A three-step submission flow previews the new card as it is written, validates the fields and adds the finished entry to the browser's directory. Featured-placement plans and newsletter preferences also have clear local confirmation states.

The template suits indie makers, small editorial teams and founders planning a focused resource library. Change the directory brand, audience, catalog focus, newsletter name and featured price to build a different publication. Content and local service adapters are kept separate so a developer can later connect real submissions and subscriptions. The supplied version works entirely as a static site, with personal choices stored on the device.

## Variables

Replace these in the prompt with your own values; everything else stays as written.

| Variable | What it is | In the demo |
|---|---|---|
| `[BRAND]` | Directory brand | Sprigstack |
| `[DIRECTORY_FOCUS]` | Directory focus | AI tools for independent work |
| `[AUDIENCE]` | Primary audience | independent makers and small teams |
| `[NEWSLETTER_NAME]` | Newsletter name | The Useful Stack |
| `[FEATURED_PRICE]` | Featured placement price | 39 |

## How to use it

1. Copy [prompt.md](prompt.md), or run `npx vibefather add ai-tools-directory-website` in your project.
2. Replace the `[VARIABLES]` with your own brand, copy and details.
3. Paste it into Claude Code, Codex, Cursor or another AI coding agent and let it build. [DESIGN.md](DESIGN.md) holds the colors, type and spacing on their own if you only want the look.

## Make it yours

- An indie maker launching a niche resource library: set BRAND and DIRECTORY_FOCUS to your topic, then replace the 64 seeded tools with your own entries and collections.
- A small editorial team publishing a curated design resource: point AUDIENCE at designers, rename the collections and keep the comparison table for font and layout tools.
- A founder testing a paid listing business: set FEATURED_PRICE, adjust the featured-placement copy and route the submission flow to your own review queue.
- A community newsletter owner: set NEWSLETTER_NAME to your publication, link the signup to your mailing list and use saved picks to drive repeat visits.

## FAQ

### What is included in the AI Tools Directory Website template?
The AI Tools Directory Website template includes 8 pages built on Vite, React, TypeScript and Tailwind CSS, with a catalog of 64 fictional tools across eight categories. Each tool has a detail page with features, pricing, strengths, limitations and a small working product preview. The template also includes live search and filters, a saved shortlist, comparison of up to three tools, curated collections, a three-step submission flow and featured-placement previews, all running as a static site with choices stored in the browser.

### Is the AI Tools Directory Website template free to use?
The AI Tools Directory Website template is free. Its prompt and DESIGN.md are free for personal, non-commercial use under CC BY-NC 4.0. Commercial use, client work and the source code of the demos require Pro. The live demos and the public brief, stack and variables are visible to everyone, so you can judge the catalog layout and interactions before deciding.

### How do I change the directory to cover a different topic or industry?
Set DIRECTORY_FOCUS and AUDIENCE in the variables to change what the catalog covers and who it speaks to. BRAND renames the directory, NEWSLETTER_NAME renames the signup and FEATURED_PRICE sets the placement figure. The template keeps its content in one place, so different values rewrite tool purposes, sample previews, collection names and audience copy while the layout and the 64-tool structure stay the same.

### Can visitors save tools and compare them without an account?
Yes. Visitors to the AI Tools Directory Website template can save tools to a shortlist, vote on them and compare up to three side by side without signing in. Choices are stored in the browser under a key derived from the brand name, so they persist between visits on the same device. If storage is blocked, the site keeps changes in memory for the visit and shows a short notice.

### How does the submission and featured-placement flow work in this directory template?
The AI Tools Directory Website template includes a three-step submission flow that previews the new card as it is written, validates the fields and adds the finished entry to the browser's directory. Featured-placement plans show a local confirmation state and use FEATURED_PRICE for the figure. Both flows run through a replaceable adapter that returns local success results without fetching, so a developer can later connect real submissions and payments.

### How do I build an AI tools directory website with AI?
Copy the prompt from this page or run npx vibefather add ai-tools-directory-website, replace [BRAND], [DIRECTORY_FOCUS], [AUDIENCE] and [NEWSLETTER_NAME] with your own content, and paste it into Claude Code, Codex, Cursor or another AI coding agent. The live demos were built from exactly that text.

AI Tools Directory Website is a 8-page site built with React and Tailwind CSS, with micro-interactions. The prompt fixes the stack so every AI tool builds the same kind of project, and the result runs as a static site you can host anywhere.
