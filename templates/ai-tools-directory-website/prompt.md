# AI Tools Directory Website

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
Build [BRAND], a complete directory of 64 invented tools for [DIRECTORY_FOCUS], with a polished lime-and-lilac catalog, rich original product previews and useful browser-persisted interactions. The directory itself is the homepage, populated on first load.

- Audience: [AUDIENCE] discovering and comparing practical tools; independent directory publishers adapting the site.
- Goal: Make search, filters, detailed evaluation, saving, comparing and local submissions work as one coherent flow. Provide honest local newsletter and featured-placement requests through a single replaceable adapter.
- Tone: Curious, concise and editorial. Describe what each tool does in ordinary English, with balanced limitations and specific sample use cases.
