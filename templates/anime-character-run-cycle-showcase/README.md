# Anime Character Run Cycle Showcase

> A toon-shaded runner loops one stride on a stage you can pause, scrub and orbit.

**[▶ Live demo on VibeFather](https://vibefather.ai/templates/anime-character-run-cycle-showcase?utm_source=github&utm_medium=readme&utm_campaign=awesome-vibe-coding-websites&utm_content=template-top)** · [prompt.md](prompt.md) · [DESIGN.md](DESIGN.md)

This template is a bright studio stage for watching one run cycle. The runner is built only from spheres, capsules and boxes, with a real bone hierarchy and dark toon outlines. Hips and chest twist against each other, the arms oppose the legs, the body rises and drops, and the head stays nearly level. Two short hair locks and a single waist tie follow a step late. Dashes on the plaster lane move at two meters per second, the same speed as the planted shoe, so the foot stays on a mark instead of skating.

The first screen is the figure. Pause, a 0.35x speed and a phase scrubber sit on the stage. Drag to orbit, or use the three-quarter, side and low-front presets. Five hair colors and five uniform colors recolor the same meshes. A side panel names contact, recoil, passing and flight, and the active card follows the playhead through the second half of the stride, when the other foot leads.

The room is warm paper. Fraunces sets the runner's name, Figtree carries the teaching notes, and IBM Plex Mono sets the phase number. Persimmon appears only on the active control and the clinic chip. A second page is the studio itself: four Tuesday evenings, eight seats, a door price, three staff portraits, a street address, weekday hours and plain answers about the moving lane and the missing download.

It suits a class handout, a small studio's public viewer, or a portfolio piece about timing. Change the studio name, the runner's name, the role used in sentences, the audience, the address and the price. Keep the meshes, the 0.80 second keys, the swatches and the layout, so another case still looks like this site.

## FAQ

### What can I actually change in the Anime Character Run Cycle Showcase template without breaking the animation?
The Anime Character Run Cycle Showcase template exposes six variables: BRAND, CHARACTER, ROLE, AUDIENCE, STUDIO_ADDRESS and CLINIC_PRICE. You rewrite the copy for each, but the runner's mesh, the 0.80 second cycle keys, the five hair and five uniform swatches and the page layout stay fixed. That means a new studio name and a new runner name still look like the same site, and the timing lesson stays accurate.

### How does the phase scrubber and the contact, recoil, passing and flight panel work together?
The phase scrubber moves a playhead from 0 to 1 across one 0.80 second stride, and the side panel highlights whichever card matches that moment: contact, recoil, passing or flight. The active card follows the playhead through the second half of the stride, when the other foot leads. Pause freezes the figure, and the 0.35x speed lets you watch a single phase without losing the scrubber position.

### How do I set up the studio page for my own class or workshop?
The Anime Character Run Cycle Showcase template's second page is a studio page with four Tuesday evenings, eight seats, a door price, three staff portraits, a street address, weekday hours and answers about the moving lane and the missing download. Change STUDIO_ADDRESS, CLINIC_PRICE and AUDIENCE to match your room and your students, then replace the three placeholder portraits with working shots from your own studio.

The Anime Character Run Cycle Showcase template falls back to a code-drawn four-pose figure instead of a blank page.
