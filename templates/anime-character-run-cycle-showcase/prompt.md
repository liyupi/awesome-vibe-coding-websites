# Anime Character Run Cycle Showcase

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
Build a run-cycle viewer for [BRAND], plus a studio page. The hero is an original human runner named [CHARACTER], a [ROLE], about 7.5 heads tall, made only from code primitives with a bone hierarchy, toon shading, dark outlines, lagged hair and a waist tie, and one seamless 0.80 second run. The plaster lane scrolls at the planted foot's speed. Controls: pause, 0.35x slow motion, a phase scrubber, orbit and zoom, three camera presets, and hair and uniform color pickers. A side panel names contact, recoil, passing and flight and stays locked to the scrubber. The studio page is written for [AUDIENCE], at [STUDIO_ADDRESS], with a four-evening clinic priced [CLINIC_PRICE].

- Audience: [AUDIENCE] who learn timing by stopping a figure, and teachers who want a class viewer rather than a model download.
- Goal: Make one stride readable: which foot is down, when the hips drop, when both feet leave the lane, and how a recolor leaves the rig unchanged.
- Tone: Calm, concrete, practical US English. Short teaching sentences. No slogans and no hype.

## Stack
- Framework: Vite 6 + TypeScript + Three.js
- Styling: Vanilla CSS
- Libraries: three (MIT), @fontsource-variable/fraunces (OFL-1.1), @fontsource-variable/figtree (OFL-1.1), @fontsource/ibm-plex-mono (OFL-1.1)
- Build: `npm run build` → static files in `dist/`. No backend, no server code, no external APIs.
- Setup:
  - Install three@0.170.0. Dev dependencies: vite@6.3.5 and typescript@5.6.3. Do not add React, a component kit, a postprocessing stack, or an animation library.
  - vite.config.ts sets base to ./, build.sourcemap to false, and build.outDir to dist. rollupOptions.input includes index.html and studio.html. The production build is minified and does not copy src/ into dist.
  - TypeScript strict mode. Import OrbitControls from three/addons/controls/OrbitControls.js in the installed package. If that path fails, use three/examples/jsm/controls/OrbitControls.js from the same package. Never from a CDN.
  - Put every visible string, swatch list, phase card, FAQ answer and image alt in src/content.ts. When any variable differs from its default, rewrite copy that would no longer be true, at the same length and structure. Do not change the rig, the cycle keys, the swatch hex values, or the layout.
  - Import @fontsource-variable/fraunces/wght.css, @fontsource-variable/figtree/wght.css, and @fontsource/ibm-plex-mono/400.css plus 500.css from the installed packages. Display stack is Fraunces with opsz 72. Text stack is Figtree. Phase numbers use IBM Plex Mono. Do not request fonts from any CDN.
  - Share one mountStage function between index and studio so the rig cannot drift. index wires the dock and the phase rail. studio mounts an autoplaying orbit-only stage.
  - index.html and studio.html each set a plain title of [BRAND], link ./favicon.svg, and load their module script. No meta description, Open Graph, JSON-LD, or analytics.
  - If WebGL cannot start, show the code-drawn four-pose fallback and keep pause, speed, scrubber and color controls working. Do not show a blank page.

- Motion: Hair and the waist tie lag their parents with exponential slerp. Reduced motion snaps them.
