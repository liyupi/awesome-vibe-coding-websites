# 拳击与力量训练健身房网站

完全按照以下描述构建此网站。将 [VARIABLES] 替换为你自己的值；其余内容保持不变。

## 简介
为 [BRAND] 打造的双页网站，[BRAND] 是位于 [CITY] 的一家精品健身房，面向 [AUDIENCE] 教授 [DISCIPLINE]。整体风格大胆粗粝：近黑色与混凝土灰为主，辅以一抹血橙色信号强调色；巨大的压缩体大写标题；带有颗粒感的双色调照片，拍摄沙袋、拳套、绳索、拳台围绳与壶铃（绝不出现人脸）；以及斜向胶带条纹分隔线。第 1 页（index.html）是一个长单页：主视觉区、课程类型、今日课程、会员定价（带月度 / 10 次课包切换）、教练（带字母组合头像）、成果与会员评价、带页面内票据确认的免费体验预约表单（含验证）、新手常见问题以及到店信息带。第 2 页（timetable.html）是可筛选的每周课程表（桌面端为日期 × 时间网格，移动端为日期标签页），带滑入式课程详情抽屉。全部为静态、纯客户端实现。

- 受众：[CITY] 的 [AUDIENCE]，对拳击好奇，但对走进一家格斗健身房感到紧张；也包括会员，用手机查看今晚的课程。他们想了解每节课是什么样、是否适合自己的水平、费用多少，以及如何免费体验。
- 目标：将紧张的访客转化为已预约的免费体验课。主视觉区、课程卡片、课程表抽屉和定价都导向体验表单；常见问题与教练卡片消除对受伤或格格不入的恐惧。次要目标：让课程表成为会员按类型和水平查找课程的最快方式。
- 语气：粗粝之下简短、直接而温暖，像一位好教练：大写祈使句标题，正文用平实句子，具体数字（时间、价格、公斤数、容量），不吹嘘，不搞格斗宣传式的逞强，不用感叹号。绝不嘲弄新手。

## 技术栈
- 框架：Vite 5 + React 18 + TypeScript
- 样式：Tailwind CSS 3.4
- 库：react（MIT）、react-dom（MIT）、motion（motion.dev，从 'motion/react' 导入）（MIT）、lucide-react（ISC）、tailwindcss（MIT）、postcss（MIT）、autoprefixer（MIT）、vite（MIT）、@vitejs/plugin-react（MIT）、typescript（Apache-2.0）、@fontsource/anton（OFL-1.1）、@fontsource-variable/archivo（OFL-1.1）、@fontsource/jetbrains-mono（OFL-1.1）
- 构建：`npm run build` → 静态文件输出到 `dist/`。无后端、无服务端代码、无外部 API。
- 设置：
  - 使用 react-ts 模板通过 npm create vite@latest 搭建脚手架。项目根目录下有两个真实的 HTML 页面：index.html（入口 src/main-home.tsx）和 timetable.html（入口 src/main-timetable.tsx）。不使用路由库。

  - 通过 PostCSS 使用 Tailwind 3.4（tailwindcss + postcss + autoprefixer），content ['./index.html', './timetable.html', './src/**/*.{ts,tsx}']。在 tailwind.config.ts 中，将每个 Design 颜色以 kebab-case 键（ink、coal、concrete、slab、dust、chalk、signal、signal-deep）添加到 theme.extend.colors 下，并设置 fontFamily display ['Anton', 'Impact', 'sans-serif']、sans ['Archivo Variable', 'system-ui', 'sans-serif']、mono ['JetBrains Mono', 'ui-monospace', 'monospace']。将 borderRadius DEFAULT 设为 0。

## 变量
- [BRAND] — 健身房名称（默认："Cinderblock Boxing Club"）。虚构的健身房名称，2–4 个单词。以 Anton 大写字体作为字标（页眉、页脚、标题）；其前两个单词的首字母构成预约参考前缀（CB-）。
- [DISCIPLINE] — 健身房教授的内容（默认："boxing and strength training"）。小写短语。驱动主视觉、六种课程类型及其描述、教练专长、跑马灯、成果、引语和 FAQ 答案。为新项目（例如 Muay Thai、kickboxing、wrestling、kettlebell sport）重写所有这些内容，保持六种类型和 34 节课。
- [CITY] — 城市（默认："Oakland, California"）。健身房所在地。用于主视觉眉标和导语、到访横幅、页脚和标题。重写地址、电话格式、货币和时区以适配；街道名称保持虚构。
- [AUDIENCE] — 在那里训练的人群（默认："busy adults, from first-timers to amateur fighters"）。小写短语。塑造主视觉导语、体验表单的安心文案、引语（会员的职业和年龄）以及 FAQ。
- [CREDIT] — 在页脚保留一个小型 "Template by VibeFather" 链接指向 https://vibefather.ai/t/boxing-and-strength-gym-website（默认：是；删除此行以移除）

页面与区块下的文案是为默认值编写的。如果你的值不同，请为它们重写每一个标题、段落、标签和图片——保持相同的长度、语气和结构。布局、颜色、字体和动效保持所述不变。
将所有文案、图片路径和链接放在一个内容文件中（例如 `src/content.ts`），按区块键控，以便日后无需改动组件即可替换内容。

### 布局与动效
- 间距：8px 基准单位。容器最大宽度 1360px，居中，侧边内边距桌面 40px、平板 24px、640px 以下 20px。12 列网格，间距 24px。区块内边距桌面垂直 128px、768px 以下 88px。每个首页区块都有 SectionHead：一条 1px Slab 分隔线横跨容器，其下 20px 是一行，包含等宽索引（'01'，JetBrains Mono 500 13px，Signal）、旁边的等宽标签（'CLASSES'，13px，字距 0.16em，Chalk 70%）以及可选的右对齐等宽计数；H2 上边距 40px。字号比例：H1 Anton clamp(76px, 13.5vw, 212px) 行高 0.86；H2 Anton clamp(52px, 7.4vw, 120px) 行高 0.9，每个 H2 写成两行，第二行用 Signal；H3 Anton 40px 行高 1；正文 Archivo 400 17px/1.6（768px 以下 16px），最大宽度 62ch；导语 Archivo 400 20px/1.5 Chalk 85%。按钮：高度 54px，内边距 0 26px，Archivo 700 14px 大写，字距 0.08em；主按钮 = Signal 背景、Ink 文字，悬停时背景 Signal Deep、transform translate(-2px, -2px) 并带硬 Chalk 阴影 box-shadow 4px 4px 0 #EDEAE3，按下时恢复无阴影无偏移；次按钮 = 1.5px Chalk 边框、Chalk 文字，悬停时 Chalk 背景配 Ink 文字。全局焦点环：2px Signal 轮廓，偏移 3px。
- 圆角：处处直角（0）：卡片、照片、按钮、标签、输入框、抽屉、票券。唯一的圆形是脉冲状态点和地图标记环。
- 动效：缓动：--ease-cut cubic-bezier(0.7, 0, 0.2, 1) 用于遮罩、擦除和切换（快速、硬朗）；--ease-out cubic-bezier(0.2, 0.7, 0.2, 1) 用于照片缩放。
- 动效：标题遮罩（Mask.tsx）：H1 和 H2 的行是 content.ts 中的数组；每行位于一个 overflow-hidden 块中，其内部 span 在 700ms 内以 --ease-cut 从 translateY(110%) 升至 0，错开 80ms，当标题 30% 可见时触发（Motion whileInView，一次）。
- 动效：硬切显现（.reveal-cut / Reveal.tsx）：块以 clip-path inset(0 0 100% 0) 和 translateY(24px) 开始，在 15% 可见时于 560ms 内以 --ease-cut 动画至 inset(0) 和 0，一次；列表按索引错开。
- 动效：条纹擦除：每个 Tape 分隔线在进入时从左擦入（clip-path inset(0 100% 0 0) → inset(0)，600ms --ease-cut）。
- 动效：计数器跳动（useCountUp，requestAnimationFrame）：英雄统计和结果的数字部分在 40% 可见时于 1200ms 内以 easeOutExpo 从 0 到其值，一次；千位分隔符和后缀（'%'、'+'）保持原位；使用 tabular-nums 使宽度不跳动。
- 动效：跑马灯：线性 translateX(0 → -50%)，38s，悬停暂停。
- 动效：照片悬停：在 overflow-hidden 框架内以 500ms --ease-out 从 scale 1 → 1.05。英雄照片加载时从 1.08 → 1。
- 动效：价格滚动、抽屉弹簧、选项卡滑动和票券下落完全按各自区块所述。
- 动效：prefers-reduced-motion: reduce — 禁用遮罩、显现、擦除、视差、照片缩放、跑马灯、脉冲和计数器（显示最终值）；抽屉和菜单以 120ms 淡入即时打开；平滑滚动关闭。颜色悬停变化保留。
- 图像：仅使用真实照片，绝不使用插图：为本模板制作的六张照片（带重沙袋的仓库健身房地面、擂台角、缠手带、摆动的重沙袋、带粉笔的壶铃、长凳上的手套和绳子）加上两张公有领域 / CC0 照片（复古黑色拳击手套、盘绕的重绳）。不出现面孔，除手和前臂外不出现人物，不出现品牌名称。每张照片通过 DuoPhoto.tsx 获得相同的双色调分级：一个背景为 #0C0C0B 的包装器；img 具有 filter grayscale(1) contrast(1.3) brightness(0.78)；一个 ::before 叠加层，背景 #FF4F1F，mix-blend-mode color，不透明度 0.22（中间调的 Signal 色调）；以及 .grain 叠加层：一个内联 SVG data-URI，含 feTurbulence（type fractalNoise，baseFrequency 0.85，numOctaves 3，stitchTiles stitch），220px 平铺尺寸，mix-blend-mode overlay，不透明度 0.22，pointer-events none。处处 object-fit cover。教练是字体排印的字母组合。其他一切用代码绘制：胶带条纹（repeating-linear-gradient -45deg Signal/Ink 16px）、票券缺口、强度条、CSS ✕ 分隔符、区块地图和 favicon。图标仅来自 lucide-react，stroke-width 2，尺寸 14–20px。

## 禁止事项
- 不得有任何形式的后端：没有服务器代码、API 路由、数据库、认证、分析、预约服务、支付链接、邮件服务或第三方 API。试用表单调用 preventDefault，仅更改本地 React 状态；它从不提交、存储或发送任何内容。
- 不得从 fonts.googleapis.com、fonts.gstatic.com、Adobe Fonts 或任何 CDN 加载字体。仅通过 Fontsource 包自托管。
- 不得使用 CDN 的 `<script>`、`<link>` 或 import maps。每个脚本、样式、字体、图标和图像都在项目中，并打包进 dist/。
- 不得使用热链接图像：每张照片一次性下载到 public/images/ 并从那里提供，每个第三方文件都列在 ASSETS.md 中。不得使用 Unsplash、Pexels、Pixabay 或其他拥有自己许可证的图库网站。
- 生产构建中不得有 source maps（build.sourcemap false），且 src/ 不会复制到 dist/。
- 使用相对资源路径（Vite base './'）。内部链接是哈希锚点或文件名，如 ./index.html、./index.html#trial、./index.html?class=mon-1730#trial 和 ./timetable.html?type=engine，绝不能是裸目录或前导斜杠。
- 除非用户要求，否则不得更改技术栈（Vite 5 + React 18 + TypeScript + Tailwind CSS 3.4 + Motion + lucide-react + Fontsource，两个 HTML 入口）。不得使用路由库、UI 套件、日历或日期库。
- 不得出现任何真实健身房、拳击推广机构、管理机构或健身连锁店的标志、名称或标牌，也不得出现属于健身连锁店的商标课程或项目名称。课程名称是此处给出的六个虚构名称。

- 不得使用带有可识别面孔、可读文字、装备品牌名称或手套、沙袋、垫子或服装上标志的照片。仅使用列出的八张图像；教练是字母组合图案，绝不是照片或 AI 肖像。
- 不得使用与体育品牌相关的商业或自定义展示字体：仅限 Anton、Archivo 和 JetBrains Mono（OFL）。
- 仅允许 MIT、ISC、BSD、Apache-2.0、0BSD、CC0 或 Unlicense 下的依赖（字体为 OFL）。不得使用 Aceternity UI、Tailwind Plus / Tailwind UI 或购买的模板代码；每个效果都从头编写。
