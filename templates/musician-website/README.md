# Musician Website

> Musician site with a custom audio player, tour dates, merch, press kit and mailing list — dark, stage-lit, fully client-side.

A single-page website for a solo musician: the artist's name in tall poster type over an amber-lit stage photograph with a play CTA; a custom audio player — play/pause, seek bar, volume and a small bar visualizer — built on the Web Audio API and fed by a short sample loop generated by a build-time script (synthesized notes and a soft beat, so nothing copyrighted is bundled); a latest-release block with a track list and per-track durations; five tour-date rows with invented venues, statuses and ticket links; a four-item merch grid with prices and a bag counter (cart-lite, client-side); a press kit section describing downloadable photos, bio and a one-sheet (placeholder links); and a mailing list with inline confirmation saved locally. The default content follows an invented ambient-soul producer, but the structure suits any solo artist or band: change the artist name, genre words and tour legs and every line still reads true. The look is stage-light moody: deep black canvas, warm amber light, one cream voice, Bebas-style tall display via Oswald over Work Sans, and vinyl/marquee details drawn in SVG. Photography shows stages, instruments and rooms — no faces. To adapt it, swap the variables and rewrite the copy in one content file.

## Variables

Replace these in the prompt with your own values; everything else stays as written.

| `[GENRE]` | Genre | ambient soul |

## How to use it

1. Copy [prompt.md](prompt.md), or run `npx vibefather add musician-website` in your project.
2. Replace the `[VARIABLES]` with your own brand, copy and details.
3. Paste it into Claude Code, Codex, Cursor or another AI coding agent and let it build. [DESIGN.md](DESIGN.md) holds the colors, type and spacing on their own if you only want the look.

## Make it yours

- A touring folk band: set ARTIST and GENRE to the group, rewrite the five tour rows as your dates and link each ticket button to your ticketing page.
- A solo electronic producer: keep the Web Audio player, swap the generated loop for your own track and rewrite the release block around your latest EP.
- A session drummer building a press kit: keep the press section and merch grid, replace the tour rows with credits and recording sessions, and point the mailing list at your booking contact.
- A jazz trio selling merch direct: rename the four merch tiles to your records and shirts, set prices and route the bag drawer to your store at checkout.

## FAQ

### How do I add a wine club signup to a winery website built with AI?
The Musician Website template's mailing list section is the piece to reuse: a single email input with inline confirmation, saved locally through the listener store. For a winery, rename that section to wine club, rewrite the surrounding copy in the content file and point the confirmation text at your club terms. Nothing is submitted anywhere, so connect your own mailing provider before launch.

### What does the custom audio player in the Musician Website template actually play?
The Musician Website template plays a bundled 12-second loop generated by a build-time script, synthesized from plucked notes and a soft beat so no copyrighted audio ships with the demo. The player has play and pause, a seek bar, volume control and a small bar visualizer driven by the Web Audio API. To use your own track, replace that generated file with your audio and keep the player logic.

### Can I sell merch from the Musician Website template, or is the bag only a demo?
The Musician Website template includes a four-item merch grid with prices and a client-side bag counter that lists quantities and a total in a drawer. Checkout is not part of the demo, so the bag records intent only. For real sales, wire the bag to your store or payment provider, or link each merch tile to an existing shop listing.

### How do I change the artist name, genre and release in the Musician Website template?
The Musician Website template exposes four variables: ARTIST, GENRE, HOMETOWN and RELEASE. Set them before building, because the artist name also drives the wordmark, page title, footer, contact email and local storage keys. Then rewrite the headlines, tour legs, press quotes and merch copy in the single content file so every line reads true for your artist.

### What should I change first in the Musician Website template for a real band?
Start with the variables and the content file, since the Musician Website template keeps every string, track, tour date and merch item in one typed place. Replace the five invented tour rows with real venues, statuses and ticket links, swap the release title and track list, then replace the press kit placeholder downloads with your own photos, bio and one-sheet.

### How do I build a musician website with AI?
Copy the prompt from this page or run npx vibefather add musician-website, replace [ARTIST], [GENRE], [HOMETOWN] and [RELEASE] with your own content, and paste it into Claude Code, Codex, Cursor or another AI coding agent. The live demos were built from exactly that text.
