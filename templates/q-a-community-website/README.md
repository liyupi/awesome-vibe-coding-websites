# Q&A Community Website

> A readable knowledge community with thoughtful answers, useful voting, topic following, and a working editor.

Q&A Community Website is a working, client-side knowledge community rather than a static forum mockup. It opens directly into a substantial trending feed, with topic navigation, searchable questions, answer previews, and contributor context sharing the first screen. Dedicated question, topic, answer-writing, and reputation views make it suitable for learning communities, professional knowledge bases, hobby groups, and product portfolios that need believable app state.

The visual direction treats answers as worth reading. Warm paper surfaces, deep green ink, vermilion details, Newsreader long-form typography, and compact Source Sans controls create an editorial rhythm without sacrificing utility. Original geometric SVG portraits and question-specific diagrams give the fictional community a human, crafted presence without stock photography or external avatar services.

Search, feed filters, upvotes, answer collapsing, topic follows, and navigation all work in the browser. The answer editor includes formatting controls, a live safe preview, local draft saving, validation, and a publish action that adds the answer to the current demo. Reputation levels and local progress are explained clearly rather than presented as real credentials. Responsive drawers, thumb-friendly voting, keyboard access, and reduced-motion support are part of the specification.

The default community serves urban gardeners, with concrete questions about balcony tomatoes, herbs, soil, and small-space planning. Five variables change the brand, community focus, audience, tagline, and featured topic; the alternate case becomes a home-baking community with entirely rewritten questions, answers, contributors, topics, and diagrams. All editable content lives in one typed content file. Vite, React, TypeScript, Tailwind CSS, Motion, Lucide icons, and self-hosted fonts produce a static build with no backend or remote assets.

## Variables

Replace these in the prompt with your own values; everything else stays as written.

| Variable | What it is | In the demo |
|---|---|---|
| `[BRAND]` | Community name | Plot & Porch |
| `[COMMUNITY_FOCUS]` | Knowledge subject | urban gardening |
| `[AUDIENCE]` | Community audience | city growers |
| `[TAGLINE]` | Community tagline | Practical growing answers from people who try them. |
| `[FEATURED_TOPIC]` | Featured topic | Small-space growing |

## How to use it

1. Copy [prompt.md](prompt.md), or run `npx vibefather add q-a-community-website` in your project.
2. Replace the `[VARIABLES]` with your own brand, copy and details.
3. Paste it into Claude Code, Codex, Cursor or another AI coding agent and let it build. [DESIGN.md](DESIGN.md) holds the colors, type and spacing on their own if you only want the look.

## Make it yours

- For a professional knowledge base: set BRAND to your firm, COMMUNITY_FOCUS to your practice area, and rewrite the featured questions as real client-facing explainers with contributor specialties.
- For a coding bootcamp: point AUDIENCE at career switchers, use FEATURED_TOPIC for first-project questions, and swap the sample answers for mentor walkthroughs with code snippets in the editor.
- For a hobby group: make BRAND your club name, set COMMUNITY_FOCUS to the craft, and replace the gardening diagrams with question-specific illustrations of your members' projects.
- For a product support community: set FEATURED_TOPIC to setup questions, rewrite topics as product areas, and adapt the reputation view into a helper recognition guide for your customers.

## FAQ

### How do I change the Q&A Community Website from urban gardening to my own topic?
The Q&A Community Website template is driven by five variables: BRAND, TAGLINE, AUDIENCE, FEATURED_TOPIC and COMMUNITY_FOCUS. Set COMMUNITY_FOCUS to your subject and rewrite the questions, answers, contributors, topics and diagrams in the single typed content file so no gardening copy survives. The home-baking demo shows the same layout with a fully rewritten knowledge base.

### Does the Q&A Community Website template need a backend or user accounts?
The Q&A Community Website template runs entirely in the browser with no backend, server code or external APIs. Search, feed filters, upvotes, answer collapsing, topic follows, draft saving and local publishing all work client-side, and visitor changes stay on the device. A confirmed Reset local demo action in the community menu clears that local state.

### What does the answer editor in the Q&A Community Website template include?
The answer editor in the Q&A Community Website template includes formatting controls for bold, italic, inline code, links, lists and block quotes, plus a live preview built from a safe allowlisted Markdown subset. Drafts save locally per question, input is validated, and publishing adds the answer to the current demo with a short entrance animation. Nothing is sent to a server.

### How do reputation levels and voting work in the Q&A Community Website template?
The Q&A Community Website template shows reputation levels and local progress in a dedicated reputation view, explained as sample community mechanics rather than real credentials. Upvotes fill the vote button and crossfade the count, followed topics and locally published answers adjust local reputation, and all of it is stored under one versioned local storage key derived from the brand name.
