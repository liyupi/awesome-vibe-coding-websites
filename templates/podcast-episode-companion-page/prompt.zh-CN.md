# 播客单集配套页面

完全按照以下描述构建此网站。将 [VARIABLES] 替换为你自己的值；其余内容保持不变。

## 简介
一个单页、图文并茂的配套页面，对应一期长篇播客节目，按章节阅读。默认故事：[BRAND] 的第 47 期，'[EPISODE_TITLE]'——[SUBJECT]，一家虚构的家族企业，把结冰的湖面锯成冰块，把寒冷卖给一座港口城市。页面像一篇印在暖色纸张上的杂志特写：五章每章开头都有一幅水彩画，档案级公有领域照片像用胶带贴上的剪贴簿照片一样嵌在正文中，十一个编号展品（手绘 SVG 图表和小型交互组件）承载数字，六条摘出的经验可以保存到笔记抽屉。一条吸顶的章节栏显示读者所在位置以及对应的节目时间戳，一个 Skim/Read 切换开关可以为只想看图表和经验的人隐藏叙述文字。

- 受众：长篇历史与商业播客的听众，他们想重温这期节目、在收听前先略读，或把某张图表或某条经验分享给朋友。
- 目标：让访客在五分钟略读或二十分钟阅读中理解整个故事，保存对他们重要的经验，并在正确的时间戳跳回节目。
- 语气：温暖、好奇且精确，像一篇优秀的杂志特写。具体的数字、日期和名称；简短的陈述句；不用炒作词，不用感叹号，不用 emoji。

## 技术栈
- 框架：Vite 5 + React 18 + TypeScript
- 样式：Tailwind CSS 3.4
- 库：react (MIT)、react-dom (MIT)、motion (motion.dev，从 'motion/react' 导入) (MIT)、lucide-react (ISC)、tailwindcss (MIT)、postcss (MIT)、autoprefixer (MIT)、vite (MIT)、@vitejs/plugin-react (MIT)、typescript (Apache-2.0)、@fontsource-variable/fraunces (OFL-1.1)、@fontsource-variable/source-serif-4 (OFL-1.1)、@fontsource/ibm-plex-mono (OFL-1.1)、@fontsource-variable/caveat (OFL-1.1)
- 构建：`npm run build` → 静态文件输出到 `dist/`。无后端、无服务端代码、无外部 API。
- 设置：
  - 使用 react-ts 模板通过 npm create vite@latest 搭建脚手架。单页面 index.html，包含锚点区块：#top、#map、#ch-1 到 #ch-5、#recap、#credits。
  - vite.config.ts：base './'，plugins [react()]，build { outDir: 'dist', sourcemap: false }。不要将 src/ 复制到 dist/。
  - 通过 PostCSS 使用 Tailwind 3.4（tailwindcss + autoprefixer）。在 theme.extend.colors 中，将下方每个调色板颜色以 kebab-case 键名添加（paper、paper-deep、print、ink、graphite、pencil、rule、indigo、glacier、ochre、rust、moss）。在 theme.extend.fontFamily 中添加 display ['Fraunces Variable', 'Georgia', 'serif']、serif ['Source Serif 4 Variable', 'Georgia', 'serif']、mono ['IBM Plex Mono', 'ui-monospace', 'monospace']、hand ['Caveat Variable', 'cursive']。
  - 在 src/main.tsx 中一次性导入字体：'@fontsource-variable/fraunces/full.css'、'@fontsource-variable/fraunces/full-italic.css'、'@fontsource-variable/source-serif-4/index.css'、'@fontsource-variable/source-serif-4/wght-italic.css'、'@fontsource/ibm-plex-mono/400.css'、'@fontsource/ibm-plex-mono/500.css'、'@fontsource-variable/caveat/index.css'。
  - 所有文案、章节元数据（编号、标题、年份、以秒为单位的起始和结束时间戳、章节颜色）、图表数据、课程、图片路径、替代文本和致谢信息都放在 src/content.ts 中。组件只从中读取。
  - 组件位于 src/components/：TopBar、Hero、EpisodeMap、ChapterRail、Chapter、Painting、Print、PullQuote、LessonCard、NotesDrawer、Recap、Credits、Footer、Watercolor（导出 WatercolorDefs、Blot、WatercolorScene）以及 charts/（BarChart、LineChart、UnitChart、WindowCard、ThicknessGauge、CrossingChart）。图表为手写 SVG；不使用图表库。
  - 钩子位于 src/hooks/：useActiveChapter（在五个章节区块上使用 IntersectionObserver，rootMargin '-35% 0px -60% 0px'）、useEpisodeTime（将活动章节内的滚动位置映射为时间戳）、useNotes（将已保存的课程 id 存入 localStorage 键 'companion-notes'）、useSkim（布尔值存入 localStorage 键 'companion-skim'）。
  - src/index.css 包含 Tailwind 层、纸张纹理背景、首字下沉和胶带样式、.skim 规则以及一个 prefers-reduced-motion 块，用于禁用过渡和绘画视差。
  - 编写 scripts/fetch-assets.sh，为 Assets 中的每张图片写一行 'curl -fL -o <target> <url>'，运行一次，并将下载的文件保存在 public/images/ 中。网站绝不外链图片。
  - 预期 dist/ 大小：小于 6 MB（自托管 woff2、六张 webp 绘画、四张档案 JPEG）。

## 变量
- [BRAND] — 节目名称（默认："The Long Ledger"）。该配套页面所属的播客（或读书俱乐部、新闻通讯）。用于顶栏字标、主视觉眉题、<title>、致谢和页脚。
- [EPISODE_TITLE] — 单集或书名（默认："Frozen Assets"）。短标题，用作主视觉巨型大标题和 <title>。两到三个词效果最佳。
- [SUBJECT] — 故事主题（默认："The rise and melt of the Halvorsen Ice Company, 1856–1934"）。大标题下方的一行文字。驱动每个章节、图表、课程和图片；当它变化时，按相同结构为新故事重写五个章节、十一个展项和六节课程。
- [HOSTS] — 主持人或讲述者（默认："Maren Okafor & Teddy Lindqvist"）。虚构姓名。显示在主视觉眉题、引语署名和致谢中。
- [RUNTIME] — 单集时长（默认："4 h 12 min"）。显示在主视觉眉题中。各章节时间戳合计等于该时长（04:12:00）；若时长变化，请按比例重新换算。
- [CREDIT] — 在页脚保留一个小的 "Template by VibeFather" 链接，指向 https://vibefather.ai/t/podcast-episode-companion-page（默认：是；删除此行即可移除）

Pages & Sections 下的文案是按默认值撰写的。如果你的取值不同，请为它们重写每个标题、段落、标签和图片——保持相同的长度、语气和结构。布局、颜色、字体和动效保持所述不变。
将所有文案、图片路径和链接放在一个内容文件中（例如 `src/content.ts`），按区块作为键，以便日后无需改动组件即可替换内容。

### 布局与动效
- 间距：8px 基准。页面容器 1280px，两侧内边距 40px（768px 以下为 24px）。正文行宽 680px；宽幅图片和图表 880px。桌面端各区块间距 128px，移动端 88px；章节开篇在桌面端顶部内边距 160px。正文 19px/1.7 Source Serif（移动端 17px/1.65），段落间距 24px。
- 圆角：纸张感、基本方正：冲印图、课程卡片和面板为 2px；按钮和工具提示为 6px；仅 Skim/Read 胶囊、章节标签和笔记计数徽章使用 999px。
- 动效：显现：文本块、冲印图、课程卡片和图表在 30% 可见时淡入并上移 16px，历时 600ms，缓动 [0.22, 1, 0.36, 1]，仅一次。列表以 80ms 错开。
- 动效：水彩晕开：每个 Blot 在进入视口时从 scale 0.85 → 1 并从不透明度 0 淡入到其设定值，历时 900ms，仅一次。
- 动效：图表在 40% 可见时绘制，仅一次：线条路径以 pathLength 0 → 1 动画，历时 1.4s ease-in-out；柱形和单位方块从基线生长，历时 700ms，错开 60ms；Caveat 注释及其手绘箭头在数据之后出现（箭头路径绘制 500ms，文本淡入 300ms）。
- 动效：绘画视差（仅 ≥1024px）：章节绘画在穿过视口的过程中从 translateY(24px) 移动到 translateY(-24px)，通过 useScroll + useTransform 实现。
- 动效：阅读进度：顶栏下方一条 2px 的 Lake Indigo 进度条，scaleX 通过 useSpring（stiffness 120，damping 30）绑定到页面滚动进度。
- 动效：冲印图静止时旋转 rotate(-1.5deg) 或 rotate(1.2deg)（交替），悬停时以 250ms 回正到 0deg，并 translateY(-4px) 和更深的阴影。
- 动效：顶栏章节标签和轨道时间戳在活动章节变化时以 200ms 交叉淡入淡出（不透明度 + 6px y 位移）。
- 动效：笔记抽屉从右侧滑入（x 100% → 0），历时 320ms ease-out，覆盖在 30% Ink 背景遮罩上；移动端为从 y 100% 升起的底部面板。保存课程时计数徽章弹跳（scale 1 → 1.25 → 1，300ms）。
- 动效：prefers-reduced-motion：无显现、晕开、视差或绘制动画；图表完整渲染；抽屉不滑动直接出现。
- 图像：三层，绝不在同一画面内混用。(1) 六幅水彩画（主视觉 + 每章一幅），以 mix-blend-mode: multiply 显示，使其白色纸张融入页面，并带羽化边缘：mask-image radial-gradient(ellipse 75% 72% at 50% 50%, #000 60%, transparent 100%)。(2) 四幅档案公有领域图像以剪贴簿冲印形式显示：Print 色边框 10px，底部 36px，图像 filter grayscale(1) sepia(0.3) contrast(1.05)，顶部两角各一条 Ochre 胶带条（72×22px，旋转 ±6°，28% 不透明度，通过 clip-path 实现锯齿端），阴影 0 14px 24px -14px rgba(31,36,48,0.35)。(3) 代码绘制的水彩晕染（Blot 组件）置于数字、引文、主视觉标题之后以及图表之中。纸张纹理覆盖页面背景：一个内联 SVG data-URI，使用 feTurbulence（baseFrequency 0.9，numOctaves 2），5% 不透明度，以 240px 平铺，设为 body background-image 覆盖在 Paper 之上。

## 不要做
- 不要后端：不要服务器代码、API 路由、数据库、认证、分析或第三方 API。笔记和 Skim 设置只存放在 localStorage 中。不要音频播放器，也不要任何会提交到某处的表单。
- 不要使用来自 fonts.googleapis.com、fonts.gstatic.com、Adobe Fonts 或任何 CDN 的字体。通过列出的 Fontsource 包自托管。
- 不要 CDN 的 `<script>` 或 `<link>` 标签。每个脚本、样式、字体、图标和图像都要打包或下载到项目中。运行时绝不要热链图像 URL。
- 生产构建中不要 source map（build.sourcemap: false），也不要把 src/ 复制到 dist/。
- 只使用相对资源路径（Vite base './'）。内部链接是本页上的哈希锚点（#top、#map、#ch-1 … #ch-5、#recap、#credits）或像 ./index.html 这样的文件名，绝不要使用裸目录。
- 除非用户要求，否则不要更改技术栈（Vite + React + TypeScript + Tailwind 3.4 + Motion + Lucide + Fontsource）。不要图表库：每个图表都是手写 SVG。
- 不要复用任何真实播客的名称、主持人、剧集标题、品牌或文案，也不要把真实公司作为主题。默认的故事、人物、地点和数字都是虚构的，必须保持如此。
- 不要真实人物的肖像：不要主持人和创始人的肖像，画中不要可辨认的面孔，主图也不要使用面孔。
- 任何地方都不要品牌标志、产品名称或 AI 工具品牌，图像内也不要文字、标牌或公司名称。
- 不要 Unsplash、Pexels、Pixabay 或其他图库网站的图像，不要占位图服务，不要 CC BY-NC 或 CC BY-SA 的内容。只使用列出的生成水彩画和公有领域 / CC0 图像，全部记录在 ASSETS.md 中。
- 不要蓝紫渐变、霓虹光晕、玻璃拟态卡片或带投影的发光按钮。颜色只来自纸张调色板和水彩晕染。
- 不要把叙述拉伸到图表上：正文保持在 680px 的排版宽度，图表保持在 880px。不要全宽文本块。
- 必须在 1440×900 和 390×844 下正常工作，控制台零错误且无水平滚动。按所述尊重 prefers-reduced-motion。
- 不要 SEO 附加项（meta 描述、Open Graph、JSON-LD、站点地图）。一个普通的 `<title>` 和 favicon 就足够了。
