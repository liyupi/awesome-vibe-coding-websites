## How to use it

1. Copy [prompt.md](prompt.md), or run `npx vibefather add online-code-playground` in your project.
2. Replace the `[VARIABLES]` with your own brand, copy and details.
3. Paste it into Claude Code, Codex, Cursor or another AI coding agent and let it build. [DESIGN.md](DESIGN.md) holds the colors, type and spacing on their own if you only want the look.

## Make it yours

- A coding bootcamp: set BRAND to your school, replace the 12 seeded pens with lesson exercises, and use DEFAULT_AUTHOR for instructor credit on each starter.
- A creative coding portfolio: keep the 3D starter, rename TAGLINE to your focus, and publish your own canvas and CSS art pens in the gallery.
- A design systems team: swap the starter templates for component demos, set EXPORT_PREFIX to your library name, and share snippets through URL hash links.
- A JavaScript instructor: seed the gallery with progressive exercises, set DEFAULT_AUTHOR to your handle, and point students at the console panel to read errors.

## FAQ

### What is included in the Online Code Playground template?
The Online Code Playground template is a dark-mode HTML, CSS and JavaScript sandbox. It includes resizable syntax-highlighted editor panes with HTML tag autocomplete, a live sandboxed iframe preview, a line-numbered console that captures logs and runtime errors, five starter templates including a locally bundled Three.js scene, three layout modes, localStorage autosave, URL hash sharing, real ZIP export, and a gallery of 12 seeded pens.

### Can I share a pen I built in the Online Code Playground without a backend?
Yes. The Online Code Playground template's Share URL button encodes your HTML, CSS and JavaScript into the URL hash and copies the link, so the project decodes straight from the address when someone opens it. There is no server or database involved. Keep in mind long sketches make long links, and the Export .zip button gives you index.html, style.css and script.js as a download instead.

### How does the live console and error reporting work in the Online Code Playground template?
The Online Code Playground template runs your code in a sandboxed iframe and captures console.log, console.warn, console.error, plus uncaught errors and unhandled promise rejections, passing them back with exact script line numbers. Entries appear timestamped in a collapsible console drawer with a Clear button and filter pills, and a mint status badge shows execution state and elapsed milliseconds after each run.

### Do I need an internet connection for the Three.js starter in the Online Code Playground template?
No. The Online Code Playground template bundles a local Three.js build from the installed package, so the 3D starter scene runs inside the sandboxed preview with zero CDN calls. Fonts are bundled locally too. That means the playground keeps working offline once built, and you avoid depending on an outside script host for the 3D sketch to load.

### Can I change the playground name, tagline and export filename in the Online Code Playground template?
Yes. The Online Code Playground template exposes four variables: BRAND sets the playground name in the top bar, document titles and exported README; TAGLINE is the short subtitle on the gallery banner; DEFAULT_AUTHOR is the creator handle on new sketches and gallery attribution; and EXPORT_PREFIX is the base filename used when you export a ZIP archive. The starter templates and seeded pens live in one data file you can edit.

### How do I build an online code playground with AI?
Copy the prompt from this page or run npx vibefather add online-code-playground, replace [BRAND], [TAGLINE], [DEFAULT_AUTHOR] and [EXPORT_PREFIX] with your own content, and paste it into Claude Code, Codex, Cursor or another AI coding agent. The live demos were built from exactly that text.

### Which AI model built the Online Code Playground demo?
The SparkBench case was built by Gemini 4 Neon in Antigravity; the LoomLab case was built by GPT-6.2 Sol in Codex. Each build used the published prompt with nothing added, so you can compare the models side by side.

### What tech stack and pages does the Online Code Playground template use?
Online Code Playground is a 2-page site built with React, Tailwind CSS and Three.js, with 3d / webgl and micro-interactions. The prompt fixes the stack so every AI tool builds the same kind of project, and the result runs as a static site you can host anywhere.

### Can I use the Online Code Playground template for a client or a business?
The Online Code Playground prompt and DESIGN.md are free for personal, non-commercial projects under CC BY-NC 4.0. Client work and commercial use need VibeFather Pro, which also includes the source code of the live demo.

### Does the Online Code Playground template work on mobile?
Yes. Every Online Code Playground build was tested on a phone-sized screen as well as desktop before it went live, checking layout, text size and touch targets. Open the live demo on your phone, or switch the preview on this page to mobile view, to check it yourself.
