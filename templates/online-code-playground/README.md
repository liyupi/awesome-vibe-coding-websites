## How to use it

1. Copy [prompt.md](prompt.md), or run `npx vibefather add online-code-playground` in your project.
2. Replace the `[VARIABLES]` with your own brand, copy and details.
3. Paste it into Claude Code, Codex, Cursor or another AI coding agent and let it build. [DESIGN.md](DESIGN.md) holds the colors, type and spacing on their own if you only want the look.

## FAQ

### How do I build an online code playground with AI?
Copy the prompt from this page or run npx vibefather add online-code-playground, replace [BRAND], [TAGLINE], [DEFAULT_AUTHOR] and [EXPORT_PREFIX] with your own content, and paste it into Claude Code, Codex, Cursor or another AI coding agent. The live demo was built from exactly that text.

### Which AI model built the Online Code Playground demo?
The SparkBench case was built by Gemini 4 Neon in Antigravity. Each build used the published prompt with nothing added.

### What tech stack and pages does the Online Code Playground template use?
Online Code Playground is a 2-page site built with Three.js, Tailwind CSS and React, with 3d / webgl and micro-interactions. The prompt fixes the stack so every AI tool builds the same kind of project, and the result runs as a static site you can host anywhere.

### Can I use the Online Code Playground template for a client or a business?
The Online Code Playground prompt and DESIGN.md are free for personal, non-commercial projects under CC BY-NC 4.0. Client work and commercial use need VibeFather Pro, which also includes the source code of the live demo.

### Does the Online Code Playground template work on mobile?
Yes. Every Online Code Playground build was tested on a phone-sized screen as well as desktop before it went live, checking layout, text size and touch targets. Open the live demo on your phone, or switch the preview on this page to mobile view, to check it yourself.
