An architectural real-estate sales website for a fictional 48-townhome residential community. Explore golden-hour photography from one cohesive shoot, filter an interactive code-drawn 48-lot site plan by status, orientation, and price, compare three home types with switchable multi-level 2D architectural floor plans, and step inside a walkable Three.js 3D model home in Dollhouse or First-Person room walkthrough mode. Includes a Phase 1–4 construction progress tracker, a code-drawn neighbourhood commute map, an interactive mortgage estimator, and a local register-interest form.

## FAQ

### How does the interactive 48-lot site plan work on the New Home Development Website template?
The New Home Development Website template draws a 48-lot master site plan in code as an SVG. Clicking any lot opens its plot size, orientation, home type, status (Available, Reserved or Sold) and price. Filters let buyers narrow the plan by status, orientation and home type, so a relocating family can see only available south-facing lots in one view.

### Can buyers walk through a home in 3D and see upgrade pricing change live?
Yes. The New Home Development Website template includes a walkable Three.js model home with a Dollhouse orbit view and a First-Person room walkthrough using WASD or arrow keys, with clickable stops in the Living Room, Chef's Kitchen, Dining Terrace and Upper Flex Study. Toggling Kitchen Finish, Flooring or Flex Space recolors the 3D surfaces and updates the running home total and estimated monthly mortgage immediately.

### What do I need to change to use this template for my own housing development?
Set the four variables: COMMUNITY_NAME, DEVELOPER_NAME, DISTRICT_NAME and STARTING_PRICE. Then rewrite the headlines, paragraphs, labels and image paths for your own community, since the default copy is written for Alder Row in Cedarbrook Valley. The 48 lots, three home types, floor-plan geometry, upgrade options and Phase 1–4 construction phases live in one data file you can edit, and the four golden-hour photographs should be replaced with your own shoot.

### Does the New Home Development Website template include a mortgage calculator and lead form?
The New Home Development Website template includes an interactive mortgage estimator that works alongside the live upgrade pricing, plus a Register-Interest form that stores submissions in the browser's localStorage. There is no backend or external API, so the form is a local capture rather than a connected CRM. You would wire it to your own mailing list or sales inbox before going live.
