# Snow Globe Toy

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
Build [BRAND], an original single-page 3D snow globe toy presenting [COLLECTION_NAME] with the headline [HEADLINE]. The large central globe contains three procedural miniature worlds whose display names come in order from [SCENE_SET]: a cabin, a lighthouse on rocks, and a generic city. Visitors shake by dragging the globe, pressing Shake globe, or explicitly enabling phone tilt; snow swirls with the input and then settles under gravity. A short text field updates [BASE_MESSAGE] on the globe's front brass plaque. Write the welcome and helper copy for [AUDIENCE] without turning the experience into a marketing page.

- Audience: Adapt the plain-language introduction and help text for [AUDIENCE]. The toy must remain understandable to a first-time visitor and fully usable without a motion sensor, account, or instructions outside the page.
- Goal: Let a visitor complete a satisfying shake within five seconds, see an obvious difference among all three scenes, and place a personal message on the physical-looking base. Keep rendering smooth and the primary controls discoverable at 1440×900 and 390×844.
- Tone: Tactile, wintry, intimate, and precise, like a handcrafted keepsake on a quiet desk. Use concise US English and concrete interaction feedback; avoid holiday sales language, whimsical filler, scores, streaks, and exaggerated claims.

## Stack
- Framework: Vite 5 + React 18 + TypeScript
- Styling: Vanilla CSS
- Libraries: react and react-dom (MIT), three (MIT), lucide-react (ISC), vite (MIT), typescript (Apache-2.0), @fontsource/fraunces (OFL-1.1), @fontsource/dm-sans (OFL-1.1)
- Build: `npm run build` → static files in `dist/`. No backend, no server code, no external APIs.
- Setup:
  - Create package.json with scripts dev = vite, build = tsc --noEmit && vite build, and preview = vite preview. Use React 18.3, Vite 5.4, TypeScript 5.6, three 0.170.0, lucide-react 0.468.0, and the listed Fontsource packages; install and bundle every dependency locally.
  - Configure vite.config.ts with base './', build.outDir 'dist', build.sourcemap false, build.target 'es2020', and minification enabled. Use one index.html entry and do not copy src/ into dist/.
  - Organize the project as src/content.ts for all variables and visible strings, src/App.tsx for UI state, src/components/GlobeStage.tsx for renderer lifecycle, src/globe/geometry.ts for the globe and shared parts, src/globe/scenes.ts for the three worlds, src/globe/snow.ts for the particle simulation, src/globe/input.ts for pointer and sensor input, and src/style.css for tokens and responsive rules.
  - Self-host Fraunces 500 and 600 plus DM Sans 400, 500, and 600 through Fontsource Latin subsets. Wait for document.fonts.ready before drawing plaque text. Set lang en, a plain document title '[BRAND] — [COLLECTION_NAME]', theme-color #0B1917, and an original local globe favicon.svg.
  - Split SCENE_SET on commas into exactly three trimmed names and map them in cabin, lighthouse, city order. Limit the editable base message to 28 UTF-16 characters. Keep selected scene, current message, shake state, sensor state, and help dialog state in React; keep per-frame positions and velocities in refs and typed arrays rather than rerendering React each frame.
  - Use THREE.WebGLRenderer with antialias true, alpha false, powerPreference high-performance, SRGB output color space, ACESFilmic tone mapping, exposure 1.08, and PCFSoftShadowMap. Generate reflections with PMREMGenerator and Three.js RoomEnvironment only; never download an HDRI. Add a cool HemisphereLight, one warm key DirectionalLight, and a soft blue rim light.
  - Use a PerspectiveCamera at 35 degrees, near 0.1, far 80, initially positioned at (0, 2.8, 10.5) and looking at (0, 2.25, 0). Fit the entire globe and base on narrow screens by moving the camera back and adjusting its target, never by cropping the dome or plaque. Do not add camera orbit controls; dragging shakes the object itself.
  - Model a globe approximately 4.5 world units in diameter centered at y 3.0, seated in a low walnut cylinder of radius 2.5 and height 0.72 with two thin brass rings. Add a front brass plaque plane about 2.65 by 0.48 units. Draw its text to a local CanvasTexture in Fraunces 600, dark walnut over brushed brass with a subtle lower-edge incision shadow; update the texture only when the message changes and dispose of replaced textures.
  - Build the glass as original sphere geometry with MeshPhysicalMaterial, transmission 0.9, thickness 0.12, roughness 0.08, IOR 1.45, transparent true, opacity 0.32, and depthWrite false. Add a restrained Fresnel rim and two narrow code-drawn curved highlights. Keep the miniature clearly visible through the glass; do not cover the scene with milky transparency, bloom, or bright reflection bands.
  - Give each world a distinct silhouette on a shared softly undulating snow mound. Cabin: a small timber house with a steep snow-capped gable, two amber windows, a chimney, five varied fir trees, a short fence, and a curved path. Lighthouse: a generic ivory and muted-cranberry tapered tower on angular rocks, a warm lantern room, tiny railing, three rock pools, and two windswept pines. City: six original narrow towers with varied setbacks and rooftop tanks, scattered warm windows, a pocket square, and three bare trees. No real landmark, flag, sign, character, or branded object.
  - Implement snow with THREE.Points and a soft circular shader sprite, not image textures. Use a fixed mulberry32 seed and 720 flakes on desktop or 420 on mobile. Store position, velocity, size, phase, and settled state in preallocated arrays. Start with a gentle visible flurry that settles within about five seconds; reduced-motion visitors start with settled snow.
  - Advance snow with a fixed 1/60-second step and at most four catch-up steps. Apply gravity -0.34 world units per second squared, velocity damping around 0.985 per step, low-amplitude curl-like drift, and input impulse from drag or Shake globe. Confine flakes to the inner sphere, collide with the scene's snow height, then damp horizontal motion until settled. A strong shake should lift settled flakes; after input stops, nearly all flakes must reach the mound within four to eight seconds without escaping the glass.
  - Pointer drag on the canvas rotates the globe group directly within ±0.16 radians on x and z and injects energy based on pointer velocity. Use pointer capture and a movement threshold, prevent double firing, and do not treat a simple click as a strong shake. On release, use a damped spring to return the globe upright over about 700ms while the snow continues to settle. Shake globe supplies a repeatable 1.1-second sequence of three diminishing impulses; Let it settle clears added energy and returns the globe upright.
  - Show Enable tilt only when DeviceOrientationEvent is available on a touch-oriented device. On supporting iOS versions, call requestPermission only from that button's user gesture. After permission, map beta and gamma changes to small target tilts and snow impulses, clamp values, and provide Disable tilt. Denied or unavailable sensors preserve drag and button play with a plain status message and no thrown error. Never transmit or persist sensor readings.
  - Cap renderer pixel ratio at 1.6 on desktop and 1.35 on mobile. Reuse geometry and materials, merge static scene parts where practical, avoid allocations in the frame loop, and pause requestAnimationFrame while document.hidden. Use ResizeObserver to resize without rebuilding the scene and dispose of renderer, textures, geometry, materials, listeners, and sensor handlers on unmount.
  - For prefers-reduced-motion, begin with snow at rest, remove idle drift, glass shimmer, automatic spring overshoot, and the lighthouse beam sweep. Explicit Shake globe produces one restrained 600ms flurry at no more than 35% of normal impulse, then places flakes at rest; scene changes use an immediate swap or 100ms opacity fade. Listen for preference changes and retain every editing and selection function.
  - Provide keyboard-equivalent DOM controls for every action. The focusable canvas supports S to shake, R to settle, and left/right arrows to change scenes only when it has focus; never intercept these keys inside inputs or buttons. Use visible focus, accessible names, a polite status region for scene changes and sensor feedback, and an original inline SVG snow-globe fallback if WebGL initialization fails. The fallback keeps scene selection, message editing, and an explicit CSS flake burst usable.
  - Write ASSETS.md at the project root covering original procedural geometry, generated Canvas textures, original SVG thumbnails and favicon, Three.js MIT, Lucide ISC, and both Fontsource packages with their OFL-1.1 licenses. Keep all runtime requests local and dist/ below 20 MB.

## Don'ts
- Do not use real brands, licensed characters, mascots, logos, slogans, recognizable product designs, real people's likenesses, famous buildings, landmark silhouettes, real city identities, flags, or branded signs. All scene and brand names must remain invented.
- Do not copy an existing snow globe's code, prompt text, interface copy, exact composition, decorative base, signature illustrations, unique icons, models, textures, photographs, video, or audio. Rebuild every visual from original procedural geometry and the declared local packages.
- Do not use image generation, stock photos, downloaded 3D models, remote HDRIs, external image textures, recorded sound, commercial fonts, restricted UI-library source, placeholder-image services, or additional physics and animation libraries. The declared Three.js simulation is sufficient.
- No backend, server code, API routes, database, authentication, remote form submission, analytics, third-party API, runtime fetch, sensor upload, sharing service, or account. Message, scene, and motion state stay local to the current page.
- No CDN scripts or styles, Google Fonts URLs, hotlinked assets, externally hosted icons, or remote runtime dependencies. Use Vite base './', relative asset paths, locally bundled packages, and self-hosted Fontsource fonts.
- Do not request motion permission on load, hide drag behind sensor support, autoplay sound, throw on denied sensors, or require a tutorial before play. Do not add audio, cookies, pop-up promotions, forced sharing, or a splash screen.
- Do not add marketing sections, pricing, visitor counts, dates, metadata beyond the plain title and favicon, Open Graph work, JSON-LD, sitemap code, extra routes, or bare-directory links. The only page is index.html.
- Do not allow unbounded particles, per-frame React rendering, per-frame geometry allocation, uncapped device pixel ratio, animation while hidden, or escaped snow. Follow the particle caps, fixed timestep, cleanup, and adaptive mobile rendering requirements.
- Production npm run build must emit minified static dist/ below 20 MB with no source maps and no src/ copied into dist/. It must run without console errors at 1440×900 and 390×844 and leave no horizontal page overflow.
- Respect prefers-reduced-motion in both CSS and WebGL, preserve explicit interaction feedback, provide keyboard-equivalent DOM controls and visible focus, trap and restore dialog focus, and keep touch targets at least 44px. Never use color alone for selected state.
- Do not hard-code default brand, collection, headline, scene names, audience copy, or base message outside src/content.ts. Never expose unresolved [VARIABLE] placeholders or retain default copy that conflicts with alternate values.
- Never mention VibeFather in the rendered site except the optional [CREDIT] link, and never use VibeFather or a real brand as a variable default. All copy, labels, sample data, and alt text must be US English.
