# Personality Quiz Funnel Page

Build this website exactly as described below. Replace the [VARIABLES] with your own values; keep everything else.

## Brief
Build a polished single-page personality quiz funnel for [BRAND], centered on an original [QUIZ_TOPIC] quiz for [AUDIENCE]. The experience moves from an editorial landing page to exactly eight visual questions, a short calculating interlude, a personalized archetype result, and an email-gated [REPORT_NAME] revealed on screen. Keep all answers, scoring, and form behavior local to the browser tab.

- Audience: The primary audience is [AUDIENCE]: people who enjoy a short, low-pressure reflective exercise and want one useful next step. The template owner is a creator, coach, marketer, or small studio using the quiz to introduce a point of view and offer a deeper resource.
- Goal: Get visitors to start the quiz, finish all eight questions, understand why their result fits, and unlock the full [REPORT_NAME]. Make every control functional and make the static email demonstration honest about not sending or storing data.
- Tone: Warm, perceptive, energetic, and specific. Use encouraging plain language rather than vague affirmations. Treat results as flexible creative patterns, never fixed identities, diagnoses, rankings, or scientific measurements.

## Stack
- Framework: Vite 5 + React 18 + TypeScript
- Styling: Tailwind CSS 3.4
- Libraries: React 18 (MIT), Vite 5 (MIT), TypeScript (Apache-2.0), Tailwind CSS 3.4 (MIT), lucide-react (ISC), @fontsource-variable/fraunces (OFL-1.1), @fontsource-variable/dm-sans (OFL-1.1)
- Build: `npm run build` → static files in `dist/`. No backend, no server code, no external APIs.
- Setup:
  - Use Vite 5 with React 18 and TypeScript. Set base: './' in vite.config.ts, set build.sourcemap to false, and emit only the production site to dist/.
  - Configure Tailwind CSS 3.4 with the colors, font families, spacing, radii, shadows, and keyframes below. Put custom keyframes, focus styles, print styles, and reduced-motion overrides in src/index.css.
  - Keep all editable brand copy, quiz topic copy, eight questions, answer choices, four archetypes, FAQs, and report sections in src/content.ts with TypeScript interfaces. Components must read content from that file rather than embedding default-specific strings.
  - When variable values change, rewrite every topic-specific headline, question, answer, archetype name, description, recommendation, FAQ answer, and report item to fit the new [QUIZ_TOPIC], [AUDIENCE], and [REPORT_NAME], while preserving the layout and interaction model.
  - Use one React state machine with the states landing, quiz, calculating, and result. Do not add a router. Keep current question, eight answers, unlocked state, and email input in memory only; do not use localStorage, sessionStorage, cookies, or URL query parameters.
  - Use lucide-react for interface icons and original inline SVG or CSS for decorative artwork. Do not add an animation library; use CSS transitions, keyframes, and a small IntersectionObserver for landing-section reveals.
  - Import Fraunces Variable and DM Sans Variable locally from their Fontsource packages. Create ASSETS.md at the project root listing both font packages, lucide-react, their sources, and their licenses; state that all illustrations are original code-drawn SVG/CSS and that no raster images are used.
  - Support keyboard operation, visible focus, semantic buttons and headings, aria-live progress and result announcements, 44px minimum touch targets, and a reduced-motion mode. Verify 1440×900 and 390×844 with no horizontal overflow or console errors.

## Variables
- [BRAND] — Brand name (default: "Moss & Meter"). An invented studio, creator, or publication name used in the wordmark, footer, and report.
- [QUIZ_TOPIC] — Quiz topic (default: "Creative Work Rhythm"). The reflective subject of the quiz; all questions and results must follow it.
- [AUDIENCE] — Audience (default: "independent creatives"). A concise lowercase audience description used in introductory and result copy.
- [REPORT_NAME] — Full report name (default: "Creative Rhythm Field Guide"). The personalized resource unlocked after the email form.
- [PRIMARY_CTA] — Primary quiz CTA (default: "Find my rhythm"). A short action label for hero and closing quiz-start buttons.
- [CREDIT] — keep a small "Template by VibeFather" link to https://vibefather.ai/t/personality-quiz-funnel-page in the footer (default: yes; delete this line to remove it)

The copy under Pages & Sections is written for the default values. If your values differ, rewrite every headline, paragraph, label and image for them — same length, tone and structure. Layout, colors, type and motion stay as described.
Keep all copy, image paths and links in one content file (for example `src/content.ts`), keyed by section, so the content can be swapped later without touching components.

- Teal `#70B8A7` — Pathfinder accents and secondary illustrations
- Muted Ink `#62665E` — Secondary copy and metadata

### Typography
- Display headlines and result archetype names: Fraunces Variable, self-hosted with @fontsource-variable/fraunces; optical sizing enabled (OFL), weights 600/700
- Body, navigation, buttons, form labels, and small metadata: DM Sans Variable, self-hosted with @fontsource-variable/dm-sans (OFL), weights 400/500/600/700

### Layout & motion
- Spacing: Use an 8px base grid. Landing sections have 104px desktop and 72px mobile vertical padding. Content max-width is 1240px with 40px desktop and 20px mobile gutters. Hero copy max-width is 610px. Card padding is 28–36px desktop and 20–24px mobile; button gaps are 12px.
- Radius: Use 24px for major cards and the quiz stage, 16px for answer cards and inputs, 999px for buttons and small tags. Major cards have a 2px Ink border and a 6px 6px 0 #20231F offset shadow; hover lifts reduce that shadow to 3px 3px 0.
- Motion: Landing sections reveal with opacity 0 to 1 and translateY(18px) to 0 over 500ms using ease-out, staggered by 70ms within a grid; never hide content when IntersectionObserver is unavailable.
- Motion: Primary buttons and answer cards translate 2px upward on hover and return on press over 160ms. Selected answers fill with Lime and show a check icon before advancing.
- Motion: Starting the quiz crossfades and slides the landing view out and quiz view in over 280ms. Each answer advances after a 240ms selected state; question content exits 8px left and enters 8px right.
- Motion: The progress bar and active segment animate width or color over 240ms. The calculating interlude lasts 1100ms and cycles three status phrases; result content follows with a 420ms fade and 14px rise.
- Motion: Decorative hero shapes float no more than 8px over six seconds and an orbit label rotates slowly over 24 seconds; disable both under prefers-reduced-motion.
- Motion: Under prefers-reduced-motion, remove reveals, floating, rotation, smooth scrolling, and slide transforms; use immediate state changes or opacity-only transitions under 80ms.
- Imagery: Use no photographs, AI-generated portraits, external illustrations, or raster placeholders. The hero's visual anchor is a rich, layered quiz UI mock with original CSS/SVG geometric artwork, answer cards, progress, a paper-grid backdrop, and offset color shapes. Give each archetype a reusable original SVG emblem: radiating strokes for Spark, a precise modular grid for Anchor, interlocking loops for Weaver, and a winding contour path for Pathfinder. Keep all geometry abstract and generic.
