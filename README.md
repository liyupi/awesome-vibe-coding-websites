1. **Copy a prompt.** Open any template folder, copy `prompt.md`, replace the `[VARIABLES]` with your own brand, copy and colors, and paste it into Claude Code, Codex, Cursor, Windsurf, Gemini CLI or another coding agent.
2. **Or pull it from your terminal:**
   ```bash
   npx vibefather add <slug>        # writes prompt.md and DESIGN.md into ./vibefather/<slug>/
   ```
3. **Or give your agent the Skill**, so it can search and build templates by itself:
   ```bash
   npx skills add liyupi/awesome-vibe-coding-websites
   ```
4. **Or connect the MCP server** `https://mcp.vibefather.ai` (tools: `search_templates`, `get_prompt`, `get_design_md`).

Every `prompt.md` has the same shape — **Brief → Stack → Variables → Design → Pages & sections → Assets → Don'ts** — so your agent knows exactly what to change and what to keep.
